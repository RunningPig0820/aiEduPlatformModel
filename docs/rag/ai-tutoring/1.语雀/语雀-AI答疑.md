# 一、业务目标

本模块作为智启学坊AI教育平台的核心前端交互模块，核心业务目标围绕"教育属性优先、低成本落地、用户体验适配"三大核心展开：

+ **核心目标**：面向小学至高中全学段学生，提供轻量化、引导式数学答疑服务，践行可汗学院启发式教育理念，拒绝直接投喂答案，引导学生规范提问、培养逻辑思维与提问能力，实现"教学相长"的教育核心。
+ **成本目标**：适配个人项目资源限制，采用免费小模型、轻量存储方案，控制开发、部署及运维成本，支持多套部署与多并发，无需复杂技术架构与高额投入。
+ **用户目标**：适配学生非书面化、模糊化的真实提问习惯，降低使用门槛，同时为家长提供精准学情分析，满足"学生答疑+家长监控"的双重需求。
+ **迭代目标**：留存对话及答疑数据，为模型优化、引导策略调整、知识图谱完善提供数据支撑，实现"答疑-分析-迭代"的闭环。

# 二、关联模块

AI答疑模块作为项目核心交互入口，与知识图谱、家长端报表模块深度联动，同时适配小模型部署架构，形成完整的业务闭环：

+ **与知识图谱模块（核心关联）**：知识图谱是AI答疑模块的底层数据底座，二者形成双向联动。一方面，AI答疑模块通过调用知识图谱的结构化知识点，实现精准答疑、知识点溯源及举一反三；另一方面，AI答疑过程中产生的对话数据、学生薄弱点数据反向回流至知识图谱，完善知识点标签与知识关联逻辑，优化后续答疑精准度。

> ⚠️ **最新逻辑（2026-08 代码）**：答疑链路**不直接调用图谱结构化知识点**——掌握度按**题型**落库（label→canonical 聚集 → ScoreMapper），图谱点亮/知识点解析由 `kp-matching-lightup` 变更独立承担；「举一反三」🚫 阶段2（无题库）。对话数据回流 → 部分落地（题型掌握度/题目表/错误事件，供学情与图谱观测消费）。
+ **与家长端报表模块**：AI答疑模块存储的对话数据、学情分析结果（如学生提问频次、薄弱知识点、提问能力成长轨迹），为家长端报表提供核心原始数据，支撑家长实时了解学生学习情况，实现"答疑-分析-反馈"的教育闭环。

> 🚫 **最新逻辑（2026-08 代码）**：家长端报表/学情分析为**阶段3规划，未落地**；当前仅落库题型掌握度 + 题目记录 + 错误事件（数据面已提供，如 `POST /students/{id}/mastery/query` 分页掌握度查询）。
+ **与小模型部署架构**：AI答疑模块依托轻量小模型实现答疑逻辑处理与提问引导，适配小模型多套部署、多并发的特点，确保多名学生同时提问时的响应效率，降低部署成本。

# 三、方案设计

本方案以"轻量化、低成本、教育化"为核心，结合行业标杆理念，联动关联模块：

## 1. 核心理念参考

+ **可汗学院**：借鉴其启发式答疑理念，采用分步引导模式，不直接给出答案，通过提问引导学生自主思考，培养逻辑思维，同时坚持轻量化、普惠免费的模式，匹配项目低成本定位。
+ **科大讯飞**：参考其虚拟人教学模式，采用口语化、情感化交互设计，适配学生自然提问习惯，降低使用门槛，强化引导的亲和力，避免生硬的标准化要求。
+ **猿辅导**：借鉴其举一反三教学法，依托知识图谱的知识点关联逻辑，在答疑过程中推送同类变式习题，帮助学生通过一道题掌握一类题，强化知识体系构建。
+ **好未来（学而思）**：参考其依托九章大模型实现的"答疑-错题溯源-个性化引导"闭环，简化复杂功能，适配轻量小模型，实现基础的错题溯源与个性化提问引导。

## 2. 对话存储设计

### （1）存储必要性

+ **上下文交互支撑**：留存历史对话，解决学生模糊提问问题，为引导式提问提供基础，提升答疑精准度。
+ **学情数据来源**：存储学生提问内容、提问频次、薄弱知识点等数据，为AI分析与家长端报表提供唯一原始数据。
+ **用户体验优化**：支持学生回溯历史答疑记录，巩固学习成果，提升产品粘性。
+ **产品迭代支撑**：为小模型优化、引导策略调整、知识图谱完善提供数据依据，实现闭环迭代。
+ **教育属性落地**：记录学生提问能力的成长过程，契合"教学相长"的核心目标，区别于单纯的答疑工具。

### （2）技术选型：MongoDB 文档型数据库

选用MongoDB作为对话存储方案，核心适配对话数据的非结构化、半结构化特点，同时贴合个人项目轻量、低成本的定位：

> ⚠️ **最新逻辑（2026-08 代码）**：存储方案**已不用 MongoDB**——最终为三层：**Redis**（活跃会话/消息，TTL 24h）+ **MySQL**（`t_tutoring_session`/`t_student_topic_mastery`/`t_student_question_record`/`t_tutoring_error_event`）+ **COS**（transcript 每轮实时整写，恒完整对话）。"轻量低成本"定位不变，选型改为免运维三层。

+ **存储内容**：学生对话记录、提问内容、答疑结果、知识点关联标签、学生ID、时间戳等。
+ **部署方式**：轻量单机部署，无需复杂集群，支持多套部署，适配小模型多并发需求。
+ **核心优势**：开箱即用、零运维成本、支持非结构化数据存储，兼顾存储与基础检索，开发难度低，适配个人项目技术能力。

## 3. AI答疑交互设计

+ **提问引导策略**：无上下文时，给出具体提问示例（贴合学生口语化习惯）；有上下文时，结合历史对话温和引导，不强制标准化提问，降低使用门槛。
+ **答疑逻辑**：依托知识图谱结构化知识点，结合轻量小模型，实现分步引导答疑，借鉴可汗学院理念，避免直接给出答案。
+ **举一反三实现**：基于知识图谱的知识点关联，在答疑后推送同类变式习题，参考猿辅导教学法，强化学生知识掌握。

> 🚫 **最新逻辑（2026-08 代码）**：举一反三（变式题推送）**未落地**——依赖题库 + 图谱知识点关联（阶段2），MVP 无题库是设计。
+ **交互风格**：参考科大讯飞虚拟人教学的亲和力，采用口语化、简洁化表述，适配小学至高中不同学段学生的认知特点。

## 4. AI智能分析设计

结合知识图谱与对话存储数据，实现轻量级AI智能分析，为家长端报表提供支撑：

+ **分析内容**：学生薄弱知识点识别、提问频次统计、提问能力成长轨迹、知识点掌握程度评估。
+ **分析逻辑**：依托小模型，结合知识图谱的知识点标签，挖掘对话数据中的核心信息，主动诊断学生学习问题。
+ **输出形式**：结构化分析结果，同步至家长端报表，直观展示学生学习情况，同时生成简单的学习建议。

# 四、方案对比

本模块方案聚焦个人项目"低成本、轻量落地"定位，针对核心技术选型及分析模式，与同类方案进行对比：

## 1. 存储方案对比（MongoDB vs ES vs HDFS）

| 对比维度 | 本项目方案（MongoDB） | Elasticsearch（ES） | HDFS 大数据方案 |
|---------|----------------------|--------------------|----------------|
| 核心能力 | 非结构化/半结构化数据存储，兼顾基础检索 | 专业全文检索，检索效率高，存储能力较弱 | 企业级海量数据分布式存储与处理 |
| 部署复杂度 | 轻量单机部署，开箱即用，零运维成本 | 部署复杂，需配置集群，资源占用大 | 部署、运维难度极高，需专业技术团队 |
| 成本投入 | 免费使用，无额外硬件/人力成本，适配个人项目 | 开源但部署成本高，存在功能冗余 | 硬件、人力成本极高，个人项目无法承担 |
| 适配性 | 完美适配对话数据存储，支持多并发，贴合项目需求 | 检索能力冗余，存储功能不足，不适配存储核心需求 | 量级过高，完全不符合个人项目的轻量化定位 |

## 2. 分析方案对比（AI智能分析 vs 传统BI报表）

| 对比维度 | 传统BI报表 | 本项目AI智能分析 |
|---------|-----------|----------------|
| 数据类型 | 仅处理结构化数据（如答题数、正确率） | 处理非结构化对话数据+结构化知识点数据 |
| 分析逻辑 | 固定模板、被动统计，无自主挖掘能力 | 结合知识图谱主动挖掘，诊断薄弱点、分析问题原因 |
| 核心价值 | 展示结果数据，无针对性建议 | 挖掘问题+生成学习建议，贴合教育场景需求 |
| 技术成本 | 依赖大数据架构，部署、开发成本高 | 轻量架构，结合小模型实现，零额外成本 |
| 与知识图谱关联 | 无任何关联，仅单纯统计数据 | 深度联动，实现知识体系与学习行为一体化分析 |
| 场景适配 | 企业运营、数据统计，不适配教育个性化需求 | 教育场景个性化学情分析，适配家长与学生核心需求 |

# 五、竞品分析

本次竞品分析聚焦教育行业头部产品的AI答疑相关功能，选取好未来（学而思）、科大讯飞、猿辅导、国家教育平台四大主体：

## 1. 竞品核心特点（AI答疑相关）

+ **好未来（学而思）**：依托自研九章大模型，AI答疑覆盖小学至高中全学段数学，支持分步讲解、错题溯源、个性化学习路径规划，联动硬件设备实现多模态交互。不足：技术成本高，核心功能需付费解锁，部署复杂，不适合个人项目；提问引导偏向标准化，部分场景强制学生规范提问，使用门槛较高。
+ **科大讯飞**：基于星火大模型V4.0，AI答疑采用虚拟人交互模式，口语化、情感化引导，支持图文识别、画图讲解。不足：核心依赖自研大模型，研发投入高，部分功能需绑定硬件，对学生提问能力培养不足，未深度联动家长端学情分析。
+ **猿辅导**：AI答疑聚焦"举一反三"，依托海量题库与知识点关联，答疑后推送同类变式习题。不足：知识库聚焦中高考，低学段覆盖不足，答疑引导较生硬，未践行启发式教育理念，部分功能需付费。
+ **国家教育平台**：官方公益类产品，AI答疑完全免费，接入DeepSeek等大模型，24小时在线，采用引导式解题，不直接给出答案。不足：无针对性提问引导，对模糊提问响应不灵活，知识点碎片化，无法联动家长端，功能固化，灵活性不足。

## 2. 本项目差异化优势

+ **成本优势**：免费小模型 + MongoDB轻量存储 + 开源知识库，成本远低于竞品，部署灵活、运维成本为零。
+ **教育属性优势**：深度践行可汗学院启发式理念，结合猿辅导举一反三、科大讯飞亲和力交互，既引导规范提问、培养逻辑思维，又不强制标准化提问，弥补竞品在提问能力培养上的不足。
+ **联动优势**：AI答疑与知识图谱、家长端报表深度闭环，既保障答疑精准度，又为家长提供个性化学情分析。
+ **灵活性优势**：轻量架构，预留扩展空间，可根据需求灵活调整引导策略、扩展知识库。

## 3. 竞品规避点

避免陷入好未来、科大讯飞"追求技术复杂、依赖付费模型与硬件"的误区；规避猿辅导"重习题推送、轻提问引导"的问题，坚守启发式教育本质；避开国家教育平台"功能固化、灵活性不足"的短板，兼顾轻量化与个性化，聚焦"低成本、易落地、有教育特色"的核心定位。
