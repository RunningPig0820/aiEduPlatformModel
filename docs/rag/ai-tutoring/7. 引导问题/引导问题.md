# AI答疑 — 面试问题整理

> 模块定位：苏格拉底式分步引导答疑，question_understand → decide → generate 三段链路，防作弊 + 图谱点亮 + 掌握度更新。
> 所属大纲段：1 项目介绍 / 2 项目如何操作 / 4 数据关联 / 5 难点

## 1. 项目介绍

| 引导（扬长） | 亮点 | 预期追问 |
|-------------|------|---------|
| AI答疑在项目里做什么？ | 苏格拉底式引导，不给答案、带着学生自己推出来 | "为什么不给答案？" → 防抄答案，价值在引导 |

**可能（防御）**

| 可能问题 | 防御要点 |
|---------|---------|
| 这和普通聊天机器人有什么区别？ | 三级意图分类 + 引导式教学 + 防作弊 + 图谱点亮 |

## 2. 项目如何操作

| 引导（扬长） | 亮点 | 预期追问 |
|-------------|------|---------|
| 一次完整答疑怎么走？ | 意图分类 → 题型识别 → 题库匹配 → 分步引导 → 答案校验 → 图谱点亮 | "没命中题库呢？" → 通用引导 + 标记待入库 |
| 图片题怎么处理？ | OCR + 视觉模型理解题意（question_understand） | "速度怎么保证？" → 关思考 + 流式，实测 1.2s |
| 怎么防学生套答案？ | 行为风控（高频/无思考）+ 题目指纹去重 | "触发了怎么办？" → 要求先作答再继续 |

## 4. 数据如何关联

| 引导（扬长） | 亮点 | 预期追问 |
|-------------|------|---------|
| 答疑和知识图谱怎么联动？ | AI预判知识点 + 学生确认 → 条件点亮 → 更新掌握度 | "为什么要点亮？" → 学习进度可视化 |

**可能（防御）**

| 可能问题 | 防御要点 |
|---------|---------|
| 知识点会不会选错？ | AI 预判 + 学生确认双保险，不空点不误点 |

## 5. 项目开发中有什么难点

| 引导（扬长） | 亮点 | 预期追问 |
|-------------|------|---------|
| 为什么拆 question_understand / decide / generate？ | 每子任务独立可控、可单测、可换模型 | "怎么保证各段正确？" → 各段独立测试 + decide 低温度 |
| 怎么防模型乱给答案/幻觉？ | 分步引导 prompt + 答案校验反问（"这一步依据是什么？"） | "学生说对了但实际错了？" → 易错分支追问 |
| 流式思考怎么提速？ | decide/generate 关思考，实测 1.2s；图片分析 20s 超时兜底 | "开了思考多慢？" → 50~145s，卡顿根源 |

**可能（防御）**

| 可能问题 | 防御要点 |
|---------|---------|
| 生成质量/正确率怎么保证？ | decide 低温度 + 题库预置步骤校验 |
| 延迟多少？体验会卡吗？ | 流式 + 思考开关实测数据 |

## ⚠️ 最危险的可能问题（防御）

| 可能问题 | 防御要点 |
|---------|---------|
| 学生没问"这题怎么做"而是其他怎么办？ | 三级意图分类：学科/学习指导/无关，分别处理 |
| 模型答错了怎么办？ | 不直接判对错，反问依据；题库命中时按预置步骤校验 |
| 没有题库怎么做？ | 通用引导兜底 + 题目标记"待入库"给教研 |
