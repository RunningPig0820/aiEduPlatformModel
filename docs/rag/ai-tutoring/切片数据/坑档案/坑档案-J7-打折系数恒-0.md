### J7. 打折系数恒 0
**1. 问题现象**：per-题型打折系数恒 0，score 全归零——掌握度全部记 0。

**2. 触发流程**：`persistQuestionAttempt` → `ScoreMapper.effectiveScore(last.isCorrect(), last.isHinted(), trainCount, signalDiscountFirst, signalDiscountSecond, signalDiscountRest)`（`TutoringAppService.java:802-803`）。

**3. 根因分析**：`@Value` 字段**无默认值**：`@Value("${ai-edu.tutoring.signal.discount-first}")`，配置缺失时注入 0.0 → `discountFactor` 返回 0 → score 全部 0。

**4. 排查过程**：从"掌握度全 0"反推 → 查 effectiveScore 的 discountFactor 分支 → 发现 @Value 注入值全 0 → 确认配置键未配置且无默认值兜底。

**5. 解决方案 & 改动点**（`TutoringAppService.java:145-150`）：补默认值 `:0.7` / `:0.8` / `:1.0`（首题/次题/后续折扣）。

**6. 面试口述要点**：讲"**配置字段缺默认值的静默坑**"——@Value 注入 0 不报错，业务悄悄全错。踩坑收获：**可空配置必须给默认值 + 兜底断言**；数值型配置尤其危险（0 是合法值，错误不显眼）。
