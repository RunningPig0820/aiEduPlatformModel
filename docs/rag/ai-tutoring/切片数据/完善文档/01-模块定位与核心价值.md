AI 答疑是学生端的核心交互模块，面向小学至高中全学段。核心教育理念是**启发式教学（可汗学院式）**：**拒绝直接投喂答案**，通过分步引导让学生自己把题推出来，培养提问能力和逻辑思维。区别于普通聊天机器人的关键：答疑带**教育目标**——不是"给答案"，而是"教你怎么想到答案"。


方案的核心是一个"**能力受限的 agent + 工具护栏**"架构：不把答疑做成自由聊天，而是规定 agent 只能输出**动作闭集**（引导 hint / 思路 approach / 答案 reveal / 概念 concept / 换题 switch / 收尾 end），由 Java 侧确定性护栏决定哪些动作放行。这样既保留对话的自然性，又守住"不给答案"的教育底线。


- **苏格拉底引导是硬约束**：decide 两分法——学生在答题（对/错/跑偏）一律给引导（hint/approach），绝不直接 end 或 reveal；只有明确表达结束才收尾。
- **判对不是关键词匹配**：decide 的 LLM 对"学生上一轮回答"做正确性评估（`eval.correct`），输出"是否在答题"的两分判定，配合 `end` 联动护栏（答错绝不能收到"恭喜"收尾）。
- **防作弊落地为确定性护栏**：答案要 2 次（第 1 次给思路、第 2 次才给答案）、会话 20 轮上限、安全内容直接终止——全部是 Java 代码规则，不依赖 LLM。
- **知识点确认不是模型说了算**：decide 预判题型/知识点 → 低置信走澄清卡（学生选/跳过）→ 双保险后条件点亮。

**演进故事**：早期方案曾设计"三级意图分类（学术/引导/无关）""知识点按 URI 单调不减掌握度"，这些在落地中演进为"动作闭集两分法""题型累计平均掌握度"（见 05）。


**预期追问：和普通聊天机器人有什么区别？**
→ **回答要点**：① 不带教育目标——不是"给答案"而是"教你怎么想到答案"（苏格拉底引导）；② 防作弊确定性护栏（答案 2 次/20 轮/安全终止）；③ 掌握度落库联动题型掌握页。

**预期追问：意图分类是什么样？**
→ **回答要点**：早期方案"三级意图分类（学术/引导/无关）"已演进——现在 decide **两分法**：判断"是否在答题"（在→hint/approach 引导，不在→concept 拉回），输出 `type` 闭集 6 值。Java 实体 `intent_category` 字段保留但实际不赋值（三级意图废弃未启用）。
