## 回答

**核心结论**：AI 答疑是学生端的核心交互模块——输入一道题，系统不直接给答案，而是用苏格拉底式分步引导带学生自己把题推出来，同时完成答案校验、知识点定位、掌握度落库，形成"答疑-分析-迭代"的闭环。

**分层展开**：
- **业务定位**：面向小学到高中全学段学生，拍题/打字/粘贴都能进，入口低门槛口语化——学生用"这题怎么做""我不会"这种模糊口语也能进答疑。
- **核心链路**：题目进来 → 学科门（subject-classify）→ 建会话 → decide 判下一步动作（hint/approach/reveal/concept/switch/end 闭集）→ Java 护栏审批 → generate 流式生成引导正文 → SSE 流回前端。
- **教育理念**：启发式教学（可汗学院式）——拒绝投喂答案，带学生自己推出来，培养提问能力和逻辑思维。教育目标是"教你怎么想到答案"，不是"给你答案"。
- **数据落库**：掌握度（题型口径累计平均）、题目记录、错误事件、transcript（COS），并联动知识图谱条件点亮，支撑学情分析、家长监控、训练数据闭环。
- **一句话总结**：它不是"答案机器"，而是一个带教育目标、防作弊护栏和数据闭环的引导式答疑 agent。
