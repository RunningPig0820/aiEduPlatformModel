## 回答

**核心结论**：靠确定性护栏，不靠 LLM 自觉——教育底线不能交给模型自主判断。

**分层展开**：
- **答案护栏（防直接要答案）**：学生要答案 decide 判 reveal → Java 看 answer_request_count：第 1 次拦下降级 approach 给思路（计数→1），第 2 次才放行完整答案并**立即收尾** ANSWER_REVEALED（防反复要）；被拒后仍 reveal → Java 直接降级固定思路话术（不依赖 LLM）；前端第 2 次点击弹确认框（单向门）。
- **轮次护栏（防无限刷）**：round_count ≥ 20 且本轮是引导类 → 强制收尾 ROUND_LIMIT，固定话术无 generate；只有 hint/approach 消耗轮次（concept/switch/end/reveal 不消耗）。
- **安全护栏（防高危内容）**：decide 输出 safety_flag=true → 终止会话 TERMINATED，无 token 流，回复在 meta.reply。
- **判对防作弊延伸**：end 联动护栏——答错绝不"恭喜"（COMPLETED 必须 correct && exercise_complete）。
- **诚实边界**：行为风控（高频/无思考）、题目指纹去重是阶段 3 规划，当前未落地；防套答案完全靠确定性规则。
