## 回答

**核心结论**：AI 预判 + 学生确认双保险 → 条件点亮 → 更新掌握度，答疑链路本身不直接写 Neo4j。

**分层展开**：
- **联动链路**：decide 输出题型/知识点 label → 低置信走澄清卡 resolveKp（PENDING + candidates）→ 学生选/跳过 voteKp → 观测落库 → kp-matching-lightup 条件点亮。
- **为什么要点亮**：学习进度可视化——学生/家长能看到哪些知识点已掌握；同时掌握度（题型口径）回流 decide 作快照上下文，形成闭环。
- **边界划分**：点亮由独立变更（kp-matching-lightup）承担，答疑链路不直接写 Neo4j，职责清晰、可独立回滚。
- **追问点**："如果学生跳过了呢？" → 不点亮、保持 PENDING，数据不丢，后续可再确认；模型预判只是候选，学生有最终确认权。
