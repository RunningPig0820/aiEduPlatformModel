## 回答

**核心结论**：不会误点——AI 预判只给候选，最终确认权在学生，不空点不误点。

**分层展开**：
- **双保险闭环**：decide 预判 label → 低置信走 resolveKp（PENDING + candidates 澄清卡）→ 学生选/跳过 voteKp → 观测落库 → kp-matching-lightup 条件点亮。
- **为什么是双保险**：单靠模型预判可能误点（空点/错点）；单靠学生自选没有候选。模型给候选、学生确认，两边互补。
- **落库不裂行**：题型侧用向量最近邻聚集 canonical（"鸡兔同笼"与"鸡兔同笼问题"归一到同一题型），保证口径稳定。
- **追问点**："模型预判置信度怎么定的？" → 低置信才走澄清卡，高置信直接点亮；学生跳过 = 不点亮，不阻塞答疑主线。
