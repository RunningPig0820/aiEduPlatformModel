## 回答

**核心结论**：动作闭集 + 分步引导 prompt + Java 放行权，三层防幻觉防乱给。

**分层展开**：
- **动作闭集 + 两分法**：decide 只输出六值闭集，且在答题的内容（对/错/偏/求助）一律 hint/approach，绝不 reveal/end——答错 ≠ 要答案，从源头掐断"乱给答案"。
- **reveal 是软意图，放行权在 Java**：模型输出 reveal 只是建议，Java 看 answer_request_count（2 次）才放行，reveal 未授权时正文一个字不会吐出去。
- **分步引导 prompt**：hint 只给一条反问（"这一步依据是什么？"），approach 只给思路大纲不给最终数值；GENERATION_RULES 按动作类型硬约束正文形态。
- **判对防幻觉**：判对前代入验算（数值代回题目算一遍），不凭直觉/语气；"学生说对了但实际错了"走确认复核——核对之前答案，错了明确告知"答案不对"。
- **兜底**：结构化输出四段降级（function calling→JSON→正则→type=hint）+ end 联动护栏，杜绝"答错被恭喜/泄完整解答"。
