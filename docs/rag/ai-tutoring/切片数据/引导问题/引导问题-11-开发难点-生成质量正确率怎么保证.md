## 回答

**核心结论**：decide 低温度 + 结构化输出四段降级 + 判对验算 + 分类型生成规约，四道闸保证质量。

**分层展开**：
- **decide 低温度（0.3）**：决策密集，低温度减少随机发散，输出稳定。
- **结构化输出四段降级**：bind_tools(function calling) → JSON mode → 正则提取 + Pydantic → 兜底 type=hint+degraded；段内 schema 纠错重试（只修 JSON 不整段重生成），绝不吐畸形、绝不抛异常。
- **判对验算**：判对前把数值代回题目算一遍（reason 写验算过程），不凭直觉/语气；疑问/不确定语气也算作答，按数值判。
- **end 联动护栏**：COMPLETED 必须 correct && exercise_complete，否则降级 concept，杜绝"答错被恭喜"。
- **generate 分类型规约（GENERATION_RULES）**：hint 零步骤零答案、approach 不给最终数值、reveal 才给完整解答——正文形态由动作类型决定，防止越权泄答案。
- **空流兜底**：generate 零 token → 固定引导话术，学生不收到空回复；各段独立单测覆盖。
