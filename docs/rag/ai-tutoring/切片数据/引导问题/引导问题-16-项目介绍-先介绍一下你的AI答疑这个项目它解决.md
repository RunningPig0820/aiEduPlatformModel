## 回答

**核心结论**：AI 答疑解决的是"搜题软件直接投喂答案、学生抄答案不思考"的痛点，面向小学到高中全学段学生，用苏格拉底式分步引导带学生自己推题。

**分层展开**：
- **业务痛点**：① 学生端——传统搜题给完整答案，学生只记结果不训练，思维能力退化；② 家长/老师端——看不到学习过程，无法掌握孩子真实掌握情况；③ 数据端——没有沉淀，无法做学情分析和个性化。
- **用户**：小学到高中全学段学生；入口低门槛（拍题/打字/粘贴），用模糊口语也能进。
- **方案**：输入题目 → 学科门 → 建会话 → decide 判动作 → Java 护栏 → generate 引导 → 落库掌握度/题目记录/错误事件 → 图谱点亮。
- **闭环价值**：每次答疑既解决当下问题，又沉淀数据；掌握度回流 decide 决策，题型掌握页给学生/家长看进度，transcript 沉淀训练数据——形成"答疑-分析-迭代"闭环。
- **一句话**：教育领域"启发式教学"的工程化落地，不是答案机器，是引导式教学 agent。
