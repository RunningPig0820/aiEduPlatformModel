## 回答

**核心结论**：本质区别在三个维度——教育目标、动作约束、数据闭环；底层都是 LLM，差别在产品化的约束层。

**对照**：
- **普通聊天机器人**：有求必应、直接给答案；没有教育目标；动作不受限；无状态、无数据沉淀。
- **AI 答疑**：
  - ① 教育目标——不是给答案，是教你想答案（苏格拉底式）；答对才收尾、答错继续引导，教育底线用确定性护栏守（答案 2 次/20 轮/安全终止）。
  - ② 动作受限——agent 只能输出动作闭集六值（hint/approach/reveal/concept/switch/end），"能力受限的 agent + 工具护栏"架构，决策权在 Java 确定性规则。
  - ③ 数据闭环——掌握度落库（题型口径）、题型掌握页、知识图谱条件点亮、transcript 训练数据。
- **追问点**："三级意图分类是什么？" → 早期方案已演进为两分法（是否在答题），更简单更稳；intent_category 字段保留但实际不赋值。
