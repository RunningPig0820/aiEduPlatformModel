## 回答

**核心结论**：答疑不是一次性交互，而是"答疑-分析-迭代"闭环的数据起点——落库的数据支撑学情、家长、图谱、训练四层闭环。

**分层展开**：
- **5 类落库数据**：① 掌握度 t_student_topic_mastery（题型口径累计平均）；② 题目记录 t_student_question_record（一道题一条，事实源）；③ 错误事件 t_tutoring_error_event（真实错误门控）；④ 题型↔知识点关联；⑤ transcript（COS 每轮整写）。
- **支撑面**：掌握度 → 题型掌握页（分页/分桶/查看原题跳回会话）；题目记录 → 跨模块回溯 + 题型/知识点/图谱关联；错误事件 → 学情分析（未来错题溯源）；transcript → 历史回看 + 训练数据闭环。
- **回流**：掌握度快照回流 decide（snapshot_top_n 薄弱优先），让引导更贴合学生当前水平。
- **追问点**："家长端报表做了吗？" → 家长端报表/多维画像未落地（阶段 3 规划），当前只提供数据面（掌握度/题目/错误事件可查询）。
