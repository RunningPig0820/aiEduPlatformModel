## 回答

**核心结论**：差别在消息通道、换题感知和题型识别三个点，其余链路完全一致。

**对照**：
- **文字题**：题目文本作为 user 消息进 history，decide/generate 用纯文本 HumanMessage。
- **图片题**：图片直传 COS → URL 作 image_url 进 history → decide/generate 用多模态 HumanMessage（text+image_url），doubao 直接看图解题、判对；prompts 渲染时带图的消息显示 [图片题目] 占位。
- **换题感知**：图片题靠 Java 检测新图 URL 首次出现 → is_new_question=true → Python 短路 switch；文字题同理检测新题文本首次出现。
- **题型识别**：图片题走独立端点 question_understand 看图识别 1~5 个题型名（题型分析页）；文字题由 decide 读题顺带产出 question_kps。
- **为什么双通道**：数学题大量含公式 + 图形，传统 OCR 拆解丢信息；主通道直接看图最稳，OCR 只是截屏/公式/手写题的兜底，且要学生确认。
