## 回答

**核心结论**：感知在 Java、短路在 Python——Java 检测到新题信号，Python 直接返回 switch 不调 LLM。

**分层展开**：
- **Java 检测**：新图 URL 或新题文本首次出现在 history → 本轮置 is_new_question=true（Java 知道何时收到新图，这是它的信息优势）。
- **Python 短路**：decide 看到 is_new_question=true → 直接返回 type=switch（new_question 填新题文本），不调 LLM——100% 准、省一次模型调用和时间。
- **Java 重置**：换题后重置 answer_request_count/轮次计数，新题从零开始。
- **为什么判定放 Java**：Python 无状态，区分不了"本轮刚换 vs 早几轮已换"；只有 Java 知道图片/新题何时进来。如果放 Python 从 history 推断，做不准还容易误判。
- **追问点**："换题会不会被模型带偏？" → 换题是确定性短路，不依赖模型判断；decide 提示词同时约束"历史旧题只作参考，不能按旧题决策"。
