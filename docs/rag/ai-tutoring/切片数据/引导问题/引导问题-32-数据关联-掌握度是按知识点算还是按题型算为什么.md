## 回答

**核心结论**：落地是题型口径（t_student_topic_mastery），不是知识点——这是产品/题目分析口径的权衡，不是技术必然。

**分层展开**：
- **为什么选题型**：题目天然可聚到题型——canonical 向量聚类稳定、可打分、可观测、落库不裂行（"鸡兔同笼"不会裂成多个名字）；而知识点映射依赖图谱（label→URI 解析易错、需 ADMIN 维护），数据链路更长。
- **计算口径**：一道题 → decide 判 eval.correct + 是否被引导（hinted=answerRequestCount>0）→ onRoundSignal 累计 → 结算：题型名聚集 canonical → ScoreMapper：直接答对 1.0 / 引导后答对 0.5 / 答错 0.0，× 第 1 题 0.7 / 第 2 题 0.8 / 第 3 题起 1.0（打折鼓励多练同一题型）→ 累计平均（不是 max 单调不减，答错会降、反映真实水平）。
- **不是技术必然**：若题目分析直接产出知识点，掌握度按知识点也成立——是数据口径选择。
- **追问点**："为什么不用单调不减？" → max 单调不减答错永不降、会虚高；累计平均反映真实水平，打折防"第 1 题答错→题型 0%"假低。
