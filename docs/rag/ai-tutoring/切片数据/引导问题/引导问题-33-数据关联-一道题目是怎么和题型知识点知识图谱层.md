## 回答

**核心结论**：题目是连接题型、知识点、图谱的中间环节——题目记录 → 题型 canonical → 知识点 → 图谱点亮。

**分层展开**：
- **链路**：题目落库（t_student_question_record，事实源）→ decide 输出题型名 topic_label → 向量最近邻聚集 canonical（题型库 t_question_type，ADMIN 维护）→ 知识点关联（教材知识点 KgKnowledgePointPo）→ 图谱条件点亮（kp-matching-lightup）。
- **掌握度**：按题型累计平均（t_student_topic_mastery），题目记录是它的原始事实来源。
- **边界**：题型↔知识点的映射由后端维护接口承担（ADMIN 维护），答疑链路不直接写 Neo4j——点亮由独立变更承担，职责清晰、可独立回滚。
- **为什么题目是中间环节**：题目天然落到题型，题型再映射知识点，比题目直接映射知识点更稳（题型 canonical 稳定、知识点需维护）。
- **追问点**："答疑不直接写图谱，那点亮谁做？" → kp-matching-lightup 独立变更，答疑只产出 label，点亮是订阅式协作。
