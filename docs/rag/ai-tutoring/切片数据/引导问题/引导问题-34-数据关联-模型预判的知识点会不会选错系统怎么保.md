# 模型预判的知识点会不会选错？系统怎么保证不误点不空点？

> summary: 双保险闭环——AI 只给候选，最终确认权在学生，不空点不误点。
> 权威度: 1.0 ｜ 来源: 引导问题 ｜ 锚点: 模型预判的知识点会不会选错？系统怎么保证不误点不空点？
> 模块: ai-tutoring ｜ 节: 数据关联
> 类别：数据关联

## 回答

**核心结论**：双保险闭环——AI 只给候选，最终确认权在学生，不空点不误点。

**分层展开**：
- **闭环**：decide 预判 label → 低置信走 resolveKp（PENDING + candidates 澄清卡）→ 学生选/跳过 voteKp → 观测落库 → kp-matching-lightup 条件点亮。
- **为什么是双保险**：单靠模型预判可能误点（空点/错点，教育数据污染）；单靠学生自选没有候选无从选起。模型给候选、学生确认，两边互补。
- **低置信才走澄清卡**：高置信预判直接点亮，低置信才弹候选让学生确认——不过度打扰学生。
- **答疑链路不直接写 Neo4j**：点亮由独立变更承担，答疑只产出 label，边界清晰。
- **追问点**："学生跳过会怎样？" → 不点亮、保持 PENDING，数据不丢、不阻塞答疑主线；后续可再确认。
