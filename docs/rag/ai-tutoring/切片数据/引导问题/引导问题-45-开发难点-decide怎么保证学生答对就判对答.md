## 回答

**核心结论**：判对靠验算不靠直觉，收尾靠护栏不靠模型格式——正确性评估由"验算 + 硬规则"双保险。

**分层展开**：
- **判对前代入验算**：学生给数值答案，先把数值代回题目算一遍再判对错，reason 里写出验算过程（例：题"小明10岁、妈妈38岁，几年后妈妈年龄是小明2倍"，学生答"18年" → 验算 38+18=56、10+18=28、56=2×28 ✓ 判对；答"20年" → 验算不符 ✗ 判错）。
- **疑问/不确定语气也算作答**：正确性按数值判断不看语气——"是18吗""答案是不是18"数值对就是答对，绝不因问句判错、回到 hint 引导循环。
- **独立解出即收尾**：学生独立给出正确数值（含用问句确认）→ exercise_complete=true → type=end COMPLETED 肯定收尾，不回到 hint。
- **确认复核**：学生说"我刚刚答案是对的" → 核对学生之前答案：对才确认收尾，错明确告知"答案不对"并指出错因，继续引导。
- **兜底**：end 联动护栏——COMPLETED 必须 correct && exercise_complete，模型误判答对 → 降级 concept。
- **追问点**："为什么不直接看关键词匹配？" → 判对是数学验算问题，关键词匹配会被"语气/措辞"骗；验算 + 数值判定最可靠。
