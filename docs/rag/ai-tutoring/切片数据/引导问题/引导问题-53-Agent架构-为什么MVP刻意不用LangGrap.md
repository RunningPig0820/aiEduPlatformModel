## 回答

**核心结论**：因为答疑流程是固定的——判动作 → 护栏审批 → 生成 → 落库，确定性工作流就够；agent 的"灵活性"在这里是风险不是优势。

**分层展开**：
- **流程固定**：学生不会按预设流程走，但系统的应对是闭集的（动作闭集六值 + Java 确定性护栏），不需要 agent 自主规划下一步——L0 单次调用（decide/generate 各一次 LLM）就覆盖全部场景。
- **agent 灵活性是风险**：① 可能某次就甩出完整答案（教育事故）；② 路径不可预测，难测、难控预算、难复现 bug。苏格拉底引导是硬约束，不能交给 LLM 自主。
- **成本与可测性**：两个确定性端点每个都可单测、可独立换模型、可独立降级；LangGraph 编排让调用边界模糊。
- **什么场景才升级**：自适应学习——"下一步教什么"需根据掌握度/情绪动态决策（补前置知识点/降难度/出变式题）时，那是决策问题，agent 决策循环 + 工具集（查薄弱点/出变式题，工具=Java 内部接口）。
- **迁移成本已预留**：ActionMeta 契约早定、工具 API 早定形状、护栏仍在 Java——阶段 2 升 LangGraph 低摩擦。
