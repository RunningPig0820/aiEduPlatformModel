# 一道题目是怎么被拆解成"hint 一步、approach 一步"这种逐步引导任务的？

## 回答

**核心结论**：decide 每轮只判一步动作，generate 按动作类型渲染对应正文，多轮推进形成"逐步引导"链，直至学生独立解出。

**分层展开**：
- **先想一步原则**：默认 hint——只推一步反问（"这题要先设哪个未知数？"）；学生明确求助/卡住（"我不会""太难了""给个思路"）才升 approach（思路大纲）。
- **作答反馈循环**：答错/答偏 → hint（让学生再想一步）；答对但未独立解出 → approach（续推思路，不给最终数值）；学生独立解出 → end COMPLETED。
- **generate 分类型规约（GENERATION_RULES）**：动作类型决定正文形态——hint 一条反问、approach 步骤名+关键公式、reveal 完整解答；正文不会越权（hint 不会泄答案）。
- **多轮闭环示例**：鸡兔同笼——hint"先设哪个未知数" → 学生答 x → approach"根据头数列方程→根据脚数列方程→联立" → 学生算错 → hint"验算一下脚的数对不对" → 学生解出 → end COMPLETED。
- **效果**：一道题 = 多轮 hint/approach 拆解的引导链，学生是逐步自己想出来的，不是被一次投喂的。
