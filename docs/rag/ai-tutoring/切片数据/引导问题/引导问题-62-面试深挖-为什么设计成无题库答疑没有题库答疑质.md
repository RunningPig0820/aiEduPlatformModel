## 回答

**核心结论**：无题库是设计选择，不是能力缺口——数据拿不到、规模撑不起，质量靠"决策 + 生成"双大模型引导兜底。

**分层展开**：
- **为什么无题库**：① 数据可得性——菁优网等题库需企业级对接，个人申请困难、拿不到数据；② 数据规模——即使有小数据量题库，也做不出"数据裂变"，无法支撑举一反三/自适应学习的规模效应。
- **质量靠什么兜底**：decide 判动作（苏格拉底引导 + 判对代入验算）+ generate 按动作类型生成（GENERATION_RULES 约束 hint/approach/reveal 形态）；判对验算（数值代回）保正确性，end 联动护栏保收尾。
- **题目是中间环节**：题目记录 → 题型 canonical → 知识点 → 图谱点亮——为将来接入题库后的举一反三/自适应铺垫，不是"没题库所以没数据"。
- **追问点**："没题库怎么保证不教错？" → 判对靠验算不靠题库；题库命中时按预置步骤校验是阶段 2 增强（答错分支更准），不推翻现有架构。
