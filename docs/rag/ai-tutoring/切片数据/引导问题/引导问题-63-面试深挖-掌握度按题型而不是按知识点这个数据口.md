## 回答

**核心结论**：这是产品/题目分析口径的权衡，不是技术必然——我认同题型口径，因为它落地更稳、更贴近学生做题场景。

**分层展开**：
- **为什么题型更好落地**：题目天然可聚到题型——canonical 向量聚类稳定、可打分（对/错/引导后）、可观测（题型掌握页）、落库不裂行（"鸡兔同笼"不会裂成多个名字）；而知识点映射依赖图谱（label→URI 解析易错、需 ADMIN 维护），数据链路更长、易错。
- **题型和知识点边界本就模糊**：一元二次方程既是题型也是知识点——选口径是数据治理选择，不是能力边界。
- **如果题目分析直接产出知识点**：掌握度按知识点也成立——不是做不到，是当前题目分析主产题型（canonical 稳定），知识点由后端从题型派生。
- **取舍收益**：口径稳 → 掌握度页可观测 → 回流 decide 决策上下文可信 → 学情分析数据干净。
- **追问点**："会不会丢失知识点维度？" → 不会——题型↔知识点映射由后端维护，题目记录同时留题型和知识点关联，只是"掌握度主体"选题型。
