## 回答

**核心结论**：本质区别——RAG 在"答"（检索事实给答案），答疑在"教"（决策循环 + 多轮引导 + 确定性护栏）。

**对照**：
- **普通 RAG**：检索外部知识库 → 生成答案；回答事实性问题；一次检索一次回答；无动作约束、无状态护栏、无教育目标。
- **答疑 agent**：不是检索知识，是决策循环 + 多轮引导——decide 判动作（闭集）、generate 按动作生成；带会话状态（3 态 + 计数器）、确定性护栏（答案 2 次/20 轮/安全终止）、教育目标（教你想答案）。
- **三个差异**：① 目的——RAG 给答案，答疑教你想答案；② 形态——RAG 单轮检索生成，答疑多轮 hint/approach 推进直至独立解出；③ 约束——答疑有动作闭集 + 三道护栏 + end 联动，RAG 没有。
- **底层共同点**：都复用 LLM，差异在产品化约束层——答疑把"教育底线"做成确定性护栏，把"引导"做成决策 + 生成双段。
- **追问点**："答疑能不能也接 RAG？" → 可以——答疑的知识（题型步骤/知识点）将来可由 RAG 供给，但那是工具层增强，不改变"决策 + 引导 + 护栏"的核心形态。
