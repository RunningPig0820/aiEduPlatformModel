## 回答

**核心结论**：不会无限引导——有轮次护栏、主动结束、答案放行三条优雅收尾路径，收尾话术按原因区分。

**分层展开**：
- **轮次护栏**：round_count ≥ 20 强制收尾 ROUND_LIMIT，固定话术说明本轮结束、鼓励下次，无 generate——这是硬兜底。
- **学生主动结束**：明确"我不做了/结束吧/再见" → end ABANDONED，鼓励收尾（不批评、给正反馈）。
- **学生要答案**：2 次后 reveal 放行 → 给完整解答后立即收尾 ANSWER_REVEALED——"引导不动就干脆教懂"。
- **独立解出**：学生自己推出来 → end COMPLETED，肯定掌握情况并简要总结。
- **收尾话术按 end_reason 区分**：COMPLETED=肯定+总结 / ANSWER_REVEALED=确认已给答案不复述 / ABANDONED=鼓励 / ROUND_LIMIT=说明本轮结束——不是生硬切断，是体面的结束。
- **追问点**："20 轮会不会太少，基础差学生做不完？" → 20 轮 hint/approach 足够覆盖典型引导链；基础差有 approach 升级 + reveal 兜底，路径完整。
