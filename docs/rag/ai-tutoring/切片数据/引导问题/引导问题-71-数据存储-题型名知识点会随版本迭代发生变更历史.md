## 回答

**核心结论**：题型 canonical 落库时归一，历史记录保留原题型名、靠 session 回溯；掌握度主体是题型而非知识点，天然避开知识点版本漂移。

**分层展开**：
- **落库归一**：题型名 → 向量最近邻聚集 canonical 再落库，口径稳定；历史已落记录不重写（保留当时数据，可追溯）。
- **掌握度避开知识点漂移**：掌握度主体是题型（t_student_topic_mastery）而非知识点 URI——知识点版本迭代不影响掌握度口径；题型库 t_question_type 由 ADMIN 维护映射，版本变更收敛在一处。
- **兼容**：历史题目记录按 session_id 跳回原会话回溯（掌握度页"查看原题"）；transcript COS 长期保留可重放。
- **迁移**：掌握度是累计平均，trainCount 保留，口径调整可重算（不是破坏性迁移）。
- **追问点**："题型改名了历史数据怎么办？" → canonical 是稳定口径，改名走 ADMIN 映射；历史记录保留旧名 + 归属新 canonical，可查询可追溯。
