## 回答

**核心结论**：用数据面的对比信号区分——单生信号 + 同题型横比，共性错误指向引导问题而非学生能力。

**分层展开**：
- **单生信号**：该生掌握度（薄弱题型 struggle）+ error_type 记录 + 引导后答对率（hinted）——学生反复在同一 error_type 错，说明该知识点引导没讲透。
- **对比信号**：同一题型不同学生的答对率差异——普通差 = 学生不会；**普遍性差** = 引导/题目本身的问题（不是学生个体能力）。
- **共性错误**：error_type 集中出现（如都是"设未知数错误"）→ 引导话术对该知识点的铺垫不足，这是 bad case 的核心来源。
- **工具**：transcript 回放（后端代理读）+ bad case 复盘（阶段 2/3 人工复盘能力）；评测集覆盖边界。
- **诚实边界**：当前数据面支持观测和归因，家长端报表/多维画像未落地；引导质量评价靠"普遍性对比 + error_type 聚集"两把尺子。
