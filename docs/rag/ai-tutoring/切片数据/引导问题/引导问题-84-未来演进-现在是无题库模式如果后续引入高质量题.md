## 回答

**核心结论**：题库嵌在 decide 之前做"匹配"，命中走预置步骤、未命中走现有通用引导——不推翻现有架构，是数据源增强。

**分层展开**：
- **位置**：题目进来 → 题库匹配（题目指纹/向量检索 canonical）→ **命中**：按预置步骤校验/引导（decide 参考题库步骤，答错分支更准，易错分支追问）；**未命中**：现有苏格拉底通用引导 + 标记"待入库"给教研。
- **支撑扩展**：题库 + 题型知识点关联 → 举一反三变式题、结构化步骤校验、行为风控（题目指纹防反复做同一题）。
- **现有铺垫**：题目已落库（题目记录 → 题型 canonical → 知识点 → 图谱），题库接入只是补齐"标准答案/预置步骤"数据源，链路位置明确。
- **为什么当初无题库**：数据可得性（菁优网需企业对接）+ 数据规模（小题库做不出数据裂变）——题库是阶段 2 增强，不是推翻设计。
- **追问点**："命中率低怎么办？" → 未命中走通用引导兜底（现状能力），命中提升质量——渐进增强，不存在"没题库就没法用"。
