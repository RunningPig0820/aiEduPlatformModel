## 3. AI答疑交互设计

+ **提问引导策略**：无上下文时，给出具体提问示例（贴合学生口语化习惯）；有上下文时，结合历史对话温和引导，不强制标准化提问，降低使用门槛。
+ **答疑逻辑**：依托知识图谱结构化知识点，结合轻量小模型，实现分步引导答疑，借鉴可汗学院理念，避免直接给出答案。
+ **举一反三实现**：基于知识图谱的知识点关联，在答疑后推送同类变式习题，参考猿辅导教学法，强化学生知识掌握。

> 🚫 **最新逻辑（2026-08 代码）**：举一反三（变式题推送）**未落地**——依赖题库 + 图谱知识点关联（阶段2），MVP 无题库是设计。
+ **交互风格**：参考科大讯飞虚拟人教学的亲和力，采用口语化、简洁化表述，适配小学至高中不同学段学生的认知特点。
