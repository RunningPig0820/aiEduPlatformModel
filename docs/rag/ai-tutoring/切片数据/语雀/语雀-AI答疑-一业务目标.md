# 一、业务目标

本模块作为智启学坊AI教育平台的核心前端交互模块，核心业务目标围绕"教育属性优先、低成本落地、用户体验适配"三大核心展开：

+ **核心目标**：面向小学至高中全学段学生，提供轻量化、引导式数学答疑服务，践行可汗学院启发式教育理念，拒绝直接投喂答案，引导学生规范提问、培养逻辑思维与提问能力，实现"教学相长"的教育核心。
+ **成本目标**：适配个人项目资源限制，采用免费小模型、轻量存储方案，控制开发、部署及运维成本，支持多套部署与多并发，无需复杂技术架构与高额投入。
+ **用户目标**：适配学生非书面化、模糊化的真实提问习惯，降低使用门槛，同时为家长提供精准学情分析，满足"学生答疑+家长监控"的双重需求。
+ **迭代目标**：留存对话及答疑数据，为模型优化、引导策略调整、知识图谱完善提供数据支撑，实现"答疑-分析-迭代"的闭环。
