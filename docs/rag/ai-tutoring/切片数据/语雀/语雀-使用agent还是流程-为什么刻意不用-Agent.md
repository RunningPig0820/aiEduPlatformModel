## 为什么刻意不用 Agent

1. **苏格拉底原则是硬约束**：严禁直接给答案、每轮只一条提示——这些不能交给 LLM 自主判断，agent 的"灵活性"在这里是风险（它可能哪次就给你甩出完整答案）。
2. **业务规则必须确定**：20 轮上限、2 次答案出口、掌握度单调不减、图谱点亮——这些是产品规则，agent 不可控。
3. **成本与可测性**：每次调用边界清晰、单步可测；agent 循环的调用次数和路径不可预测，难测也难控预算。
