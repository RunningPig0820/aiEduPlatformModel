## 为什么自适应学习天然是 agent 逻辑

两者的差别不在"用没用 LLM"，而在智能坐在哪里：

```
苏格拉底答疑（执行问题）                    自适应学习（决策问题）
─────────────────────────               ─────────────────────────
策略固定：一步步问，不问对错               策略可变：根据状态选"下一步做什么"
"下一步"由代码规则决定                      "下一步"取决于学生状态，需动态决策
   · answer_request_count → 出口          · 掌握度 < 40 → 补前置知识点
   · round_count → 收尾                   · 连续错 3 次 → 降难度 + 换讲解方式
   · 每轮 mode 固定                        · 情绪沮丧 → 先给鼓励再推进
                                         · 已掌握 → 加快 / 出变式题
策略是写死的 → workflow                   策略本身是智能 → agent
```

自适应学习的核心是一个决策循环：观察状态 → 决定教学动作 → 执行 → 观察新状态。这恰恰是 agent 的标准结构——状态 + 工具 + 决策者。LangChain/LangGraph 的价值在"决策层"真正发挥出来，而不只是拼个 JSON。
