## 一、功能小点清单（AI答疑模块）

| 编号 | 功能小点 | 说明 |
|------|---------|------|
| F1 | 意图与题型识别 | 判断用户输入属于"学科问题""学习指导""完全无关"三类；同时识别题型（选择/填空/解答等）和任务意图（求解析/求思路/求验证）。 |
| F2 | 模糊提问主动澄清 | 当用户输入过于简略（如"这题不会"）时，生成追问以明确具体需求。 |
| F3 | 通用分步引导 | 不依赖题库时，由大模型自主规划解题步骤，以苏格拉底式提问逐步给出提示、反问易错点，严禁直接输出答案。 |
| F4 | 学生回答智能反馈 | 判断学生中间步骤或最终答案的正确性，针对错误给出引导性反问（如"这一步的依据是什么？"），而非直接评判。 |
| F5 | 行为风控与防作弊 | 监测高频重复提问、无思考痕迹的请求等，触发更严格引导（如要求先写出当前理解）或暂缓响应。 |
| F6 | 对话状态保持 | 记忆当前题目、进行到的引导步骤，支持中断后从断点恢复。 |
| F7 | 情绪感知与激励 | 识别用户多次错误后的挫败情绪，切换鼓励话术或降低提示难度；成功后给予正向反馈。 |
| F8 | 知识点自动提取 | 从对话中提取涉及的知识点标签（可由大模型实时推断），用于后续写入知识图谱。 |
| F9 | 错误意图捕捉与上报 | 在引导过程中记录学生对易错分支的选择或典型误解，形成结构化错误事件，上报给知识点模块。 |
| F10 | 学习报告片段生成 | 汇总本次答疑的关键过程：涉及知识点、暴露的薄弱点、引导完成情况，供外部报告服务聚合。 |
| F11 | 安全与合规过滤 | 识别自伤、暴力等高风险内容，终止AI应答并转人工或安全流程；对话数据脱敏处理。 |

> **⚠️ 代码现状（F1-F11 落地核对，2026-08 对账）**：
> F1 → 学科门 + decide 两分法 ｜ F2 ✅ concept 澄清 ｜ F3 ✅ hint/approach 引导 ｜ F4 ✅ decide eval（correct/error_type/emotion）｜ F5 🚫 行为风控（真实=护栏）｜ F6 ✅ 断点恢复 ｜ F7 ⚠️ emotion 落库、激励为 prompt ｜ F8 ✅ label → 题型掌握度 ｜ F9 ⚠️ 错误事件有（B3 门控）｜ F10 ⚠️ 仅收尾 summary，无独立报告服务 ｜ F11 ✅ 双层安全
