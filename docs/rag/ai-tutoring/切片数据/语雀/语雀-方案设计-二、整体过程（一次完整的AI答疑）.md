## 二、整体过程（一次完整的AI答疑）

1. **提问接收** — 用户发送题目（文字/图片）。系统调用F11进行安全过滤，不通过则中断。
2. **意图分类与澄清** — F1判断意图类别：完全无关 → 终止并提示学习范围；学习指导 → 转通用建议或资源推荐；学科问题 → 继续。若输入模糊，F2发起澄清反问，直至明确需求。
3. **题型与任务判断** — F1进一步分析题型和用户真实意图，确定后续引导策略的基调（如计算题侧重步骤推导，阅读题侧重文本分析）。
4. **启动引导流程** — 若题库可用：尝试匹配题目指纹，命中则加载预置的分步引导素材，进入F3的增强模式。若题库不可用或未命中：直接进入F3通用引导模式，由大模型实时生成提示。引导过程严格遵循分步追问，绝不透露完整答案。
5. **交互循环与诊断** — 每一轮引导：AI抛出当前步骤的提示或反问题（F3）→ 学生回答 → F4分析回答，判断正误及可能原因 → F9若发现典型错误意图，结构化记录 → F7根据连续错误次数调整语气和难度 → 循环直至学生得出最终答案或主动终止。
6. **知识点同步与报告** — 答疑结束时：F8提取全程涉及的知识点标签；F9的错误事件、知识点标签等信息，通过接口发送给知识点模块，用于更新知识图谱点亮状态和能力画像；F10生成本次答疑的摘要片段，供学习报告使用。
7. **状态归档** — F6保存对话进度，允许用户稍后继续。

> ✅ **代码现状**：7 步与落地基本一致（学科门 → decide → 护栏 → 引导循环 → 掌握度/错误落库 → COS 归档/断点恢复），仅「题库匹配」一步因无题库由纯 LLM 引导代替。详见 `方案-代码对账.md`。
