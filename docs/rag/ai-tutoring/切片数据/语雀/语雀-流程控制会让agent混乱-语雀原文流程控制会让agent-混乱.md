**Q: 如果开启了一个新的题目 学生又回到了原来的题目 这个时候需要控制流程状态吗 我想说的是流程状态控制的话 状态会不会太多**

**A: 好问题，你戳到了状态设计的要害。直接回答：不需要为"回旧题"新增任何状态——状态机保持 7 个不变。** 关键是把两样东西分开，这是防止状态爆炸的根本。
