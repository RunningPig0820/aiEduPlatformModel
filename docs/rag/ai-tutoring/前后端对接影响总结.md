## 1. 后端（Java）必须适配

| # | 适配点 | 详情 |
|---|---|---|
| 1 | **请求加 `current_project`** | `POST /api/tutoring/rag/query` 和 `POST /api/tutoring/rag/assistant/ask` 请求体加 `current_project`(用户当前所在功能页: ai-tutoring/rag-system/knowledge-graph/question-analysis)。不传 → 默认 ai-tutoring,多模块下路由可能不准。 |
| 2 | **响应 `intent` 新增 `anchor` + `categories`** | `intent.anchor`=LLM 判定的模块(前端可展示"命中哪个模块");`intent.categories`=9 类切片标签(**可空数组=不筛**)。新增字段,旧逻辑忽略不影响。 |
| 3 | **`references[].file_path` 变 COS key** | 从本地路径 → `rag-source/<模块>/...` 或 `rag-slices/<模块>/...`。前端"查看原文"直接透传到 `GET /api/rag/source/{file_path}`,**不要拼本地路径**。 |
| 4 | **模块隔离拒答** | 问题判到某模块,只从该模块语料召回;该模块语料未建 → 拒答"该问题语料未覆盖"。当前仅 ai-tutoring 有语料,指向 rag-system/知识图谱/题型分析的会拒答——**预期行为**,等语料入桶自动可答。 |
| 5 | **`GET /api/rag/assistant/guide` 加 `?current_project=`** | 进页面/切换功能时传当前模块。⚠️ **direction 值变更**:`architecture/data_flow/evaluation` → `intro/operation/data_relation/difficulty/rag`。返回的引导问题为**入门级**（入口池，如"AI答疑是干什么的"），前端直接展示即可。 |
| 6 | **问候识别(6.6)** | intent 的 `category` 可能出现 `问候`(新增枚举),`ambiguous=false`(不再误触发澄清)。问候轮 done 返回固定欢迎话术 + 池内引导建议,`tokens_usage.total_tokens=0`。 |

## 2. 前端必须适配

| # | 适配点 | 详情 |
|---|---|---|
| 1 | **传 `current_project`** | 用户进入/切换功能页时,请求带上当前功能(Java 透传)。 |
| 2 | **"查看原文"透传 file_path** | `references[].file_path` 是 COS key,直接 `GET /api/rag/source/{file_path}`,不再依赖本地路径(不再报"原文不存在")。 |
| 3 | **展示"命中模块"** | 可选:用 `intent.anchor` 展示命中了哪个功能模块。 |
| 4 | **拒答降级展示** | 无语料模块问题 → answer="该问题语料未覆盖",前端按降级语义渲染。 |
| 5 | **引导 chips** | `guide` 的 `direction` 值变了(见上表#5);问候轮返回欢迎语(正常渲染即可)。 |

## 3. 内部改动(前后端无感知)

- **双池索引结构**:`rag-full`(23块) + `rag-slice`(294块),同一向量桶,检索自动按模块路由
- **Filter 下推**:module 筛选下推到向量层(COS Filter)
- **去 categories 过滤**:查询不再按 9 类过滤——评测实测 LLM 判类别不准(如"答疑和知识图谱怎么联动"被判项目介绍),过滤会误伤相关块,故去掉。`intent.categories` 保留为展示字段,不参与过滤
- **检索质量变化**:双池互补(全量池答整体、切片池答细节),hit@3 0.50 → 质量分 4.17

- **Java**:query/ask 传 `current_project`;guide 传 `current_project` + direction 新值;file_path 透传 COS key;intent 新增 anchor/categories(忽略兼容)
- **前端**:请求带当前功能页;查看原文透传 COS key;引导 chips 适配新 direction;拒答/问候轮正常渲染
- **Python**:已完成,无需改动,测试 562 全绿
