## 1. `/api/tutoring/rag/query` 请求：新增 `current_project` 字段

**变化**：`RAGQueryRequest` 新增 `current_project`（默认 `ai-tutoring`）。

```json
// Java 调用 POST /api/tutoring/rag/query
{
  "question": "项目开发遇到过哪些坑",
  "top_k": 6,
  "current_project": "ai-tutoring"   // 新增: 当前上下文模块(用户在哪个功能页)
}
```

**作用**：intent LLM 倾向保持该模块（prompt 带"当前上下文模块，除非问题明确属其他模块"）。不传 → 默认 ai-tutoring，多模块下会路由不准。

**模块闭集**：`ai-tutoring`（AI答疑）/ `rag-system`（RAG项目）/ `knowledge-graph`（知识图谱）/ `question-analysis`（题型分析）。

**Java 待办**：调用时传用户当前所在模块页。

## 2. `/api/tutoring/rag/query` 响应 `intent`：新增 `anchor` + `categories`

**变化**：`RAGIntent` 新增两字段（旧字段 `locked_sections`/`strategy` 不变，向后兼容）。

```json
"intent": {
  "locked_sections": ["04", "07"],
  "strategy": "retrieve",
  "anchor": "ai-tutoring",            // 新增: LLM 判定的模块(前端可展示"命中哪个模块")
  "categories": ["开发难点"]          // 新增: 切片池 9 类过滤标签(可空=不筛)
}
```

**Java 待办**：前端可选展示"命中了哪个模块"；解析新增字段，忽略不影响旧逻辑。

## 3. `references[].file_path` 格式变为 COS key（⚠️ 联调重点）

**变化**：`file_path` 从本地相对路径 → COS 普通桶 key。

| 以前 | 现在 |
|---|---|
| `4.完善文档/04-安全与防作弊.md` | `rag-source/ai-tutoring/完善文档/04-安全与防作弊-护栏.md` |
| `切片数据/坑档案/坑档案-J1-...md` | `rag-slices/ai-tutoring/坑档案/坑档案-J1-...md` |

**规则**（见 `向量桶入桶清单.md` 7.2）：
- 源语料：`rag-source/<模块>/<源目录>/<文件名>.md`
- 切片视图：`rag-slices/<模块>/<子目录>/<文件名>.md`

**前端"查看原文"链路**（U4 完成后）：
```
前端 file_path = "rag-slices/ai-tutoring/坑档案/坑档案-J1-...md"
  → GET /api/rag/source/{file_path}
  → Python 读 COS: ai-edu-1318177119 / 该 key → 返回文件内容
```

**Java 待办**：前端直接透传 `file_path` 到 `/api/rag/source`，不做本地路径拼接。
