## 2. 入桶字段结构（每条记录）

写入 payload = `{key, data, metadata}`（build_index.py:124）：

- **key**：`ai-tutoring/{file}/{anchor}#{chunk_idx}`（同 key upsert）
- **data**：`float32` 向量，**768 维**，embedding 输入 = `summary + "\n" + text`
- **metadata（11 字段）**：`version / doc_type / module / category / source / authority / section / file / file_path / anchor / summary`
  - `category` = 9 类闭集标签（开发难点/架构设计/项目介绍/操作流程/数据关联/业务流程/业务视角/数据存储/未来演进），2026-08-26 补齐
  - `module` = 模块闭集 id（ai-tutoring/knowledge-graph/question-analysis/rag-system）
- **text 正文不进 metadata**（20KB 限制），留在 `rag_slices.jsonl`，命中后按 key 反查

## 5. 维护注意

- 新增模块（知识图谱/题型分析/RAG 项目）→ 在 LAYERS 加一层，按同样流程切片（9 类标签）→ 入桶
- 重建索引：`cd ai-edu-ai-service && python scripts/rag/build_index.py --clear`（幂等，--clear 清空后重写）
- 入桶前校验：`rag_slices.jsonl` 每块含 `tags.category`（9 类闭集）；`build_index.py` metadata 会自动带上 category+module
