## 2. 入桶字段结构（每条记录）

写入 payload = `{key, data, metadata}`（build_index.py:124）：

- **key**：`ai-tutoring/{file}/{anchor}#{chunk_idx}`（同 key upsert）
- **data**：`float32` 向量，**768 维**，embedding 输入 = `summary + "\n" + text`
- **metadata（11 字段）**：`version / doc_type / module / category / source / authority / section / file / file_path / anchor / summary`
  - `version` = `YYYY-MM-DD-<语料sha1[:6]>`，语料变→版本变，走 metadata 不走索引名
  - `doc_type`/`module` = 模块闭集 id（ai-tutoring/knowledge-graph/question-analysis/rag-system），doc_type 取 tags.module
  - `category` = **9 类闭集标签**（项目介绍/操作流程/数据关联/开发难点/业务流程/架构设计/业务视角/数据存储/未来演进）
  - `source` = 语料来源（完善文档/语雀/OpenSpec/代码/坑档案/引导问题）
  - `authority` = 权威度（1.0/0.8/0.7）
  - `file` = 源文件名（去 .md）；`file_path` = 相对语料根 `docs/rag/ai-tutoring/` 路径
  - `anchor` = 块锚点；`summary` = LLM 生成的"解决什么问题"一句话
- **text 正文不进 metadata**（COS 向量索引 ~20KB/条限制），留在 `rag_slices.jsonl`，命中后按 key 反查
