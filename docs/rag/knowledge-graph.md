## 5. 项目开发中有什么难点

| 引导（扬长） | 亮点 | 预期追问 |
|-------------|------|---------|
| 双模型投票怎么防误判？ | DeepSeek + GLM 两模型投票，避免单模型误判 | "投票不一致怎么办？" → 置信度 <0.7 丢弃 |
| 匹配率 97.1% 怎么做到？ | 精确匹配(标准化+同义词) → 向量粗筛 top-20 → 双模型投票 | "剩下的 3% 呢？" → 待人工审核 |
| 本地 embedding 内存大怎么办？ | 预构建索引（10MB）vs 懒加载（3.5GB），checksum 校验 | "索引过期怎么办？" → checksum 失配强制重建 |
