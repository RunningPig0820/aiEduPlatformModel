# 教材地址（语雀原稿）

> 来源：https://www.yuque.com/zhangmin-jrrer/iu9s4m/si3pvrg2i7yigtv2
> 字数：230 ｜ 下载：2026-08-24

#### 1. ChinaTextbook（国内教材整理标杆）
+ 地址：[https://github.com/TapXWorld/ChinaTextbook](https://github.com/TapXWorld/ChinaTextbook)
+ 方法：
    - 目录：小学 / 初中 / 高中 / 大学，按年级、学科、版本分层。
    - 工具：`mergePDFs` 合并拆分文件，`tchMaterial-parser` 批量下载。
    - 技术：Git 版本管理、自动化更新、社区协作。

#### 2. TextbooksToRL（AI 导向教材结构化）
+ 地址：[https://github.com/Tufalabs/TextbooksToRL](https://github.com/Tufalabs/TextbooksToRL)
+ 方法：
    - PDF→文本→分块（3–5 页）→AI 生成问答对→校验→输出 JSON 数据集。
    - 适配多学段，支持 OpenAI/Anthropic 等模型。

#### 3. tchMaterial-parser（官方教材批量下载）
+ 地址：[https://gitcode.com/GitHub_Trending/tc/tchMaterial-parser](https://gitcode.com/GitHub_Trending/tc/tchMaterial-parser)
+ 方法：输入教材 URL，自动解析并下载 PDF，支持批量处理。

#### 4. TeachBooks / GitHub-Book（开源教材框架）
+ 地址：[https://github.com/teachBooks/template](https://github.com/teachBooks/template)
+ 方法：用 Markdown 编写教材，GitHub Actions 自动构建为网页，支持互动习题。
