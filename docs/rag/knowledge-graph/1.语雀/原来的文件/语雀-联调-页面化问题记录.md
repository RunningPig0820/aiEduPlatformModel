}

## 问题 4: 图谱关系 API 未验证

**接口**: `GET /api/kg/knowledge-points/{uri}/graph`

**当前现象**: 未触发调用

**期望返回格式**:
```json
{
  "code": "00000",
  "data": {
    "nodes": [
      {
        "id": "kg:point:xxx",
        "type": "textbook_kp",
        "label": "教材知识点名称",
        "data": {
          "uri": "kg:point:xxx",
          "name": "教材知识点名称",
          "subject": "数学",
          "grade": "七年级",
          "unit": "第一单元",
          "lesson": "第一课时"
        }
      },
      {
        "id": "kg:point:yyy",
        "type": "kp",
        "label": "知识点名称",
        "data": {
          "uri": "kg:point:yyy",
          "name": "知识点名称",
          "subject": "数学",
          "difficulty": 2,
          "cognitiveLevel": "理解"
        }
      }
    ],
    "edges": [
      {
        "id": "edge-1",
        "source": "kg:point:xxx",
        "target": "kg:point:yyy",
        "label": "关联"
      }
    ]
  }
}
```

**约束**:
- nodes[].type 必须是 `textbook_kp` 或 `kp`
- edges 需要包含 source、target、label 字段
- 节点数建议上限 50 个

**优先级**: 🔴 高（图谱渲染核心依赖）
