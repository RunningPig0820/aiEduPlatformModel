### 三 题库 
#### 1. 中小学 / 基础教育题库（论文常用）
+ **ChinaQuestionBank**（国内 K12 标杆）
    - 地址：[https://github.com/ChinaQuestionBank/ChinaQuestionBank](https://github.com/ChinaQuestionBank/ChinaQuestionBank)
    - 内容：小学 / 初中 / 高中全学科题库，含同步练习、单元测试、真题，结构化 JSON/Markdown 存储。
    - 方法：按**学段→年级→学科→知识点**分层，支持批量导出与试卷生成。
+ **OpenItem（北师大 OpenCT）**
    - 地址：[https://www.gitlink.org.cn/Open-CT/openitem](https://www.gitlink.org.cn/Open-CT/openitem)
    - 定位：AI + 大数据驱动的大规模题库与命题系统，覆盖全学段，支持智能组卷。
+ **K12-QuestionBank**
    - 地址：[https://github.com/topics/k12-question-bank](https://github.com/topics/k12-question-bank)
    - 特点：社区维护，含人教版、北师大版等主流教材配套题库。

#### 2. 大学 / 专业学科题库
+ **HHU 试题库**
    - 地址：[https://github.com/KarlRaphel/HHU-Collection-of-Test-Papers](https://github.com/KarlRaphel/HHU-Collection-of-Test-Papers)
    - 内容：德国杜塞尔多夫大学课程试题，含计算机、数学、工程等学科。
+ **大学计算机题库**
    - 地址：[https://github.com/topics/university-computer-question-bank](https://github.com/topics/university-computer-question-bank)
    - 覆盖：数据结构、操作系统、计算机网络、数据库等专业课真题与习题。

#### 3. 编程 / 算法题库（最丰富）
+ **doocs/leetcode**
    - 地址：[https://github.com/doocs/leetcode](https://github.com/doocs/leetcode)
    - 内容：LeetCode、剑指 Offer 全题解，多语言实现（Java/Python/C++），分类清晰。
+ **coding-interview**
    - 地址：[https://github.com/doocs/coding-interview](https://github.com/doocs/coding-interview)
    - 内容：互联网大厂面试算法题、系统设计题，含详细解析。
