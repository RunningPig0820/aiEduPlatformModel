## 硬性规则（强制继承）

### 状态判定标准
- ✅【已落地设计】文档+代码双存在、可观测实现
- ⚠️【建议项(未实现)】仅文档构想、无代码落地
- ❓【待决策】无明确结论

### 证据标注规范
1. 语雀证据：`证据：语雀-原文件-xxx.md`
2. 代码证据：`文件:函数/类/逻辑片段`，禁止编造行号
3. 不可读来源如实标注，不脑补

### RAG 块级结构（强制）
1. **每组选型 = 一个 `### 选型# {选型点}` 独立 H3 块**——一个 chunk = 一组选型，回答"为什么不选 X"。
2. 每条 `### 选型#` 开头必须带：
   ```
   > 状态：✅/⚠️/❓
   > 检索摘要：{1-2句，≤120字符，埋核心实体（选型点+被否决方案）}
   ```
3. 用窄表承载候选方案（列：方案/优点/缺点/结论）；禁止宽横向大表作主体。
