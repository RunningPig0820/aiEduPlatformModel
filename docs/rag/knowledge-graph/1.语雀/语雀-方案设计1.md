# 知识图谱数据整理方案设计
## 一、目标
将现有数据整理成支持 AI 作业答疑业务的知识图谱：

+ 按学科、年级组织知识点
+ 建立知识点前置/后置依赖关系
+ 支持学习路径推荐和知识缺陷诊断

---

## 二、数据模型设计
### 2.1 知识点层级结构
```plain
学科 (Subject)
  └── 学段 (Stage: 小学/初中/高中)
        └── 年级 (Grade)
              └── 教材 (Textbook)
                    └── 章节 (Chapter)
                          └── 知识点 (KnowledgePoint)
```

### 2.2 Neo4j 节点模型
```cypher
// 学科节点
(:Subject {name: "数学", code: "math"})

// 学段节点
(:Stage {name: "高中", code: "high_school"})

// 年级节点
(:Grade {name: "高一", code: "g10", order: 1})

// 教材节点
(:Textbook {
  name: "高中数学必修第一册",
  isbn: "9787107336270",
  subject: "math",
  grade: "g10"
})

// 章节节点
(:Chapter {
  name: "集合与函数概念",
  order: 1,
  textbook_isbn: "9787107336270"
})

// 知识点节点 (核心)
(:KnowledgePoint {
  uri: "http://edukg.org/knowledge/0.1/instance/math#516",
  name: "一元二次方程",
  subject: "math",
  stage: "初中",
  grade: "初三",          // 推断或标注
  chapter: "一元二次方程",
  type: "定义",           // 定义/性质/定理/公式
  difficulty: 3,          // 1-5 难度等级
  source: "edukg"         // 数据来源
})
```

### 2.3 关系模型
```cypher
// 层级关系
(:Subject)-[:HAS_STAGE]->(:Stage)
(:Stage)-[:HAS_GRADE]->(:Grade)
(:Grade)-[:USE_TEXTBOOK]->(:Textbook)
(:Textbook)-[:HAS_CHAPTER]->(:Chapter)
(:Chapter)-[:CONTAINS]->(:KnowledgePoint)

// 分类关系 (从 relations/)
(:KnowledgePoint)-[:BELONGS_TO]->(:Category)

// 核心关系：前置依赖（LLM 推理生成）
(:KnowledgePoint)-[:PREREQUISITE {
  confidence: 0.85,      // 置信度
  source: "llm",         // 来源：llm/textbook
  verified: false        // 是否已人工验证（demo阶段全部false）
}]->(:KnowledgePoint)

// 知识点关联（TTL 原生 relateTo 数据，必须保留）
(:KnowledgePoint)-[:RELATED_TO {
  source: "edukg_relateTo"
}]->(:KnowledgePoint)

// 分类层级关系（TTL 原生 subCategory 数据）
(:KnowledgePoint)-[:SUB_CATEGORY]->(:KnowledgePoint)
(:KnowledgePoint)-[:BELONGS_TO]->(:Category)
```

### 5.2 教材章节顺序算法
**Demo 阶段策略**: 只生成同章节内部前置关系，跨章节关系由 LLM 推理补充

```python
def infer_prerequisites_from_textbook(knowledge_points, textbook_data):
    """
    基于教材章节顺序推断前置关系

    Demo 阶段策略:
    - 只生成同章节内部的前置关系（按 mark 顺序）
    - 跨章节关系暂由 LLM 推理补充
    - 避免"章末知识点 → 章首知识点"的硬编码假设
    """
    prerequisites = []

    # 按教材分组
    for textbook, kps in group_by_textbook(knowledge_points):
        # 按章节排序
        sorted_kps = sort_by_chapter_and_mark(kps)

        # 建立前置关系（仅同章节内部）
        for i in range(1, len(sorted_kps)):
            prev = sorted_kps[i-1]
            curr = sorted_kps[i]

            # 同章节: 直接前置
            if prev.chapter == curr.chapter:
                prerequisites.append({
                    'from': prev.uri,
                    'to': curr.uri,
                    'confidence': 0.85,
                    'source': 'textbook_chapter'
                })
            # 跨章节: 不生成，由 LLM 推理补充

    return prerequisites
```

**后续优化**: 待验证跨章节关系质量后，再决定是否引入章节顺序算法

### 5.4 LLM Prompt 设计
```plain
你是一个教育专家，请分析以下知识点之间的前置学习关系。

学科：数学
知识点列表：
| 序号 | 名称 | 类型 | 描述 |
| 1 | 一元一次方程 | 定义 | 含有一个未知数且次数为1的方程 |
| 2 | 一元二次方程 | 定义 | 含有一个未知数且次数为2的方程 |
| 3 | 因式分解 | 方法 | 将多项式分解为因式乘积 |
| 4 | 完全平方公式 | 公式 | (a±b)² = a² ± 2ab + b² |
| 5 | 二次函数 | 定义 | 形如 y=ax²+bx+c 的函数 |

请判断每个知识点学习前需要先掌握哪些知识点，输出严格 JSON 格式：
{
  "一元二次方程": {
    "prerequisites": ["一元一次方程", "因式分解"],
    "reason": "一元二次方程的求解需要理解方程的基本概念（一元一次方程）和因式分解方法",
    "confidence": 0.9
  },
  ...
}

注意：仅输出合法 JSON 对象，禁止任何额外解释、markdown 格式、代码块包裹。
```

**输入内容**:

+ 知识点名称（必须）
+ TTL 原生描述/定义（必须）
+ 知识点类型（定义/性质/定理/公式/方法）
+ 学科分类路径

**输出处理**:

+ 严格 JSON 格式
+ 单条解析失败重试 1 次
+ 重试仍失败丢弃该条，写入错误日志
+ 置信度 < 0.7 直接过滤丢弃

### 5.5 知识点类型信息
**数据来源**: TTL 谓词 `edukg:knowledgeType` + `rdf:type`

**取值范围**: 固定枚举（定义/性质/定理/公式/方法）

**覆盖率**: 数学学科 > 90%

**用途**: 辅助 LLM 推理前置关系逻辑

**缺失处理**: 留空或标记为 "unknown"，不额外推断
