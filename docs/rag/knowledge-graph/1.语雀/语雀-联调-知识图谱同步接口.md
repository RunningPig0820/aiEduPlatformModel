**知识图谱同步接口改动点（2026-04-20）**

****

**一、同步任务拆分****改动说明**同步任务从**单一长事务**改为**按年级拆分的独立子任务**：

| 维度 | 旧逻辑 | 新逻辑 |
| --- | --- | --- |
| 锁粒度 | 全局锁 ai-edu:kg:sync:lock | 细粒度锁 ai-edu:kg:sync:lock:{edition}:{subject}:{stage}:{grade} |
| 同步记录 | 一条全局记录 | 每个年级独立记录 |
| 失败影响 | 全量回滚 | 仅该年级失败，其他年级继续 |
| 对账范围 | 全量对账 | 仅对账当前年级范围 |


**前端影响**同步请求参数不变，后端自动按年级拆分执行返回结果新增年级统计字段：**二、同步历史记录接口改动****接口变更****请求参数**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| edition | String | 否 | 教材版本筛选 |
| subject | String | 否 | 学科筛选 |
| stage | String | 否 | 学段筛选 |
| grade | String | 否 | 年级筛选 |
| size | Integer | 否 | 返回数量，默认 10 |

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| edition | VARCHAR(100) | 教材版本 |
