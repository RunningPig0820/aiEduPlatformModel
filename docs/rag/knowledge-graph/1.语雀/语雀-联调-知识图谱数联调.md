# 知识图谱节点展开接口联调
## 接口 1：展开结构关系
**端点:** `POST /api/auth/kg/graph/expand/structure`

**说明:** 展开节点的结构层级邻居（IN_UNIT、CONTAINS），用于教材知识点定位和导航树展示。

**请求体:**

```json
{
  "nodeUri": "http://edukg.org/knowledge/3.1/kp/math#renjiao-g1s-1-1-1",
  "limit": 20
}
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| nodeUri | String | 是 | - | 节点 URI |
| limit | int | 否 | 20 | 返回数量上限 |


---

## 接口 2：展开知识关系
**端点:** `POST /api/auth/kg/graph/expand/knowledge`

**说明:** 展开节点的语义知识邻居（MATCHES_KG、RELATED_TO、BELONGS_TO 等），用于知识图谱可视化和概念扩展。

**请求体:**

```json
{
  "nodeUri": "http://edukg.org/knowledge/3.1/kp/math#renjiao-g1s-1-1-1",
  "limit": 20
}
```

参数同结构关系接口。

---

## 响应格式
```json
{
  "code": 200,
  "data": {
    "nodes": [
      {
        "id": "http://edukg.org/knowledge/3.1/kp/math#renjiao-g1s-1-1-1",
        "type": "kp",
        "label": "1-5的认识",
        "data": {
          "uri": "http://edukg.org/knowledge/3.1/kp/math#renjiao-g1s-1-1-1",
          "name": "1-5的认识"
        }
      }
    ],
    "edges": [
      {
        "id": "edge-0",
        "source": "http://edukg.org/knowledge/3.1/kp/math#renjiao-g1s-1-1-1",
        "target": "http://edukg.org/knowledge/3.1/section/math#renjiao-g1s-1-1",
        "label": "IN_UNIT"
      }
    ],
    "hasMore": false
  }
}
```

### 节点 type 枚举
| type | Neo4j 标签 | 说明 |
| --- | --- | --- |
| kp | TextbookKP | 教材知识点 |
| concept | Concept | 概念 |
| statement | Statement | 陈述/命题 |
| class | Class | 类别 |
| section | Section | 小节 |
| chapter | Chapter | 章节 |
| textbook | Textbook | 教材 |
| unknown | 其他 | 未识别类型 |


### 边 label 枚举
**结构关系：**

| label | 方向 | 说明 |
| --- | --- | --- |
| IN_UNIT | TextbookKP → Section / Chapter | 知识点属于哪个层级 |
| CONTAINS | Textbook → Chapter → Section | 教材包含章节/小节 |


**知识关系：**

| label | 说明 |
| --- | --- |
| MATCHES_KG | 知识点匹配概念 |
| RELATED_TO | 关联关系 |
| BELONGS_TO | 归属关系 |
| PART_OF | 部分关系 |
| HAS_TYPE | 有类型 |
| SUB_CLASS_OF | 子类关系 |
| DEVELOPS | 发展关系 |
| HAS_DIMENSION | 有维度 |
| ASSOCIATED_WITH | 关联 |
| PEER_RELATION | 同级关系 |


### hasMore 字段
+ `hasMore: true` — 还有更多数据未返回，前端可展示"加载更多"按钮，用户操作后传入更大的 `limit` 继续拉取
+ `hasMore: false` — 数据已全部返回

## 联调检查项
- [ ] 结构关系接口能正确返回 IN_UNIT、CONTAINS 关系
- [ ] 知识关系接口能正确返回 MATCHES_KG、RELATED_TO 等关系
- [ ] 传递的 nodeUri 不存在时，返回空结果（nodes: [], edges: []）
- [ ] hasMore 分页正常：limit=1 时传入有多个邻居的节点，hasMore 为 true
- [ ] 默认 limit=20 生效（不传 limit 时）
- [ ] 前端能根据 type 字段渲染不同颜色/形状的节点
- [ ] 前端能根据 edge.label 区分关系类型并展示合理样式
