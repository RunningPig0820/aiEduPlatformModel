# 知识图谱同步接口改动点（2026-04-20）
## 一、同步任务拆分
### 改动说明
同步任务从**单一长事务**改为**按年级拆分的独立子任务**：

| 维度 | 旧逻辑 | 新逻辑 |
| --- | --- | --- |
| 锁粒度 | 全局锁 `ai-edu:kg:sync:lock` | 细粒度锁 `ai-edu:kg:sync:lock:{edition}:{subject}:{stage}:{grade}` |
| 同步记录 | 一条全局记录 | 每个年级独立记录 |
| 失败影响 | 全量回滚 | 仅该年级失败，其他年级继续 |
| 对账范围 | 全量对账 | 仅对账当前年级范围 |


### 前端影响
+ 同步请求参数不变，后端自动按年级拆分执行
+ 返回结果新增年级统计字段：

```json
{
  "status": "success",
  "insertedCount": 100,
  "updatedCount": 20,
  "statusChangedCount": 5,
  "reconciliationStatus": "matched",
  "duration": 1234,
  "completedGrades": 3,
  "failedGrades": 0,
  "totalGrades": 3
}
```

## 二、同步历史记录接口改动
### 接口变更
```diff
- GET /api/auth/kg/sync/records?page=1&size=10
+ POST /api/auth/kg/sync/records
+ Body: { edition, subject, stage, grade, size }
```

### 请求参数
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| edition | String | 否 | 教材版本筛选 |
| subject | String | 否 | 学科筛选 |
| stage | String | 否 | 学段筛选 |
| grade | String | 否 | 年级筛选 |
| size | Integer | 否 | 返回数量，默认 10 |


### 请求示例
```json
POST /api/auth/kg/sync/records
{}

POST /api/auth/kg/sync/records
{
  "edition": "人教版",
  "subject": "math",
  "grade": "七年级",
  "size": 20
}
```

### 返回结构变化
```json
{
  "id": 1,
  "syncType": "full",
  "edition": "人教版",
  "subject": "math",
  "stage": "middle",
  "grade": "七年级",
  "status": "success",
  "insertedCount": 100,
  "updatedCount": 20,
  "statusChangedCount": 5,
  "reconciliationStatus": "matched",
  "startedAt": "2026-04-20T10:00:00",
  "finishedAt": "2026-04-20T10:05:00"
}
```

## 三、教材同步接口改动

```plain

```

{

## 四、年级查询接口改动
### 4.1 获取年级+教材URI列表
```diff
- GET /api/auth/kg/dimensions/grades
+ POST /api/auth/kg/dimensions/grades
+ Body: { edition, subject }
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| edition | String | 否 | 教材版本筛选 |
| subject | String | 否 | 学科筛选 |


**返回结构：**

```json
[
  { "grade": "一年级", "textbookUri": "uri:textbook:001" },
  { "grade": "二年级", "textbookUri": "uri:textbook:002" },
  { "grade": "七年级", "textbookUri": "uri:textbook:003" }
]
```

**请求示例：**

```json
// 查询所有年级+教材
POST /api/auth/kg/dimensions/grades
{}

// 按教材版本+学科筛选
POST /api/auth/kg/dimensions/grades
{
  "edition": "人教版",
  "subject": "math"
}
```

**使用说明：**

+ 返回的 `textbookUri` 可用于调用 `GET /api/kg/textbooks/{uri}/chapters` 获取章节树

### 4.2 获取学科下的年级列表
```diff
- GET /api/auth/kg/subjects/{subject}/grades
+ POST /api/auth/kg/subjects/grades
+ Body: { edition, subject }
```

## 六、前端联调要点
1. **同步历史列表**：改用 POST 请求，请求体传筛选参数
2. **显示维度信息**：历史记录列表需展示 edition/subject/grade 字段
3. **筛选功能**：可按教材/学科/年级筛选同步历史
4. **同步结果展示**：显示 completedGrades/failedGrades 统计
5. **年级下拉**：返回 grade + textbookUri，用 textbookUri 获取章节树
