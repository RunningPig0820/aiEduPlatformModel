## 一、定位

**引导问题源 + 评测集问题矿**——问题列表.md 是引导问题池（guide_pool）与 RAG 评测集（run_eval）的**问题来源**。与 4.完善文档（正文层）区别：正文层是"答案"，问题列表是"问题矿"——两者配套才构成完整的问答闭环。

```
问题列表.md（9 视角 ~60-70 问，纯问题）
   ├──▶ guide_pool（前端引导候选，intro/operation/data_relation/difficulty/rag 分组）
   └──▶ 评测集（run_eval 用问题，检查 RAG 能否答对）
        ↑ 答案检索源
   └──▶ 完善文档 1.0（全量池）+ 分析/坑 0.8（切片池）
```
