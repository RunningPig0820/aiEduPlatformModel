### 2. 学习报告总纲 + 掌握度子视图（题型明细 + 点题型展开派生知识点）

> 检索摘要：学习报告总纲（摘要卡）下挂掌握度（题型四类明细，点题型展开派生知识点）与知识点总览两视图，复用菜单学习报告占位。

学习报告为总纲（摘要卡：已掌握/练习中/待巩固/待确认 的**题型**计数），下挂「掌握度」（**题型**四类明细，点某题型展开它派生的知识点）与「知识点总览」（题型派生的全量知识地图）。

理由：摘要 + 明细 + 全图诉求不同，混一页会重；但「题型明细」与「题型→知识点」是同一维度的两层，合成一页（见 Decision 4）。菜单已有「学习报告」占位，翻 active 即接入。
