# 边界场景与兜底

> summary: 匹配不准确、小学缺失、OCR 准确率、API 成本的风险与缓解

> 类别：开发难点

本设计明确识别的边界场景与兜底（Risks）：

Risk 1 知识点匹配不准确：模糊匹配可能关联错误的知识点。缓解：输出匹配报告人工确认；记录匹配置信度，低置信度标记待确认；不自动导入，需人工确认。

Risk 2 小学知识点大量缺失：EduKG 没有小学知识点，需要手动创建。缓解：从课标提取小学知识点作为基准；对比报告标记缺失知识点；人工确认后手动导入。

Risk 3 OCR 识别准确率：课标 PDF 扫描质量影响 OCR 准确率。缓解：人工校验 OCR 结果；提取后人工整理知识点列表；不直接导入，先确认再入库。

Risk 4 API 调用成本：百度 OCR 收费、LLM API 费用。缓解：OCR 控制调用次数，使用免费额度或套餐；LLM 使用 glm-4-flash 免费；分批处理，记录进度。

边界场景总体设计原则：所有产出（匹配报告、对比报告、中间文件）均经人工确认后再入库，宁可慢而准，不自动写入低质量数据，且所有操作可回滚可调整。
