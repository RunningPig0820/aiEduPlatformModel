# 演进与未来

> summary: 三阶段实施路径与后续迭代方向

实施路径（三阶段）：阶段一 课标 OCR + 提取（先补全知识点）；阶段二 教材解析 + 匹配；阶段三 TTL 生成（可选），整合教材与课标知识点后人工确认导入 Neo4j。整体遵循"先补全小学、再匹配教材、最后可选生成 TTL"的演进顺序。

后续迭代方向（本期明确不做）：
- 作业切题功能：后续迭代实现。
- 学生学习状态跟踪：后续迭代实现。
- 多学科扩展：本期仅数学，后续支持物理、化学等其他学科。约束中明确"需要支持多学科扩展"，架构上通过 EduKG 的学科命名空间与通用导入脚本预留扩展能力。

数据治理演进：当前阶段为"不直接导入 Neo4j、人工确认后导入"，随数据质量稳定可逐步转向更自动化的导入链路；匹配报告、对比报告机制持续保留，作为追踪与回滚依据。
