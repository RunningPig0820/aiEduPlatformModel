> 检索摘要：EDUKG main.ttl 仅含高中教材标注 28,438 条，小学初中缺失；由教师之家网站补充人教版数学教材目录（小学 12 册、初中 6 册、高中必修选修），数据获取边界为仅数学、仅人教版、仅目录结构、不建前置关系。

**背景：EDUKG main.ttl 小学初中教材标注缺失**

EDUKG 知识图谱的 main.ttl 只包含高中教材标注数据（28,438 条），小学初中教材标注缺失。这导致图谱在小学、初中学段没有教材目录结构支撑，知识点无法与教材章节对应，是发起教材目录爬取的根本原因。

**数据来源：教师之家网站**

教师之家网站提供了完整的人教版数学教材目录，作为补充数据源。入口页面为 `https://www.renjiaoshe.com/renjiaoshuxue/`，包含小学、初中、高中三个学段的教材目录链接。该网站为静态页面，无需 JavaScript 渲染。

覆盖内容：
- 小学数学 1-6 年级（12 册）
- 初中数学 7-9 年级（6 册）
- 高中数学（必修+选修）
- 每册书的章节目录和知识点列表

**数据获取边界（Goals / Non-Goals）**

本爬虫的数据获取目标：
- 从教师之家爬取人教版数学教材目录（小学+初中+高中）
- 解析章节结构和知识点列表
- 生成与 main.ttl 兼容的 TTL 格式数据
- 输出 JSON 格式便于验证和分析

明确不做（Non-Goals）的边界：
- 不爬取课件、教案等具体内容（仅目录结构）
- 不爬取其他学科（仅数学）
- 不爬取其他版本教材（仅人教版）
- 不建立知识点前置关系（仅目录结构）

**数据可信度与治理**

- 教师之家为第三方资料网站，目录结构需人工核对，可信度低于 EDUKG 官方 TTL。
- 知识点命名可能存在不一致，需建立知识点标准化映射表治理（详见边界场景与兜底块）。
- 爬取产出以 JSON 与 TTL 双格式保存，JSON 供人工验证、TTL 供导入，形成数据来源可追溯、可校验的治理闭环。
