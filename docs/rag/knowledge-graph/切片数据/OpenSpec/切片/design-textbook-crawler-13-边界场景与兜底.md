> 检索摘要：教材目录爬虫的边界场景与兜底，覆盖网站结构变化、爬取频率过高被封禁、知识点命名不一致、页面解析失败四类风险，各有缓解措施（多 CSS 选择器容错、请求间隔与 User-Agent、标准化映射表、失败 URL 断点续爬）。

教材目录爬虫在数据抓取阶段的主要边界场景与兜底策略如下。

**风险一：网站结构变化导致爬虫失效**

触发：教师之家改版，页面 DOM 结构或链接层级变化，原有 CSS 选择器失效，爬虫拿不到章节或知识点。

处理与兜底：使用多种 CSS 选择器备选，增加容错；当某个选择器解析为空时自动尝试备选路径。

风险：若网站整体重构（入口 URL 变更、渲染方式改为 JS 动态加载），静态爬虫需人工介入改写解析逻辑。

**风险二：爬取频率过高被封禁（IP 封禁）**

触发：短时间高频请求触发网站反爬，IP 被临时或永久封禁，后续请求返回异常。

处理与兜底：添加请求间隔（1-2 秒），设置合理 User-Agent 模拟浏览器；必要时扩展代理池。

风险：仍可能被识别为爬虫，需人工观察并调整频率。

**风险三：知识点命名不一致**

触发：同一知识点在不同章节或册次中表述不同，或网站收录的命名与 EDUKG 标准命名不一致。

处理与兜底：建立知识点标准化映射表，爬取后统一映射到规范命名。

风险：映射表维护成本高，漏映射的知识点会保留原始命名，需人工抽查。

**风险四：页面解析失败**

触发：单个教材页面结构异常、网络超时、内容缺失导致解析抛异常。

处理与兜底：记录失败 URL，支持断点续爬（重跑时跳过已成功页面，只重试失败页面）。

风险：失败页面过多时爬取结果不完整，需在导入前校验章节数量完整性。
