# 4. 数据加载策略
> summary: 数据加载采用逐级懒加载+状态缓存，树展开时请求子节点、切换教材根清空缓存，详情数据选中实时请求不缓存。

> 检索摘要：数据加载采用逐级懒加载+状态缓存，树展开时请求子节点、切换教材根清空缓存，详情数据选中实时请求不缓存。

**逐级懒加载 + 状态缓存**

- 树节点展开时请求子节点列表，已展开的节点缓存子节点数据
- 缓存失效：切换教材根节点时清空缓存，避免陈旧数据
- 点击知识点节点时加载图谱关系数据
- 详情数据在节点选中时实时请求，不缓存（保证数据一致性）
