## 合并规则

1. 每份源文档只产它覆盖的主题块（不产空块）；同一主题跨多份源文档 → 各自文档内合并，不跨文档合并（文档独立性保持）。
2. 一块 = 该主题在该文档内的所有相关条目合并（决策+选型+场景+###），**去掉结构编号头**（D#/选型N/场景N/阶段N 作正文内容保留，不作文件名）。
3. 块命名：`{源文档前缀}-{主题编号}-{主题短名}.md`（语雀如 `语雀-06-知识点匹配与双模型投票.md`；OpenSpec 如 `design-kg-math-complete-graph-06-知识点匹配与双模型投票.md`），同主题跨文档块靠源文档前缀区分。
4. 每块带 检索摘要（业务向，模拟用户提问）+ 头部精简 5 行（summary/权威度/模块/COS路径/类别）+ 权威度（语雀 0.8 / OpenSpec 0.7）。
5. **块正文 ≤ ~5000 字符（全文向量化入桶约束）**：embed(summary+text) 超 5000 会被 dashscope 8192 token 静默截断 → 超长主题按子块拆 -2/-3（每子块仍自包含可独立检索）。
6. summary 短标题式 `{主题短名}`；机器元信息（entry_id/source_doc）由摄入时从文件名+状态+层配置推导，不在 md 头冗余。
7. 被结构切片（D#/### 一文件）的旧块：重切完成后由主会话清理。
