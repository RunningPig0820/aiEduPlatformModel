## 代码事实（机制视角）

### 关键机制：TextbookDataGenerator（教材 JSON → 标准节点/关系）

1. **文件发现**：小学 primary/grade1-6 上下册（12 册）、初中 middle/grade7-9 上下册（6 册）、高中 high/bixiu* 与 xuanxiu_bixiu* 的 textbook.json（5 册），共 23 册教材。
2. **教材节点**：label 用「学段名+年级+学期」（学期为未知则省略）；subject 硬编码"数学"。
3. **知识点过滤前置**：生成 TextbookKP 前先过滤非知识点条目（数学活动/小结/整理和复习/复习题/数学乐园等标记），从源头防污染图谱。
4. **TextbookKP URI 全局序号**：跨所有教材维护一个全局递增序号，生成 `textbook-{stage}-{seq:05d}` 形式的唯一 URI，不依赖语义名去重。
5. **关系生成**：生成 Textbook→Chapter + Chapter→Section 的 CONTAINS 关系（共 728 条）；IN_UNIT（TextbookKP→Section）在解析节时同步生成。
6. **输出**：一次全量生成写 6 个 JSON（textbooks/chapters/sections/textbook_kps/contains/in_unit）+ import_summary.json 统计；导入文件输出到教材目录根路径、中间文件留在 output/。
7. **缓存/增量**：生成教材/章节只产出对应节点，其余方法触发全量生成——方法间混用有 URI 序号从头计的碰撞风险。

### 关键机制：URIGenerator（v3.1 URI 编码与反向解析）

1. **ID 层级编码**：textbook_id = `{出版社}-{年级}{学期}`（如 renjiao-g1s）；chapter_id 追加 -order；section_id 再追加 -order，可读可解析。
2. **编码表**：年级 g1-g6/g7-g9/bixiu1-3/xbixiu1-3，学期上册=s 下册=x 高中空，出版社"人民教育出版社/人教版"→renjiao。
3. **URI 版本隔离**：统一前缀 `http://edukg.org/knowledge/3.1/{type}/math#{id}`，URI_VERSION="3.1" 避免与 EduKG v0.1/v0.2 冲突。
4. **反向解析**：按 `-` 拆 publisher/grade+semester，兼容 bixiu1 无学期形式。

### 关键机制：KPNormalizer（DeepSeek 单模型标准化知识点名）

1. **模型选择**：标准化只用 DeepSeek（副模型）单模型，注释"只用 DeepSeek，标准更严格"；不走双模型投票。
2. **流程**：教材知识点 → LLM 推断标准概念名（concepts 列表 + best_match）→ 供后续向量检索与匹配。
3. **缓存**：缓存键 = md5(知识点名_学段_年级)，同名同阶段同年级共享；原子写（临时文件 + 重命名）防并发损坏。
4. **并发防重**：异步锁 + 处理中集合防同 key 并发重复调用；等待超时 60s 仍处理中 → 返回原名称兜底。
5. **失败降级**：LLM 异常 → 返回原名称 + confidence 0.0 + reason，不中断批量；JSON 解析失败 → 空 concepts。
6. **批量并发**：默认并发 5（asyncio 并发 + CLI 可调），信号量限流避免打爆 LLM API。
7. **断点续传**：基于缓存目录实际文件判断已完成 URI，跳过已缓存只处理 pending；全缓存则直接加载写完整输出文件。

### 边界与降级

- 标准化 LLM 失败 → 返回原名称 + 置信度 0.0，不中断整批。
- 缓存文件损坏 → 日志告警后当未命中重新处理。
- 并发同 key 等待超时 60s → 放弃处理返回默认结果，避免重复 API 调用。
- 提示词模板文件不存在 → 抛 FileNotFoundError 显式暴露。
- 无 pending（全部已缓存）→ 直接加载缓存写完整输出。

## 设计要点

- **先过滤后建点**：非知识点条目（数学活动/小结/复习题）在生成节点前就用过滤器拦掉，防污染图谱。
- **序号化 URI 保证唯一**：TextbookKP 用全局递增序号 + 学段前缀，简单可靠，不依赖语义去重；结构节点用 publisher-grade-semester-order 层级编码可读可解析。
- **URI 版本隔离**：v3.1 前缀避免与 EduKG v0.1/v0.2 冲突，教材数据与权威语义层物理可分、逻辑上靠 MATCHES_KG 连接。
- **标准化用"更严格的 DeepSeek"**：用副模型单模型而非双模型——标准化是纯名称映射任务，单强模型足够且省一半调用。
- **缓存 + 原子写 + 断点续传**：LLM 标准化 10-20 分钟可中断恢复；原子写防并发损坏；处理中集合防同 key 并发重复 API 调用——LLM 长任务工程化的三件套。
- **批量并发限流**：并发度 5 控制，避免打爆 LLM API 限流。
