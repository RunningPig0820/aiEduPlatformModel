## 隐性坑与注意事项

- **final_prereq.json 没有生产方**：`infer_prerequisites.py` 只写 `llm_prereq.json`；`validate_dag.py` 默认读 `final_prereq.json`，但融合(fuse_results)未接入 CLI，**没有任何脚本产出 final_prereq.json**——直接跑 `validate_dag.py` 会 FileNotFoundError，需 `--input` 指定 llm_prereq.json 或先手动融合。
- **低阈值 0.6 形同虚设**：主链路 `_infer_pair` 只用 0.8 一个分界，`CONFIDENCE_THRESHOLD_LOW=0.6` 只在未被调用的 `vote_prerequisite()` 里生效；README/语雀口径"<0.6 丢弃"在代码主链路不存在。
- **候选对数量与成本估算严重不符**：`generate_kp_pairs` 实际产 ~10N 对，`estimate_inference_cost` 按 2N 对估算（`prerequisite_inferer.py:350`），成本预估偏低约 5 倍。
- **断点续传未落地**：design（D5/D11）要求 `--resume` + llmTaskLock（TaskState/CachedLLM/ProcessLock），但 `infer_prerequisites.py` 参数只有 `--dry-run/--batch-size/--stats`，无 `--resume`；`PrerequisiteInferer.infer_batch` 签名无 resume 参数。推断中途失败需重跑（成本虽低）。
- **年级倒置惩罚未实现**：语雀 D10 的 ×0.95/0.9/0.5/0.3 惩罚在代码中搜不到（validate_dag 无年级倒置检测）——方案有、代码无。
- **投票不一致的加权路径会放大误判**：只要 DeepSeek=True 且 GLM=False，加权 0.6≥0.5 就采纳为 PREREQUISITE，与 D7 语雀"两模型一致才采纳"口径不符（代码实际允许 DS 一票通过）。
- **模拟模式静默**：无网关时返回全 True+0.8 的假数据，跑完整流程不报错，容易把假前置导入。

## 对账要点（复盘）

### 方案 vs 实现

- **投票规则**：语雀/design 口径"两模型一致才采纳；≥0.8→PREREQUISITE、≥0.6→CANDIDATE、不一致不采纳" → 实际落地主链路 `_infer_pair` 只用 0.8 一个分界（`prerequisite_inferer.py:127`），不一致走加权投票（DS=0.6/GLM=0.4×0.7）可采纳，0.6 阈值仅在未被调用的方法中。**⚠️翻转：投票从"一致才采纳+0.6/0.8 双阈值"改为"主链路 0.8 单分界+不一致 DS 加权可采纳"。**
- **年级倒置惩罚**：语雀 D10 方案 ×0.95/0.9/0.5/0.3 惩罚、<0.6 降级候选 → 实际代码中无任何年级/学段惩罚逻辑。**⚠️方案有/代码无：年级倒置惩罚未实现。**
- **断点续传 --resume**：design D5/D11 要求 llmTaskLock + `--resume` → 实际 CLI 无 `--resume` 参数，`infer_batch` 无 resume 参数。**⚠️方案有/代码无：断点续传未落地，中途失败需重跑。**
- **三来源融合**：D9 要求教材顺序+定义依赖+LLM 多证据融合出 final_prereq.json → 实际 `fuse_results` 方法存在（`prerequisite_inferer.py:261-336`），但 CLI 只产 llm_prereq.json、从不调融合。**⚠️半落地：三来源融合方法已实现但未接入 CLI，final_prereq.json 无生产方。**
- **TEACHES_BEFORE≠PREREQUISITE**：D8 要求严格区分 → 实际 `infer_from_textbook_order` 仅限章节内按小节顺序产 TEACHES_BEFORE（conf=1.0，source=textbook_order），LLM 投票产 PREREQUISITE。**✅落地：TEACHES_BEFORE 与 PREREQUISITE 严格区分（但未接入主流程）。**

### 接口契约

- **DAG 默认输入**：validate_dag 默认读 `final_prereq.json` → 实际无任何脚本产出该文件，直接跑会 FileNotFoundError 退出码 1，需 `--input` 指定。**⚠️契约断裂：DAG 默认输入文件无生产方。**

### 注释 vs 运行行为

- **generate_kp_pairs**：注释自称"简化版本，应基于启发式规则筛选候选对" → 实际运行就是 label 排序前后±5 邻居配对（`infer_prerequisites.py:110-125`）。**✅注释如实：简化版本即实际实现。**
- **成本估算**：注释假设"每个知识点平均 2 个潜在前置" → 实际配对 ~10N，`estimate_inference_cost` 按 2N 估算（`prerequisite_inferer.py:350`）。**⚠️估算失真：成本预估偏低约 5 倍。**
