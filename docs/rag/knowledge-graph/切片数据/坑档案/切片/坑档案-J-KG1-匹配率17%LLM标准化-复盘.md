## 坑点复盘
**现象**：教材知识点到图谱知识点的匹配率只有 17%——1350 个教材知识点仅 229 个匹配成功，83% 未匹配，图谱页面上大量知识点「点不亮」。

**触发链路**：匹配脚本把教材知识点逐条与图谱概念做匹配——先精确匹配，失败进 LLM 双模型投票；而图谱概念几乎全是函数/方程这类抽象数学概念，小学的"1-5的认识""连加连减"这类具体知识点几乎没有对应概念。

**根因**：语义颗粒度错位——教材知识点贴近教学场景，图谱概念是抽象数学概念，两者不在同一语义空间；直接用原始教材名去检索/投票，精确匹配命中率低，LLM 投票也因为输入名太"教学化"而大量否决。

**解决思路与权衡**：引入 LLM 标准化预处理——先用 LLM 把教材名推断为抽象概念列表 + 最优匹配（"1-5的认识"→"自然数"），再用标准名去做向量检索和双模型投票，匹配率从 17% 提到 97%。标准化本身有成本，所以标准化结果走缓存，避免重复计算。

## 面试口述要点
匹配率瓶颈不在"投票模型不强"，而在输入与候选的语义空间不一致。先用 LLM 做名称标准化、把教学名映射到概念名，是性价比最高的提点手段；匹配率 17%→97% 的关键是"把教材名翻译成图谱语言"再匹配，而不是盲目加模型。
