## 坑点复盘
**现象**：教材目录 JSON 里小学 3-6 年级知识点全空、高中必修也仅剩"综合测试"标记，只有初中 7-9 年级 252 个较完整——教材图谱小学/高中学段"没有知识点可挂"。

**触发链路**：解析教材 JSON 生成章节后，发现小学 1-6 与高中大量小节的已有知识点为空，脚本分析出 295 个缺失章节，逐章节调 LLM 推断。

**根因**：上游教材数据源不完整——人教版教材 JSON 本身没标注知识点，小学/高中尤其缺（小学 3-6 与高中必修为 0 个），不是解析 bug，是源数据没有知识点这一列。

**解决思路与权衡**：用双模型投票的 LLM 推断补全——两模型都输出才采纳、取主模型结果，给每条带置信度供下游过滤；缺失 295 个章节推断出 1052 个知识点，平均置信度 0.93，再合并回主文件并重生成归属关系。

## 面试口述要点
遇到"数据缺一半"先分层定位——是解析丢了、还是源数据就没有（本项目是后者）。LLM 补数据要用双模型投票降低幻觉（两模型一致才采纳），并给每条带置信度供下游过滤。推断类任务天然要接断点续传，否则两三小时的任务中断就全废。
