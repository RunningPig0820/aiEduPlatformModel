## 坑点复盘
**现象**：教学知识点推断预估 2-3 小时、图谱匹配 1-2 小时，中途断网或进程被杀后从头重跑，已花的 LLM 费用和进度全丢。

**触发链路**：长任务运行中被中断（网络/超时/手动 Ctrl-C）→ 重启脚本发现又是从 0 开始。

**根因**：修前任务无状态——每批循环都是临时变量，LLM 调用结果既不落盘进度也不缓存；长任务天然易中断，中断即全损。

**解决思路与权衡**：集成三件套：进度检查点（每完成一个单位即落盘、粒度越细丢得越少，重启后从检查点恢复）、结果缓存（同一 prompt 的投票结果缓存，相同知识点对不重复调 API）、进程锁（串行模式防多进程并发写同一进度）。状态写入用临时文件 + rename 原子写 + 备份，防止中断那一下把状态文件写坏。

## 面试口述要点
长 LLM 任务的三层防护：进度检查点、结果缓存、进程锁。写进度要原子（tmp+rename），否则中断正好把状态文件写坏。缓存键用 prompt 全文 MD5，保证"同一知识点对 + 同一候选"才命中，语义变了不误命中——避免为重复计算花二次 LLM 费用。
