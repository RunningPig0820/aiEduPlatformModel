# 切片数据 / 引导问题

> 来源：`7. 引导问题/问题列表.md`（9 视角 ~60-70 问，纯问题不回答）
> 切片方式：**一问题一文件**逐问作答（问题列表=问题矿，问答切片=答案库）。

## 一、源头（语料就绪）

- 问题矿：`7. 引导问题/问题列表.md`（9 视角，每条带 `<!--tag:{视角}-->` 标签）
- 生成提示词：`7. 引导问题/处理方案/提示词/问题列表-生成-提示词.md`

## 二、切片（提示词 + 大模型逐问作答）

- 每问 1 文件：`引导问题-{编号}-{视角}-{问题短名}.md`，标题 = 问题原文，正文 = 可直接照讲的答案
- **防编造第一铁律**：只答语料里有的，语料未实现/未做的如实写"本期未实现 / 不做（Non-Goal）"；参考语料缺答案 → 写明"当前参考语料未覆盖该问题"不编造
- 答案来源按视角映射（完善文档 1.0 + 分析/坑档案 0.8 + 语雀 0.8），口径对齐 3.代码/坑档案 > 语雀/design
- 证据标注精确到编号：每个要点末尾标 `（依据：完善文档 01 / 分析-06 / 坑档案 J-KG#）`

- 权威度 1.0（**合成问答答案切片**——指"直接作答"，不是原始证据；原始证据文档权威度 0.8，勿混淆）
