# 小学/高中教材没有知识点，这些缺失的知识点是怎么补的？

> summary: 操作流程引导问题回答：源数据本身知识点字段为空（小学 3-6 全空、高中必修仅"综合测试"），用 TextbookKPInferer 双模型投票（GLM-4-flash 主+deepseek-chat 副）按章节 LLM 推断补齐——缺失 295 节→补 1052 条、平均置信 0.93，source=llm_inferred 标记合并回主文件

**核心结论**：源数据本身知识点字段为空（不是解析 bug），用 TextbookKPInferer 双模型投票（GLM-4-flash 主 + deepseek-chat 副）按章节 LLM 推断补齐——缺失 295 节→推断 1052 条、平均置信 0.93，`source=llm_inferred` 标记合并回主文件。

## 分层展开
- **缺在哪**：人教版教材 JSON 未标注知识点，小学 1-6 与高中必修整片空白（小学 3-6 年级 `knowledge_points` 全空、高中必修仅"综合测试"标记），初中 252 个较完整——不是解析 bug，是源数据本身没有知识点列（依据：坑档案 J-KG4）
- **怎么判定**：`infer_textbook_kp.py` 的 `analyze_missing_kps` 判定 `need_infer = len(existing_kps)==0`，分析出 295 个缺失章节（依据：坑档案 J-KG4）
- **怎么补**：TextbookKPInferer 双模型投票——两模型都有输出才采纳、取主模型 GLM 结果、置信度取平均；llmTaskLock 每 10 节存检查点断点续传（依据：完善文档 02 落地真相表 / 坑档案 J-KG4）
- **产出与合并**：缺失 295 章节→推断 1052 知识点、平均置信 0.93（落地真相表口径 433 节→1616 条、平均置信 0.934）；`merge_inferred_kps.py` 合并回 textbook_kps.json 并重生成 IN_UNIT 关系（依据：完善文档 02 / 坑档案 J-KG4）
- **防编造机制**：双模型都有输出才采纳、每条带 confidence、断点续传可回溯、`source=llm_inferred` 标记（依据：引导问题.md 操作流程）

## 追问防御
- **可能追问：补的是不是编的？** → 双模型都有输出才采纳、带 confidence、断点续传可回溯、`source=llm_inferred` 标记；推断任务接 llmTaskLock 断点续传，2-3 小时任务中断不废（依据：引导问题.md 操作流程 / 坑档案 J-KG4 口述要点）
- **可能追问：LLM 推断会不会幻觉？** → 用双模型投票降低幻觉（两模型一致才采纳），每条带 confidence 供下游过滤；这是推断类任务的标配手段（依据：坑档案 J-KG4 口述要点）
