# 教材里的年级信息是怎么来的？数据里自带吗？

> summary: 操作流程引导问题回答：数据不自带，靠教材→年级映射表 TEXTBOOK_TO_GRADE 反推（"必修第一册"→高一、"七年级上册"→初一），STAGE_FALLBACK 学段兜底，mark 字段兼容解析小节序号

> 类别：操作流程

**核心结论**：数据不自带，靠教材→年级映射表 `TEXTBOOK_TO_GRADE` 反推（"必修第一册"→高一、"七年级上册"→初一）为主，学段 `STAGE_FALLBACK` 反向推断兜底，`mark` 字段（`6.2.1`/`6-2-1`/`第六章第二节`）兼容解析小节序号。

## 分层展开
- **非自带**：年级不是数据里带的，是**教材→年级映射表反推**出来的（依据：完善文档 02 追问与防御 / 引导问题.md 操作流程）
- **映射表为主**：`TEXTBOOK_TO_GRADE` 显式可维护（"必修第一册"→高一、"七年级上册"→初一）（依据：完善文档 02 关键设计 / 追问与防御）
- **学段兜底**：`STAGE_FALLBACK` 反向推断只在映射表外生效（依据：完善文档 02 追问与防御）
- **mark 字段兼容**：`mark` 字段兼容解析小节序号（`6.2.1`/`6-2-1`/`第六章第二节`）（依据：完善文档 02 关键设计）
- **落地一致**：设计口径如此，落地一致（依据：完善文档 02 追问与防御）

## 追问防御
- **可能追问：反推错怎么办？** → 映射表是显式可维护的，学段兜底只在表外生效；映射表记录可审计（依据：引导问题.md 操作流程 / 完善文档 02 追问与防御）
- **可能追问：教材版本不同年级一样吗？** → 本期只做人教版数学，映射表按人教版教材名配置；多版本教材（北师大/苏教版）是设计 D13 记录的本期不实现项（依据：完善文档 02 / 引导问题.md 未来演进）
