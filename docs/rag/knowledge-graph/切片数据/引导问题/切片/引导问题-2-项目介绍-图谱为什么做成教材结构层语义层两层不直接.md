# 图谱为什么做成"教材结构层 + 语义层"两层，不直接合成一张大图？

> summary: 项目介绍引导问题回答：三来源（教材/EduKG/课标）名称对不上、颗粒度错位，合成一张图会互相污染；两层分存 + MATCHES_KG 软连接，各答各的问题又互不影响
> 权威度: 1.0（合成问答答案切片，非原始证据）
> 模块: knowledge-graph
> COS路径: rag-slices/knowledge-graph/引导问题/引导问题-2-项目介绍-图谱为什么做成教材结构层语义层两层不直接.md
> 类别：项目介绍

**核心结论**：因为人教教材、EduKG 开源概念、课标三来源分散异构、名称对不上、颗粒度错位，直接合成一张图会互相污染；两层分存 + 软连接既能各答各的问题，又互不影响。

## 分层展开
- **来源异构**：教材给教学结构（"1-5 的认识"），EduKG 给抽象概念（"自然数"），两者名称对不上、颗粒度错位；早期曾考虑简单标签打标/关系库直存，已演进为两层图谱方案（依据：完善文档 01 为什么）
- **各答各的问题**：结构层回答"课程长什么样、知识点挂在哪"，语义层回答"概念是什么、概念间怎么关联"（依据：完善文档 01 两层图谱结构）
- **为什么不合成**：教材结构层是逐年可增的业务事实，语义层是有限的权威概念，强行合一会导致任意一层变化污染另一层——核心哲学是"无限的业务事实与有限的权威结构分存"（依据：完善文档 01 / 分析-01 设计要点）
- **连接方式**：两层靠 MATCHES_KG 软连接（TextbookKP→Concept，方向固定、置信度≥0.5 才连），互不污染（依据：完善文档 01 / 分析-01）

## 追问防御
- **可能追问：两层会不会对不上？** → 两层分存靠 MATCHES_KG 软连接，方向固定、置信度≥0.5 才连，任意一层变化不污染另一层（依据：引导问题.md 项目介绍可能防御）
- **可能追问：TTL 和教材数据怎么合一？** → 不合一，两层分存 + MATCHES_KG 软连接：TTL（v0.1）建语义层，教材（v3.1 URI）建结构层，URI 版本化（v0.1/v0.2/v3.1）区分来源，互不污染（依据：完善文档 02 追问与防御）
