# 两层结构是靠什么连起来的？"软连接"是什么意思，为什么互不污染？

**核心结论**：靠 MATCHES_KG 匹配关系连接（TextbookKP→Concept，1690 条，置信度≥0.5）；"软连接"指两层用一条可审计的匹配边连接而不是合并存储，任何一层变化不强制另一层跟着变，物理分存互不污染。

## 分层展开
- **连接关系**：MATCHES_KG 方向固定 TextbookKP→Concept（不可逆），置信度≥0.5 才连边；两层靠它连接（依据：完善文档 01 / 分析-01）
- **软连接含义**：两层不强行合一、不共享一张大图，各自独立演进，只通过匹配关系连接；连接链路是"标准化精确匹配 + 向量粗筛 top-20 + 双模型投票"（依据：完善文档 01 两层图谱结构 / 追问与防御）
- **互不污染**：教材结构层是逐年可增的业务事实、语义层是有限的权威概念，两层分存使任意一层变化不污染另一层；这也支撑"权威图谱零写入"（依据：完善文档 01 / 完善文档 02 追问与防御）
- **内部连接约束**：结构层内部 TextbookKP 有且仅有一个 IN_UNIT 指向 Section；语义层内部靠 RELATED_TO/HAS_TYPE 等关联（依据：完善文档 01 追问与防御 / 分析-01）

## 追问防御
- **可能追问：连接会不会连错？** → MATCHES_KG 有置信度门槛（≥0.5 才连、投票 <0.7 丢弃）、方向固定不可逆、未匹配不硬连留 candidate_review，是保守连接（依据：引导问题.md 数据关联 / 完善文档 02）
- **可能追问：一层改了另一层怎么办？** → 两层物理分存互不污染，改结构层只需重跑该层与匹配，语义层权威冻结只读不动（依据：完善文档 01 / 引导问题.md）
