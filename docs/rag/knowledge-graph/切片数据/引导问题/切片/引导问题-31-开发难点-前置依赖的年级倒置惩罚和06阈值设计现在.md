# 前置依赖的"年级倒置惩罚"和 0.6 阈值设计现在落地了吗？
> summary: 开发难点引导问题回答：都没有——年级倒置惩罚（×0.95/0.9/0.5/0.3）在代码中搜不到是设计质量目标非现状；0.6 低阈值只在未调用的 vote_prerequisite() 里，主链路实际只有 0.8 一个分界

> 类别：开发难点

**核心结论**：都没有落地。**年级倒置惩罚**（×0.95/0.9/0.5/0.3 跨年级惩罚）在代码中搜不到，是设计质量目标非现状；**0.6 阈值**只在未被主链路调用的 `vote_prerequisite()` 方法里，形同虚设——主链路 `_infer_pair` 实际只有 confidence≥0.8 一个分界。

## 分层展开
- **年级倒置惩罚（设计口径）**：前置年级 > 目标年级时按跨度乘惩罚系数——相邻 ×0.95 / 跨 1 学段 ×0.9 / 跨 2 学段 ×0.5 / 跨度太大 ×0.3；惩罚后 <0.6 降级 PREREQUISITE_CANDIDATE；质量目标年级倒置率 ≤5%（依据：完善文档 06）。
- **落地真相（方案有/代码无）**：×0.95/0.9/0.5/0.3 跨年级惩罚在代码中搜不到，validate_dag 也无年级倒置检测——"惩罚后 <0.6 降级候选、倒置率 ≤5%"是设计质量目标非现状（依据：完善文档 06 / 分析-08）。
- **0.6 阈值（设计口径）**：config.CONFIDENCE_THRESHOLD_LOW=0.6 + vote_prerequisite() 方法（≥0.8→PREREQUISITE、≥0.6→CANDIDATE、<0.6→None）确实存在（依据：分析-08 / 完善文档 06）。
- **落地真相（0.6 形同虚设）**：主链路 `_infer_pair` 只用 confidence≥0.8 一个分界，0.6 低阈值从未被 infer_batch 主链路调用——README/语雀口径"<0.6 丢弃"在主链路不存在（依据：分析-08 / 完善文档 06）。
- **同类未落地项**：三来源融合未接入主链路、final_prereq.json 无生产方、断点续传 --resume 未落地——面试要如实区分设计口径 vs 落地现状（依据：完善文档 06 / 分析-08）。

## 追问防御
- **可能追问：那低置信前置怎么处理？** → <0.8 不丢弃，落 PREREQUISITE_CANDIDATE 保留待人工补审；投票不一致不采纳（但加权路径 DS=True 可一票通过，置信×0.7 打折）（依据：完善文档 06）。
- **可能追问：倒置率≤5% 达标了吗？** → 无代码检测年级倒置，无数据支撑——这是质量目标非现状，要如实讲（依据：完善文档 06 / 分析-08）。
- **可能追问：这些设计项是不是没做完？** → 如实讲是设计目标非落地现状：年级倒置惩罚代码不存在、0.6 阈值未接入主链路、三来源融合未接、评审未上线——讲清方案与现状边界本身就是可信度（依据：引导问题.md 9 / 完善文档 06）。
