# 家长报表和掌握度是什么关系？图谱价值怎么落到家长端？

**核心结论**：家长报表是掌握度/薄弱点的消费端展示——答疑记录回流支撑报表，让图谱价值可感知；报表读 MySQL 派生数据，不直读权威图。

## 分层展开
- **报表与掌握度的关系**：家长报表 = 掌握度 + 薄弱点汇总展示；答疑记录回流支撑报表数据。（依据：完善文档 09）
- **价值落点**：家长报表是图谱价值在家长端的落点——掌握度/薄弱点以可读形式呈现，让"孩子会不会"有依据、可感知。（依据：完善文档 09 / 引导问题.md §7）
- **数据来源**：报表展示的是 MySQL 派生数据（掌握度/薄弱点），不是直读权威图——配合"权威图谱零写入"，派生信号只存 MySQL。（依据：完善文档 09）
- **闭环位置**：家长报表是消费闭环的最终一环——前面的答疑点亮（吃 MATCHES_KG）、掌握度（吃 PREREQUISITE+RELATED_TO）、学习路径（吃 PREREQUISITE）三个消费环真实消费图谱关系，报表是最终展示面。（依据：完善文档 09）
- **⚠️ 落地边界**：掌握度主体翻转（题型 topic_key）、报表口径等属 Java 侧 design（D16/D17），Java/前端代码不在本仓，分析-11 明确"非代码真值"，只能以 design 口径引用。（依据：完善文档 09 / 分析-11）

## 追问防御
- **可能追问：报表数据从哪来？** → 消费端展示 MySQL 派生数据，不是直读权威图——掌握度/薄弱点只存 MySQL，权威图谱零写入。（依据：完善文档 09）
- **可能追问：图谱是不是只是展示？** → 不是——报表是消费闭环的最后一环，答疑点亮、掌握度前置链诊断、学习路径补课顺序三个消费环都真实消费图谱关系，页面化/报表只是消费面之一。（依据：完善文档 09）
- **可能追问：报表的掌握度可信吗？** → 掌握度事件驱动可追溯（错题→知识点→前置链→正确率/次数），前置依赖带置信度与 reason，非拍脑袋。（依据：引导问题.md §7 / 完善文档 09）
