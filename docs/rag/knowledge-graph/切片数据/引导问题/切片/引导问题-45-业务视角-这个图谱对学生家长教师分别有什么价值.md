# 这个图谱对学生、家长、教师分别有什么价值？

**核心结论**：学生受益于答疑时定位知识点 + 沿前置链做前置回顾；家长看掌握度 + 薄弱点报表；教师/教研页面化浏览知识体系——三端在消费闭环上各取所需。

## 分层展开
- **学生**：答疑时定位"这个题考哪个知识点、这个知识点前置是什么"，沿前置链做前置回顾与引导——这是图谱支撑答疑/学习路径的核心价值。（依据：完善文档 01 / 引导问题.md §7）
- **家长**：通过掌握度 + 薄弱点报表了解孩子"知识点到底会不会"，让结论有依据、可感知。（依据：完善文档 09 / 引导问题.md §7）
- **教师/教研**：页面化浏览知识体系——教材→章→节→知识点逐级下钻、查看知识点关联图与详情，做教学教研参考。（依据：分析-11 / 引导问题.md §7）
- **底座能力**：两层图谱（教材结构层 + 语义层，MATCHES_KG 软连接）是答疑/掌握度/学习路径的知识底座，不是一张扁平标签表。（依据：完善文档 01）
- **落地边界**：学生答疑/家长报表/教师看结构三个消费环节分别落点；Python 桥部分可核验，Java 侧消费按 design 口径如实标注（非代码真值）。（依据：完善文档 09 / 分析-11）

## 追问防御
- **可能追问：三个角色谁最受益？** → 消费闭环上各取所需——学生答疑定位+前置回顾、家长看掌握度报表、教师看知识结构，没有单点受益，是一个知识底座服务三个角色。（依据：引导问题.md §7 / 完善文档 09）
- **可能追问：价值能证明吗？** → 三层证据：①数据真值（6757 节点/20887 关系/匹配率~97%）；②消费闭环（答疑点亮、掌握度、学习路径三个消费环真实吃图谱关系）；③如实防御（方案与现状边界讲清）。（依据：完善文档 09）
- **可能追问：教师真的在用页面吗？** → 页面化方案 B 已拍板但 Java/前端代码不在本仓，属"联调收口"状态，不能讲成已上线——按 design 口径如实标注。（依据：完善文档 03 / 分析-11）
