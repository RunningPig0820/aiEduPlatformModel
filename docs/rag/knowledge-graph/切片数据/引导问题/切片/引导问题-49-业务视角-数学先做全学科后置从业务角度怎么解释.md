# 数学先做、全学科后置，从业务角度怎么解释？

> summary: 业务视角引导问题回答：数学结构化程度最高(教材层级清晰、初中JSON完整可作调试基线)、EduKG语义层覆盖好、K-12刚需；匹配率17%→97%的坑都在数学踩完，扩学科复用同一管道风险更低

> 类别：业务视角

**核心结论**：数学先做是因为数学结构化程度最高（教材层级清晰、初中 JSON 完整可作调试基线）、EduKG 语义层覆盖好、K-12 刚需；匹配率 17%→97% 的坑已在数学踩完，扩学科复用同一管道风险更低，全学科后置是成本/优先级排序的结果。

## 分层展开
- **数学结构化程度最高**：数学教材层级清晰（小学 12 册/初中 6 册/高中人教 A 版 5 册），初中 7-9 年级 JSON 知识点较完整可作调试基线；小学/高中缺失用 LLM 双模型补 1052 个。（依据：坑档案 J-KG4 / 完善文档 01）
- **EduKG 语义层覆盖好**：EduKG 开源概念对数学覆盖最完整（Concept 1295/Statement 2932/Class 39），数学是图谱落地性价比最高的学科。（依据：完善文档 01 / 分析-01）
- **K-12 刚需**：数学是 K-12 核心学科，答疑/掌握度/学习路径的消费闭环最能体现价值。（依据：引导问题.md §7）
- **坑已在数学踩完**：匹配率 17%→97% 的坑（小学教学名 vs 抽象概念语义错位、LLM 标准化预处理、向量粗筛 top-20、双模型投票）全在数学踩完并沉淀为可复用管道——扩学科复用同一管道风险更低。（依据：坑档案 J-KG1 / 引导问题.md §7）
- **全学科后置**：全学科 56,391 知识点、成本/优先级未定；管道 Phase0-3 与学科无关，扩学科只需跑同一管道 + v3.2 URI 前缀 + 课标基准——数学已提供可复制的范式，后置是业务优先级而非技术不可行。（依据：引导问题.md §9）
- **Non-Goal（方案边界）**：本期仅数学学科，全学科扩展是刻意不做（Non-Goal），不是已实现能力。（依据：完善文档 01）

## 追问防御
- **可能追问：扩学科风险大吗？** → 匹配率 17%→97% 的坑都在数学踩完（语义错位/标准化/粗筛/双模型），扩学科复用同一管道风险更低。（依据：坑档案 J-KG1 / 引导问题.md §7）
- **可能追问：为什么不是一次做齐？** → 全学科知识点量大（56,391）、成本/优先级未定；数学已提供可复制的管道范式，先做高价值、后做长尾是合理的业务排序。（依据：引导问题.md §9）
- **可能追问：数学先做会不会让图谱价值受限？** → 数学是 K-12 刚需且结构化最高，先做数学能让答疑/掌握度/学习路径闭环先跑通，验证后再横向复制。（依据：引导问题.md §7）
