## 分层展开
- **来源逐类可讲**：6757 节点 = Textbook 23 / Chapter 148 / Section 580 / TextbookKP 1740 / Concept 1295 / Statement 2932 / Class 39；来自 EduKG 开源 TTL（v0.1）+ 小学新增（v0.2）+ 人教版爬虫 23 册教材（v3.1）+ 课标 2022，URI 版本化区分来源，每类节点都能讲清出处。（依据：完善文档 01 / 分析-01）
- **自建管道**：Phase0 爬取 → Phase1 生成/清洗/增强/LLM 推断 → Phase2 匹配 → Phase3 导入 → 校验；小学/高中缺失知识点是 LLM 双模型推断补的 1052 个（平均置信 0.93，source=llm_inferred 标记）。（依据：完善文档 01 / 坑档案 J-KG4）
- **质量背书**：匹配率 17%→~97%（精确+向量粗筛 top-20+双模型投票）；匹配率口径要讲清——97.1%（1690/1740 早期里程碑）vs 当前数据文件 96.96%（1905 基线、平均置信 0.973），对外讲"~97%"准确；置信度 0.975、URI 唯一 100%。（依据：完善文档 01 / 坑档案 J-KG1 / 分析-01）
- **可回溯**：断点续传（llmTaskLock 三件套：TaskState 检查点 + CachedLLM SHA256 缓存 + ProcessLock 进程锁）、校验脚本（verify_import 查重复 URI/无类型/版本分布）、导入日志均可回溯。（依据：坑档案 J-KG8 / 分析-10）
- **如实防御**：讲清方案与现状边界（前置融合未接主链路、匹配评审审核未上线、Java 侧非本仓）本身就是可信度——不夸大已实现范围。（依据：完善文档 09 / 引导问题.md §7）

## 追问防御
- **可能追问：匹配率 97.1% 是真的吗？** → 口径讲清：97.1% 是 1690/1740 早期里程碑快照，当前数据文件 1905 条基线匹配率 96.96%、平均置信 0.973——对外讲"~97%"准确，精确数字要带基线。（依据：引导问题.md §9 / 完善文档 01）

- **可能追问：数据来源可信吗？** → EduKG 是清华学术开源（官方 SPARQL）+ 人教版教材基准 + 课标 OCR+人工，四类来源各有背书，匹配率 ~97% 是质量答卷。（依据：引导问题.md §2）
