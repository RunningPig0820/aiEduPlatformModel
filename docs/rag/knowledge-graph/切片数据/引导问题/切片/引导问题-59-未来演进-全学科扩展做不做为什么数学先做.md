# 全学科扩展做不做？为什么数学先做？
> summary: 未来演进引导问题回答：做，逐学科按优先级（数理化生 P1/语言 P2/主题 P3）不是本期；数学先做因为结构化程度最高、EduKG 覆盖好、K-12 刚需，且 17%→97% 的坑都在数学踩完，扩学科复用同一管道风险更低

**核心结论**：全学科扩展**做，但是逐学科按优先级演进**（数理化生 P1/语言 P2/主题 P3），不是本期；数学先做因为数学结构化程度最高（教材层级清晰、人教版 JSON 初中完整可作调试基线）、EduKG 语义层覆盖好、是 K-12 刚需，且匹配率 17%→97% 的坑（LLM 标准化/向量粗筛/双模型投票）都在数学踩完，扩学科复用同一管道风险更低。

## 分层展开
- **做，但逐学科**：管道 Phase0-3 与学科无关，扩学科只需跑同一管道 + v3.2 URI 前缀 + 课标 2022/2017 层级基准（依据：完善文档 08）。
- **数学先做的原因**：数学结构化程度最高（教材层级清晰、人教版 JSON 初中完整可作管道调试基线）、EduKG 语义层对数学概念覆盖好（1295 Concept）、K-12 刚需（依据：完善文档 08 / 引导问题.md 7）。
- **规模对比**：全学科 56,391 知识点 vs 数学约 1,740-1,905 个；逐学科成本估算 10-20 元、DeepSeek 调用约 1120 次，导入优先级未定（依据：完善文档 08）。
- **风险**：各学科名称颗粒度不同、匹配率难复制；数学已踩完 17%→97% 的坑，扩学科复用同一管道风险更低（依据：完善文档 08）。
- **落地边界**：全学科扩展是 Non-Goal，任何一节不得描述成已实现功能——只在方案演进口径出现（依据：完善文档 08）。

## 追问防御
- **可能追问：为什么不是一次做齐？** → 全学科规模大（56,391 知识点）、成本/优先级未定；MVP 先做数学验证"两层图谱 + MATCHES_KG + 学习路径"可行性，再横向复制到理化生（依据：完善文档 08）。
- **可能追问：扩学科匹配率能复制吗？** → 管道通用但各学科颗粒度不同，匹配率难复制是显式风险；数学把 LLM 标准化/向量粗筛/双模型投票的坑都踩完，扩学科复用同一管道（依据：完善文档 08）。
- **可能追问：扩学科需要什么前置？** → 课标 2022/2017 层级基准 + 多学科导入优先级 + 新学科 v3.2 URI 前缀（依据：完善文档 08）。
