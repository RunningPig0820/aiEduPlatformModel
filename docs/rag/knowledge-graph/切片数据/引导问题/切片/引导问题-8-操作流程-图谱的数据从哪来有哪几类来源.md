# 图谱的数据从哪来？有哪几类来源？

**核心结论**：四类来源：EduKG TTL（v0.1 语义层）、main.ttl（v3.0 教材出处）、人教版爬虫 23 册教材 JSON、课标 2022（OCR 补小学）；同一领域数据散在四个独立数据集，ontology 版本不同、小学/高中知识点还整片空白。

## 分层展开
- **EduKG TTL v0.1**：语义层 Concept/Statement/Class，来自清华 THU-KEG 学术开源（官方 SPARQL 端点）（依据：完善文档 02 为什么 / 追问与防御）
- **main.ttl v3.0**：教材出处，约 16MB（依据：完善文档 02 主流程 / 分析-02）
- **人教版爬虫**：23 册教材 JSON（小学 12 + 初中 6 + 高中人教 A 版 2019 5），Phase0 爬取教师之家（依据：完善文档 02 / 分析-01）
- **课标 2022**：OCR 补小学（依据：完善文档 02 为什么）
- **数据源可信背书**：四层来源各有背书——EduKG 学术开源 + 官方 SPARQL、main.ttl 教材基准、爬虫目录经课标对齐校验、课标小学 OCR+人工；一条铁律：权威基准 TTL 冻结只读，业务派生数据只存 MySQL（依据：完善文档 02 追问与防御）

## 追问防御
- **可能追问：数据源可信吗？** → 可信，四层来源各有背书；最终匹配率 97.1%、平均置信 0.975 是质量答卷（依据：完善文档 02 追问与防御）
- **可能追问：TTL 和教材怎么合一？** → 不合一，两层分存 + MATCHES_KG 软连接，URI 版本化（v0.1/v0.2/v3.1）区分来源，互不污染（依据：完善文档 02 追问与防御）
