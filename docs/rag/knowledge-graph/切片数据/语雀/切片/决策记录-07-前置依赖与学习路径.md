### D8 教学顺序 TEACHES_BEFORE ≠ 学习依赖 PREREQUISITE（严格区分）
> 检索摘要：为什么教材顺序不能直接当前置依赖？教学顺序≠学习依赖——勾股定理先于圆，但学圆不需先学勾股定理。

| 属性 | 内容 |
|---|---|
| 背景 | 早期方案设计1 曾把章节顺序直接转 PREREQUISITE |
| 演进 | 方案设计1（简单版）→ 方案设计2/3（区分 TEACHES_BEFORE / PREREQUISITE） |
| 拍板理由 | 教学顺序只生成 TEACHES_BEFORE；学习依赖需多证据融合确认；relateTo 与 PREREQUISITE 语义严格区分 |
| 系统影响 | TEACHES_BEFORE（教材章节内部）+ PREREQUISITE（业务查询用）+ PREREQUISITE_ON（EduKG 标准互操作）+ PREREQUISITE_CANDIDATE（低置信候选） |
| 证据 | 证据：语雀-方案设计2/3.md / design-python-kg-math-prerequisite-inference.md |

### D9 前置依赖多证据融合（教材顺序/定义依赖/LLM/教师）
> 检索摘要：前置依赖怎么确认？多证据融合——教材顺序仅 TEACHES_BEFORE、定义依赖直接 PREREQUISITE、LLM 双模型投票、教师标注 1.0。

| 属性 | 内容 |
|---|---|
| 背景 | 单一证据不可靠，需多源交叉 |
| 演进 | 设计权重 0.7/0.85/0.8/1.0 → 代码落地 1.0/0.9/+0.1 |
| 拍板理由 | 教材顺序 0.7（仅→TEACHES_BEFORE）；定义/定理依赖 0.85（代码 conf 0.9 → PREREQUISITE）；LLM 双模型 0.8（已有前置则升级 +0.1 封顶 1.0）；教师 1.0（demo 不做） |
| 系统影响 | 阈值 HIGH=0.8 / LOW=0.6；投票 ≥0.8 → PREREQUISITE、≥0.6 → CANDIDATE、不一致不采纳 |
| 证据 | 证据：语雀-方案设计2/3.md / edukg/core/llm_inference/prerequisite_inferer.py fuse_results() |

### D10 年级倒置惩罚（跨年级前置降权）
> 检索摘要：前置年级比目标年级高怎么办？按跨度惩罚 ×0.95/0.9/0.5/0.3，惩罚后 <0.6 降级候选。

| 属性 | 内容 |
|---|---|
| 背景 | LLM 推断前置时年级倒置（高年级知识作低年级前置）会污染学习路径 |
| 演进 | 无 |
| 拍板理由 | 前置年级高于目标年级按跨度乘惩罚系数：相邻 ×0.95 / 跨 1 学段 ×0.9 / 跨 2 学段 ×0.5 / 太大 ×0.3 |
| 系统影响 | 惩罚后 <0.6 降级 PREREQUISITE_CANDIDATE；质量目标年级倒置率 ≤5% |
| 证据 | 证据：语雀-方案设计3.md / design-python-2026-04-10-knowledge-graph-data-research.md 9.3 |
