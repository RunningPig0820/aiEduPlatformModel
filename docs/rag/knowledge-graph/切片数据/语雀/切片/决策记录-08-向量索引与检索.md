### D5 embedding 双轨：bge 本地 512 维（匹配）+ dashscope 768 维（服务侧 RAG）
> 检索摘要：知识点向量怎么算？匹配侧 bge-small-zh-v1.5 本地 512 维，服务侧 RAG 用 dashscope text-embedding-v3 768 维，索引维度固定不可改。

| 属性 | 内容 |
|---|---|
| 背景 | 匹配需本地批量粗筛，服务侧答疑需在线 embedding |
| 演进 | 早期无向量 → bge 预构建索引（D4.3 采纳 DeepSeek 建议，vs difflib） |
| 拍板理由 | bge-small-zh-v1.5 中文小模型 SOTA、维度 512、numpy 暴力搜索 ≤5000 条 <10ms、总内存约 3.5GB；dashscope 768 维服务侧 |
| 系统影响 | 匹配侧索引文件 kg_vectors.npy（1295×512）；服务侧 RAG 桶 rag-full/rag-slice 768 维；维度固定不可改 |
