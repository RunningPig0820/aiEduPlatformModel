## TTL 数据源术语（§2）

TTL = 语义网 RDF 数据格式，EduKG 开源数据源（`ttl/*.ttl` v0.1 知识点 + `relations/*.ttl` 关系 + `main.ttl` v3.0 教材出处 + `entities/*.json` 实体列表）。URI 是节点唯一标识，正式数据一律 `http://edukg.org/knowledge/{version}/...`（edukb.org 仅出现在下载脚本/旧 TTL 兼容分析）。

## 数据治理与可信度

- **权威 TTL 冻结只读**：EduKG 静态权威库冻结只读，绝不修改基准 TTL（方案 C 专家避坑原则第 1 条）；业务派生数据永远不写权威图。
- **维度不一致 v0.1 vs v3.0（§12 兜底）**：TTL 与 main.ttl 数据不匹配（维度不一致），靠标签匹配容忍缺失。
- **来源背书**：EduKG 开源概念作为语义层权威来源，人教版爬虫作为教材结构层事实来源，课标作层级基准，ChinaQuestionBank/好未来作题库与小学层级参考。
