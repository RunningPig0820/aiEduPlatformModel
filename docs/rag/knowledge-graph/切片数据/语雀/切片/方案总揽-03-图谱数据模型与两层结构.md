## 两层图谱结构（§1）

- **教材结构层（人教 K-12 数学，真值）**：Textbook(23) / Chapter(148) / Section(580) / TextbookKP(1740)，关系 CONTAINS / IN_UNIT；真实教学结构（学科→学段→年级→教材→章节→小节→知识点 6 层），节点带 URI，是"事实"。
- **语义层（EduKG 概念，有限）**：Concept(1295) / Statement(2932) / Class(39)，关系 RELATED_TO / HAS_TYPE / SUB_CLASS_OF；EduKG 开源概念（TTL v0.1 导入），是"概念"。content 属性在 **Statement**，不在 Concept。
- 两层通过 `MATCHES_KG` **软连接**（教材知识点 TextbookKP → Concept，匹配率 97.1%，置信度 ≥0.5，方向固定不可逆）。

## URI 设计（§4.3）

| 版本 | 前缀 | 用途 |
|---|---|---|
| v0.1 | `/0.1/instance/math#516`、`/0.1/class/math#`、`/0.1/statement/math#` | EduKG 原始 Concept/Statement/Class |
| v0.2 | `/0.2/...` | 小学新增数据（课标 2022），ID `{label_pinyin}-{md5_32bit}` |
| v3.0 | `/3.0/instance/math#textbook-xxx` | EduKG TTL 教材知识点 |
| v3.1 | `/3.1/textbook|chapter|section/kp/math#{id}` | 自建人教教材数据（代码常量 `URI_VERSION="3.1"`） |
| v3.2 | （规划） | 评审新知识点/多版本教材 |

ID 编码：Textbook `{publisher}-{grade}{semester}` → `renjiao-g1s`；Chapter `renjiao-g1s-1`；Section `renjiao-g1s-1-1`；TextbookKP `textbook-primary-00001`。年级映射：小学 g1~g6、初中 g7~g9、高中 bixiu1-3/xuanxiu 系列。
