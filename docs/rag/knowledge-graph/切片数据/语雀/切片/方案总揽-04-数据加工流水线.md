## 加工流水线（Python 离线构建）（§3.2）

```
Phase 0 爬取：renjiaoshe_math_crawler.py（断点续爬，--no-resume 重爬）
  → 原始教材 JSON
Phase 1 数据生成与处理：generate_textbook_data.py（节点/关系 JSON）
  → clean_textbook_data.py（清洗）→ enhance_chapters.py（专题）
  → infer_textbook_kp.py（LLM 推断缺失知识点，断点续传）
  → merge_inferred_kps.py（按 section 去重合并）→ enhance_kp_attributes.py（属性补全）
  → 中间 JSON（textbooks/chapters/sections/textbook_kps）
Phase 2 知识点匹配：build_vector_index.py（bge 索引）→ normalize_textbook_kp.py（标准化）
  → match_textbook_kp.py（精确+向量+LLM 投票）→ matches_kg_relations.json
Phase 3 Neo4j 导入：scripts/kg_data/import/ 11 个脚本严格按依赖顺序（类→概念→陈述→关系→教材→章节→小节→知识点→归属→匹配）
  → 校验（verify/analyze_textbook_matching）→ DAG 验证（前置依赖）
```

- **方案 C：CSV→Neo4j**：关系处理在 Python 内存/CSV 完成，Neo4j 只是最后仓库；`neo4j-admin import` 对 CSV 批量导入性能是 TTL 导入 **10 倍以上**，MERGE 幂等（所有导入脚本支持 `--clear` 幂等操作）。权威基准冻结、教研可维护 CSV、计算与存储分离。
- **计算与存储分离**：离线构建 → 批量导入，在线只消费。

## 数据清洗与增强（§5）

- **DataCleaner**（`data_cleaner.py`）：检测"通用"标签跨小节复用（88 组，非错误）、Section 标签序号前缀提取到 `order_in_book`、移除末尾冒号/全角→半角、数据质量检查（全角字符/多余空格）。
- **ChapterEnhancer**（`chapter_enhancer.py`）：基于章节名关键词匹配 4 大专题（数与代数/图形与几何/统计与概率/综合与实践）+ 默认"其他"，匹配 17 个数学专题。
- **KPAttributeInferer**（`kp_attribute_inferer.py`）：**纯规则、无 LLM**——difficulty 1~5（年级基础难度 + 关键词 ±1 调整）、importance（核心>重要>了解）、cognitive_level（分析>应用>理解>识记，布卢姆）、topic 直接继承章节 topic。
- **知识点过滤**（`filters.py`）：`NON_KNOWLEDGE_POINT_MARKERS`（数学活动/小结/整理和复习/本章综合与测试/复习题等）+ 前缀 + 正则（`^例\d`）+ 章节编号。
- **执行顺序坑**：早期属性增强在 LLM 推断**之前**执行导致 enhanced 覆盖率仅 22%（299/1350），修复为 LLM 推断完成后重跑属性增强补 1052 个（详见「关键坑与解法」块）。
