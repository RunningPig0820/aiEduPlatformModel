## 核心原则

教学顺序（TEACHES_BEFORE）≠ 学习依赖（PREREQUISITE）——教材顺序只生成 TEACHES_BEFORE，不直接转 PREREQUISITE（勾股定理先于圆，但学圆不需先学勾股定理）。PREREQUISITE_ON 为 EduKG 标准互操作。

## 多证据融合（PrerequisiteInferer.fuse_results）

| 证据 | 设计权重 | 代码落地 | 产物 |
|---|---|---|---|
| 教材章节顺序 | 0.7 | conf 1.0, source=textbook_order（仅章节内部） | TEACHES_BEFORE |
| 定义/定理依赖 | 0.85 | conf 0.9（已有 TEACHES_BEFORE 则升级 PREREQUISITE） | PREREQUISITE |
| LLM 多模型投票 | 0.8 | 已有前置则升级，conf `min(existing+0.1, 1.0)` | PREREQUISITE/CANDIDATE |
| 教师标注 | 1.0 | demo 不做 | 人工 |

> **口径标注**：设计文档证据权重表为 0.7/0.85/0.8/1.0；**代码最终常量无 0.85**，落地为 TEACHES_BEFORE conf 1.0 / DEFINITION_DEP conf 0.9 / LLM +0.1 封顶 1.0；阈值 HIGH=0.8 / LOW=0.6。

## 投票分类（vote_prerequisite）

两模型一致且 ≥0.8 → PREREQUISITE；一致 ≥0.6 → PREREQUISITE_CANDIDATE；不一致 → 不采纳。前置 <0.6 降级候选（PREREQUISITE_CANDIDATE）、<0.7 丢弃、≥0.8 才 PREREQUISITE。

## 年级倒置惩罚

前置年级高于目标年级按跨度乘 0.95（相邻）/0.9（跨 1 学段）/0.5（跨 2 学段）/0.3（跨度太大）；惩罚后 <0.6 降级 PREREQUISITE_CANDIDATE。目标年级倒置率 ≤5%。

## DAG 验证与学习路径

- **DAG 验证**（`validate_dag.py`）：DFS 环检测（`detect_cycles`），退出码 0=无环/1=有环，输出覆盖率/平均链长/置信度分布。
- **学习路径**：Cypher `MATCH path=(start)-[:PREREQUISITE*..10]->(target) RETURN path ORDER BY LENGTH(path)`；离线预计算 prerequisite_level 属性（BFS 最长前置路径）优化。
- **知识缺陷诊断**：给定已掌握集合，多跳查未掌握的前置点（业务优先级 P0=前置依赖查询、P1=知识点识别+缺陷诊断、P2=学习路径推荐）。
- **质量目标（demo）**：前置覆盖率 ≥30%、DAG 合规 100%、平均前置链 2-4 跳、年级倒置率 ≤5%、高置信度(≥0.8)占比 ≥60%、抽样准确率 ≥70%。
