## 三端分工（§1）

- **Python**（edukg 管道 + ai-edu-ai-service 桥）离线构建 + 在线 API；
- **Java**（Spring Boot + MyBatis-Plus，双数据源）页面化接口 + 掌握度派生；
- **前端**（React SPA）三栏布局（树+图谱+详情）只读消费。

```
Neo4j 最终存储（bolt://81.71.130.57:7687）
  ← Python 离线构建 → CSV → 批量导入（MERGE 幂等）
  → Java 页面化同步 → MySQL ai_edu_kg → 前端 SPA 读
  → 图谱关系（MATCHES_KG/PART_OF/RELATED_TO）直查 Neo4j
```

## 消费侧（§3.3）

- ③ 页面化：Neo4j→MySQL 同步 → 前端教材导航/年级知识体系/知识点详情/点亮展示（详见「页面化与服务化」块）。
- ④ 图谱关系：MATCHES_KG/PART_OF/RELATED_TO 等关系直查 Neo4j（Redis TTL 300s + 降级）。

## Python 服务 API（§10）

- **api/kg.py**（prefix `/api/kg`，八端点）：`/entities` 搜索、`/entity/{uri}` 详情、`/link` 实体识别、`/subject/{subject}/tree` 知识树（depth 默认3 最大5）、`/subject/{subject}/classes`、`/student/{id}/progress`、`/recommend`、`/learning-path`。
- **api/neo4j.py**（prefix `/api/neo4j`，`x-internal-token` 鉴权）：`/health`、`/stats`、`/nodes/{label}`（+batch/search/count）、`/relationships`、`/query`（裸 Cypher，read_only 默认 true）。
- **实体链接**（`core/kg/entity_linker.py`）：jieba 分词 + 内存实体字典（从 `data/edukg/entities/*_entities.json` 加载，~40,000 实体约 10MB）做实体链接。
