## llmTaskLock 断点续传三件套

（`core/llmTaskLock/`）：
- **TaskState**：检查点/进度；
- **CachedLLM**：SHA256 缓存键，同 Prompt 不重复调用；
- **ProcessLock**：portalocker 文件锁。

推断 2-3 小时、匹配 1-2 小时，中断可续（`--resume`）；先修关系推断 ~8,980 次调用断点续传价值最高。

## 工程化状态管理

- **MySQL 状态表**：processing_state / llm_cache / cost_tracking / chapter_state+subbatch_state 两层 / failed_batches / progress_view；
- **优雅退出**：SIGINT/SIGTERM；
- **重试策略**：超时 2 次/格式错误 1 次/网络 3 次；
- **成本预算告警**：日预算 5000 分/总预算 20000 分/70% 告警。

## 关键选型速览（§13）

断点续传 llmTaskLock JSON 状态 + SHA256 缓存 + portalocker；状态存储 MySQL 替代早期 SQLite（并发/运维/备份成熟）。
