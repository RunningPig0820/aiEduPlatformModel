本块合并《语雀-方案总揽》中「已知风险」与「清洗增强」中的踩坑实录（原文 §5 执行顺序坑 + §7 匹配率历程 + §12 各类风险），说明属性增强顺序 bug、topic 继承污染、匹配率 17% 根因=抽象层级错位、在线 :Entity 标签坑。

## 坑一：属性增强执行顺序 bug（覆盖率 22%）

早期属性增强在 LLM 推断**之前**执行导致 enhanced 覆盖率仅 22%（299/1350）；修复为 LLM 推断完成后重跑属性增强补 1,052 个。属 Phase 1 数据加工的执行顺序问题。

## 坑二：topic 继承偏差污染 Class（修正 144 个）

知识点直接继承章节 topic 导致语义矛盾（「加法」在「位置」章被错继承），基于匹配 Concept 的 Class 类型修正 144 个。

## 坑三：匹配率 17% 根因 = 抽象层级错位（小学 69.6%）

初始匹配率仅 17%（LLM 仅 2%）；小学 69.6% 教材知识点（如「1-5 的认识」）与 EduKG 高中抽象概念不对齐 → LLM 推断标准化名再匹配（「1-5 的认识」→「自然数的基本概念」→ 匹配 EduKG「自然数」）。

## 坑四：在线 :Entity 标签坑

在线实体链接/识别中 `:Entity` 标签与具体标签（Concept/Statement/Class）不一致导致查询/匹配失配，需按具体标签处理。

## 坑五：LLM 自证循环

LLM 修正 LLM 可能自我强化；强制"每次判断被客观信号校准"（做题结果/多模型交叉/学生意图），冷启动弱化（WEAK 态等第二独立信号）。

## 坑六：联调问题

教材导航 API 空数组、图谱关系 API 未验证、同步并发冲突/URI 脏数据（对账校验缓解）、前端节点上限 50。
