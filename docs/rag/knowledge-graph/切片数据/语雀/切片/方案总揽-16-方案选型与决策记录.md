## 关键选型速览（详见独立文档）

- 图数据库 **Neo4j**（vs ES/MySQL，图遍历/前置链/CSV 批量导入 10x）；

- 匹配粗筛 **bge-small-zh-v1.5 + numpy**（vs difflib，采纳 DeepSeek 建议）；

- 前端图谱库 **React Flow**（vs D3/ECharts）；
