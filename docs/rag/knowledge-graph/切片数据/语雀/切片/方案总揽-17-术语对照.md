本块提取《语雀-方案总揽》中「核心概念与术语」相关内容（原文 §2），作为 TTL/URI/节点类型/关系类型/双模型投票/置信度分级/断点续传/GraphRAG/bge 512/dashscope 768 等术语基准。

| 术语 | 定义 |
|---|---|
| TTL | 语义网 RDF 数据格式，EduKG 开源数据源（`ttl/*.ttl` v0.1 知识点 + `relations/*.ttl` 关系 + `main.ttl` v3.0 教材出处 + `entities/*.json` 实体列表） |
| URI | 节点唯一标识，正式数据一律 `http://edukg.org/knowledge/{version}/...`（edukb.org 仅出现在下载脚本/旧 TTL 兼容分析） |
| Textbook / Chapter / Section | 教材结构层节点（人教 K-12 数学，23/148/580） |
| TextbookKP | 教材知识点（1740，教学粒度），经 MATCHES_KG 匹配到 Concept |
| Concept / Statement / Class | 语义层节点（EduKG，1295/2932/39）；content 属性在 **Statement**，不在 Concept |
| MATCHES_KG | 教材知识点↔概念匹配关系（1690，97.1%），方向 TextbookKP→Concept |
| PREREQUISITE | 前置依赖（学习依赖），业务查询用；PREREQUISITE_ON 为 EduKG 标准互操作 |
| PREREQUISITE_CANDIDATE | 低置信前置候选（<0.6/<0.8），待确认 |
| TEACHES_BEFORE | 教学顺序（教材章节顺序），≠ 学习依赖（勾股定理先于圆，但学圆不需先学勾股定理） |
| 双模型投票 | DeepSeek(0.6) + GLM(0.4) 加权投票，threshold 0.5；两模型一致取平均置信度 |
| 置信度 | 匹配/关系可信度；匹配 <0.5 跳过、前置 <0.6 降级候选、<0.7 丢弃、≥0.8 才 PREREQUISITE |
| 断点续传 llmTaskLock | TaskState + CachedLLM(SHA256 缓存) + ProcessLock 三件套，LLM 长任务中断可续 |
| GraphRAG | 向量命中 Concept → 沿关系扩展邻居 → 可解释推理路径 |
| 年级推断 | TEXTBOOK_TO_GRADE 映射表 + STAGE_FALLBACK + mark 字段兼容解析（6.2.1/6-2-1/第六章第二节） |
