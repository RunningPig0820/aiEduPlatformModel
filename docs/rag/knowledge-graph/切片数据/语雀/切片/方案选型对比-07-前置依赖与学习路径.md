**选型7｜前置依赖构建：多证据融合 vs 教材顺序直转**

> 检索摘要：前置依赖怎么建？多证据融合——教材顺序仅 TEACHES_BEFORE、定义依赖/LLM 投票才出 PREREQUISITE，避免"教学顺序≠学习依赖"误连。

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 多证据融合（顺序/定义/LLM/教师） | 语义准/可解释/年级惩罚 | 实现复杂 | 采用 |
| 教材顺序直接转 PREREQUISITE | 简单 | 教学顺序≠学习依赖（勾股定理先于圆） | 早期方案，演进放弃 |
| 证据 | 证据：语雀-方案设计1(早期)/2/3(演进) / design-data-research 5.2 |  |  |

**选型8｜前置置信度低值处置：丢弃 vs 降级候选**

> 检索摘要：低置信前置关系怎么办？<0.7 直接丢弃、<0.6 降级 PREREQUISITE_CANDIDATE 保留待确认，两模型一致 ≥0.8 才转正式 PREREQUISITE。

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 降级候选（PREREQUISITE_CANDIDATE） | 不丢信息/可补审 | 需维护候选 | 采用 |
| 直接丢弃 | 干净 | 丢真实信号 | 早期方案（<0.7 丢弃），演进为降级 |
| 证据 | 证据：语雀-方案设计1/2/3.md / design-prerequisite-inference D2 |  |  |
