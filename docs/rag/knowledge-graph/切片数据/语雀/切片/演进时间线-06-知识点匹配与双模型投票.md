本块合并《语雀-演进时间线》阶段3 中教材知识点匹配 Concept 的内容，说明完整图谱的匹配链路与最终规模。

## 匹配链路

- concept-linking（教材↔概念匹配）：课标 OCR 百度 API + 教材解析 + 匹配报告 + v0.2 URI。
- complete-graph：MATCHES_KG 匹配阈值 + bge 向量粗筛 + v3.1 URI 与属性扩展。
- 匹配三阶段：精确匹配 → 向量粗筛 → 双模型投票（由粗到精，控制 LLM 调用成本）。

## 最终规模与质量

- 23 本教材 / 148 章 / 580 节 / 1740 个教学知识点。
- 匹配率 97.1%（TextbookKP 经 MATCHES_KG 匹配到 Concept）。

## 关键决策

- 匹配三阶段（精确+向量+投票）：先精确命中，再用 bge 向量粗筛，最后双模型投票定案。
- 输出 JSON 不直接导入：防低质量 Concept + 可回滚。
