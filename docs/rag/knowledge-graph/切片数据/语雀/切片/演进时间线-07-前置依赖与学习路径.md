## 概念严格区分（阶段2 data-research）

- 教学顺序 TEACHES_BEFORE ≠ 学习依赖 PREREQUISITE：教学顺序是教材讲授次序，学习依赖是知识掌握前提，二者必须严格区分。
- 年级推断：TEXTBOOK_TO_GRADE 映射 + mark 格式兼容。

## 前置依赖生成（阶段4 prerequisite-inference D1-D7）

- 双模型投票 / 提示词文件化 / TextbookKPInferer / 断点续传 / validate_dag DAG 验证。
- 多证据融合权重：教材顺序 0.7 / 定义依赖 0.85 / LLM 0.8 / 教师 1.0。
- 年级倒置惩罚 ×0.95 / 0.9 / 0.5 / 0.3（依赖高年级→低年级时按倒置程度降权）。
- 投票阈值：≥0.8 判 PREREQUISITE；<0.6 判 CANDIDATE（PREREQUISITE_CANDIDATE）。

## 匹配失败评审（阶段4 kp-match-review-system）

- MySQL 审核表 + LLM 推荐接口 + 审核导入：人工确认后导入权威图谱。
- 308 个未匹配教学知识点进人工评审：其中 297 个投票不通过、11 个无候选。
