本块合并《语雀-演进时间线》阶段5 中页面化与服务化的内容，说明图谱数据如何被前端浏览、如何支撑答疑掌握度点亮。

## 目标

图谱数据可被前端浏览（教材导航/年级知识体系/知识点详情）；支撑答疑掌握度点亮（阶段5 数据层完成、点亮前端部分）。

## 数据层（backend-datasource）

- 双数据源 @DS("kg")，ai_edu_kg 与业务库物理隔离。
- backend-ui：方案 B Neo4j→MySQL 同步 8 张表 + API。

## 方案 B 同步策略

- Neo4j→MySQL 同步：前端读 MySQL；图谱关系（MATCHES_KG/PART_OF/RELATED_TO 等）不同步，直查 Neo4j + Redis TTL 300s 降级（neo4jAvailable:false）。
- 主键用 URI（非自增 ID）；权威图谱零写入（业务只读权威图谱）。

## 前端（frontend-ui）

- React SPA 三栏布局（树+图谱+详情）+ React Flow 关系图谱。

## 掌握度点亮（kp-matching-lightup）

- 派生层 MySQL 4 表；掌握度主体翻转题型；点亮/疑似状态。
