## 基础设施（阶段1 kg-infrastructure-init D1-D5）

- 落地三件套：TaskState（任务状态）/ CachedLLM（缓存 LLM）/ ProcessLock（进程锁）。
- 断点续传方案：JSON 状态文件 + SHA256 缓存 + portalocker 锁。

## 关键决策

- 断点续传用 JSON 状态 + SHA256 缓存 + portalocker 锁，支撑长 LLM 任务中断后从断点恢复，避免重复调用 LLM 产生重复成本。
- 阶段4 prerequisite-inference（D1-D7）同样复用断点续传能力。
