## 阶段0 立项与调研（2026-03，已完成）

目标：支撑 AI 答疑识别知识点、学习进度可视化、教师备课推荐，服务家长端报表。
做了什么：数据源调研（EduKG 论文/教育局知识总纲/教材地址/题库/好未来）；Neo4j 图存储选型；LLM Gateway 集成（智谱/DeepSeek/百炼）。
关键决策：低成本易落地定位；知识图谱作为 AI 助手"活文档"；区别于客服系统高效答疑，凸显教学相长。
落地证据：语雀-知识图谱.md / 语雀-EduKG论文.md / 语雀-教育局知识总纲.md / design-python-2026-03-28-integrate-edukg-knowledge-graph.md。

## 阶段1 基础设施与集成（2026-03-28~04-08，已完成）

目标：Neo4j 存储查询、TTL 导入、实体链接、断点续传四大基础能力。
做了什么：integrate-edukg（D1-D5：Neo4j/n10s/结巴分词+内存词典/三层架构/Student+LEARNED）；kg-infrastructure-init（D1-D5：TaskState/CachedLLM/ProcessLock）。
关键决策：选 Neo4j（vs rdflib/Jena/NebulaGraph）；实体链接用内存词典约 10MB（vs ES 1-2GB）；断点续传 JSON 状态 + SHA256 缓存 + portalocker 锁。
落地证据：design-python-2026-03-28-integrate-edukg-knowledge-graph.md / design-python-2026-04-08-kg-infrastructure-init.md / edukg/core/llmTaskLock/。

## 阶段2 数据调研与教材爬虫（2026-04-10，已完成）

目标：摸清数据面：知识点层级、跨源映射、年级推断、前置依赖构建算法；补教材目录。
做了什么：knowledge-graph-data-research（数据模型 Subject→Stage→Grade→Textbook→Chapter→KnowledgePoint、关系模型、多学科策略、成本估算）；textbook-crawler（教师之家爬虫补人教版小初教材）。
关键决策：教学顺序 TEACHES_BEFORE ≠ 学习依赖 PREREQUISITE；年级推断 TEXTBOOK_TO_GRADE 映射 + mark 格式兼容；全学科 56,391 知识点、成本 10-20 元。
落地证据：design-python-2026-04-10-knowledge-graph-data-research.md / design-python-2026-04-10-textbook-crawler.md。

## 阶段3 教材匹配与完整图谱（2026-04-10~04-15，已完成）

目标：补全缺失教学知识点（小学 3-6 年级初始 0、高中必修初始 0）、教材知识点匹配 Concept、输出完整图谱 JSON。
做了什么：concept-linking（课标 OCR 百度 API + 教材解析 + 匹配报告 + v0.2 URI）；complete-graph（D1-D13：TextbookKPInferer 补 1052 知识点、MATCHES_KG 匹配阈值、bge 向量粗筛、v3.1 URI、属性扩展）。
关键决策：LLM 推断补知识点（平均置信 0.93）；匹配三阶段（精确+向量+投票）；属性扩展纯规则（difficulty/importance/cognitive_level/topic）；输出 JSON 不直接导入（防低质量 Concept + 可回滚）。
落地证据：design-python-2026-04-10-textbook-concept-linking.md / design-python-2026-04-15-kg-math-complete-graph.md / edukg/README.md（最终 23 教材/148 章/580 节/1740 知识点、匹配率 97.1%）。

## 阶段4 前置依赖推断与匹配评审（2026-04，已完成）

目标：生成高质量前置依赖（TEACHES_BEFORE/PREREQUISITE/PREREQUISITE_CANDIDATE）；处理匹配失败余量。
做了什么：prerequisite-inference（D1-D7：双模型投票/提示词文件化/TextbookKPInferer/断点续传/validate_dag DAG 验证）；kp-match-review-system（MySQL 审核表 + LLM 推荐接口 + 审核导入）。
关键决策：多证据融合权重（教材顺序 0.7/定义依赖 0.85/LLM 0.8/教师 1.0）；年级倒置惩罚 ×0.95/0.9/0.5/0.3；投票 ≥0.8 判 PREREQUISITE、<0.6 判 CANDIDATE；308 个未匹配（297 投票不通过 + 11 无候选）进人工评审。
落地证据：design-python-kg-math-prerequisite-inference.md / design-python-kp-match-review-system.md / edukg/scripts/kg_inference/validate_dag.py。

## 阶段5 页面化与服务化点亮（2026-06，数据层完成/点亮前端部分）

目标：图谱数据可被前端浏览（教材导航/年级知识体系/知识点详情）；支撑答疑掌握度点亮。
做了什么：backend-datasource（双数据源 @DS("kg") ai_edu_kg 物理隔离）；backend-ui（方案 B 同步 8 张表 + API）；frontend-ui（React SPA 三栏 + React Flow）；kp-matching-lightup（派生层 MySQL 4 表 + 掌握度主体翻转题型 + 点亮/疑似）。
关键决策：方案 B Neo4j→MySQL 同步（前端读 MySQL，图谱关系直查 Neo4j + Redis TTL 300s 降级）；URI 主键；权威图谱零写入。
落地证据：design-backend-2026-06-03-knowledge-graph-datasource.md / design-backend-2026-06-03-knowledge-graph-ui.md / design-frontend-2026-06-09-knowledge-graph-ui-front.md / design-backend-kp-matching-lightup.md。
