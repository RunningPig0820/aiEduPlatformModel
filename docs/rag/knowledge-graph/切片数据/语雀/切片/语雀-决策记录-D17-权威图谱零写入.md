### D17 权威图谱零写入（派生数据只存 MySQL）
> 检索摘要：业务派生数据为什么不能写进图谱？权威图谱零写入——无限业务事实（掌握度/点亮/题型）只存 MySQL，物理上不污染权威结构。

| 属性 | 内容 |
|---|---|
| 背景 | 权威图谱（Neo4j + kg-sync 镜像）为教育局教材数据，节点有限 |
| 演进 | 早期方案曾考虑 Neo4j 扩展命名空间 → 拒绝，留阶段 2 再评估 |
| 拍板理由 | 派生层只存 MySQL（ai_edu_learning）；解析管线最终 kp 必经镜像校验（SHALL NOT 凭空生成镜像不存在的 kp）；错误只发生在派生层可纠 |
| 系统影响 | 掌握度/点亮/题型库全部落 MySQL；图谱只读；GraphRAG 消费 |
| 证据 | 证据：design-backend-kp-matching-lightup.md D1/D2 |
