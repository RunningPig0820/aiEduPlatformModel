### D8 教学顺序 TEACHES_BEFORE ≠ 学习依赖 PREREQUISITE（严格区分）
> 检索摘要：为什么教材顺序不能直接当前置依赖？教学顺序≠学习依赖——勾股定理先于圆，但学圆不需先学勾股定理。

| 属性 | 内容 |
|---|---|
| 背景 | 早期方案设计1 曾把章节顺序直接转 PREREQUISITE |
| 演进 | 方案设计1（简单版）→ 方案设计2/3（区分 TEACHES_BEFORE / PREREQUISITE） |
| 拍板理由 | 教学顺序只生成 TEACHES_BEFORE；学习依赖需多证据融合确认；relateTo 与 PREREQUISITE 语义严格区分 |
| 系统影响 | TEACHES_BEFORE（教材章节内部）+ PREREQUISITE（业务查询用）+ PREREQUISITE_ON（EduKG 标准互操作）+ PREREQUISITE_CANDIDATE（低置信候选） |
