### 解法：LLM 标准化预处理，先翻译成抽象概念
> 检索摘要：抽象层级错位怎么解？先用 LLM 把教学名标准化成抽象概念列表再匹配——1-5的认识→[数的认识,自然数,数字]，匹配自然数（相似度0.711）。

解法不是换算法，而是**在匹配前先用 LLM 做标准化预处理**：把具体的教学名翻译成抽象概念列表，再走向量粗筛 + 投票：

```
"1-5 的认识" → LLM 标准化 → ["数的认识", "自然数", "数字"] → 匹配 EduKG "自然数"（相似度 0.711）
"连加连减"   → LLM 标准化 → ["减法"]（相似度 0.655）
"秒的认识"   → LLM 标准化 → ["秒"]（相似度 0.830）
```

> 一句话面试答案："匹配率 17% 的根因是抽象层级错位——69.6% 小学具体知识点对不上 EduKG 高中抽象概念；解法是匹配前先用 LLM 把教学名标准化成抽象概念列表，1-5的认识翻译成[数的认识,自然数]再匹配。"
