### 问题：全量遍历候选，LLM 调用爆炸
> 检索摘要：LLM 匹配为什么会调用爆炸？穷尽遍历 top-20 候选 × 2 个模型 = 最坏 40 次 API 每个知识点，3.5 小时才处理 290 个。

三段式匹配里 LLM 是最后一道，但**穷尽遍历候选**会爆炸：top-20 候选 × 2 个模型 = 最坏 **40 次 API 调用**每个知识点。实测 3.5 小时才处理 290 个知识点。
