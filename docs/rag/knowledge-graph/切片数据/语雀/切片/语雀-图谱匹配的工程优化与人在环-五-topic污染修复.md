### 五、Topic 继承污染的逆向修复（数据血缘 bug）
#### 简单继承的代价：加法被标成"图形与几何"
> 检索摘要：知识点专题继承有什么 bug？属性规则里 topic 直接继承章节，导致"加法"在"位置"章节被错标为图形与几何——用匹配到的 Concept 的 Class 类型反向修正 144 个。

匹配工程里还踩了一个**数据血缘 bug**：知识点属性 `topic` 直接继承章节，结果"加法"知识点出现在"位置"章节，被错标成"图形与几何"。

**修复是逆向数据流**——用**下游匹配结果回改上游字段**：

- 知识点匹配到的 EduKG Concept → 拿它的 Class 类型 → 反推规则映射 topic
- 映射表：数学概念/数学运算 → 数与代数；几何图形/几何性质 → 图形与几何；统计概念 → 统计与概率
- 结果：**修正 144 个**（数与代数 +36、图形与几何 -44）

> 一句话面试答案："踩过数据血缘 bug——topic 直接继承章节，加法在位置章节被错标成图形与几何；用下游匹配到的概念 Class 类型反向修正了 144 个。"
