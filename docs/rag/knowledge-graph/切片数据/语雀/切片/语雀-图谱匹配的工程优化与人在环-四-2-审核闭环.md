### 审核闭环：MySQL 审核表 + LLM 推荐 + Web 人工确认
> 检索摘要：未匹配的审核闭环怎么设计？308 个进 MySQL 审核表（textbook_kp_match_review），LLM 推荐前 5 候选，Web 页面人工审核（确认/拒绝/改选/新建），审核结果回写 Neo4j MATCHES_KG。

审核闭环 = **自动化 + 人在环**，可解释且可回滚：

```
308 未匹配
  → MySQL 审核表 textbook_kp_match_review（前 5 候选 JSON + 置信度）
  → LLM 推荐接口 /api/kp-match/recommend（输入教材知识点 → 前 5 候选）
  → Web 审核页：人工确认 / 拒绝 / 改选 / 新建知识点
  → 审核结果回写 Neo4j MATCHES_KG（置信度 + 方法）
```

- 新知识点用 **v3.2 URI** 前缀（不与已有版本冲突）
- 批量误确认可追溯（reviewer_id/review_time）

> 一句话面试答案："308 个未匹配按根因分类——297 个颗粒度差异、11 个图谱缺失；进 MySQL 审核表，LLM 推荐前 5 候选，Web 人工确认后回写图谱，可追溯可回滚。"
