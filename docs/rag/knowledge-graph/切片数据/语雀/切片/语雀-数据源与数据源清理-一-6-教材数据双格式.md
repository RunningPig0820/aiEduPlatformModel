### 教材数据双格式：JSON + TTL 兼容 EduKG
> 检索摘要：教材爬虫数据为什么出两种格式？JSON 面向程序处理 + TTL 兼容 EduKG main.ttl 可直接 n10s 导入 Neo4j——为互操作性预留数据格式。

爬虫出来的教材数据**同时输出 JSON 和 TTL 两种格式**：

- **JSON**：面向程序处理（结构化、易改）
- **TTL**：兼容 EduKG main.ttl，可用 n10s 插件**直接导入 Neo4j**

层级 schema 自带章节序号规范化：`subject/stage/grade/semester/publisher/edition/chapters[chapter_name → sections[section_name → knowledge_points]]`。这是**为互操作性预留格式**的设计——下游无论是程序还是 Neo4j 都能直接消费。

> 一句话面试答案："教材数据出 JSON + TTL 双格式——JSON 给程序、TTL 兼容 EduKG 能直接 n10s 进 Neo4j，为互操作性预留。"
