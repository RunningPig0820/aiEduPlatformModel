### 坑三：小学和高中知识点是空的，得靠 LLM 补
> 检索摘要：小学高中知识点缺失怎么处理？教材数据小学 3-6 年级、高中必修知识点全空，用 LLM 根据章节信息推断补全 1052 个（平均置信度 0.93），初中 252 个完整不用补。

数据下载下来才发现：**小学 3-6 年级和高中必修的知识点字段是空的**，只有初中是完整的。

- 缺的用 **LLM 根据章节信息（学段/年级/章节名/小节名）推断**知识点，补了 **1052 个**，平均置信度 0.93
- LLM 推断是长任务（2-3 小时），所以配套做了**断点续传**（llmTaskLock），中断了接着跑

> 面试讲法："EduKG 和教材数据在小学高中都是空的，用 LLM 根据章节信息推断补了 1052 个，平均置信 0.93；因为是长任务还做了断点续传。"
