### 3. 完整业务流程

#### 3.1 数据来源（四类）

| 来源 | 内容 | 用途 |
|---|---|---|
| EduKG TTL | `ttl/relations/entities` v0.1 主数据源 | 语义层（Concept/Statement/Class）+ 原生 relateTo 关系 |
| main.ttl | v3.0 教材出处（131,736 行约 16MB，8 学科 6,975 实体，高中教材标注 28,438 条） | 教材信息基准 |
| 人教版爬虫 | 教师之家 renjiaoshe.com（高中只保留人教A版2019） | 小学初中教材目录（main.ttl 缺） |
| 课标/题库/好未来 | 义务教育课标 2022（16 学科）+ 普通高中课标 2017-2020（20 学科）+ ChinaQuestionBank + 好未来小学层级参考 | 层级参考/题库补充 |

#### 3.2 加工流水线（Python 离线构建）

```
Phase 0 爬取：renjiaoshe_math_crawler.py（断点续爬，--no-resume 重爬）
  → 原始教材 JSON
Phase 1 数据生成与处理：generate_textbook_data.py（节点/关系 JSON）
  → clean_textbook_data.py（清洗）→ enhance_chapters.py（专题）
  → infer_textbook_kp.py（LLM 推断缺失知识点，断点续传）
  → merge_inferred_kps.py（按 section 去重合并）→ enhance_kp_attributes.py（属性补全）
  → 中间 JSON（textbooks/chapters/sections/textbook_kps）
Phase 2 知识点匹配：build_vector_index.py（bge 索引）→ normalize_textbook_kp.py（标准化）
  → match_textbook_kp.py（精确+向量+LLM 投票）→ matches_kg_relations.json
Phase 3 Neo4j 导入：scripts/kg_data/import/ 11 个脚本严格按依赖顺序（类→概念→陈述→关系→教材→章节→小节→知识点→归属→匹配）
  → 校验（verify/analyze_textbook_matching）→ DAG 验证（前置依赖）
```

#### 3.3 消费侧（在线）

```
① GraphRAG 答疑：学生提问 → 提取核心知识点 → Neo4j 查前置依赖/考法/例题
   → 「前置回顾→考点讲解→解题引导→易错提醒」引导式答疑（Cypher [:前置依赖*1..2] 控深）
② 掌握度诊断：错题 → 对应知识点 → 前置链 → 结合正确率算掌握度 → 定位薄弱根因
③ 页面化：Neo4j→MySQL 同步 → 前端教材导航/年级知识体系/知识点详情/点亮展示
④ 图谱关系：MATCHES_KG/PART_OF/RELATED_TO 等关系直查 Neo4j（Redis TTL 300s + 降级）
```
