### 课标知识点 ≠ 纯数学概念，是个复合体
> 检索摘要：课标知识点和普通概念有什么区别？课标知识点是"核心概念+教学属性"的复合体（100以内数的认识=数+范围+动作），直接当概念节点建会污染概念图谱，所以要先拆分。

为什么小学数据要专门从课标建一条链路？因为 **EduKG 和教材都缺小学**（教材 JSON 小学 3-6 年级知识点全空）。而义务教育课标 2022 是唯一把小学知识点写全的权威文件。

但课标有个特殊问题：**课标知识点不是纯数学概念，是"核心概念 + 教学属性"的复合体**：

```
"100以内数的认识"
  ├─ 核心概念: 数（EduKG 里已存在，uri 0.1/instance/math#341）
  ├─ 教学属性: scope=100以内（范围限定）
  └─ 教学属性: action=认识（认知动作）

"三角形内角和" → 核心概念: 三角形 + 属性: 内角和
"20以内加法"   → 核心概念: 加法 + 属性: 范围 20以内
```

**关键决策（方案 C）**：不能把"100以内数的认识"整个字符串当一个概念节点建进图谱——那会污染概念图谱（"100以内数的认识"不是概念，是"数"的一种教法）。要**拆成核心概念 + 属性**，只把核心概念建点，属性作为标签/字段保留完整信息。

> 一句话面试答案："课标知识点是核心概念+教学属性的复合体，直接建点会污染概念图谱，所以拆开——100以内数的认识拆成核心概念'数'加范围/动作属性。"
