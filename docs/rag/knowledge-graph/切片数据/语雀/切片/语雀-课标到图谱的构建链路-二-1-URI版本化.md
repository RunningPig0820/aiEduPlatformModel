### URI 版本化：匹配上的用 v0.1，新增的用 v0.2
> 检索摘要：小学数据加进图谱会不会污染已有的？不会——匹配到 EduKG 已有概念用 v0.1 URI，新增概念用 v0.2 URI，带 version/is_existing 字段可解释、可回滚。

加数据最怕污染已有图谱。这里的关键设计是 **URI 版本化区分**：

- 课标知识点匹配到 **EduKG 已有的概念** → 用 **v0.1 URI**（复用现有节点，不新建）
- 匹配不到的 **新增概念** → 用 **v0.2 URI**（`{拼音}-{md5}`，如小学的"估算"）
- 每个概念带 **`version` / `is_existing`** 字段，可溯源、可审计

结果：434 个课标知识点 → 122 个概念（**102 个已存在于 v0.1 + 20 个新增 v0.2**），过滤 15 个非核心（购物/招聘/游戏这类跟数学无关的条目）。

> 一句话面试答案："加小学数据不污染已有图谱——匹配到 EduKG 概念的复用 v0.1 URI，新增概念用 v0.2 URI，每个带 version/is_existing 可溯源可回滚。"
