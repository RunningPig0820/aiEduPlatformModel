### 收费 OCR vs 免费 LLM：贵的跑一次、便宜的随便跑
> 检索摘要：OCR 为什么用收费的百度 API？扫描版 PDF 只能 OCR 识别；成本选型是"贵的跑一次、便宜的随便跑"——百度 OCR 收费但一次性执行，后续全部 LLM 步骤用免费 glm-4-flash。

成本驱动架构的一个例子：**OCR 用收费的百度 API，LLM 用免费的 glm-4-flash**。

- **百度 OCR**：收费，但**一次性执行**（189 页扫描版 PDF 识别一次就完事）
- **glm-4-flash**：免费，后续所有 LLM 步骤（知识点提取/定义生成/关系分析）都用它

> 一句话面试答案："OCR 收费但只跑一次，LLM 免费所以全流程随便用——成本选型就是'贵的跑一次、便宜的随便跑'。"
