## Context

后端已完成行政班管理 API（`/api/admin-classes`），提供学段/年级/班级三层树形节点的 CRUD 操作。前端需在学校工作台中新增行政班管理页面。交互方案已通过 brainstorming 确认，采用与 `DepartmentManagement` 一致的左右分栏布局。

**技术约束：**
- 前端框架：React 18 + React Router 6
- UI 框架：Tailwind CSS 3 + daisyUI
- HTTP 客户端：axios（通过 `request.js` 拦截器统一处理响应）
- 认证方式：Cookie/Session（`withCredentials: true`）
- 后端 API 基础路径：`/api/admin-classes`

## Goals / Non-Goals

**Goals:**
- 在学校工作台中新增行政班管理页面，左右分栏布局（左侧树 + 右侧节点详情）
- 左侧树节点简洁展示（只显示名称），hover 显示操作按钮
- 右侧面板展示选中节点属性 + 操作按钮，未选中时显示引导提示
- 抽屉表单只显示当前节点类型可编辑的字段，继承字段不展示
- 学段编码、年制、年级编码的下拉选项从后端枚举接口获取，降级到本地常量
- 级联约束：学段→年级→班级，有子节点时阻止删除

**Non-Goals:**
- 学生列表展示（行政班结构完成后处理）
- 批量创建、拖拽排序
- 学生端/教师端/家长端展示行政班
- 不修改后端 API

## Decisions

### 1. 布局：左右分栏与 DepartmentManagement 一致

**选择：** 左侧树 256px + 右侧自适应，与现有组织管理体验统一。

### 2. 左侧树：节点仅显示名称

**选择：** 节点只展示名称文字，无类型图标、无副文本。通过层级缩进和展开/折叠箭头表达树形关系。hover 时显示操作按钮（新增子节点/编辑/删除）。

**原因：** 与 brainstorming 沟通结论一致——简洁优先。行政班的类型信息（学段/年级/班级）在右侧详情面板中展示即可。

### 3. 右侧面板：节点详情卡片

**选择：** 选中节点后，右侧以卡片形式展示节点属性，拓扑如下：

| 节点类型 | 展示属性 | 操作按钮 |
|---------|---------|---------|
| 学段 | 名称、学段编码（中文）、年制（中文）、描述 | 新增年级、编辑、删除 |
| 年级 | 名称、学段编码、年级编码（中文）、入学年份、描述 | 新增班级、编辑、删除 |
| 班级 | 名称、学段编码、年级编码、入学年份、描述 | 编辑、删除 |
| 未选中 | 引导提示「请在左侧选择行政班节点」 | — |

编码中文映射（本地常量，后续可迁移至后端枚举 API）：

- 学段编码：`PRIMARY`→小学、`JUNIOR_HIGH`→初中、`SENIOR_HIGH`→高中
- 年制：`4`→小学六年制、`5`→初中三年制、`7`→高中三年制
- 年级编码：`1-12`→一年级~高三

### 4. 抽屉表单：只显示可编辑字段

**选择：** 继承字段（如年级继承学段的 stageCode/stageYearCode）不在表单中展示，减少干扰。

**各类型表单字段：**

| 类型 | 字段 | 数据来源 |
|------|------|---------|
| 学段 | 名称、学段编码（下拉）、年制（下拉）、排序、描述 | 学段编码、年制：后端枚举接口→本地常量降级 |
| 年级 | 名称、年级编码（下拉）、入学年份、排序、描述 | 年级编码：根据所属学段年制确定范围 |
| 班级 | 名称、排序、描述 | — |

**原因：** 与 brainstorming 沟通结论一致。继承字段由父节点决定，不应在子节点表单中展示或修改。

### 5. 枚举数据获取策略

**选择：** 优先调用后端枚举接口，失败时降级到前端本地常量。

**原因：**
- 后端枚举接口待开发，前端不能阻塞
- 本地常量与后端 API 文档中定义的编码一致，切换无成本
- 后续后端接口就绪后只需替换数据源

### 6. API 模块：扩展现有 organizationApi

**选择：** 在 `src/api/modules/organization.js` 中新增行政班 CRUD 方法。路由作为 `SchoolWorkspaceLayout` 子路由。

## Risks / Trade-offs

- [枚举接口未就绪] → 前端先用本地常量降级，接口就绪后切换数据源，改动仅限抽屉组件
- [学生列表后续对接] → 右侧面板预留学生列表区域（本期为引导提示），后续只需替换右侧内容区
