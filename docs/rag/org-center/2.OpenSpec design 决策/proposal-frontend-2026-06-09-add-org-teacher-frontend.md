## Why

学校组织架构已完成部门树（Department）管理，现在需要在此基础上添加教职工管理功能。教职工本质上是"用户与部门的关联关系"，前端需要配合后端实现教职工的添加、查看、编辑、删除交互，支持按部门筛选教职工列表。

## What Changes

- 新增教职工添加功能：右侧抽屉表单，输入姓名、手机号、选择所属部门
- 新增教职工查看功能：右侧抽屉展示教职工详情（只读）
- 新增教职工编辑功能：右侧抽屉编辑所属部门（姓名/手机号在用户中心修改）
- 新增教职工删除功能：确认删除后移除关联关系
- 新增教职工列表展示：姓名、联系电话、学科/专业（默认"未分配"）、职务（默认"教师"）
- 新增按部门筛选教职工：点击左侧部门树节点，右侧列表显示该部门教职工
- 新增教职工 API 模块：调用后端 `/api/org/teachers` 相关接口

## Capabilities

### New Capabilities

- `org-teacher-ui`: 教职工前端交互功能，包括添加、查看、编辑、删除教职工，以及按部门筛选教职工列表

### Modified Capabilities

（无修改的现有能力）

## Impact

- **前端组件**：
  - DepartmentManagement.jsx：教职工列表展示、按部门筛选、添加/查看/编辑/删除操作
  - TeacherDrawer.jsx（新增）：教职工抽屉表单组件（添加/查看/编辑）
  - organization.js API 模块：新增教职工相关 API 接口

- **后端 API 联调**：
  - GET /api/org/teachers（获取教职工列表）
  - POST /api/org/teachers（添加教职工）
  - GET /api/org/teachers/{id}（获取教职工详情）
  - PUT /api/org/teachers/{id}（更新教职工所属部门）
  - DELETE /api/org/teachers/{id}（删除教职工）

- **交互逻辑**：
  - 选中部门后添加教职工：部门字段预设
  - 未选中部门添加教职工：需手动选择部门
  - 学科/职务默认值处理：前端显示"未分配"、"教师"
