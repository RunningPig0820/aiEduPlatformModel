## 硬性规则（强制全部遵守）

### 术语强制统一
固定术语：canonical标准题型 / 派生层 / obs观测层 / 掌握度 / 解析管线 / 动态涌现 / 两域解耦。禁止自行创造别名。

### 状态判定标准（严格区分，禁止混淆）
- ✅【已落地设计】：代码可观测到实现逻辑；语雀文档描述+代码同时存在。
- ⚠️【建议项(未实现)】：仅语雀方案文档描述，代码无对应实现，属于设计构想、备选方案。
- ❓【待决策 Open Question】：语雀和代码均无明确结论，待后续评审拍板。

### 证据标注规范
1. 语雀来源证据：`证据：语雀-原文件-xxx.md`；引用总揽：`[总揽§X.X]`
2. 代码来源证据：优先写 `文件:函数名/类名`；无法获取真实行号时禁止编造虚假行号，写 `文件:逻辑片段`；只有明确可见行号才写 `文件:行号`。
3. 某类来源不可读（如 Java 代码无法解析），证据字段写 `来源不可读，无有效证据`，禁止编造逻辑。

### 格式与内容约束
1. 移除全部对话、问答、来回讨论口吻；输出正式技术综述，禁止提问者/回答者视角。
2. 规则、阈值全部使用表格承载；段落简短，避免大段无分割文本。
3. 同主题信息归并，一处讲透；总揽已详述内容直接引用章节标记。
4. **禁止业务臆造，所有内容必须来自来源材料，没有来源就如实标记信息缺失。**
5. 引用本库内部文档标记：决策记录条目标记 `D#序号`。

### 输出前强制自检（不输出自检文本，只保证结果符合）
1. 是否区分 ✅/⚠️/❓ 状态，没有把建议项标记为已落地。
2. 所有代码相关条目是否附带证据，没有编造行号。
3. 是否删除问答对话口吻。
4. 是否出现术语别名。
5. 是否有重复内容，同类决策已合并。
6. 文档顶部元信息完整，summary、权威度、模块、COS路径、类别字段齐全。

### 失败降级
某类来源完全不可读，直接跳过该来源信息，如实在证据字段标记，不编造内容。

# 任务：产出「语雀-决策记录.md」

用途：回答"为什么这么设计"，抽取语雀文档、代码中所有拍板的设计决策，条目化记录决策、背景、演进、理由、影响。

> 输出文件名：语雀-决策记录.md
> summary: 汇总题型知识点模块全部设计决策，记录每一项决策的背景、演进过程、拍板理由与系统影响
> 权威度: 0.8
> 模块: question-analysis
> COS路径: rag-source/question-analysis/语雀/语雀-决策记录.md
> 类别：架构设计

## 强制输出约束（RAG 切片友好，必须严格遵守）

1. ❌ 禁止把全部决策塞进一张超大横向主表格作为文档主体（宽表切片时行被切断、语义单元断裂）。
2. 文档开头增加【文档说明】小节，说明 D# 编号用途、阅读提示：分块小节用于 RAG 检索，末尾附录总表仅供人工查阅。
3. 将全部 D# 决策按业务领域分组：
   - 架构层决策
   - 掌握度口径决策
   - 向量&聚集归并算法决策
   - 机制取舍决策
   - 建议项（未实现 ⚠️）
   - 待决策（❓ Open Question）
4. 每一条决策使用 `### D{num}` 标题独立小节，一条决策一个 h3，适配标题切片策略——一个 chunk 就是一条决策。
5. 每条决策最上方输出：`> 状态：xxx`；`> 检索摘要：xxx`。检索摘要为 1-2 句话，提炼该决策核心语义，专门用于向量召回（对应 -q 向量锚点）。
6. 单条决策内部使用**窄属性竖向小表**，字段：背景、演进、拍板理由、系统影响、证据。不要宽横向大表。
7. 全部决策输出完成后，文档最末尾增加【附录：全决策总索引】，放完整原始大表格；必须写注释：`⚠️注意：向量切片不要依赖本表，业务检索请使用上面分章节的单条决策小节。`
8. 所有原始信息、D# 编号、证据链接、状态标识**不能丢失、不能篡改**。

## 提取范围（逐项覆盖，不遗漏）

1. 架构类：权威图谱零写入/派生层、Python桥、两域解耦、多索引vector_type
2. 口径翻转类：掌握度主体：知识点→题型；掌握度数值：离散四档→累计平均；PENDING语义定义变更
3. 算法参数类：累计平均公式、打折系数、归并阈值、聚合触发阈值(CANDIDATE/STABLE)
4. 机制取舍类：编辑距离近字归并移除、自动关联→手动维护、去定时、挂起不落掌握度
5. 来源约束类：掌握信号唯一来源、候选列表接地约束

## 校验规则

1. 每一条决策必须包含「拍板理由」，不能只描述做了什么；
2. 演进列必须写清楚改造前后对比；
3. 代码相关决策必须填写证据；
4. D# 为本文档内部序号，供其他文档引用；
5. 重复的同类决策必须合并，不要多条重复记录；
6. **每条决策必须是一条独立 h3 块**（含检索摘要），不得退回宽表主体。
