> summary: 解答「题型知识点模块做什么 / 核心价值是什么」——把散乱答题记录聚成 canonical 题型、算题型掌握度，核心主张：掌握度主体是题型不是知识点，与知识图谱本质区别（个人能力画像 vs 知识结构）。

## 为什么（语雀）

学生做题的原始记录是散乱的：一道"鸡兔同笼"题，不同学生、不同轮次问出来叫法五花八门（"鸡兔同笼""鸡兔同笼问题""假设法""笼中鸡兔"）。要让这些零散答题记录变成可分析、可展示的能力画像，必须先把它们**聚到统一的题型**（canonical），再算**题型掌握度**、出**多维能力画像**（概念理解/计算/逻辑/审题）。

核心业务目标（语雀-方案设计2）：**掌握度主体是题型，不是知识点**——学生掌握的是"解题模式"（鸡兔同笼类题做得怎么样），不是抽象知识点（二元一次方程组）。题目 → 识别题型 → 当场判该题型状态（已掌握/练习中/待巩固/待确认），不绕道知识点。知识点是从题型派生的（后置）。

## 怎么设计（方案）

**（方案口径，已演进）** 早期方案把掌握度挂**知识点 URI**（`mastered→75/practicing→50/struggling→25`，取 max 单调不减），题目直接关联知识点。**这已不是最终形态**——落地演进为题型口径（见下）。

演进后的核心设计（语雀-方案设计2-问题3/4 + design-question-type-mastery-backend）：

- **无题库、零锚点**：没有预置的题型分类表。canonical 由学生题目**动态涌现**——第一条题建锚，后续题目标题名向量查最近邻，命中归并/未命中建新。题型是"长出来的"，不是"规定出来的"。
- **动态聚集 = 字符规则 + 题型名向量最近邻**：字符规则先拦"解X/求X"类确定性变体，向量层处理语义同型（鸡兔同笼/鸡兔同笼问题/假设法）。**题目向量本期不落库**（Non-Goal，相似题后续）。
- **掌握度 = 累计平均正确率**：`new = old×n/(n+1) + score×1/(n+1)`，替代 max 单调不减。答对/求助后答对/答错映射 1.0/0.5/0.0，per-题型前几题打折。
- **权威图谱零写入**：题型↔知识点关联放派生层（MySQL），Neo4j 只被"借结构"（持 URI 向外展开），不污染权威图。
- **两域解耦**：域 A「题目→题型」（本期，掌握度）与域 B「题型→知识点」（独立维护）完全解耦，一个故障不影响另一个。

## 落地真相（代码）

> ⚠️ **最大翻转**：掌握度主体从"知识点 URI"改为"**题型**"，从"单调不减"改为"**累计平均**"。`mastery_signals` 字段 `kp_label → topic_label`，`mastery_snapshot` 脱钩（不再为题型提供知识点候选接地）。表 `t_student_kp_mastery` 被 `t_student_topic_mastery`（canonical key + 累计平均）替代。

- **题型分析完整链路**：贴题/答疑题目 → `subject_classify`（学科门，decide 之前）→ `question_understand`（题型识别，status=RESOLVED/PENDING）→ 题型名向量查最近邻归并 canonical → 落题目表（事实源）+ 掌握表（累计平均）。
- **掌握度信号题型化**：`decide` 的 `mastery_signals[].topic_label` 稳定输出题型名（鸡兔同笼/相遇问题/牛吃草），不输出知识点名——否则后端题型库混入知识点名，整条链路脏。
- **Python 桥向量**：`api/vector.py` put/query，`vector_type="topic"` 路由 topic-index（768 维 cosine），embedding 复用 dashscope（text-embedding-v3）。归并阈值 distance ≤ 0.2（保守，只并同型）。

## 追问与防御

**预期追问：这和知识图谱有什么区别？**
→ **回答要点**：知识图谱是**知识结构**（教材知识点 + 关系，权威、可枚举）；这是**学生个人能力画像**（题型掌握度 + 答题证据，动态、可增长）。图谱管"课程长什么样"，题型掌握度管"这个学生练得怎么样"。

**预期追问：题型和知识点边界这么模糊（一元二次方程既是题型也是知识点），怎么不打架？**
→ **回答要点**：题型是**可测的解题模式**（题目天然可聚），知识点是**课程锚点**（映射依赖图谱）。掌握度锚题型因为题目可聚到题型、可打分可观测、落库不裂行；知识点由题型派生（后置）。两域解耦，canonical 名经别名表收敛，互不污染。

**预期追问：这模块是不是只是统计报表？**
→ **回答要点**：不是。题型动态聚集用**真实向量检索**（cosine 最近邻，threshold 0.2 归并旋钮），是真实的检索能力；掌握度是**事件驱动的累计正确率**（可追溯每道题）；且题型库反过来喂变式题/错题分组/薄弱诊断（数据飞轮闭环）。
