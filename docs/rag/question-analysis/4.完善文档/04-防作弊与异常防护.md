# 04 防作弊与异常防护
> COS路径: rag-source/question-analysis/完善文档/04-防作弊与异常防护.md

> 模块=question-analysis｜节=04｜问题表=难点｜权威度=高（正文）

## 为什么（语雀）

题型识别/学科门是答疑链路的**前置闸门**，判断错了会污染整条数据：把数学题误判成别的学科 → 学生问不了数学；识别题型乱猜 → 掌握度算错、图谱点亮错。且这些 LLM 环节不能成为新的**性能卡点**（开思考实测 50~145s，必须关思考 + 快速失败）。

## 怎么设计（方案）

**核心原则：宁可放过，不可误判；宁可快速失败，不可无限等待。**

- **学科门**（decide 之前）：只判学科不解题。"宁可放过，不可把数学题误判成别的学科"，拿不准 → 输出 math；图片无法辨认/非学科 → other。闭集外（地质/天文）→ 不硬归类。
- **题型识别**：低置信不硬猜——识别失败 = 空结果，Java 降级 PENDING（走澄清卡），不编造题型名。
- **慢修复**：学科门/题型识别统一关思考（thinking disabled）+ 20s 超时 + 关 SDK 重试——慢或失败快速返回空结果，不让调用方无限等。
- **结构化输出兜底**：四段降级管线（function calling → JSON mode → 正则提取 → 兜底 `type=hint, degraded=true`），保证 ActionMeta 绝不畸形、绝不抛异常。

## 落地真相（代码）

> ⚠️ 代码口径：Python 侧不判置信度——"识别失败 = 空 topic_labels = Java 降级 PENDING"。低置信挂起/澄清卡（resolve/vote）全在 Java/前端。

**Python 侧护栏（ai-edu-ai-service）：**
- **subject-classify**：K12 十值闭集（math/physics/chemistry/biology/chinese/english/politics/geography/history/other），闭集外 → `None`（防把地质/天文误判成 other）→ Java 按 math 放行（宁漏拦不误拦）。写死 doubao mini、temp 0.3、**关思考 + 20s 超时 + 重试 0**，整个函数 try/except 绝不抛异常。（`core/tutoring/subject_classify.py:24-87`）
- **question-understand**：图片题题型识别，`topic_hint`（Java 传题型库 top-20 常用名）注入 prompt 收敛命名，从源头压变体漂移；解析失败/LLM 失败 → 空结果，绝不抛异常。（`core/tutoring/question_understand.py:82-111`）
- **decide 答题护栏**：不在答题（闲聊/非数学题）→ `type=concept` 引导回题，绝不 end；任何在答题内容（无论对错）绝不 `type=end`/`type=reveal`；`_sanitize_end_consistency` 防"答错被恭喜/泄答案"。（`core/tutoring/decider.py:24-53`、`prompts.py:61-68`）
- **换题短路**：Java 检测新题 → `is_new_question=true` → 直接 `type=switch` 不调 LLM（确定性 100% 准，省调用）。（`core/tutoring/decider.py:67-74`）
- **safety_flag**：学生消息含自伤/暴力 → `safety_flag=true`（拦截由 Java 执行）。（`prompts.py:85-86`）

## 追问与防御

**预期追问：题型识别错了怎么办？**
→ **回答要点**：低置信不硬猜——识别失败返回空结果，Java 降级 PENDING 走澄清卡（resolve/vote，学生确认或跳过），不编造题型名进掌握表。识别对的信号才落库，错的不会污染。

**预期追问：学科门判错了（数学题判成非数学）？**
→ **回答要点**：设计取向是"宁漏拦不误拦"——拿不准输出 math，闭集外返回 None 按 math 放行。代价是"垃圾学科题"可能进答疑，但数学题永远不会被拦在门外。误拦（学生问数学被拒）是更糟的产品事故。

**预期追问：这些 LLM 前置环节会不会拖慢答题？**
→ **回答要点**：专门做了"慢修复"——关思考（thinking disabled，实测 50~145s → 秒出）+ 20s 超时 + 关 SDK 重试。慢或失败快速返回，让 Java 走降级路径，不阻塞主链路。
