## 为什么（语雀）

没有题库、没有预置的题型分类表，学生题目一条条来，LLM 每次猜的题型名是**弱标注**（会飘：鸡兔同笼/鸡兔同笼问题/假设法/笼中鸡兔）。要把 20 条散名并成 5 个真实题型，需要一个**零锚点**的聚集机制——题型不是"规定出来的"，是"长出来的"。

## 怎么设计（方案）

**（方案口径，已演进）** 早期方案：预置 canonical 池 + 新名归进池 + 字符规则（编辑距离 ≤1 近字归并）。**已调整**——编辑距离移除（"一元一次/一元二次"一字之差与错别字"方成/方程"同为距离 1，字符级无法区分会误并）；近字/错别字归并全交给向量层（语义最近邻正确区分"一次/二次"、归并"方成/方程"）。

### 动态涌现（零锚点）

```
第 1 条题：向量桶无近邻 → 建 canonical（锚点诞生）
第 N 条题：题型名向量查最近邻 → 命中归并 / 未命中建新
批量（手动触发）：散名全量聚类 → 补归并 + LLM 归纳规范名 → 重算聚合
```

- **canonical 是动态涌现的**：由"第一条相似题"创建（首见名/最高频名兜底），后续题目落进已有 canonical。池 = 向量桶里已聚集的题型，**从零长出来**。
- **聚集依据 = 字符规则 + 题型名向量最近邻（单信号）**：
  - 字符级规则先拦确定性变体（"解X/求X"前缀剥离 + 全半角/空白/标点归一），省 embedding 调用。
  - 题型名向量处理**语义同型**（鸡兔同笼/鸡兔同笼问题/假设法）。
  - **题目向量本期不落库**（Non-Goal，相似题检索后续；聚集不依赖题面相似，题目文本仍落 MySQL 作事实源）。

### 归并阈值（粒度旋钮）

```
distance ≤ 0.2   归并到命中 canonical（写别名表）—— 只并同型，不并异型
0.2 ~ 0.3       建新不误并
≥ 0.3           异型建新（宁可拆不误并）
```

- 实测：self≈0、同型 ~0.077（鸡兔同笼→鸡兔同笼问题）、异型 ≥0.33（相遇→行程 0.332）。同型/异型在 0.08~0.33 有清晰间距，0.2 是保守默认。
- "相遇 vs 行程"（0.332）不被 0.2 归并 → **默认拆分**。粒度是产品定义，不是向量能替你定的。

## 落地真相（代码）

> ⚠️ 代码口径：Python 只提供向量**原语**（put/query），canonical 决策在 Java（`TopicLabelAggregationService.aggregate`）。Python 侧无定时批量聚类（设计明确"不做批处理/定时任务，后端已定手动触发"）。

**Python 侧（ai-edu-ai-service）：**
- `POST /api/tutoring/vector/put|query`，同步 JSON，`x-internal-token` 鉴权。（`api/vector.py:30-81`）
- `vector_store.py`：`embed(text)`（dashscope text-embedding-v3，显式 `dimensions=768`，默认 1024 必须显式）+ `put_vector`/`query_vector` + `_resolve_index` 路由。（`core/tutoring/vector_store.py:26-28, 87-179`）
- `vector_type` 必填，本期唯一合法值 `"topic"` → 索引 `topic-index`（768 维 cosine）；`question`/`rag` 纯配置占位。未知 → 400。（`settings.py:99-105`）
- key = 业务 ID（Java 传），本期语义 = 题型名向量；metadata 透传（student_id/topic_label/canonical_label/timestamp），Python 不改写。（`models/vector.py:16-24`）
- **写入延迟坑**：`put_vectors` 后索引异步生效 ~10s，立即 query 可能 miss（空 vectors）。（`vector_store.py:126-127`）

**Java 侧（canonical 决策）：**
- ① 字符规则归一（全半角/空白/去标点 + "解/求"前缀剥离）② 题型名向量最近邻（distance ≤0.2 归并写别名表 / 0.2~0.3 建新 / ≥0.3 异型建新）③ 首题建锚（零锚点，动态涌现）。

## 追问与防御

**预期追问：为什么用向量不用字符规则？**
→ **回答要点**："一元二次方程" vs "解一元二次方程" vs "鸡兔同笼/假设法"——字符规则只能拦确定性变体（解/求前缀、全半角），语义同型（叫法完全不同但同一解题模式）规则匹配不了。向量最近邻在同型 0.077 vs 异型 ≥0.33 之间有清晰间距，能正确归并近义、区分近似（一次/二次）。

**预期追问：归并错了怎么办（误并/漏并）？**
→ **回答要点**：阈值 = 粒度旋钮，保守默认 0.2（宁可拆不误并——误并的题权重会互相污染；漏并后续人工/别名表补）。spike 实测"相遇 0.332/行程"默认拆分，等更多证据再并。累计百分比对个别误并可容忍。

**预期追问：为什么不做相似题检索（题目向量）？**
→ **回答要点**：本期范围收敛——掌握度/动态聚集只需要**题型名向量**（归并 canonical 够用）；相似题检索是独立功能（"和这题类似的题"），题目向量不落库（`question` 索引仅配置占位），后续启用零架构改动。
