```
问题列表.md（9 视角 67 问，纯问题）
   ├──▶ guide_pool（前端引导候选，intro/operation/data_relation/difficulty/rag 分组）

```

## 三、生成指引

1. 用 `提示词/问题列表-生成-提示词.md` 重生成（输入：主文档 + 完善文档 + 分析 + 坑档案）
2. **可回答性第一**：每条问题必须能在语料中找到答案（对照完善文档/分析文档）
3. **纯问题不回答**：只产问题清单，答案走检索链路
4. 生成后按 intro/operation/data_relation/difficulty/rag 映射进 `guide_pool.py` 的 `GUIDE_POOL["question-analysis"]`
