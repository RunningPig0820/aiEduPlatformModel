### 决策 2：题目来源：全入口采集，且是唯一证据源

> 检索摘要：全入口题目采集唯一证据源：AI 答疑唯一产生信号，题型分析页只记题不产生信号，掌握表每行有题可回查。

所有入口的题目统一落库：
- AI 答疑（学生提问时的题目）——**唯一产生掌握信号**的入口；
- 题型分析页（贴题/拍题/粘贴图片）——记录题目，但**不产生掌握信号**（学生只是贴了题，没做）；
- 未来扩展：练习、题库做题。

**为什么这样设计**：掌握度必须可追溯。零散观测无法回答「这个题型练了几道、答对几道、从哪来」；全量采集后，掌握表每一行都有题目证据可回查（跳转题目）。
