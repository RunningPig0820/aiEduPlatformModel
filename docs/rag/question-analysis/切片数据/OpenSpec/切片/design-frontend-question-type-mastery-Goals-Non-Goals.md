### 目标与非目标

> 检索摘要：目标=题目→题型掌握数据底盘（采集→向量→聚类→聚合）+可追溯累计平均+列式展示；非目标=题型知识点关联/题库/确认关联/管理端审核。

**Goals:**
- 建立「题目 → 题型掌握」的完整数据底盘：采集 → 向量 → 聚类 → 聚合。
- 掌握度可追溯：每道题都有记录，掌握度 = 累计平均（可解释）。
- 掌握度页列表化：题型 / 来源 / 掌握程度% / 训练数 / 跳转题目。

**Non-Goals（本期明确不做）：**
- **题型↔知识点关联不做**——知识点不从题型派生覆盖度，知识点总览页仅展示知识地图（不标熟练度）。
- 题库建设（当前题库无题）。
- 学生确认关联 / 待确认清单确认 / 候选搜索（沿用 `kp-question-analysis` 的范围降级，转后续独立功能）。
- 管理端全局审核题型↔知识点。
