### 验收反馈 C：摘要卡点击筛选（已掌握 / 练习中 / 待巩固）

> 检索摘要：摘要卡点击筛选档位：前端按 masteryBucket 过滤本地 items，纯前端后端不改。

- **反馈**：点击摘要卡「已掌握 / 练习中 / 待巩固」时，列表按该档位筛选。
- **方案**：摘要卡可点击 → 选中档位 → 前端按 `masteryBucket(level)` 过滤本地 items 展示。**纯前端，后端不改**。
- **交互**：未选中 = 全部；选中某档 = 只显示该档；再次点击取消筛选。
