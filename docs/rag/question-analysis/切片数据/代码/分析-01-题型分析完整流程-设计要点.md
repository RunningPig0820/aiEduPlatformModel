## 设计要点

- **Python 纯智能无状态**：不落库，所有状态在 Java Redis/掌握表；Python 只做 LLM + 向量原语。
- **信号跟题目走，不跟题型走**：PENDING 题型照常采信号落题目表，归属确定后再聚合，不因待定丢数据。（`decider.py` + `mastery_signals`）
- **四类失败语义分治**：业务判定吞异常降级空结果；向量基础设施错误冒泡让 Java 感知后降级。（`api/vector.py:8-9`）
