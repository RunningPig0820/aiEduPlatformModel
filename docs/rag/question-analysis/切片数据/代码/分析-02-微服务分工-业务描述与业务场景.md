## 业务描述与业务场景

**业务描述**：一次答疑/题型分析是**三方协作**的业务——学生在前端操作，Java 后端决定"要不要处理、怎么落库"，Python AI 服务负责"判断学科、认题型、出掌握度信号"。本节讲清三方各管业务的哪一块。

**业务场景**：
1. 学生点「发送消息」→ 前端触达 Java → Java 先过学科门（决定收不收数学题）→ 再调 Python decide（决定这轮怎么引导）。
2. 图片题在 Java 上传 COS 后交给 Python question-understand 认题型；文本题由 Java 自己用 KpQuestionAnalyzer 识别——业务入口不同，分工不同。
3. 题型归并 canonical、掌握度落库全在 Java；Python 只管"出信号、存向量"，故障时 Java 桥侧降级——分工决定谁的故障影响谁。
