## 业务描述与业务场景

**业务描述**：学生掌握的是**题型**（解题模式，如鸡兔同笼）而不是抽象知识点。系统在答题过程中判断 Ta 对每类题型练得怎么样，累计成可解释的掌握度（连续百分比），让"这个学生哪里薄弱"看得见。

**业务场景**：
1. 学生在答疑里做「鸡兔同笼」题——直接答对/求助后答对/答错被折算成信号，落进该题型的掌握度（第 1 题打折更保守），报表上可看「64%·练了10题」。
2. 下一次决策时，系统把学生已有掌握度快照塞回给 AI（薄弱题型排在前面）——AI 优先照顾不会的题，快照只是上下文，不会反过来污染题型名。
3. 学生在掌握度页看到列式的题型清单 + 训练数 + 可跳转原题——掌握度可追溯，不是拍脑袋数字。
