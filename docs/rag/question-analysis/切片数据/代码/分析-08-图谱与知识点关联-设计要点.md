## 设计要点

- **两域解耦**：域 A「题目→题型」（本期，掌握度）与域 B「题型→知识点」（独立维护）完全解耦，一个环节故障不影响另一个。
- **查表只读 + ADMIN 维护**：识别题型 → 查题型库（findByTopicLabelOrAlias → 分布桶）→ 命中返回权威分布/未命中返回"仅题型+canonical+空知识点"——不挂起、不写 obs、不顺带 LLM kps。（design Decision 10，Java 侧）
- **权威图谱零写入**：Neo4j 只被"借结构"（持 URI 向外展开），题型↔知识点放派生层 MySQL，权威图不被污染。（refer 对账）
