## 设计要点

- **确定性护栏不信任模型格式**：end 联动、换题短路都是代码层面的硬校验，LLM 只被当候选输出，不是最终裁决。
- **两类失败语义分治**：业务判定（学科门/题型识别）= 吞异常降级空（宁返回空不阻塞）；向量基础设施 = 错误冒泡（Java 有降级，Python 正常报错便于定位）。
- **识别失败不是错误**：空结果 → Java PENDING（低置信挂起，走澄清卡），不编造题型名。
