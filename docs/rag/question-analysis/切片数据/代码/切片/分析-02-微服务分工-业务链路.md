## 业务描述与业务场景

**业务描述**：一次答疑/题型分析是**三方协作**的业务——学生在前端操作，Java 后端决定"要不要处理、怎么落库"，Python AI 服务负责"判断学科、认题型、出掌握度信号"。本节讲清三方各管业务的哪一块。

**业务场景**：
1. 学生点「发送消息」→ 前端触达 Java → Java 先过学科门（决定收不收数学题）→ 再调 Python decide（决定这轮怎么引导）。
2. 图片题在 Java 上传 COS 后交给 Python question-understand 认题型；文本题由 Java 自己用 KpQuestionAnalyzer 识别——业务入口不同，分工不同。
3. 题型归并 canonical、掌握度落库全在 Java；Python 只管"出信号、存向量"，故障时 Java 桥侧降级——分工决定谁的故障影响谁。

## 职责

Python（ai-edu-ai-service）本模块 = **纯智能四端点桥**：学科门/图片题型识别/掌握度信号输出/向量原语，全部无状态、不落库。
Java（aiEduPlatform）= 编排 + 决策（canonical 归并/掌握度计算/落库/防作弊）+ 前端契约。
**Python 显式禁止做题型↔知识点映射**（`models/tutoring.py:73-76`）。

## 高层业务调用链（前端→Java 编排→Python 六端点）

```mermaid
flowchart TD
    FE[前端 AiQa.jsx] -->|start/send/requestAnswer| JAVA[Java TutoringAppService 编排]
    JAVA -->|① 学科门 decide 前| SC[POST /api/tutoring/subject-classify 同步JSON]
    SC -->|空 subject / 非 math| SKIP[跳过: 不建/不续会话 不落库]
    SC -->|math| ENSURE[ensureCreateAllowed 频率限制]
    JAVA -->|图片题| QU[POST /api/tutoring/question-understand 同步JSON]
    QU -->|空 topic_labels| PENDING[Java 降级 PENDING 挂起]
    ENSURE -->|每轮| DECIDE[POST /api/tutoring/decide 流式SSE]
    DECIDE -->|meta ActionMeta| GUARD[Java 护栏审批 type]
    DECIDE -.流中段失败.-> ERR[event:error 流终止 Java 不可重试]
    QU -->|topic_labels| JAVA
    GUARD -->|放行| GEN[POST /api/tutoring/generate 流式SSE]
    GEN -.失败.-> ERR
    GEN -->|token 流| FE
    JAVA -->|题型名归一| V[POST /api/tutoring/vector/put|query 同步JSON]
    V -.失败 HTTP 400/500.-> FALLBACK[Java 桥降级: 回退字符规则 + 原样落库]
```

**文字复述**：前端 AiQa.jsx 自动路由（start/send/requestAnswer）→ Java TutoringAppService 编排总控。①先过学科门 `POST /api/tutoring/subject-classify`（同步 JSON，decide 前置）：返回空 subject 或非 math → 跳过（不建/不续会话、不落库）；math → `ensureCreateAllowed` 频率限制。图片题走 `POST /api/tutoring/question-understand`（同步 JSON）认题型，返回空 topic_labels 时 Java 降级 PENDING 挂起，有 topic_labels 回传 Java；文本题由 Java 自研 KpQuestionAnalyzer 识别，不经过此端点。每轮 decide `POST /api/tutoring/decide`（流式 SSE）输出 meta ActionMeta → Java 护栏审批 type；decide 流中段失败发 event:error 流终止，Java 不可重试。护栏放行后 `POST /api/tutoring/generate`（流式 SSE）生成正文，token 流回前端；generate 失败同样走 event:error。题型名归一走 `POST /api/tutoring/vector/put|query`（同步 JSON）归并 canonical；失败（HTTP 400/500）时 Java 桥降级回退字符规则 + 原样落库。
