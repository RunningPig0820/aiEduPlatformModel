## 隐性坑与注意事项

- **put 后 ~10s 异步生效**：建锚后不立查、留重试（`vector_store.py:13` spike 实测注释）。
- **subject-classify 闭集外 → None，不是 other**：other = "明确非学科内容"，None = "不知道"；Java 按 math 放行，宁漏不误（`models/tutoring.py:212-216`）。
- **decide/generate 中段失败 Java 不可重试**，提示重发（`api/tutoring.py:93` 注释）——别把 error 事件当可恢复。
- **embedding 维度一旦建索引就不可改**：768 维必须与索引一致，否则写失败（`vector_store.py:27-28`）。
- **未知 vector_type → 400**：Java 传错逻辑名直接 400，不是 500（`api/vector.py:45-47`）。
- **is_new_question 短路**：Java 换题信号 → Python 直接 `type=switch` 不调 LLM，别误当决策错误（`models/tutoring.py:143`）。

## 对账复盘（原始方案 → 实际落地 → 业务影响）

**掌握度主体 ⚠️翻转**：语雀/design 口径以知识点 URI 为主体；实际落地以**题型（canonical 题型名）**为掌握度主体。影响：学生掌握的是解题模式，题目可聚可打分可观测，落库不裂行。

**canonical 来源 ⚠️翻转**：语雀/design 口径为预置题型池；实际落地为**动态涌现**（首题建锚、向量最近邻靠拢）。影响：无题库也能跑，题型从做题数据里长出来。

**掌握度数值 ⚠️翻转**：语雀/design 口径为离散四档、max 单调不减；实际落地为**连续 0-100 累计平均**。影响：可算"练了几道、对了几道"，答错真实反映不虚高。

**字符归一 ⚠️翻转**：语雀/design 口径为编辑距离 ≤1 近字归并；实际落地**已移除，全交向量层**（"一元一次/一元二次"一字之差与错别字同为距离 1，无法区分会误并）。影响：语义最近邻正确区分"一次/二次"、归并"方成/方程"。

**题型↔知识点映射职责 ✅落地**：语雀/design 口径把映射放 Python 桥；实际落地 **Python 显式禁止**（代码注释明确不做题型↔知识点映射，映射由 Java ADMIN 维护）。影响：权威图谱零写入红线，域名 B 独立化。

**analyze-question 接口 🚫Python 不做**：语雀/design 提及 Python 提供 `analyze-question` 端点；实际落地 **Python 无此端点**（在 Java）。影响：排查端点时别在 Python 找，该端点归属 Java 侧。

**decide 契约 ⚠️翻转（BREAKING）**：注释早期待遇为非流式 JSON；实际落地**已改 SSE 流式**（BREAKING 变更）。影响：前端逐步收 token，体验更好但属破坏性变更。
