## 隐性坑与注意事项

- **topic_label 是题型不是知识点**：Python 输出题型名，否则污染后端题型库 → 掌握度/派生覆盖度/图谱点亮全脏。（`prompts.py:78-83`）
- **快照不是候选池**：`mastery_snapshot` 已脱钩（题型无法从知识点快照接地），仅作上下文提示，不要从快照挑 topic_label。（`prompts.py:88-89`）
- **信号只在 AI 答疑产生**：题型分析页只记题目不产生信号；PENDING 题型照常采信号先落题目表。
- **打折作用于 score 不作用于结果**：防"第一题答错→题型 0%"假低；每题型自己的第 1 题打折（per-题型 scoping）。

## 对账要点（复盘）

### 方案 vs 实现

- **掌握度主体**：原始方案以"知识点 URI"为掌握度主体 → 实际落地为"题型（canonical 题型名）" → 业务影响：Python 侧 `mastery_signals` 的 topic_label 必须是题型名，否则污染后端题型库，连带掌握度/派生覆盖度/图谱点亮全脏。**⚠️翻转：掌握度主体从知识点 URI 改为题型（canonical 题型名）。**
- **掌握度数值**：原始方案为"离散四档、max 单调不减" → 实际落地为"连续 0-100 累计平均" → 业务影响：数值形态与累加策略均改变，连续累计平均可解释、稳定、不抖动。**⚠️翻转：掌握度数值从离散四档改为连续 0-100 累计平均。**
- **掌握度信号字段**：原始方案字段为 `kp_label` → 实际落地为 `topic_label` → 业务影响：字段名已改，开发对账、接口消费一律以 `topic_label` 为准。**⚠️翻转：信号字段从 kp_label 改为 topic_label。**
- **信号枚举**：原始方案为"离散四档" → 实际落地为三档 `mastered/practicing/struggling` → 业务影响：档位从四档缩为三档，不是四档百分比。**⚠️翻转：信号枚举从离散四档改为三档 mastered/practicing/struggling。**

### 注释 vs 运行行为

- **快照用途**：原始注释设想"给题型做候选接地" → 实际运行行为为"仅作上文提示、不照抄为 topic_label" → 业务影响：快照已脱钩（题型无法从知识点快照接地），不作为候选池。**⚠️翻转：快照从候选接地改为仅作上下文提示，不照抄。**
- **打折作用域**：原始无明确口径 → 实际落地为"per 题型、作用于 score 不作用于结果" → 业务影响：防"第一题答错→题型 0%"假低。**✅落地：per 题型打折、作用于 score 不作用于结果，与设计一致。**

### 接口契约

- **getMastery**：原始接口契约返回"离散四档+status" → 实际落地为"0-100 连续+source/trainCount" → 业务影响：返回结构已改，前端掌握度页按新契约消费（连续百分比+训练数）。**⚠️翻转：getMastery 从离散四档+status 改为 0-100 连续+source/trainCount。**
