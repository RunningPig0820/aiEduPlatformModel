## 隐性坑与注意事项

- **开思考是 32s+ 卡顿根源**：decide/generate 全关思考，别在识别/学科门开思考当"精确提升"。（`question_understand.py:84-85` 注释）
- **向量增强层哲学**：主链路不依赖向量，挂了只是归一退化为字符规则 + 原样落库。（`vector_store.py:8-9`、`api/vector.py:44`）
- **COS 未配置 ≠ 不可启动**：懒加载保证 endpoints 可加载，调时 500。
- **degraded 监控**：Java 依 degraded=true 监控 Python 降级频次，排查是降级不是 bug。

## 对账要点

**慢修复（方案vs实现）**：原始方案建议慢/失败快速返回空结果，实际落地为关思考 + 20s 超时 + 重试0，秒出不阻塞调用方——✅落地：前置判定（题型识别/学科门）统一慢修复，实测开思考 50~145s、关思考秒出。

**向量失败语义（方案vs实现）**：早期设计是吞异常静默降级，实际翻转为错误冒泡——Python 侧 embedding/COS 失败报 HTTP 500，让 Java 感知后再桥侧降级（回退字符规则 + 原样落库），业务影响是归一精度略降但学生作答不受影响——⚠️翻转：从吞异常改为错误冒泡，便于 Java 感知与 Python 侧定位。

**COS 挂了（注释vs运行行为）**：注释/设计未约定 COS 挂了的语义，实际运行行为是 `_get_cos_client` 懒加载、`COS_VECTORS_*` 未配齐抛 RuntimeError → 端点 500 → Java 桥降级不阻塞主链路——✅落地：懒加载 500 由 Java 侧承接，向量作为增强层挂了不影响题目落库/掌握表/接口。

**generate 空流（接口契约）**：接口契约未约定模型 0 token 场景，实际落地为固定引导话术兜底 0 token，学生收到可继续对话而非空回复——✅落地：generate 0 token 空流输出固定引导话术，避免空回复。
