## 隐性坑与注意事项

1. **开思考是 32s+ 卡顿根源**：decide/generate 全关思考，别在识别/学科门开思考当"精确提升"。
2. **向量增强层哲学**：主链路不依赖向量，挂了只是归一退化为字符规则 + 原样落库。
3. **COS 未配置 ≠ 不可启动**：懒加载保证 endpoints 可加载，调时失败。
4. **degraded 监控**：Java 依 degraded=true 监控 Python 降级频次，排查是降级不是 bug。

## 方案 vs 落地的复盘（原始设计 → 实际实现 → 影响）

**慢修复落地（✅落地）**
原始方案建议；落地关思考 + 20s 超时 + 重试0 秒出。影响：题型识别/学科门不再是答疑链路卡点。

**向量失败语义翻转：早期吞异常 → 错误冒泡**
原始方案向量失败吞异常；落地错误冒泡（Java 感知再降级）。影响：Java 桥侧有降级（回退字符规则+原样落库），Python 正常报错便于定位——基础设施失败与业务判定失败语义刻意不对称。

**COS 挂了（✅落地）**
懒加载 + 错误冒泡 → Java 降级不阻塞。影响：主链路不依赖向量，挂了只是归一精度降一点。

**generate 空流兜底（✅落地）**
0 token → 固定引导话术。影响：学生不收到空回复，可继续对话。
