# 切片数据 / 代码 / 处理方案

> 本来源（3.代码 分析文档）从源文档到切片数据的完整处理路径。

## 一、源头

- 源文档：`3.代码/分析-01~10.md`（10 份，权威 0.8，代码证据层）
- 生成提示词：`3.代码/处理方案/提示词/代码深读-分析文档-提示词.md`（真读代码/三端核对/业务场景先行/元数据锚点）

## 二、切片

- 切片器：`ai-edu-ai-service/scripts/rag/slice_corpus.py`（LAYERS 含 `("3.代码/分析-*.md", 0.8, "代码", 2, "split")`——**split_level=2 按 h2 切**）
- 块式摘要：`gen_summaries.py`（块级 summary，不手工回写 md 头）
- 切片注意事项见 `../模块语料搭建SOP.md` 第④步·切片注意事项（h2 切/≤6000字符/表不切破/块元数据）

## 三、导出视图

- `export_slices_md.py` 从 jsonl 导出到本目录（QT⑥）

## 四、检索侧规则

- code_analysis 只答**接口/参数/降级/对账翻转/代码真实行为**；不答"为什么这么设计/选型权衡"（canonical 决策职责）——RAG 系统 prompt 按 doc_type 做来源过滤。
