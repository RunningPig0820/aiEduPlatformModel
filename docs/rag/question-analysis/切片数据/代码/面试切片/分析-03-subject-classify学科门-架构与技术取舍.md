## 架构与技术取舍

### 核心设计：宁漏不误（产品红线）
学科门只判学科不解题。拿不准放行 math，**数学题永远不会被拦在门外**——误拦（学生问数学被拒）是更糟的产品事故。宁可放过垃圾学科题，不可误拦数学题。

### 空值语义分离（关键细节）
- **other = 明确非学科内容**（语文/英语/闲聊/图片无法辨认）
- **空(None) = 不知道**（闭集外/失败/超时）
- 两者语义分开：Java 收到 other 跳过，收到空按 math 放行。**不要把闭集外（地质/天文）硬归成 other**——那是"不知道"，不是"非学科"。

### 慢修复（前置卡点性能护栏）
学科门是答疑链路前置，不能成为新卡点：**关思考 + 20s 超时 + 关 SDK 重试**。开思考实测 50~145s、关思考秒出——前置判定必须快速返回，慢/失败 20s 内让 Java 走降级，不阻塞主链路。

### 失败语义：吞异常降级空
整个判定函数 try/except 包裹，LLM 失败/超时返回空 subject——业务判定失败 ≠ 错误，快速空结果让 Java 放行。

## 设计要点

- **宁漏不误**：拿不准放行 math——误拦是更糟的产品事故。
- **闭集外不硬归类**：空（不是 other）对 Java 表示"不知道"，语义清晰。
- **慢修复原则**：学科门是前置卡点，必须秒出，20s 超时快速返回让 Java 降级。
- **闭集是 K12 十值**：math/physics/chemistry/biology/chinese/english/politics/geography/history/other（早期 5 值扩为完整十值）。
