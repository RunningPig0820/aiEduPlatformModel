## 架构与技术取舍

### 零锚点动态涌现（没有题库怎么归并）
没有预置的题型分类表。canonical 由"第一条相似题"创建（首题建锚），后续题目题型名向量查最近邻：命中归并 / 未命中建新。**题型是长出来的，不是规定出来的**——canonical 池从零长出来。

### 归并阈值 = 粒度旋钮（核心设计）
```
distance ≤ 0.2   归并到命中 canonical（写别名表）——只并同型，不并异型
0.2 ~ 0.3        建新不误并
≥ 0.3            异型建新（宁可拆不误并）
```
- **spike 实测距离语义**：self≈0、同型 ~0.077（"鸡兔同笼"→"鸡兔同笼问题"）、异型 ≥0.33（"相遇"→"行程"0.332）
- 同型/异型在 0.08~0.33 有清晰间距，0.2 是保守默认
- "相遇 vs 行程"（0.332）不被 0.2 归并 → 默认拆分——**粒度是产品定义，不是向量能替你定的**

### 向量原语与决策分离
- **Python 只提供向量原语**（存/查 + embedding），canonical 归并决策在 Java——Python 不判断"该不该并"
- 无"批量聚类"：Python 无定时任务/批处理，只是即时存查原语（Java 定时任务已移除改手动触发）

### 失败降级（向量是增强层）
向量挂了**不阻塞主链路**：Java 桥降级为字符规则（解X/求X 前缀）+ 原样落库——归一精度下降，学生作答不受影响。向量是增强层，不是主链路依赖。

### embedding 细节（维度坑）
text-embedding-v3 显式 768 维（默认 1024，维度必须与索引一致，索引建好不可改）。

## 设计要点

- **无"批量聚类"**：Python 侧无定时任务/批处理，只是即时存查原语。
- **阈值保守**：distance ≤0.2 只并同型，宁可拆不误并——canonical 是"长出来"的不是"规定出来的"。
- **聚集依据 = 题型名向量单信号**：题目向量本期不落库（相似题检索后续），别以为题目向量参与归一。
- **失败语义 = 错误冒泡**：向量是基础设施，让 Java 感知失败再降级（与业务判定吞异常相反）。
