## 双切片（同目录，文件名区分）

| 类型 | 文件 | 消费方 | 处理 |
|---|---|---|---|
| 开发向 | `坑档案-J-QT#-*.md` | 开发查问题/对账 | 6 段原文 + 证据（commit、文件:行号） |
| 面试向 | `坑档案-J-QT#-*-复盘.md` | 面试官提问/候选人介绍 | 复盘叙事，过滤证据噪声，`target: 面试项目问答` |

## 与 完善文档（1.0 全量池）的分工（关键）

- **完善文档 1.0** = 面试主答案（整篇全量池，优先召回）——答"业务是什么/为什么"
- **坑档案切片 0.8** = 踩坑/复盘补充——答"踩过什么坑/怎么修的/面试怎么讲"
- **检索规则**：先 1.0 主答案，切片补深度；面试向切片转述后必须带**证据指针**（详见 坑档案.md / 分析-0X / 完善文档 0X），追问可回源

- 批量：按提示词逐个处理 J-QT1~8（已完成）
