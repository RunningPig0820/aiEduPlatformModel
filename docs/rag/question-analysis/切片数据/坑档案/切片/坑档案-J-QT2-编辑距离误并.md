# 坑档案 J-QT2 编辑距离误并：一字之差与错别字无法区分

> summary: 编辑距离误并：一字之差与错别字无法区分
> 权威度: 0.8 ｜ 来源: 坑档案 ｜ 锚点: J-QT2. 编辑距离误并
> 模块: question-analysis ｜ 节: 坑档案
> COS路径: rag-slices/question-analysis/坑档案/坑档案-J-QT2-编辑距离误并.md
> 类别：开发难点

---

**1. 问题现象**："一元一次方程"和"一元二次方程"被字符级规则归并成同一题型。

**2. 触发流程**：字符规则按编辑距离 ≤1 归并近字变体。

**3. 根因分析**："一元一次/一元二次"**一字之差**与错别字"方成/方程"**同为距离 1**——字符级无法区分是"语义不同的真题型"还是"错别字"，会误并。

**4. 排查过程**：联调发现近字归并把相似但不相同的题型并了。

**5. 解决方案 & 改动点**：**编辑距离 ≤1 近字归并移除**，近字/错别字归并全交给题型名向量层（语义最近邻正确区分"一次/二次"、归并"方成/方程"）。（design Decision 4）

**6. 面试口述要点**：字符级近字归并有个致命缺陷——"一元一次"和"一元二次"是一字之差，错别字"方成/方程"也是一字之差，编辑距离都是 1，字符规则分不清哪个该并哪个不该并。所以把近字归并砍了，交给向量层，用语义最近邻区分。
