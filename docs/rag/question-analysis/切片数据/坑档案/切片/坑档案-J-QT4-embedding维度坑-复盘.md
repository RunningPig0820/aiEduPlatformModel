## 坑点复盘
**现象**：写入索引的向量维度与索引声明维度不一致，查询报错或结果为空。

**触发链路**：embedding 接口不显式指定维度 → 输出默认 1024 维 → 写入 768 维索引。

**根因**：embedding 模型默认输出 1024 维，合法维度可选 1024/768/512 等，不显式指定就按默认 1024，与已建的 768 维索引对不上；而**索引维度建好后不可改**。

**解决思路与权衡**：把显式维度（768）写死成常量；把"先验证实际输出维度 → 再建索引"钉成固定顺序、不可颠倒——在建索引前就把维度对齐问题解决掉。

## 面试口述要点
embedding 维度必须和索引维度严格一致，这是建索引前就要钉死的。embedding 模型默认输出 1024 维，不显式传 768 就和索引对不上，而且索引建好后改不了。所以 spike 第一步就是验证显式 768 的实际输出，把维度钉死在常量里。
