## 坑点复盘
**现象**：学生练了很多"鸡兔同笼"，掌握度页却显示"未开始"。

**触发链路**：题型分析接口返回原始题型名（如"解一元二次方程"）→ 前端拿它查掌握度（key 是归并后的规范名"一元二次方程"）→ 等号匹配 miss → 误判未开始。

**根因**：分析接口返回的题型名没走归并归一，不是规范名（canonical）；掌握表 key 是 canonical。名字不对齐，前端查不到——而且是**静默降级**，不报错只显示"未开始"。

**解决思路与权衡**：后端保证分析接口返回的题型名 = canonical（返回前也过一遍归并归一）——前端直接等号匹配即可，把名字对齐问题收敛在后端一处。

## 面试口述要点
这个坑是"静默降级"——匹配不上不报错，直接显示未开始。原因是分析接口返回的是 LLM 原始名，掌握表 key 是向量归并后的 canonical 名，两个名字对不上。解法是让分析接口返回前也过一遍归并归一，前端用 canonical 名等号匹配。
