## 坑点复盘
**现象**：学科门判定一次要 50~145 秒，答疑主链路等死。

**触发链路**：学科门分类、题型识别两个前置环节用默认参数调大模型（开了思考模式）。

**根因**：思考模式下模型长思考，连学科门这种简单判定也被拖到分钟级——前置环节成了整条链路的卡点。

**解决思路与权衡**：统一做"慢修复"——关思考 + 20 秒超时 + 关 SDK 重试；慢或失败就快速返回空结果，让上游走降级（闭集外放行数学、空题型标签降级待确认）。**宁可快速失败走降级，也不让主链路等**——用降级换可用性。

## 面试口述要点
前置判定环节最怕变卡点。实测开思考模式下学科门判定要 50~145 秒，完全不可接受。所以专门做了慢修复：关思考 + 20 秒超时 + 关重试，宁可快速失败让上游走降级，也不让主链路等——把"慢"变成"快速失败 + 降级"。
