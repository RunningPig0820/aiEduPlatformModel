## 坑点复盘
**现象**：掌握度信号静默丢失（信号列表为空），没有任何报错。

**触发链路**：字段改名 → 纠错提示词里仍硬编码旧字段名 → 模型按提示词输出旧名 → 校验要新名 → 反复纠错失败 → 掉进兜底 → 信号丢失。

**根因**：绑定数据模型的 function calling schema 会自动跟随新字段名，但**纠错提示词里硬编码的旧字段名不会**——模型按提示词输出旧名、schema 要新名，永远校验不过。

**解决思路与权衡**：改名字段时把纠错提示词里的硬编码旧名一并同步为新名，并用测试断言提示词里含新字段名——把"改名必须连带改提示词"固化进测试，防止再次脱节。

## 面试口述要点
字段改名是个连环坑——Pydantic schema 会自动跟上新字段名，但纠错提示词里硬编码的旧名不会。模型按提示词输出旧名、schema 要新名，一直校验失败最后掉兜底，掌握度信号就静默丢了。所以改名必须连纠错提示词一起改，并用测试锁死。
