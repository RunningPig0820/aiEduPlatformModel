## 坑点复盘
**现象**：非 K12 学科内容（如"地质""天文"）被归为 other，污染了 other 桶的语义。

**触发链路**：学科门分类解析到闭集外内容 → 硬归到 other。

**根因**：other 的语义是"明确非学科内容"，而闭集外是"**不知道**"——两回事。把"不知道"硬归成"明确非学科"，是语义污染。

**解决思路与权衡**：闭集外返回 None（不是 other），让上游按数学放行——**宁漏拦不误拦**：宁可少拦一些，也不污染 other 桶的语义边界。

## 面试口述要点
other 和 None 语义必须分开——other 是"明确非学科"，None 是"我不知道"。把"地质""天文"这种闭集外内容硬归到 other 是污染，返回 None 让上游放行更安全。宁可放过，不可误判。
