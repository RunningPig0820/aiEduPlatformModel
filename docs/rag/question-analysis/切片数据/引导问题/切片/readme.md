## 与 完善文档（1.0 全量池）的分工（关键）

- **完善文档 1.0** = 面试主答案（整篇全量池，优先召回）——答"业务是什么/为什么"
- **引导问题问答切片 1.0** = 精确问答补充——答"具体某个问题怎么答"（问题即锚点，直接召回）
- **检索规则**：先 1.0 主答案，问答切片补精确问题命中；每片带证据指针（回源完善文档/分析/坑档案）
