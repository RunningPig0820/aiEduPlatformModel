## 回答

**核心结论**：模块做「题目 → 题型 → 掌握度」闭环——把散乱答题记录聚成统一题型（canonical）、算题型掌握度，让学生/家长看得见"这类型题练得怎么样、哪里薄弱"。

**分层展开**：
- **做什么**：题目进来 → 识别题型 → 题型名向量归并 canonical → 落题目表（事实源）+ 掌握表（累计平均）→ 掌握度页展示可回看原题。（依据：完善文档 01 / 分析-01）
- **痛点**：学生一道"鸡兔同笼"题叫法五花八门（鸡兔同笼/鸡兔同笼问题/假设法），零散记录无法聚成可分析的能力画像——需要零锚点动态聚集把它们收敛。（依据：完善文档 01）
- **业务目标**：掌握度主体是**题型**不是知识点——学生掌握的是"解题模式"，当场判该题型状态（已掌握/练习中/待巩固/待确认），不绕道知识点。（依据：完善文档 01 / 分析-05）
- **闭环价值**：每次作答落题目+掌握表，掌握度回流下一次 decide（薄弱题型优先讲解），题型库反喂变式题/错题分组/薄弱诊断。（依据：完善文档 09 / 01 追问）
