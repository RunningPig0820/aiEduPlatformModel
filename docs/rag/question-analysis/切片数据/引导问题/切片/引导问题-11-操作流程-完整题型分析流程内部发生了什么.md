## 回答

**核心结论**：贴题 → 学科门筛选 → 识别题型 → 题型名向量归并 canonical → 查掌握度 → 展示。关键：分析页只认题型、只记题目，**掌握度是查已有的**（由答疑链路积累），分析页不产生新对错信号。

**分层展开**：
- **① 学科门**：贴题先过 subject-classify（K12 十值闭集，decide 之前），非数学直接不放行，数学题进入链路。（依据：完善文档 02 / 分析-01）
- **② 识别题型**：文本题走 Java `KpQuestionAnalyzer`；图片题走 Python `question-understand`（视觉多模态，topic_hint 词表压漂移），返回题型名 + 顺带知识点。（依据：分析-01 / 分析-04）
- **③ 归并 canonical**：题型名 `vector/query` 查最近邻 → distance ≤0.2 归并 / 首题建锚——**落库前**归并，掌握表源头不裂行。（依据：完善文档 02 落地真相 / 分析-06）
- **④ 查掌握度**：前端拿 canonical 题型名等号匹配查 `getMastery`——命中返回连续 0-100 掌握% + 训练数，未命中显示"未开始"灰态。（依据：完善文档 02 / 05）
- **⑤ 展示**：题型 | 来源(ai/bank) | 掌握% | 训练数 | 跳转原题（session_id 关联答疑会话）。（依据：完善文档 05 / 分析-07）
- **关键口径**：题型分析页**只记题目不出对错**——掌握度唯一来源是 AI 答疑 decide 信号，贴题分析不产生新信号。（依据：完善文档 02 追问 / 分析-01）
