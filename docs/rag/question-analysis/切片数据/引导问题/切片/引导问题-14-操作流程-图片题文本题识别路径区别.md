## 回答

**核心结论**：**文本题**由 Java 自研 `KpQuestionAnalyzer` 识别（Python 无此端点）；**图片题**由 Python `question-understand` 视觉多模态识别（看 COS 签名 URL 图 → topic_labels 1~5 个）。识别出的题型名都汇入同一向量归并 canonical 链路。

**分层展开**：
- **文本题**：Java `KpQuestionAnalyzer` 自研规则/模型识别，不进 Python——Python 只有图片题端点，别误以为 Python 收全部题目识别。（依据：分析-01 隐性坑 / 分析-04）
- **图片题**：Java 上传图片到 COS → 传签名 URL → Python `question-understand`（写死 doubao 视觉模型，`text + image_url` 多模态，关思考 + 20s 超时 + 重试 0）→ 返回 `topic_labels` 1~5 个 + 顺带 `question_kps`。（依据：分析-04）
- **命名收敛**：`topic_hint`（Java 传题型库 top-20 常用名）注入 system prompt 作"参考题型名词表"，优先从词表选、词汇不足可自拟——从源头压低变体漂移；冷启动题型库空时跳过，模型自拟名动态涌现。（依据：分析-04）
- **汇合点**：两路识别出的题型名都过 `vector/query` 查最近邻归并 canonical（distance ≤0.2），再落库。（依据：分析-01 / 完善文档 02）
