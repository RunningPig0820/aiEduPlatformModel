## 回答

**核心结论**：答疑 decide 每轮输出题型三档信号 → Java 把答题结果映射成分数（直接答对 1.0 / 求助后答对 0.5 / 答错 0.0）× per-题型打折 → **累计平均** `new = old×n/(n+1) + score×1/(n+1)` → 落掌握表。

**分层展开**：
- **信号来源**：`mastery_signals[].topic_label`（题型名）+ signal（mastered/practicing/struggling）+ `Eval.correct`（对错）——**只来自 AI 答疑 decide**，题型分析页不出对错。（依据：完善文档 05 / 分析-05）
- **分数映射（Java ScoreMapper）**：直接答对（answer_request_count=0）→ 1.0；求助后答对（≥1）→ 0.5；答错/未完成 → 0.0。（依据：完善文档 05 / 分析-05）
- **per-题型打折**：第 1 题 0.7 / 第 2 题 0.8 / 第 3 题起 1.0——作用于 score 不作用于结果，防"第一题答错→题型 0%"假低；学习新题型都是从不会开始。（依据：完善文档 05 / 分析-05）
- **累计平均**：`new = old×n/(n+1) + score×1/(n+1)`，trainCount+=1；一次作答算一次（不做去重），反映真实练习量；不用 max 单调不减（会虚高）、不用 EWMA（难解释）。（依据：完善文档 05 / 分析-05）
