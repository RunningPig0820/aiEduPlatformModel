## 回答

**核心结论**：掌握度页按**题型列式**展示「题型 | 来源 | 掌握% | 训练数 | 跳转题目」；"查看原题"靠题目表的 `session_id` 跳回对应答疑会话；没有会话链接就显示题目原文兜底。

**分层展开**：
- **展示列**：题型名（canonical）、来源（ai/bank）、掌握% （连续 0-100，前端分桶保留四档视觉：<25 待巩固 / 25-50 练习中 / 50-75 偏稳 / ≥75 已掌握）、训练数、跳转题目。（依据：完善文档 05 / 分析-07）
- **查看原题**：题目表 `t_student_question_record` 存 `session_id` 关联答疑会话，掌握度页"查看原题"靠它跳回那一次作答。（依据：完善文档 05 / 分析-07）
- **无会话链接兜底**：没有会话链接时显示题目原文（Java 侧），不展示死链。（依据：分析-07 隐性坑）
- **数据口径**：掌握度可追溯——每道题在题目表有 score 生效分值 + 引导轮数 + 会话链接，不是拍脑袋数字。（依据：完善文档 05 追问）
