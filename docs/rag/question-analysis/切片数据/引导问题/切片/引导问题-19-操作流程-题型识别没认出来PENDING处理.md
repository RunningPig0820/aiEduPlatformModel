## 回答

**核心结论**：识别失败 → 空结果 → Java 降级 PENDING 走**澄清卡**（resolve/vote，学生确认或跳过），**不编造题型名**进掌握表；**不会丢数据**——信号跟题目走，PENDING 题型照常采信号落题目表，归属确定后再聚合。

**分层展开**：
- **不硬猜**：低置信不硬猜——识别失败返回空 `topic_labels`，Java 降级 PENDING 挂起，事后澄清卡让学生确认，不留死胡同。（依据：完善文档 04 追问 / 分析-04）
- **澄清流程**：识别失败 → PENDING → 前端澄清卡（resolve 确认 / vote 投票 / 跳过）——不是错误，是待确认状态。（依据：完善文档 04 / 分析-09）
- **不丢数据**：PENDING 题型照常采信号先落题目表，归属确定后再聚合进掌握表——不因题型待定丢数据。（依据：分析-01 设计要点 / 完善文档 05）
- **两层 PENDING 区分**：识别层 PENDING = "题型没认出"（展示候选）；掌握度层 PENDING = "已练但 canonical 未归属"——别混。（依据：坑档案 J-QT3 / 完善文档 02）
