## 回答

**核心结论**：学生掌握的是"解题模式"（鸡兔同笼类题做得怎么样），不是抽象知识点（二元一次方程组）；题型**可聚、可打分、可观测**，掌握度锚题型才能算得准、落库不裂行，知识点由题型派生（后置）。

**分层展开**：
- **语义上**：学生做题直接对应解题模式，题型是"可测的"——题目天然可聚到题型、答对答错可打分；知识点是"课程锚点"，映射依赖图谱。（依据：完善文档 01 追问）
- **工程上**：掌握度 = 累计正确率，信号 = 答题对错，只有题目能聚成题型、产生可观测的对错信号；知识点由题型派生，本模块后置处理。（依据：完善文档 05 / 分析-05）
- **⚠️翻转事实**：早期方案把掌握度挂**知识点 URI**（mastered/practicing/struggling max 单调不减），落地演进出**大翻转**——掌握度主体改为题型、数值改连续 0-100 累计平均；`mastery_signals` 字段 `kp_label → topic_label`，掌握表 `t_student_kp_mastery → t_student_topic_mastery`。（依据：完善文档 01 落地真相 / 分析-01 对账）
- **不打架**：题型和知识点边界模糊（一元二次方程既是题型也是知识点）——题型可测、知识点可映射，两域解耦，canonical 名经别名表收敛，互不污染。（依据：完善文档 01 追问 / 07）
