## 回答

**核心结论**：三条链——**题目→题型→掌握度**（本期核心，域 A）、**题型→知识点**（域 B，独立维护）、**题目→知识点**（顺带 question_kps 展示）。本期只做题目→题型（掌握度），题型→知识点查表只读 + ADMIN 维护。

**分层展开**：
- **本期核心 = 题目→题型**：题目落库 → 题型名向量归并 canonical → 掌握表累计平均，产出题型掌握度——这是 MVP 最小闭环。（依据：完善文档 07 / 09）
- **题型→知识点（域 B，独立）**：题型库 `t_kp_question_type` 查表只读 + ADMIN 维护，命中返回权威分布 / 未命中返回空知识点——不自动关联。（依据：完善文档 07 / 分析-08）
- **题目→知识点（顺带）**：decide 的 `question_kps` / question-understand 顺带输出题目知识点（可选、不要求每次必填），只作展示不送匹配。（依据：分析-08）
- **canonical 是对接缝**：域 A 产出 canonical 题型名 → 进别名表查域 B 映射；两域通过 canonical 对接，互不污染。（依据：完善文档 09）
