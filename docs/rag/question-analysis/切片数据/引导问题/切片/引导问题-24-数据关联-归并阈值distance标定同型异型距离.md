## 回答

**核心结论**：阈值 0.2 是 **spike 实测标定**的——self≈0、同型 ~0.077（鸡兔同笼→鸡兔同笼问题）、异型 ≥0.33（相遇→行程 0.332），同型/异型在 0.08~0.33 有清晰间距，0.2 是保守默认。

**分层展开**：
- **标定方式**：spike 把常见题型名两两 embedding 查距离，实测 self≈0、同型 ~0.077、异型 ≥0.33——间距清晰，取中间保守值 0.2。（依据：完善文档 06 / 分析-06）
- **三档阈值**：distance ≤0.2 归并到命中 canonical（只并同型）/ 0.2~0.3 建新不误并 / ≥0.3 异型建新（宁可拆不误并）。（依据：完善文档 06）
- **粒度是产品定义**："相遇 vs 行程"（0.332）不被 0.2 归并 → 默认拆分——粒度旋钮是产品/业务定义，不是向量能替你定的。（依据：完善文档 06）
- **为什么保守**：误并的题权重互相污染，漏并可后续人工/别名表补；累计百分比对个别误并可容忍。（依据：完善文档 06 追问）
