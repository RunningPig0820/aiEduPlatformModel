## 回答

**核心结论**：聚集目标是"题型归并"——题型名向量够用；题目向量是**相似题检索**（"和这题类似的题"）的独立功能，本期收敛不做，`question` 索引已配置占位，后续启用零架构改动。

**分层展开**：
- **为什么不用题目向量聚集**：聚集要归并的是**题型**（同解题模式的不同叫法），题型名向量语义最近邻正好处理（鸡兔同笼/鸡兔同笼问题/假设法）；题目向量管题面相似，语义目标和聚集不同。（依据：完善文档 06 / 分析-06）
- **⚠️翻转事实**：早期方案"题目向量为主 + 题型名向量为辅"——已翻转，落地为**只题型名向量单信号**，题目向量不参与归一。（依据：完善文档 06 / 分析-06 对账）
- **相似题检索为什么不做**：独立功能（"和这题类似的题"），需要题目向量 + 题目文本落库；本期掌握度/动态聚集只需要题型名向量，收敛范围。（依据：完善文档 08 / 06 追问）
- **预留**：`question` 索引已配置占位（768 维与 topic 同款），题目文本不落向量是本期收敛非能力边界——后续启用零架构改动。（依据：完善文档 08 / 分析-06）
