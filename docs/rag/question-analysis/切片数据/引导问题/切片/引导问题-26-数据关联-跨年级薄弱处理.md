## 回答

**核心结论**：掌握度按题型名（canonical）记，**不绑定当前学年**；图谱 URI 全局（年级只是 URI 一部分），跨年级薄弱天生可展示——七年级二元一次方程卡壳，低年级图谱也能展示那个薄弱节点。

**分层展开**：
- **数据口径**：掌握表 key = canonical 题型名，与"当前学年"无关——学生换年级、跨年级做题，掌握度连续累计。（依据：完善文档 07 追问 / 05）
- **图谱维度**：URI 全局，年级只是 URI 一部分，跨年级薄弱天生可展示。（依据：完善文档 07）
- **跨年级的意义**：学生七年级二元一次方程卡壳，落库的题型掌握度在低年级图谱也能展示那个薄弱节点——年级只是展示维度，不是数据边界。（依据：完善文档 07 追问）
- **边界**：题目识别时年级锚定过滤候选（避免小学鸡兔同笼关联到高中对数方程），但掌握度本身跨年级累计。（依据：完善文档 07 / 09 引用）
