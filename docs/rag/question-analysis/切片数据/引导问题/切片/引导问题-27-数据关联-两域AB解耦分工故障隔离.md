## 回答

**核心结论**：域 A「题目→题型」（本期核心，掌握度）只消费题目记录；域 B「题型→知识点」（独立维护）查表只读 + ADMIN 维护——**故障互不影响**：域 B 挂，掌握度链路照跑；域 A 挂，知识点展示分支不受影响。这是设计红线，不是口头承诺。

**分层展开**：
- **分工表**：域 A 职责 = 题目落库→向量聚集→掌握表累计平均（产出题型掌握度）；域 B 职责 = 题型库 `t_kp_question_type` + 分布桶 + 别名表（产出题型↔知识点权威分布）。（依据：完善文档 09）
- **数据依赖隔离**：域 A 只消费题目记录，**不依赖域 B**；域 B 入口查表只读 + ADMIN 手动维护，**不依赖域 A 对错信号**。（依据：完善文档 09）
- **故障隔离**：canonical 名是两域对接缝——域 A 产出 canonical 进别名表查域 B 映射，域 A 不碰图谱、域 B 不碰答题信号。（依据：完善文档 09）
- **为什么拆开**：题型（无限、随 LLM 叫法漂移）与知识点（有限、教材权威）本质不同——合并会让"学生答错"污染权威图谱，且题型↔知识点有年级相关性，需独立维护/审核。拆开 = 权威数据零写入红线 + 故障隔离双保险。（依据：完善文档 09 追问）
