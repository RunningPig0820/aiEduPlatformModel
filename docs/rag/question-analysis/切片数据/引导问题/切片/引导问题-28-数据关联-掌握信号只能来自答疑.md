## 回答

**核心结论**：掌握度 = 累计正确率，信号 = **答题对错**。只有答疑链路有真实的答题行为（decide 判 eval.correct + 是否被引导）；题型分析页是"贴题分析"，学生没做题，无法产生对错信号，所以只记录题目。

**分层展开**：
- **信号定义**：掌握度是累计正确率，必须有真实的"答对/答错"判定——这是答疑链路 decide 才有的（`Eval.correct` + `exercise_complete`）。（依据：完善文档 05 / 分析-05）
- **为什么分析页不出对错**：题型分析页是"贴题→识别题型→看掌握度"，学生没做题，哪来的对错——贴题不产生掌握度。（依据：完善文档 02 追问）
- **数据底盘共用**：两条入口的题目都落 `t_student_question_record`（事实源），但掌握表只会被答疑链路的 decide 信号更新。（依据：完善文档 02 / 分析-07）
- **防污染**：如果分析页也出对错，会混入"没真实作答"的信号，污染累计正确率的语义。（依据：完善文档 02 追问 / 05）
