## 回答

**核心结论**：字符规则只能拦"确定性变体"（解X/求X前缀、全半角），处理不了"语义同型"（叫法完全不同但同一解题模式）；编辑距离归并有致命缺陷——一字之差和错别字距离都是 1 分不清，**已移除**，近字/错别字归并全交给题型名向量层。向量最近邻在同型 ~0.077 vs 异型 ≥0.33 之间有清晰间距，能正确归并近义、区分近似。

**分层展开**：
- **字符规则能拦什么**：只处理确定性变体——"解X/求X"前缀剥离 + 全半角/空白/标点归一，这些是规则能确定的，省 embedding 调用。（依据：完善文档 06）
- **编辑距离的致命缺陷**："一元一次/一元二次"一字之差与错别字"方成/方程"同为编辑距离 1——字符级**无法区分**"语义不同的真题型"和"错别字"，必然误并（把不相关的题型并到一起，污染掌握度）。这是方案评审时就发现的坑。（依据：坑档案 J-QT2 / 完善文档 06）
- **为什么向量能区分**：语义最近邻能正确区分"一次/二次"（距离远，不并）、归并"方成/方程"（语义近，并）——spike 实测同型 ~0.077、异型 ≥0.33，间距清晰。（依据：分析-06）
- **当前口径（⚠️翻转）**：编辑距离 ≤1 近字归并**已从代码移除**（原方案有，落地砍掉），近字/错别字归并全部交给题型名向量层——**单信号**，题目向量不参与。（依据：分析-06 对账）
- **归并阈值（粒度旋钮）**：distance ≤0.2 归并 / 0.2~0.3 建新 / ≥0.3 异型建新——保守默认 0.2，**宁可拆不误并**（误并的题权重互相污染；漏并可后续人工/别名表补）。（依据：完善文档 06）
