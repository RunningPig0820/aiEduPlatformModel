## 回答

**核心结论**：两个入口、一个数据底盘——答疑和题型分析页都走「题目→题型→掌握度」链路，题目都落 `t_student_question_record`；区别在掌握信号：**答疑产生对错信号，题型分析页只记题目不出对错**。

**分层展开**：
- **入口差异**：答疑对话（学生做题，decide 每轮出 `mastery_signals` 题型三档 + eval.correct）；题型分析页（贴题/拍题，出题型识别 + 关联知识点，无对错）。（依据：完善文档 02 追问 / 分析-01）
- **共用底盘**：两条入口的题目都落题目表（事实源），题型名都过向量归并 canonical，掌握表累计平均。（依据：完善文档 02）
- **信号唯一来源 = AI 答疑**：掌握度 = 累计正确率，只有答疑链路有真实答题行为（decide 判 eval.correct + 是否被引导）；分析页"贴题"学生没做题，无法产生对错信号，所以只记录题目。（依据：完善文档 02 追问 / 分析-05）
- **⚠️翻转/补充**：代码在主流程**新增前置学科门**（subject-classify，decide 之前，K12 十值闭集）——先判学科再进题型链路，非数学直接不放行。（依据：完善文档 02 落地真相 / 分析-01）
