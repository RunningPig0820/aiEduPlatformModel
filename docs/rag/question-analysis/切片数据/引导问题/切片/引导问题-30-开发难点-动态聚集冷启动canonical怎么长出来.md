## 回答

**核心结论**：零锚点动态涌现——第一条题向量桶无近邻 → **建 canonical（锚点诞生）**，后续题目题型名向量查最近邻：命中归并、未命中建新。canonical 由"第一条相似题"创建（首见名/最高频名兜底），**题型不是规定出来的，是从学生做题数据里长出来的**。

**分层展开**：
- **冷启动机制**：第 1 条题 → 向量桶无近邻 → 建 canonical；第 N 条题 → 题型名向量查最近邻 → distance ≤0.2 归并（写别名表）/ 无近邻建新。（依据：完善文档 06 / 分析-06）
- **⚠️翻转事实**：早期方案"预置 canonical 池 + 新名归进池"——已翻转，落地为**动态涌现（首题建锚）**，无预置题型池。（依据：完善文档 01 落地真相 / 分析-06 对账）
- **命名收敛辅助**：图片题识别时 `topic_hint`（题型库 top-20 常用名）注入 prompt 压漂移；冷启动题型库空则跳过，模型自拟名动态涌现补。（依据：分析-04）
- **数据飞轮**：答疑越多 → 题型库越准 → 变式/诊断越好 → 更多答疑——题型库从答疑数据里长出来。（依据：完善文档 08 / 09）
