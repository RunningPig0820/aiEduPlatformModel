## 回答

**核心结论**：COS 向量索引 **put 后 ~10s 异步构建**，立即 query 命中不到刚写入的向量（返回空 `vectors: []`）。处理：① 首题建锚后不立查（本身无近邻）；② 聚集编排「put 后查」路径容忍延迟/留重试。

**分层展开**：
- **现象**：首题建锚后立查最近邻，返回空 `vectors: []`，动态聚集没反应。（依据：坑档案 J-QT1）
- **根因**：COS 向量索引 put 后 ~10s 异步构建生效，不是网络/权限问题——spike 反复 put→query 实测稳定 ~10s 延迟。（依据：坑档案 J-QT1 / 分析-06）
- **处理**：① 首题建锚后不立查（本身无近邻可查）；② 聚集编排「put 后查」路径容忍延迟/留重试，等写入生效近邻可见再查。（依据：坑档案 J-QT1 / `core/tutoring/vector_store.py:126-127`）
- **设计哲学**：把时序问题挡在业务设计层面——不依赖"写入后立即可见"的强一致性。（依据：坑档案 J-QT1）
