## 回答

**核心结论**：dashscope `text-embedding-v3` **默认输出 1024 维**（合法 1024/768/512…），不显式指定就 1024，与建的 **768 维索引对不上**——而且**索引维度建好后不可改**，所以必须显式 `dimensions=768` 写死常量。

**分层展开**：
- **坑**：写入索引的向量维度与索引声明维度不一致，查询报错或结果为空——embedding 默认 1024 维写进 768 维索引。（依据：坑档案 J-QT4）
- **为什么必须显式**：text-embedding-v3 合法维度 1024/768/512…，不显式指定按默认 1024；索引维度建好后不可改，所以 spike 第一步就是验证显式 768 的实际输出。（依据：坑档案 J-QT4 / 分析-06）
- **落地**：`dimensions=768` 写死常量（`core/tutoring/vector_store.py:26-28`）；spike 顺序必须是"先验证维度 → 再建索引"，不可颠倒。（依据：坑档案 J-QT4）
- **关联**：`vector_type="topic"` 路由 topic-index 就是 768 维 cosine 索引。（依据：分析-06）
