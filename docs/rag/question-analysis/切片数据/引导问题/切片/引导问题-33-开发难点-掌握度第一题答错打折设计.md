## 回答

**核心结论**：per-题型**前几题打折**——第 1 题 0.7 / 第 2 题 0.8 / 第 3 题起 1.0（可配置）。打折作用于单题 score 不作用于结果，防"第一题答错 → 题型 0%"的假低；学习新题型都是从不会开始。

**分层展开**：
- **公式**：score = 映射分 × 打折系数（第 1 题 0.7 / 第 2 题 0.8 / 第 3 题起 1.0）；`new = old×n/(n+1) + score×1/(n+1)`。（依据：完善文档 05 / 分析-05）
- **为什么打折作用于 score 不作用于结果**：如果打折作用于最终掌握度，第一题答错会永久压低题型百分比；作用于单题 score，后续题正确能把累计拉回。（依据：完善文档 05 追问 / 分析-05）
- **per-题型 scoping**：打分打折按"每个题型自己的第 1 题/第 2 题"计——学习新题型都是从不会开始，不给负起点。（依据：完善文档 05 / 分析-05）
- **信号映射回顾**：直接答对 1.0 / 求助后答对 0.5 / 答错 0.0（Java ScoreMapper 从 `answerRequestCount` 推断）。（依据：完善文档 05 / 分析-05）
