## 回答

**核心结论**：字段改名导致掌握度信号**静默丢失**——`kp_label → topic_label` 改名后，Pydantic schema 自动跟上新字段名，但纠错提示词里硬编码的旧名没跟上：模型按提示词输出旧名、schema 要新名，反复纠错失败最后掉兜底，信号丢失。

**分层展开**：
- **现象**：掌握度信号静默丢失（`mastery_signals` 为空），没有任何报错。（依据：坑档案 J-QT7）
- **根因**：function calling schema（绑定 Pydantic 模型，自动变 topic_label）与纠错提示词字段名**脱节**——`_schema_instructions` 仍硬编码 `"kp_label"`，模型输出旧名、schema 要新名，永远校验不过。（依据：坑档案 J-QT7）
- **解决**：纠错提示词同步改为 `"topic_label"`，并用测试断言纠错提示词含 topic_label——把"改名必须连带改提示词"固化进测试。（依据：坑档案 J-QT7）
- **教训**：字段改名是连环坑——schema 会自动跟新名，但提示词里硬编码的旧名不会，改名必须连提示词一起改。（依据：坑档案 J-QT7）
