## 回答

**核心结论**：不会拖垮。向量是**增强层**——主链路（题目落库/掌握表/接口）不依赖向量。向量失败走**错误冒泡**（Python 报 HTTP 错误让 Java 感知）→ Java 桥降级**回退字符规则 + 原样落库**，归一精度降一点但学生作答不受影响。

**分层展开**：
- **失败语义**：向量 put/query 失败 → HTTP 500（未知 vector_type → 400），错误冒泡不吞异常——向量是基础设施，让 Java 感知失败再降级。（依据：完善文档 03 / 分析-10）
- **Java 桥降级**：回退字符规则（解X/求X 前缀 + 全半角归一）+ 原样落库——归一精度下降但不阻塞主链路。（依据：完善文档 03 追问 / 分析-10）
- **为什么错误冒泡而非吞异常**：业务判定（学科门/题型识别）= 吞异常降级空（宁返回空不阻塞）；向量 = 错误冒泡（Java 有降级，Python 正常报错便于定位）——两类失败语义分治。（依据：完善文档 04 / 分析-10）
- **COS 未配置**：`_get_cos_client` 懒加载，未配齐抛 RuntimeError → 端点 500 → Java 降级；COS 未配置 ≠ 不可启动。（依据：分析-10）
