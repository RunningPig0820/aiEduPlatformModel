## 回答

**核心结论**：三入口（答疑对话 / 题型分析页贴题 / 图片题）汇入 → ①学科门筛掉非数学 → ②识别题型（文本 Java / 图片 Python）→ ③题型名向量归并 canonical → ④落三处（题目表 + 掌握表 + 向量桶）→ ⑤掌握度页展示 → ⑥掌握度快照回流 decide——讲题、记题、涨熟练、回看环环相扣。

**分层展开**：
- **三入口**：答疑对话（做题，产生对错信号）、题型分析页贴题（文本，看题型+知识点）、图片题（拍照识别）。（依据：完善文档 09）
- **各环节**：① 学科门 subject-classify（decide 之前，非 math 直接不放行）；② 题型识别——文本题 Java KpQuestionAnalyzer / 图片题 Python question-understand；③ 题型名字符规则 + 向量最近邻归并 canonical（零锚点动态涌现）；④ 落库——题目表（事实源）+ 掌握表（累计平均）+ 向量桶（题型名向量）；⑤ 展示——掌握度页（题型|来源|掌握%|训练数|跳转原题）；⑥ 回流——mastery_snapshot 组装回传下一次 decide（薄弱题型优先讲解）。（依据：完善文档 09）
- **信号唯一来源**：掌握度信号只来自答疑 decide，题型分析页只记题目不出对错。（依据：完善文档 09 / 分析-01）
