## 回答

**核心结论**：没有题库、零锚点——canonical 由学生**第一条题建锚**（首题建锚动态涌现），后续题目题型名向量查最近邻：命中归并、未命中建新。**题型是"长出来的"，不是"规定出来的"**。

**分层展开**：
- **动态涌现机制**：第 1 条题向量桶无近邻 → 建 canonical（锚点诞生）；第 N 条题题型名向量查最近邻 → 命中归并（写别名表）/ 未命中建新。（依据：完善文档 06）
- **聚集依据**：字符规则先拦确定性变体（解X/求X前缀、全半角）+ 题型名向量最近邻处理语义同型（鸡兔同笼/鸡兔同笼问题/假设法）；**题目向量本期不落库**。（依据：完善文档 06 / 分析-06）
- **归并阈值（粒度旋钮）**：distance ≤0.2 归并（只并同型）/ 0.2~0.3 建新 / ≥0.3 异型建新——保守默认，宁可拆不误并。（依据：完善文档 06）
- **数据飞轮**：答疑越多 → 题型库越准 → 变式题/错题分组/薄弱诊断越好 → 更多答疑——题库从答疑数据里长出来。（依据：完善文档 08/09）
