## 回答

**核心结论**：业务闭环是"三入口 → 学科门 → 识别 → 归并 → 落库 → 展示 → 回流"，每个环节都带**异常/降级分支**：学科门失败放行、识别失败降 PENDING、向量挂退字符规则、decide 流失败降非流式。

**分层展开**（图源自 `3.代码/分析-01` + `分析-09`，含降级分支）：

```mermaid
flowchart TD
    FE[前端 AiQa.jsx / 题型分析页] -->|贴题/拍题| JAVA[Java 编排]
    JAVA -->|① decide 前置| SC[subject-classify 学科门]
    SC -->|非 math/subject 空| MATHGATE[跳过: 仅支持数学 不建会不落库]
    SC -->|math 文本题| ANALYZER[Java KpQuestionAnalyzer 自研识别题型]
    JAVA -->|图片题| QU[question-understand 看图 → topic_labels+question_kps]
    QU -->|空 labels| QUFAIL[失败/识别不出 → Java 降级 PENDING 挂起]
    ANALYZER -->|题型名| VEC[vector query 最近邻归并 canonical]
    QU -->|题型名| VEC
    VEC -->|distance≤0.2 归并| MERGE[落 canonical 归并]
    VEC -->|无近邻| NEWANCH[首题建锚 动态涌现]
    VEC -.向量失败.-> FALLBACK[Java 桥降级: 回退字符规则 + 原样落库]
    JAVA -->|答疑每轮| DECIDE[decide SSE → meta ActionMeta]
    DECIDE -->|mastery_signals 题型三档| APPLY[Java 落题目表 + 掌握表累计平均]
    DECIDE -.原始流失败.-> DECIDEFALLBACK[降级非流式四段管线]
    DECIDE -.换题信号.-> SWITCH[type=switch 短路 不调LLM]
    DECIDE -.答非所问/联动不一致.-> GUARD[护栏降级 type=concept 引导回题]
```

- **降级分支全景**：学科门闭集外→None 放行；识别失败→空 labels→Java PENDING；向量失败→错误冒泡→Java 回退字符规则；decide 流失败→降非流式四段管线；generate 空流→固定引导话术兜底。（依据：分析-01 / 分析-09 / 分析-10）
- **端到端语义**：题目进来不丢——PENDING 题型照常采信号落题目表，归属确定后再聚合。（依据：分析-01 设计要点）
