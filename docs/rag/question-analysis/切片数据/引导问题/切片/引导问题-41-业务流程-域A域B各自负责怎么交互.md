## 回答

**核心结论**：域 A「题目→题型」产出题型掌握度（本期核心，只消费题目记录）；域 B「题型→知识点」产出题型↔知识点权威分布（独立维护，查表只读 + ADMIN）。交互靠 **canonical 名对接**——域 A 产出 canonical 进别名表查域 B 映射，互不碰对方的数据。

**分层展开**：
- **域 A 职责**：题目落库 → 向量聚集 → 掌握表累计平均，产出题型掌握度；数据依赖只消费题目记录，不依赖域 B。（依据：完善文档 09）
- **域 B 职责**：题型库 `t_kp_question_type` + 分布桶 + 别名表，产出题型↔知识点权威分布；入口查表只读 + ADMIN 手动维护，不依赖域 A 对错信号。（依据：完善文档 09 / 分析-08）
- **交互方式**：canonical 名是两域对接缝——识别题型后 `findByTopicLabelOrAlias` 查题型库，命中返回权威分布 / 未命中返回"仅题型+canonical+空知识点"。（依据：完善文档 09 / 分析-08）
- **故障隔离**：域 B 挂，掌握度链路照跑；域 A 挂，知识点展示分支不受影响。（依据：完善文档 09）
