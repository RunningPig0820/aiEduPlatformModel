## 回答

**核心结论**：数据飞轮 = 答疑产生个体信号 → 落题目表/掌握表 → 共现沉淀题型库 → 题型库喂变式题/错题分组/薄弱诊断 → 更多答疑。canonical 由第一条相似题建锚（无题库、零锚点），后续向量最近邻自动靠拢——**题型库从学生真实做题数据里动态涌现，不是靠教材预置**。

**分层展开**：
- **飞轮四步**：答疑产生个体派生信号 → 共现沉淀题型库 → 题型库反哺变式题/错题分组/薄弱诊断 → 更多答疑——循环滚起来数据越多越准。（依据：完善文档 08 / 09）
- **"长出来"的含义**：没有预置题型分类表，canonical 由学生题目动态涌现（首题建锚 + 向量最近邻归并）——题型是动态的、随真实做题数据增长的。（依据：完善文档 06 / 01）
- **⚠️翻转**：早期方案"预置 canonical 池 + 新名归进池"——已翻转，落地为动态涌现。（依据：完善文档 01 / 分析-06 对账）
- **闭环价值**：每次答疑既解决当下问题，又沉淀数据，回流下一次 decide——"讲题、记题、涨熟练、回看"环环相扣。（依据：完善文档 09）
