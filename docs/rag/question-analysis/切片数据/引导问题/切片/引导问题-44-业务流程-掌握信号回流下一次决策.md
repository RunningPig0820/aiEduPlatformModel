## 回答

**核心结论**：答疑 decide 输出掌握信号 → Java 落掌握表（累计平均）→ 下次 decide 时 Java 从掌握表组装 `mastery_snapshot`（按薄弱升序取 top-10）回传 Python 作上下文——**薄弱题型优先讲解**，且快照仅作上下文不污染题型名。

**分层展开**：
- **信号产生**：decide 每轮输出 `mastery_signals[].topic_label + signal`（题型三档）+ `Eval.correct`（对错）。（依据：分析-05）
- **落库**：Java 把信号映射分数 × 打折 → 累计平均 → 掌握表 `t_student_topic_mastery`（canonical key + 连续 0-100 + trainCount）。（依据：完善文档 05 / 分析-05）
- **回流**：`DecideRequest.mastery_snapshot: List[KpSnapshot]`（Java 从掌握表组装），Python 只按 `mastery_level` **升序**取 top-10（薄弱在前）作上下文。（依据：完善文档 09 / 分析-07）
- **边界**：快照仅作上下文提示，不照抄为 mastery_signals 的 topic_label——不会反过来污染题型名。（依据：分析-05 / `prompts.py:88-89`）
