## 回答

**核心结论**：题目表 = **事实源**（每道题一条，对错信号 + 引导轮数 + 会话链接，可回查原题）；掌握表 = **聚合结果**（canonical key + 累计平均）。隔离红利：**改信号映射/打折系数 → 重算聚合即可，题目证据不丢**。

**分层展开**：
- **两表分工**：`t_student_question_record`（题目表，事实源——每道题原始记录）+ `t_student_topic_mastery`（掌握表，聚合结果——canonical key 唯一 + 连续 0-100 累计平均 + train_count + source）。（依据：完善文档 05 / 分析-07）
- **解决的问题**：① 可追溯——每道题有原始证据（score 生效分值 + 引导轮数 + session_id），掌握度不是拍脑袋；② 可重算——改信号映射/打折系数只需重算聚合，题目证据不丢；③ 事实与聚合分离——题目记录稳定，聚合口径可变。（依据：完善文档 05）
- **掌握表字段**：topic_key（canonical 唯一）/ topic_label / mastery（0-100 累计平均）/ train_count / source（ai/bank）。（依据：完善文档 05）
- **关联**：题目表 `session_id` 关联答疑会话，掌握度页"查看原题"靠它跳回。（依据：完善文档 05 / 分析-07）
