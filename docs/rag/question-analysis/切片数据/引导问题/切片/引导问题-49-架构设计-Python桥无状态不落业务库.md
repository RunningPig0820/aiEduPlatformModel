## 回答

**核心结论**：Python 是**纯智能无状态桥**——不落任何业务库（无 ORM/MySQL/Redis 依赖），唯一"存储"是 COS 向量桶（题型名向量，metadata 透传不落库）。意味着：可水平扩展、任何一轮可被新机器接管、Java 管状态与数据。

**分层展开**：
- **无状态实现**：Python 无 ORM/MySQL/Redis 依赖，题目完全由 history 推断（Java 零题目状态）；会话历史在 Java Redis、掌握度在 Java 掌握表。（依据：分析-07 / 分析-02）
- **唯一存储**：Python 唯一"存储" = COS 向量桶（put/query，metadata 透传不落库）——别误以为 Python 把题目/掌握度存了库。（依据：分析-07）
- **意味着什么**：① 可水平扩展，任何实例无状态可接管；② 故障不影响数据——主链路数据都在 Java；③ Python 只做 LLM + 向量原语，职责纯智能。（依据：分析-02 设计要点）
- **边界**：落库/映射/决策全在 Java（题目表 + 掌握表 + Redis 会话），Python 显式禁止做题型↔知识点映射。（依据：分析-02 / 分析-08）
