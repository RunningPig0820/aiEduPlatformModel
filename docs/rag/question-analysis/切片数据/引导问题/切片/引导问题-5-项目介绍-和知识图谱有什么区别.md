## 回答

**核心结论**：知识图谱是**知识结构**（教材知识点 + 关系，权威、可枚举）；这个模块是**学生个人能力画像**（题型掌握度 + 答题证据，动态、可增长）。图谱管"课程长什么样"，题型掌握度管"这个学生练得怎么样"。联动靠"借结构"——**权威图谱零写入**。

**分层展开**：
- **本质区别**：图谱 = 权威知识结构（URI 全局、可枚举、教材锚点）；掌握度 = 个人能力画像（canonical 题型 + 连续百分比 + 答题证据）。（依据：完善文档 01 追问 / 07）
- **联动方式**：题型↔知识点关联放**派生层 MySQL**（查表只读 + ADMIN 维护），Neo4j 只被"借结构"持 URI 向外展开——**零写入红线**，关联错了也不污染教育局图谱。（依据：完善文档 07 / 分析-08）
- **跨年级**：掌握度按题型名（canonical）记，与当前学年无关；图谱 URI 全局（年级只是 URI 一部分），跨年级薄弱天生可展示。（依据：完善文档 07 追问）
- **职责边界**：Python 显式禁止做题型↔知识点映射（`models/tutoring.py:73-76`），图谱点亮是独立变更（kp-matching-lightup），答疑/题型链路不直接写 Neo4j。（依据：分析-08）
