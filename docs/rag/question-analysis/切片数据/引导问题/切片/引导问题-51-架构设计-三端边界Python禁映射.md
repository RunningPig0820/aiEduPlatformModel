## 回答

**核心结论**：三端边界 = **前端触发展示 / Java 编排决策落库 / Python 纯智能桥（LLM + 向量原语）**。Python 显式禁止做题型↔知识点映射，因为映射是"业务隔离的派生数据"——需独立维护/审核、易污染权威图谱，且 Python 不该碰 Java 的业务数据职责。

**分层展开**：
- **三端边界**：前端（触发 + 渲染）；Java（编排 + canonical 归并 + 掌握度计算 + 防作弊 + 落库）；Python（学科门/图片识别/decide 信号/向量原语，无状态不落库）。（依据：分析-02 / 分析-01）
- **为什么禁映射**：① 权威图谱零写入红线——映射错污染教育局图谱；② 题型↔知识点是"业务隔离"的派生数据（鸡兔同笼→四年级假设法 / 七年级二元一次方程组，年级相关），需独立维护/审核；③ 职责边界——Python 只出信号，映射收敛在 Java 派生层（ADMIN 维护）。（依据：完善文档 07 / 分析-08）
- **代码铁证**：`models/tutoring.py:73-76` KpSnapshot 注释"Python 不要拿 kp_key 反查图谱/做题型↔知识点映射（桥已移到后端 ADMIN 维护接口）"。（依据：分析-08）
- **两域解耦**：Python 被显式禁止做映射，域 A 只消费题目记录、域 B 查表只读——故障隔离双保险。（依据：完善文档 09 / 分析-08）
