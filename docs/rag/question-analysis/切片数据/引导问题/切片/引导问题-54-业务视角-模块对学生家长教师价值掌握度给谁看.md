## 回答

**核心结论**：对学生——看清自己哪类题型薄弱、练习方向；对家长——看得见孩子"这类型题练得怎么样、哪薄弱"（掌握度页主要给家长/学生看）；对教师——薄弱分布/错题分组做学情诊断（演进中）。**掌握度页 = 学生/家长视角**，后端回流 decide 是内部闭环。

**分层展开**：
- **对学生**：题型掌握度让"这类型题练得怎么样"看得见——薄弱题型优先被答疑照顾（回流 decide），错题可回看。（依据：完善文档 01 / 09）
- **对家长**：掌握度页（题型 | 来源 | 掌握% | 训练数 | 跳转原题）是可解释、可追溯的能力画像——"孩子练了多少、哪题型不行"一目了然，不是拍脑袋。（依据：完善文档 05 / 07）
- **对教师**：题型薄弱分布、错题分组、学情分析——是演进路线阶段 3（多维能力画像 + 家长/教师视图），本期以掌握度为基础逐步展开。（依据：完善文档 08）
- **产品边界**：掌握度给谁看 = 学生/家长（掌握度页），答疑闭环回流（mastery_snapshot）是系统内部决策依据。（依据：完善文档 09 / 分析-05）
