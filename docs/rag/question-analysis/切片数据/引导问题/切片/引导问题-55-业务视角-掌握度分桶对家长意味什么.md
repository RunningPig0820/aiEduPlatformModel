## 回答

**核心结论**：底层是连续 0-100 累计正确率，前端保留**四档视觉分桶**——<25 待巩固 / 25-50 练习中 / 50-75 偏稳 / ≥75 已掌握。对家长：一眼看出孩子每类题型处于哪个阶段，**待巩固 = 优先要补的**，已掌握 = 可以放心。

**分层展开**：
- **数值与分桶**：`getMastery` 返回连续 0-100（masteryLevel），前端分桶保留四档视觉——<25 待巩固 / 25-50 练习中 / 50-75 偏稳 / ≥75 已掌握（⚠️契约从离散四档 0/25/50/75 改连续，视觉分桶保留）。（依据：完善文档 05 / 分析-05）
- **对家长含义**：待巩固 = 练得少/错得多，优先辅导；练习中 = 在进步；偏稳 = 接近掌握；已掌握 = 可信。分桶把连续百分比变成可行动的提示。（依据：完善文档 05）
- **可信基础**：每个分桶背后是累计正确率 + 训练数 + 可跳转原题——家长能往下钻到具体哪道题，不是空标签。（依据：完善文档 05 / 分析-07）
- **注意**：训练数少时分桶参考性有限（第 1 题打折更保守），但方向上可解释。（依据：完善文档 05 追问）
