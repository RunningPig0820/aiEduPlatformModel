## 回答

**核心结论**：产品口径——**题型是"练一类题做得怎么样"的计量单位，知识点是"课程里学什么"的锚点**。"题型可测" = 题目天然能聚到题型、能判对错、能量化掌握；一元二次方程"作为题型"可测熟练度，作为知识点它只是课程位置。两者不打架，因为测的是不同维度。

**分层展开**：
- **可测的含义**：题型 = 解题模式，题目天然可聚（向量归并 canonical）、可打分（答对/答错）、可累计（掌握%）——**能测**；知识点 = 课程概念，映射依赖图谱，本身不直接产生对错信号。（依据：完善文档 01 追问 / 05）
- **产品话术**："孩子一元二次方程这类型题练得怎么样"（题型，可测）vs"一元二次方程在课程里对应什么"（知识点，可映射）——两个问题，两个系统。（依据：完善文档 01 追问 / 07）
- **为什么锚题型**：题目可聚到题型、落库不裂行、掌握度可观测；知识点由题型派生（后置）。（依据：完善文档 01 追问）
- **边界保护**：两域解耦 + canonical 对接，题型掌握度不污染权威图谱，产品口径上两者"各测各的"。（依据：完善文档 09 / 07）
