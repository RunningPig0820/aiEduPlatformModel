## 回答

**核心结论**：没有题库正是**动态涌现**的用武之地——canonical 由学生第一条题建锚，后续题目题型名向量最近邻自动靠拢，**题型从真实做题数据里长出来**。比预置强在：① 无冷启动预置成本；② 题型随真实使用动态增长、不滞后；③ 数据飞轮越滚越准。

**分层展开**：
- **靠什么支撑**：零锚点动态涌现——首题建锚 + 向量最近邻归并，不需要预置题型分类表。（依据：完善文档 06 / 08 追问）
- **比预置强在哪**：① 预置题型是"规定出来的"，跟不上 LLM 叫法漂移；动态涌现是"长出来的"，随真实做题收敛；② 无题库数据也能跑（先采集后沉淀）；③ 数据飞轮——答疑越多题型库越准。（依据：完善文档 08 追问 / 06）
- **演进衔接**：将来题库引入（`source=bank` 已预留）会减少 LLM 猜名漂移，但本期无题库数据，先从答疑/题型分析入口采集。（依据：完善文档 08）
- **兜底**：题库没有，靠动态涌现 + 别名表收敛，掌握度可追溯每道题。（依据：完善文档 08 追问 / 05）
