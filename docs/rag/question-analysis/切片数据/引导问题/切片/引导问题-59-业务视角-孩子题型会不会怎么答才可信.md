## 回答

**核心结论**：用**可解释、可追溯**的数据答——"孩子鸡兔同笼练了 10 道、答对 6 道、掌握度 64%（偏稳档）"，附训练数 + 掌握% + 可跳转原题。每个数字背后是题目表的事实证据（每道题的对错 + 引导轮数 + 会话链接），不是拍脑袋。

**分层展开**：
- **可解释数字**：掌握度 = 累计正确率——"某题型练 10 道对 6 道 = 64%"是可直接解释的，公式 `new = old×n/(n+1) + score×1/(n+1)`。（依据：完善文档 05 追问）
- **可追溯**：每道题落题目表（score 生效分值 + 引导轮数 + session_id），家长可跳转原题看"哪道错了、是不是被引导才答对"。（依据：完善文档 05 / 分析-07）
- **分桶给结论**：<25 待巩固 / 25-50 练习中 / 50-75 偏稳 / ≥75 已掌握——把连续数字翻译成可行动建议。（依据：完善文档 05 / 分析-05）
- **边界诚实**：训练数少时参考性有限（第 1 题打折更保守）；求助后答对只算 0.5——"会"和"独立会"分得清。（依据：完善文档 05 追问 / 05）
