## 回答

**核心结论**：题型是**可测的解题模式**（题目天然可聚、可打分、可观测），知识点是**课程锚点**（映射依赖图谱）——两者本质不同，靠"两域解耦 + canonical 名对接"互不污染。

**分层展开**：
- **本质区分**：一元二次方程"作为题型"关注学生会解这类题吗、练了多少（可聚可打分）；"作为知识点"关注它在课程结构里的位置（映射依赖图谱）。掌握度锚题型因为题目可聚到题型、落库不裂行。（依据：完善文档 01 追问 / 07）
- **两域解耦**：域 A「题目→题型」（本期核心，掌握度）与域 B「题型→知识点」（独立维护）完全解耦——域 A 只消费题目记录，域 B 查表只读 + ADMIN 维护，一个故障不影响另一个。（依据：完善文档 09 / 分析-08）
- **canonical 是对接缝**：域 A 产出 canonical 题型名 → 进别名表查域 B 映射；域 A 不碰图谱、域 B 不碰答题信号。（依据：完善文档 09）
- **零写入红线**：权威图谱 Neo4j 只被"借结构"，题型↔知识点放派生层 MySQL——关联错了也不污染权威数据。（依据：完善文档 07 / 分析-08）
