## 回答

**核心结论**：核心三张表 + 两类外部存储——题目表（事实源）、掌握表（聚合）、题型↔知识点派生表（域 B）+ Redis（会话）+ COS（题型名向量桶、答疑 transcript）。**全是 Java 写**，Python 不落业务库只写 COS 向量桶。

**分层展开**：
- **题目表** `t_student_question_record`：每道题一条（内容/source/score/引导计数/session_id），Java 写，作事实源回查原题、对错证据、题目页展示。（依据：完善文档 05 存储拓扑）
- **掌握表** `t_student_topic_mastery`：canonical key 唯一 + 连续 0-100 累计平均 + train_count + source，Java 写，掌握度页分桶展示 + 回流 decide。（依据：完善文档 05 存储拓扑）
- **题型↔知识点派生表**（`t_kp_question_type` 等，Java learning 库）：查表只读 + ADMIN 维护，域 B 权威分布。（依据：完善文档 05 / 分析-08）
- **Redis（会话）**：Java 侧，会话 3 态（ACTIVE/ARCHIVED/TERMINATED）+ 护栏计数。（依据：完善文档 05 存储拓扑）
- **COS**：题型名向量桶（topic-index，Python put）+ 答疑 transcript 普通桶（Java 写）。（依据：完善文档 05 存储拓扑 / 分析-07）
