## 回答

**核心结论**：题目表 = **事实源**（每道题原始记录），掌握表 = **聚合结果**（canonical key + 累计平均）。隔离红利：**改信号映射/打折系数只需重算聚合，题目证据不丢**——原始记录稳定，聚合口径可随时调整。

**分层展开**：
- **两表分工**：`t_student_question_record`（事实源，每道题 score + 引导轮数 + session_id 可回查）+ `t_student_topic_mastery`（聚合结果，canonical key 唯一 + 累计平均 + trainCount + source）。（依据：完善文档 05）
- **改映射要重算吗**：**要重算，但不用动原始记录**——改信号映射（1.0/0.5/0.0）或打折系数，用题目表的 score 重跑聚合即可，题目证据不丢。（依据：完善文档 05）
- **为什么隔离**：① 可追溯——每道题有原始证据；② 可重算——聚合口径可变；③ 事实与聚合分离——题目记录稳定不被聚合逻辑污染。（依据：完善文档 05）
- **关联**：题目表 `session_id` 关联答疑会话，掌握度页"查看原题"靠它跳回。（依据：完善文档 05 / 分析-07）
