## 回答

**核心结论**：会话状态在 **Java 侧 Redis**（会话 3 态 ACTIVE/ARCHIVED/TERMINATED + 护栏计数）——断线重连不丢；AI 服务本身无状态，任何一轮可被新机器接管。答疑中途断线，已落库的数据（题目/掌握度）不丢，未落库的当轮由前端提示重发。

**分层展开**：
- **会话存储**：Redis（Java 侧），会话 3 态 + 护栏计数，断线重连不丢。（依据：完善文档 05 存储拓扑 / 分析-07）
- **AI 无状态**：Python 不存会话，任何一轮可被新机器接管——会话状态全在 Java Redis。（依据：分析-07 / 完善文档 05）
- **断线会丢吗**：已落库的数据（题目表/掌握表）不丢；decide/generate SSE 中段失败 Java 不可重试，提示重发——别把 error 事件当可恢复。（依据：分析-02 隐性坑 / 分析-07）
- **兜底**：AI 生成 0 token 空流给固定引导话术，学生收到可继续对话，不是空回复。（依据：分析-10）
