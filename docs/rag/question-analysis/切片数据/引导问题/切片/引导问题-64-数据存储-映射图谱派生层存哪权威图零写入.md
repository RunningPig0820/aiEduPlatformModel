## 回答

**核心结论**：题型↔知识点映射放**派生层 MySQL**（Java learning 库：`t_kp_question_type` / `t_kp_question_type_kp` / `t_kp_question_type_alias`）；权威图谱是 **Neo4j（只读）**，只被"借结构"持 URI 向外展开。**权威图零写入**是红线——映射错了会污染教育局图谱，派生层坏了不波及时权威数据。

**分层展开**：
- **三处存储**：派生层 MySQL（映射，Java learning 库，查表只读 + ADMIN 维护）；权威图谱 Neo4j（只读，持 URI 展开）；派生层与权威图分离。（依据：完善文档 05 存储拓扑 / 分析-08）
- **为什么零写入**：① 权威图谱是有限权威知识结构（教育局/教材），写入错误会污染全体学生（错误关联经先验放大）；② 题型↔知识点有年级相关性（鸡兔同笼四年级=假设法/七年级=二元一次方程组），需独立维护/审核。（依据：完善文档 07 / 09 追问）
- **Python 不碰**：Python 显式禁止做题型↔知识点映射（`models/tutoring.py:73-76`），相关表 Python 不触碰。（依据：分析-08）
- **故障隔离**：映射放派生层，坏/慢不波及时权威数据；域 B 挂，域 A 掌握度链路照跑。（依据：完善文档 09 / 分析-08）
