## 回答

**核心结论**：本期四项 Non-Goal——**题型↔知识点自动关联 / 相似题检索 / 定时批量聚类 / 题库建设**。相似题检索不做因为它需要**题目向量 + 题目文本落库**（独立功能），本期掌握度/聚集只需要题型名向量，收敛范围；`question` 索引已配置占位，后续启用零架构改动。

**分层展开**：
- **Non-Goal 清单**：① 题型↔知识点自动关联（业务不成熟，改查表只读 + ADMIN）；② 相似题检索（题目向量不落库，独立功能）；③ 定时批量聚类（面试项目不引入定时复杂度，改手动触发）；④ 题库建设（无题库数据，source=bank 已预留）。（依据：完善文档 08）
- **相似题检索为什么不做**：相似题（"和这题类似的题"）需要题目向量 + 题目文本落库，本期掌握度/动态聚集只需要题型名向量（归并 canonical 够用）——是范围收敛不是能力边界。（依据：完善文档 08 / 06 追问）
- **预留**：`question` 索引已配置占位（768 维与 topic 同款），题目文本不落向量是本期收敛——后续启用零架构改动。（依据：完善文档 08 / 分析-06）
- **诚实口径**：Non-Goal = 刻意不做（不是忘了），演进要清晰边界——哪些现在不做、为什么，哪些将来做、怎么做。（依据：完善文档 08）
