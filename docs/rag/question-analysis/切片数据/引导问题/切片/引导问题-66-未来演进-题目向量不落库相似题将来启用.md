## 回答

**核心结论**：题目向量不落库是**本期范围收敛**（不是能力边界）——掌握度/动态聚集只需要题型名向量归并 canonical；相似题检索（"和这题类似的题"）是独立功能，需要题目向量 + 题目文本落库。`question` 索引已配置占位，将来启用**零架构改动**。

**分层展开**：
- **为什么不落库**：聚集目标是"题型归并"，题型名向量语义最近邻足够（鸡兔同笼/鸡兔同笼问题/假设法）；题目向量管题面相似，语义目标和聚集不同，本期不做。（依据：完善文档 06 / 08）
- **相似题检索将来怎么启用**：① 启用 `question` 索引（768 维与 topic 同款，已配置占位）；② 题目文本落库/落向量（`models/vector.py:22` 注释"题目文本不落库"）；③ 零架构改动——`vector_type` 路由已预留 `question`。（依据：完善文档 08 / 分析-06）
- **⚠️翻转事实**：早期方案"题目向量为主 + 题型名向量为辅"——已翻转为只题型名向量单信号，别按旧方案理解。（依据：完善文档 06 / 分析-06 对账）
- **边界**：题目文本仍落 MySQL（`t_student_question_record` 作事实源），只是不 embedding 进向量桶。（依据：完善文档 08 / 分析-06）
