## 回答

**核心结论**：题库引入是**演进阶段 1**——题库题目带固定题型/知识点，能显著降低 LLM 猜名漂移。掌握表 `source` 已预留 `bank` 口径，题库题目进来后按 `source=bank` 标注、用固定题型直落 canonical，减少动态涌现的漂移压力。

**分层展开**：
- **演进位置**：阶段 1（题库引入 bank + 相似题检索启用 question 索引）——在"题目→题型→掌握度 + 动态聚集 + 两域解耦"（阶段 0）之后。（依据：完善文档 08）
- **source=bank 预留**：掌握表 `source`（ai/bank）已入设计，`t_question` 题库域与"学生作答记录"是两回事——题库题带固定题型/知识点，显著减少 LLM 猜名漂移。（依据：完善文档 08 / 分析-07）
- **怎么演进**：题库数据源（企业级对接教材/题库）→ `source=bank` 题目带固定题型/知识点 → 直落 canonical/掌握表，与答疑来源（ai）区分。（依据：完善文档 08）
- **本期状态**：无题库数据，先从答疑/题型分析入口采集；题库建设是独立工程，本期 Non-Goal。（依据：完善文档 08）
