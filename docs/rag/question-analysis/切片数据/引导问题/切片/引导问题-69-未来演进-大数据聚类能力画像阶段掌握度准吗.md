## 回答

**核心结论**：**大数据语义聚类 = 阶段 4**（embedding 把近义题型名归成同一簇）；**多维能力画像 = 阶段 3**（概念理解/计算/逻辑/审题）。现在的掌握度是**题型维度累计正确率**，量小先有趋势、量大后聚合更准——"掌握度趋势准吗"要看训练数，训练少时参考性有限。

**分层展开**：
- **阶段划分**：阶段 3 = 学情分析/多维能力画像（概念理解/计算/逻辑/审题）+ 家长/教师视图；阶段 4 = 大数据语义聚类（embedding 把近义题型名归成同一簇）+ 派生层物化。（依据：完善文档 08）
- **现在的掌握度**：题型维度累计正确率（`new = old×n/(n+1) + score×1/(n+1)`），可解释、可追溯、稳定不抖动。（依据：完善文档 05 / 08）
- **准吗**：训练数足时准（累计平均反映真实水平）；训练少时参考性有限（per-题型前几题打折更保守）——量小先有趋势，量大后聚合更准。（依据：完善文档 08 追问）
- **将来更准**：多维能力靠事件累计 + 多信号（`answer_request_count`/`hint_count` 引导量做 `0.6^hint_count` 衰减）。（依据：完善文档 08 追问）
