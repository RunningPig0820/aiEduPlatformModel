## 回答

**核心结论**：掌握度 = **累计平均正确率**（`new = old×n/(n+1) + score×1/(n+1)`），完整链路可追溯——每道题落题目表（score 生效分值 + 引导轮数 + 会话链接）→ 题型名向量归并 canonical → 掌握表累计平均。"某题型练 10 道对 6 道 = 64%"是可直接解释的数字。

**分层展开**：
- **计算链路**：题目落题目表（事实源，score + 引导计数 + session_id）→ canonical 归并 → 掌握表累计平均（trainCount 计数）。一次作答算一次，反映真实练习量。（依据：完善文档 05 / 分析-07）
- **信号映射**：直接答对 1.0 / 求助后答对 0.5 / 答错 0.0，**× per-题型打折**（第 1 题 0.7 / 第 2 题 0.8 / 第 3 题起 1.0，可配置）——打折作用于 score 不作用于结果，防"第一题答错→题型 0%"假低。（依据：完善文档 05 / 分析-05）
- **为什么不 max 单调不减**：max 是置信度视角，答错永不降会虚高；累计平均是正确率视角，可解释、可回查、稳定不抖动。（依据：完善文档 05 追问）
- **可追溯**：掌握度页按题型列式 + 训练数 + 跳转原题（session_id 关联答疑会话）——不是拍脑袋数字。（依据：完善文档 05 / 分析-07）
