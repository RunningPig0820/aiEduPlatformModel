## 回答

**核心结论**：两个学生入口——**答疑对话**（做题，产生对错信号 + 掌握度）和**题型分析页**（贴题/拍题，看题型 + 关联知识点），两条入口走同一套「学科门 → 题型识别 → 归并 canonical → 落两表」底盘。

**分层展开**：
- **答疑对话入口**：学生发题 → 学科门 → 题型识别 → decide 每轮引导并输出 `mastery_signals`（题型三档 + eval.correct）→ Java 落题目表 + 掌握表累计平均——**掌握度信号只在这里产生**。（依据：完善文档 02 / 分析-01）
- **题型分析页入口**：贴文本/拍图片 → 识别题型（文本题 Java / 图片题 Python question-understand）→ 返回「题型 + 关联知识点」清单；**只记题目不出对错**，不产生掌握度。（依据：完善文档 02 追问 / 分析-04）
- **共用数据底盘**：两条入口的题目都落 `t_student_question_record`（事实源），题型名都过向量归并 canonical，掌握度页统一展示。（依据：完善文档 02 / 分析-07）
- **前置闸门**：进入链路前都过 subject-classify（K12 十值闭集），非数学直接不放行。（依据：完善文档 02 / 分析-03）
