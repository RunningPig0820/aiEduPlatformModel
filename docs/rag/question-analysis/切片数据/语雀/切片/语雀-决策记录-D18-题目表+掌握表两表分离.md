### D18 题目表 + 掌握表两表分离（事实源 + 聚合结果）
> 状态：✅
> 检索摘要：新增题目记录表作为事实源，掌握表作为聚合结果，两表隔离「题目证据」与「聚合值」，后续改折扣/信号重算聚合即可，题目证据不丢。


| 属性 | 内容 |
|---|---|
| 背景 | 掌握度数据底盘零散：无题目记录，掌握表 key 是字符串级归一，算不出「练了几道、答对几道」正确率 |
| 演进 | 无统一题目表 → 新增 `t_student_question_record` + 改造 `t_student_topic_mastery`（加 source/train_count，mastery 语义改累计平均） |
| 拍板理由 | 题目表是事实源（含对错信号与引导轮数可回查）；掌握表是聚合结果（canonical key + 累计平均）；两表隔离后可重算聚合不丢证据 |
| 系统影响 | 全入口题目统一落库（AI 答疑唯一产生信号，题型分析页只记题不产生信号）；掌握度每行有题目证据可跳回原题 |
| 证据 | design-backend-question-type-mastery Decision 1 |

> 证据：详见 `1.语雀/语雀-决策记录.md`（§D18）｜ 完善文档 05-数据落库与掌握度.md
