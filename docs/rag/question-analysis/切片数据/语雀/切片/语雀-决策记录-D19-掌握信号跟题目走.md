### D19 掌握信号跟题目走（PENDING 照常采集）
> 状态：✅
> 检索摘要：题型名未识别（PENDING）的题照常采集对错信号落题目表，题型归属确定后再聚合进掌握表，不因题型待定丢信号。


| 属性 | 内容 |
|---|---|
| 背景 | PENDING 是「题型暂时没认出」，不代表「题没做」 |
| 演进 | 信号等题型确定才记 → 信号跟题目走先落表 |
| 拍板理由 | 答对/答错信号是确定的，不能因题型待定就丢；否则 PENDING 高频场景掌握度大面积漏采 |
| 系统影响 | 题目表先落，canonical 归属（聚集/人工）确定后再聚合进掌握表 |
| 证据 | design-backend-question-type-mastery Decision 8；design-frontend-question-type-mastery Decision 4 |
