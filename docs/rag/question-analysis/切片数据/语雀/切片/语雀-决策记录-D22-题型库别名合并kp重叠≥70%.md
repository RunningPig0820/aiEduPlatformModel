### D22 题型库别名合并：kp 分布重叠 ≥70% → canonical + 别名表

> 状态：✅
> 检索摘要：相似题型名按知识点分布重叠（≥70%）收敛到 canonical 题型 + 别名表，查询统一走 findByTopicLabelOrAlias，聚合阈值不再被变体稀释。

| 属性 | 内容 |
|---|---|
| 背景 | 聚合按 topic_label 逐字聚类，相似题型叫法不一裂成重复条目、聚合阈值被劈开稀释 |
| 演进 | 逐字聚类 → 新表 `t_kp_question_type_alias` + kp_uri 重叠 ≥70% 判变体折叠 |
| 拍板理由 | 变体题型的语义锚是它指向的知识点，kp 重叠是确定性信号、零 LLM、零误判成本；字符串/归一化兜不住「鸡兔同笼」vs「鸡兔同笼问题」 |
| 系统影响 | 解析管线②/vote/analyze/聚合统一走别名命中；canonical 名只增不改（合并只加别名） |
| 证据 | design-backend-kp-question-analysis D3/D4 |

> 证据：详见 `1.语雀/语雀-决策记录.md`（§D22）｜ 完善文档 06-题型动态聚集与向量.md ｜ 坑档案 J-QT5-alias匹配miss
