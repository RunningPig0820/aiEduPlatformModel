### D26 题型名稳定规范（prompt 约束 + few-shot，后端只字面归一化）
> 检索摘要：prompt 强制同一题型用最常见最短规范名 + few-shot 锚定常见题型；后端只做字面归一化不做同义词聚类，稳定性负担在 prompt 端。

| 属性 | 内容 |
|---|---|
| 背景 | LLM 天生爱换说法，「鸡兔同笼」vs「鸡兔同笼问题」会被当两个题型 |
| 演进 | 无约束 → prompt 约束 + few-shot 锚定（鸡兔同笼/相遇问题/牛吃草） |
| 拍板理由 | 后端只做字面归一化（全角半角/空白/去语气词），不做同义词聚类；命名稳定性负担前移到 prompt |
| 系统影响 | 题型名稳定依赖 prompt + 后端字面归一化兜底（不完美，本期不做同义词聚类） |
| 证据 | design-python-ai-tutoring-topic-mastery-signal Decision 4 |
