### D4 掌握度信号映射 + per-题型打折

> 状态：✅
> 检索摘要：定义答疑行为得分权重，答对 1.0、求助答对 0.5、答错 0；前 N 题做分数打折，缓解首题答错带来掌握度假低。

| 属性 | 内容 |
|---|---|
| 背景 | 掌握信号需定义（答对/求助/答错）；首题答错会造成假低 |
| 演进 | 定稿 |
| 拍板理由 | 区分不同答题行为质量；首题打折降低单次作答对掌握度的冲击 |
| 系统影响 | 掌握表只被 AI 答疑信号更新；题型分析页无对错信号 |
