### 问题11：掌握度显示错误
> 检索摘要：学生没做过该类题却显示"待巩固/待确认"，根因是未命中题型（true miss）与 alias miss（false miss）未区分；未命中应显示"未开始"灰态。

| 属性 | 内容 |
|---|---|
| 现象 | 学生没做过该类题却显示"待巩固/待确认" |
| 触发流程 | getMastery 查不到该题型 |
| 根因 | 未命中题型（true miss）被当待巩固；alias miss（false miss）也被吞成未开始 |
| 修复方案 | 未命中显示"未开始"灰态；alias miss 该修后端收敛，前端不吞 bug |
| 状态 | ✅ 已修复（方案定稿）`前端需适配` |
