### 选型11：图片题型识别方案选型（方案A 通用 chat vs 方案B 独立视觉端点）

> 状态：✅ 已落地
> 检索摘要：图片题默认走多模态视觉模型直接看图，独立 stateless 端点不经 OCR；不经通用 chat 避免路由到非视觉模型导致图片识别失败。

- 选型场景：图片题目题型识别的模型调用路径
- 候选方案A：通用 /api/llm/chat 多模态
  - 方案A优劣（致命短板）：复用通用路由；但不是所有模型都是视觉功能，路由到非视觉模型图就废
- 候选方案B：独立 question-understand 端点，模型写死视觉
  - 方案B优劣：模型 Python 侧写死视觉、Java 不指定，非视觉风险天然隔离；方舟开通 ID 不同改 Python 一行 Java 无感
- 最终拍板：方案B 独立视觉端点（POST /api/tutoring/question-understand）
- 拍板理由：方案A 非视觉风险不可控；方案B 视觉模型隔离 + 独立端点可降级（topic_labels 空 → PENDING）（D23）
- 证据：design-backend-kp-question-analysis D13
