## 已落地（Python 侧 ✅）

- **subject-classify 学科门**：K12 十值闭集、关思考+20s 超时、闭集外→None 放行 math。（`core/tutoring/subject_classify.py`）
- **question-understand 图片题型识别**：topic_hint 词表收敛、顺带 question_kps、失败降级空结果。（`core/tutoring/question_understand.py`）
- **decide 掌握度信号题型化**：`mastery_signals`（题型三档）+ `question_kps`（顺带知识点）。（`models/tutoring.py:119,121`）
- **向量端点 put/query**：dashscope 768 维 embedding + COS 向量桶、vector_type 多索引路由、错误冒泡。（`api/vector.py` + `vector_store.py`）

## 明确不做（🚫 Non-Goal）

- **题型↔知识点自动关联**：域 B 独立化——查表只读 + ADMIN 手动维护（backend design Decision 10）
- **相似题检索**：题目向量不落库（`question` 索引仅配置占位）
- **定时批量聚类**：`@Scheduled` 移除，改按钮手动触发（backend design Decision 9）

## 关键边界（Python 不承担）

- analyze-question / mastery 端点在 Java（Python 只留 question-understand 图片入口）
- canonical 归并决策在 Java `TopicLabelAggregationService`
- 掌握度计算/落库/防作弊落库全在 Java
- Python 显式禁止做题型↔知识点映射（`models/tutoring.py:73-76`）
