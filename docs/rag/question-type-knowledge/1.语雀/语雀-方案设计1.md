  问题 1：鸡兔同笼不在图谱里 → 会不会污染？

  不会，因为答案不是“往图谱里加节点”，而是“加一张别名映射表”。

  鸡兔同笼本质是题目考点（问题类型），二元一次方程组才是教材知识点（课程锚点）。它们是两套词表，对应关
  系是“多对一”。你要做的是把这种对应关系记下来：

  权威层（教育局，只读）           派生层（自建，可增长）
  ────────────────────          ──────────────────────────
  Neo4j 图谱 ──────────┐         t\_kp\_alias（别名映射表）
  kg-sync MySQL 镜像 ───┼─────►   鸡兔同笼 → 二元一次方程组 URI
    (uri + label)       │        相遇问题 → 行程问题 URI
    merged\_to\_uri 去重   │        t\_kp\_unresolved（待解析队列）
                        └──────►  未命中的 label 落这里

+ 写入永远发生在派生层（我们自己的一张 MySQL 表），权威图一个字不动 → 零污染。
+ 现成的 resolveLabelToUri 就是升级点：从“精确→LIKE→丢”升级成“精确 → 别名表 → LLM 消歧 → 挂起队列”。

  问题 2：跨年级怎么办？用户不懂的地方不在当前学年

  这不是问题，是免费获得的优势——因为 URI 是全局的，年级只是 URI 的一部分。

  教材 URI：...#renjiao-g1s  ← 一年级上
  知识点 URI：...#renjiao-g1s-2-2-xxx

  掌握度按 URI 记，和“当前学年”毫无关系。学生七年级答二元一次方程卡壳 → decide
  报了“一元一次方程掌握不足” → 解析成五年级的 URI → 落库。点亮时：他在七年级图谱看当前年级的亮/灰，去五
  年级图谱也能看到那个低年级薄弱节点。跨年级是天生的。

+ 权威图被污染（教育局图谱失去了“权威”的意义）
+ 业务逻辑（题型）和领域结构（课程）耦合
