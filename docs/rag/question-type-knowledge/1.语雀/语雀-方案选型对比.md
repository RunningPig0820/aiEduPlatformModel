> summary: 题型知识点模块各技术点多方案权衡对比，记录候选方案优劣、最终拍板结果以及否决理由

## 1. 存储选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 派生层存储 | **A. MySQL 派生层** | 快、可事务、好审核；无限题型空间可写可改 | ✅ MySQL 派生层（现状）；Neo4j 阶段2 物化（ExtAlias + ALIAS_OF） | 数据量上来能力强；权威图零写入（D1）；阶段2 需要图遍历时才物化，可过滤还原纯教育局视图 |
| | **B. Neo4j 物化扩展层** | 可图遍历（薄弱溯源）；但无限题型挂有限知识点会图爆炸、污染权威图 | | |
| | **C. Java 直调 COS** | 全 Java 零依赖；但不用 Vector Bucket、后续 RAG 要另起 | | |

## 2. 关联引擎选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 题型↔知识点关联引擎 | **A. 纯 LLM** | 灵活、可处理语义变体；但自由猜测不可控（空候选/跨学段错配）、成本高 | ✅ 分层混合：字符规则拦确定性变体 + 题型名向量最近邻（动态涌现，不需预置池）+ LLM 兜底命名/仲裁 | 纯 LLM 自由猜测不可控（D15 空候选）；字符规则覆盖不了语义同型；向量最近邻确定性/便宜、且零锚点动态涌现（D6） |
| | **B. 题型名向量最近邻** | 确定性、便宜、可聚类；但需池或动态涌现、对数学术语区分度依赖 spike | | |
| | **C. 字符规则** | 确定性、免费；但只拦变体（解/求前缀），覆盖不了语义同型 | | |
| | **D. 分层混合** | 各层各司其职、确定性优先、LLM 兜底；实现复杂度稍高 | | |

## 3. 掌握度锚点选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 掌握度锚点 | **A. 题型** | 题目天然可聚到题型（canonical 向量聚类稳定、可打分可观测、落库不裂行）；贴合学生认知 | ✅ 题型；知识点由题型派生 | 学生做的是题、题对应题型可测；知识点映射依赖图谱、易错需维护（D2） |
| | **B. 知识点** | 课程锚点、挂图谱直观；但映射依赖 label→URI 解析、易错需 ADMIN 维护 | | |

## 4. 掌握度算法选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 掌握度算法 | **A. 累计平均正确率** | new=old×n/(n+1)+score×1/(n+1)；正确率视角、可解释可回查、稳定不抖动 | ✅ 累计平均 | max 算不出正确率（置信度视角虚高）；EWMA 难解释难回查（D3） |
| | **B. max 单调不减** | 置信度视角、答错永不降；简单但虚高、算不出正确率 | | |
| | **C. EWMA** | 对近期更敏感；但难解释、难回查 | | |

## 5. 关联模式选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 题型↔知识点关联模式 | **A. 自动关联** | obs 共现 → LLM 归纳 ratio；数据驱动但引入 5 环节（状态机/聚合批处理/LLM 归纳/vote 澄清/派生覆盖度）、业务不成熟易污染 | ✅ 查表只读 + ADMIN 手动维护（域 B 独立化） | 自动关联 5 环节分散本期核心（题目→题型→掌握度）；手动维护一张表可演示/可解释/可控（D8） |
| | **B. 查表只读 + ADMIN 维护** | 入口只读、独立维护；可控但需要人工配数据 | | |

## 7. 确认机制选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 关联确认机制 | **A. 纯人工打标** | 开发者/教研脱离解题、可能错；等于不专业人工替代不专业 LLM | ✅ 分层信任模型：LLM 主裁判 + 学生意图信号 + 人工边界仲裁 | 问意图非事实，学生是意图唯一权威；防恶意 4 招（只碰自己/票数稀释/不暴露底层/跳过弃权）；人工只处理极少数边界（D16） |
| | **B. 学生众包** | 量最大；但恶意乱点/捣乱污染数据，完全交给用户不成立 | | |
| | **C. 学生澄清意图** | 问"你想学哪个"（主观意图）学生唯一权威；source=student_vote、confidence=60 | | |
| | **D. LLM 高置信自动** | 规模化；但高置信幻觉会绕过低置信挂起 | | |

## 8. 候选约束选型

| 选型点 | 候选方案 | 各自优劣 | 拍板结果 | 拍板理由 |
|---|---|---|---|---|
| 关联候选生成 | **A. 开放域自由猜测** | 灵活；但无数据锚时 LLM 自由猜测，空候选频繁（5 次 4 空）、跨学段错配 | ⚠️ 封闭域池内选择（建议项） | 题目 + 该生年级知识点池 → LLM 只能从池里选 → 恒返回 top-N 不空；年级锚定消灭跨学段错误（D15） |
| | **B. 封闭域池内选择** | 从有限选项选、恒非空；但依赖年级知识点池完备性 | | |
