# 分析-05 掌握度计算与信号（代码真相）

> 来源：ai-edu-ai-service 深读（2026-08-26）｜权威度 0.8 ｜ 模块=question-analysis

## 职责

Python 只**输出掌握度信号**（三档），0-100 累计平均计算在 Java ScoreMapper + 掌握表。

## 代码事实

- **mastery_snapshot 结构**：`KpSnapshot(kp_key, label, mastery_level: int 0-100)`。（`models/tutoring.py:70-79`）
- **掌握度主体 = 题型，不是知识点**：KpSnapshot 注释明确"2026-08 语义变更：掌握度主体从知识点切为题型，kp_key 现在是题型名(canonical)不是 TextbookKP URI"；"Python 不要拿 kp_key 反查图谱/做题型↔知识点映射"。（`models/tutoring.py:70-76`）
- **信号枚举**：`MasterySignal(mastered/practicing/struggling)` 三档——不是四档百分比。`MasterySignalItem(topic_label + signal)`。（`models/tutoring.py:38-42,93-96`）
- **信号来源**：`Eval.correct` + `exercise_complete` + 换题短路无作答。（`models/tutoring.py:85-90`）
- **decide 提示词**：强调"mastery_signals 记录学生对题型的掌握度，不是知识点，知识点由后端根据题型派生"。（`prompts.py:78-83`）
- **快照回流 decide**：`snapshot_top_n` 按 `mastery_level` **升序**取 top-10（薄弱题型在前），让模型优先关注薄弱项 + 防撑爆上下文。（`core/tutoring/context.py:26-43`、`decider.py:78-80,116-119`）
- **快照仅作上下文**：提示词"仅作上下文提示，不照抄为 mastery_signals 的 topic_label"。（`prompts.py:88-89`）

## 对账要点（Java 侧职责，Python 不承担）

- **0-100 累计平均**：`new = old×n/(n+1) + score×1/(n+1)`，n=train_count。
- **信号映射**：直接答对 1.0 / 求助后答对 0.5（answer_request_count≥1）/ 答错 0.0 × per-题型前几题打折（第1题 0.7/第2题 0.8/第3题起 1.0）。
- **两表**：`t_student_question_record`（事实源）+ `t_student_topic_mastery`（聚合，canonical key）。
- **getMastery BREAKING**：masteryLevel 0-100 连续（原离散四档），前端分桶保留四档视觉。

## 关键设计

- 打折作用于 score 不作用于结果（防"第一题答错→题型 0%"假低）；per-题型 scoping（每个题型自己的第 1 题打折）。
- 一次作答算一次（不做去重），反映真实练习量。
- 掌握信号唯一来源 = AI 答疑（题型分析页只记题目不出对错）。
