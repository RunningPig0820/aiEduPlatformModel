# 分析-06 向量动态聚类（代码真相）

> 来源：ai-edu-ai-service 深读（2026-08-26）｜权威度 0.8 ｜ 模块=question-analysis

## 职责

Python 提供向量**原语**（put/query + embedding），canonical 归并决策在 Java（`TopicLabelAggregationService.aggregate`）。

## 代码事实

- **端点**：`POST /api/tutoring/vector/put`、`POST /api/tutoring/vector/query`，同步 JSON，`x-internal-token` 鉴权。（`api/vector.py:30-81`）
- **存**：`put_vector(key, text, vector_type, metadata)` → dashscope embedding → `CosVectorsClient.put_vectors`；**key 相同 upsert**。（`core/tutoring/vector_store.py:124-147`）
- **查**：`query_vector(text, top_k, vector_type, filter_)` → embed → `query_vectors`，返回 `{key, metadata, distance}`，**按 distance 升序（越小越相似）**。（`vector_store.py:150-179`、`models/vector.py:46-50`）
- **key 格式**：`VectorPutRequest.key` = 业务 ID（Java 传）；本期语义 = 题型名向量，**题目文本不落库**。（`models/vector.py:16-24`）
- **路由**：`vector_type` 必填，唯一合法值 `"topic"` → 索引 `topic-index`；`question`/`rag` 配置占位。未知 → ValueError → 400。（`vector_store.py:106-121`、`settings.py:99-105`）
- **embedding**：dashscope `text-embedding-v3`，显式 `dimensions=768`（默认 1024，维度必须与索引一致，索引建好不可改）。（`vector_store.py:26-28,87-103`）
- **写入延迟**：`put_vectors` 后 ~10s 异步生效，立即 query 可能 miss（空 vectors）。（`vector_store.py:126-127`）

## Java 侧归并逻辑（参考 analysis-07 + design Decision 4）

```
① 字符规则归一：全半角/空白/去标点 + "解/求"前缀剥离
② 题型名向量最近邻：
     distance ≤ 0.2  归并到命中 canonical（写别名表）
     0.2 ~ 0.3       建新不误并
     ≥ 0.3           异型建新（宁可拆不误并）
③ 首题建锚（零锚点，动态涌现）——canonical 由第一条相似题创建
```

## 关键设计

- **编辑距离 ≤1 近字归并已移除**："一元一次/一元二次"一字之差与错别字"方成/方程"同为距离 1，字符级无法区分会误并——近字/错别字全交给向量层。
- **聚集依据 = 题型名向量单信号**（题目向量本期不落库）；字符规则只拦确定性变体（解/求前缀）。
- **无定时批量聚类**：Python 侧无实现；设计明确"不做批处理/定时任务，后端已定手动触发"（Java `@Scheduled` 已移除改按钮）。
- **spike 实测**：self≈0、同型 ~0.077（鸡兔同笼→鸡兔同笼问题）、异型 ≥0.33（相遇→行程 0.332）。
