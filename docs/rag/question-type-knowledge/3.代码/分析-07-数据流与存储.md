# 分析-07 数据流与存储（代码真相）

> 来源：ai-edu-ai-service 深读（2026-08-26）｜权威度 0.8 ｜ 模块=question-analysis

## 数据流全景（Python 产出 → Java 落库）

```
Python 侧（stateless，不落业务库）
  subject-classify → 学科门判定（Java 编排）
  question-understand → topic_labels + question_kps（图片题）
  decide SSE → agent/thinking/meta(ActionMeta)/done
    ActionMeta.mastery_signals（题型三档）+ question_kps（顺带知识点）+ eval.correct
  vector put/query → COS 向量桶（唯一"存储"）

Java 侧（落库）
  t_student_question_record（事实源：题目文本/score/引导轮数/session_id）
  t_student_topic_mastery（掌握表：canonical key + 累计平均 + train_count）
  t_tutoring_error_event（错误事件）
  会话历史（Java Redis）
```

## 代码事实

- **Python 不落任何业务库**（无 ORM/MySQL/Redis 依赖）。当前题目完全由 history 推断（Java 零题目状态）。（`core/tutoring/decider.py:56-89`、`prompts.py:118-124`）
- **Python 唯一"存储" = COS 向量桶**：put/query，metadata 透传不落库。（`vector_store.py:124-179`）
- **decide SSE 事件**：`agent(perceive/analyze/plan/decide) → thinking* → meta(ActionMeta) → done`。（`api/tutoring.py:55-72`、`core/tutoring/agent_events.py:17-38`）
- **generate SSE 事件**：`meta(action_type) → agent(generate) → thinking* → token* → done`。（`api/tutoring.py:97-109`、`core/tutoring/generator.py:53-75`）
- **question-understand / subject-classify**：同步 JSON，一请求一返回。（`api/tutoring.py:121-149`）
- **mastery_snapshot 回流输入**：`DecideRequest.mastery_snapshot: List[KpSnapshot]`（Java 从掌握表组装，Python 只排序取 top-10 薄弱在前）。（`models/tutoring.py:141`、`context.py:33-43`）

## 对账要点

- 题目表 `session_id` 跳回答疑会话（掌握度页"查看原题"）；无会话链接显示题目原文。
- Python 是"信号来源"（mastery_signals + eval.correct），落库全在 Java。
- 事件驱动：答疑事件 → 信号 → 题目落库 + 掌握表累计平均。
