## 问题
rag llm的健壮性什么的 我们有考虑吗

## 回答
LLM 健壮性确实是今天 spec 里最薄的一层。你 spec 覆盖了超时、断连、降级，但 LLM
  自身的失败模式、以及"白盒系统被打爆"的场景基本没提。我按重要性分层列出来。

  四、还有一个偏产品的问题

  评测/证明有效性：你 spec 从头到尾没提"怎么证明这套 RAG 靠谱"。08-21 设计过评测 agent（hit@3 + 质量分 +
  版本对比），Model 仓库还有 rag-eval-agent change。如果这是面试/汇报项目，没有评估集 =
  无法回答"怎么证明有效"——建议至少每模块 5 条 Q&A 评估集 + hit@k 命中率，挂到成本展示旁边。

  断线恢复）是"不做会翻车"的；其余是"做了更完整"。
