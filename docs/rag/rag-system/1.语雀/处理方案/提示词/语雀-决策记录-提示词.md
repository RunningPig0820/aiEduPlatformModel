## 硬性规则（强制全部遵守）

### 术语强制统一
固定术语：双池检索（索引层QA池/源文档池）/ 页面锚定（页面模式/全局模式）/ 两道门（权限门/范围门，阈值0.75/0.5）/ token真算 / 白盒化 / 引导问题（索引层入口）/ 评测agent（hit@k/answer_quality）/ 多路召回（向量+BM25）/ RRF融合 / is_quoted（LCS硬匹配）/ 禁区拒答。禁止自创别名。

### 状态判定标准（严格区分，禁止混淆）
- ✅【已落地设计】：代码可观测到实现逻辑；语雀文档描述+代码同时存在。
- ⚠️【建议项(未实现)】：仅语雀方案文档描述，代码无对应实现，属于设计构想、备选方案。
- ❓【待决策 Open Question】：语雀和代码均无明确结论，待后续评审拍板。

### 证据标注规范
1. 语雀来源证据：`证据：语雀-原文件-问题X.md`；引用总揽：`[总揽§X.X]`
2. 代码来源证据：优先写 `文件:函数名/类名`；无法获取真实行号时禁止编造虚假行号，写 `文件:逻辑片段`；只有明确可见行号才写 `文件:行号`。
3. 某类来源不可读（如 Java 代码无法解析），证据字段写 `来源不可读，无有效证据`，禁止编造逻辑。

### 格式与内容约束
1. 移除全部对话、问答、来回讨论口吻；输出正式技术综述，禁止提问者/回答者视角。
2. 规则、阈值全部使用表格承载；段落简短，避免大段无分割文本。
3. 同主题信息归并，一处讲透；总揽已详述内容直接引用章节标记。
4. **禁止业务臆造，所有内容必须来自来源材料，没有来源就如实标记信息缺失。**
5. 引用本库内部文档标记：决策记录条目标记 `D#序号`（D# 为本文档内部编号，从 11 篇原文件提炼时按业务领域顺序分配，禁止凭空杜撰决策内容）。

### 输出前强制自检（不输出自检文本，只保证结果符合）
1. 是否区分 ✅/⚠️/❓ 状态，没有把建议项标记为已落地。
2. 所有代码相关条目是否附带证据，没有编造行号。
3. 是否删除问答对话口吻。
4. 是否出现术语别名。
5. 是否有重复内容，同类决策已合并。
6. 文档顶部元信息完整，summary、权威度、模块、COS路径、类别字段齐全。

### 失败降级
某类来源完全不可读，直接跳过该来源信息，如实在证据字段标记，不编造内容。

## 强制输出约束（RAG 切片友好，必须严格遵守）

## 提取范围（逐项覆盖，不遗漏，D# 从原文件提炼分配）

1. 架构类：双池检索（索引层预写 QA 池 + 源文档池，doc_type=qa/source）、页面锚定（页面模式/全局模式）、白盒流水线分层（Java 角色门/SSE 中继 + Python 无状态引擎）、SSE 事件契约（permission→intent→rewrite→switch→recall→rerank→token→reject/boundary→done）
2. 检索与重排类：多路召回（向量+BM25）、RRF 融合 Top-K=3（08-21 曾显式否决 RRF，08-25 引入——演进对比）、打分公式（相似度×问题类型×锚定加权）、is_quoted LCS 确定性硬匹配（8 中/12 英，生成完补发）
3. 两道门类：权限门（可信源取角色，禁 body 传参，非学生固定 403 不耗 token）、意图门（硬路由：架构/代码/部署/评测/接口→RAG项目；AI答疑/知识图谱/题型分析→固定拒答）、范围门（检索置信度即范围判断，阈值 0.75/0.5）、两道门共用固定话术、事件 reject vs boundary 可区分
4. 成本类：token 真算（usage 流式结尾更新、stream_options.include_usage、丢 usage 坑）、cache_hit_tokens 拿不到用估算并标注、会话累计 token 预算上限、生成模型成本叙事（免费 glm-4-flash vs doubao 付费）
5. 引导评测类：引导问题=索引层入口、规范问题 vs 变体文案配对（制造难度）、suggestions_pool 静态池随机 2~3 条（静态化降本，非 LLM 动态生成）、评测 agent（hit@k + answer_quality，编造封顶 3 分，HIT_K=5）、评估集扩充（30~50 条，覆盖 5 类场景）
6. 健壮性类：分层超时（召回 2s 硬超时降级/生成 8s）、is_disconnected 断连取消防空转、重试语义分层（intent/rewrite 0 重试，recall 幂等短重试，generate 0 重试）、429 限流/熔断、上下文窗口/轮次上限 5 轮、trace_id 断线补查 API、断线恢复（会话持久化）
7. 语料治理类：策展非全量倾倒、每页选权威版本、语料白名单即权限层、问题记录/草稿/内部规划不进语料
