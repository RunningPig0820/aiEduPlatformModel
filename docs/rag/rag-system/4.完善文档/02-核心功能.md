# 02 核心功能

## 为什么（语雀/动机）

面试要的不是"能用"，而是"点进来就能问、答案有依据可回源、过程可解释、指标可展示"。早期简答契约只回结果+检索文档列表，面试官看不到"系统怎么一步步答出来"，也证明不了"检索准、答案不编造"。08-25 定稿演进为**白盒化**——把 RAG 全链路中间状态以 SSE 事件逐阶段透传前端，一次问答从"黑盒出答案"变成"看着 6 步走完"，再用引导问题、召回面板、token 成本、评测报告把"可上手操作、可演示、可量化"一次做齐（决策 D4/D5/D13）。

## 怎么设计（方案）

**操作主线（方案口径）**：学生进页面 → 右栏白盒面板空态给引导 chips → 点引导题或自由输入 → SSE 逐事件点亮阶段 → 出带引用的流式答案 + 召回文档面板 + token 成本 → 可追问、可结束会话结算。核心功能按 6 项展开：

1. **白盒问答（全阶段 SSE 透传）**：事件时序冻结为 `permission → intent → (clarify|switch) → rewrite → rerank → (boundary|token) → done`，done 是所有分支唯一终止点；前端按事件顺序点亮 5 阶段行（权限→意图→改写→召回·重排→生成），回答流式逐字展示。clarify/switch 分支无 rewrite/recall/generate，boundary 分支无 token 流（决策 D5）。
2. **引导问题 = 索引层入口**：面板空态与每轮 done 后给引导建议；设计为索引层规范问题的**变体写法**（"为什么拆成三段" vs 索引"为什么拆 decide/generate"），强制检索真实发生，避免"点按钮=预定答案"；建议来自后端预置静态池 4 方向随机 2~3 条（决策 D23/D24）。
3. **召回可视化（先灰后亮 + 查看原文）**：rerank 事件先回传精排 Top-K 块，引用面板灰显折叠；done 携带 `quotedKeys`（is_quoted 用 LCS 最长公共子串硬匹配，连续 8 中/12 英字符命中即引用），命中块高亮 + "已引用"徽标；每块可"查看原文"（决策 D12/D13）。
4. **token 成本展示**：每轮 done 返回 `tokens_usage{prompt/completion/cache_hit/total}`，前端每轮明细 + 头部本场累计；流式 usage 真算（`include_usage` + 结尾 chunk），cache_hit 取不到按"估算"标注（决策 D19/D20）。
5. **两道门拒答**：权限门（前置，能不能看）+ 范围门（后置，检索置信度有没有覆盖）；范围门阈值 索引层 >0.75 / 源文档池 >0.5，低于 → 边界回答"未找到关联文档，我尚未掌握"，不硬编（决策 D14/D16）。
6. **评测报告**：`hit@k + answer_quality` 双信号，判分编造 ≥1 处封顶 3 分；离线报告 + 真实对话质量旁路，跑完可版本对比（决策 D25）。

**演进钩子**：页面锚定（方案前端传 `page` 锁页/全局跨页）、追问上限 5 轮/会话、双池（doc_type=qa/source）在落地时均有演进或翻转，详见下节。

## 落地真相（代码）

> **总翻转**：方案"双池 doc_type=qa/source 区分 + 引导问题=规范问题变体强制检索 + 前端传 page 锁页"在代码中全部演进：双池落地为 rag-full/rag-slice 两个物理索引（无 doc_type）、引导建议**反转池内原题直出**、页面锚定由 current_project/anchor 承载（无 page 参数）；范围门 0.75/0.5 **只在白盒链路生效**；sessionId 前端生成但**非 UUID**。正文以代码现状为准。

① **白盒问答**：落地。生产入口 `POST /api/rag/assistant/ask`（SSE 流式/非流式），学生端全局右栏常驻面板（key=pageCode 换页重挂载独立会话），请求带 currentProject+sessionId+history；问候预检（你好/在吗，≤8 字）直返欢迎话术 0 token，模糊问题 clarify 点选=重发原问+currentProject=点选模块 id；断线凭 permission.traceId 走 turns 补查，单轮 45s 超时自关闭。
② **引导问题**：翻转。结束建议直接返回 GUIDE_POOL 池内原题（不做 LLM 改编，2026-08-26 实测改编引入池外概念匹配不到切片故反转）；开始引导 GET /guide 取 3 条入口题，前端 404 兜底静态池标注"(静态建议)"；rag-system 无独立池兜底 ai-tutoring。引导题点击后仍走切片池 -q 问题路真检索（sim~0.99），可答性由池保证。
③ **召回可视化**：落地，细节翻转。rerank 到达即灰显折叠，done 带 quotedKeys 命中块"高亮 + 已引用徽标但默认折叠"（≠设计"高亮展开"）；is_quoted 是 LCS 硬匹配非 LLM 自述，纯函数可入评测；查看原文走 Java 代理（query 传参）→ Python 前缀白名单读 COS。
④ **token 成本展示**：落地（白盒链路）。include_usage=True + 流末 usage chunk 真采组装进 done.tokensUsage（非估算），前端每轮四字段 + 头部本场累计，cacheHitTokens>0 才显示并标"(估算)"（后端拿不到固定发 0，0 直接隐藏）；"结束对话"close 结算 rounds+sessionUsage（Java Redis 累计）。sessionId 非 UUID（sess_时间戳_随机串）。已知缺口：旧 1.6C /query 不采 usage、embedding token 未单列。
⑤ **两道门拒答**：部分落地（只白盒链路）。权限门 Python 未见——角色门在 Java 网关（仅 STUDENT 放行、非学生 403、0 token 不产 trace），permission 事件由 Java 产、Python 从 intent 开始；范围门 0.75/0.5 只在白盒 check_boundary 生效（rerank 空或 vec<0.75 且 bm<0.5 双路都低才拒，单路高即过），触发 → boundary 固定话术 + 短路不调 generate（0 token）；阈值语义 08-25 校正为召回置信度，旧 1.6C /query 无阈值门。rag-system 自身语料未入 MODULE_DATA，anchor=rag-system 的问题当前必然边界拒答——"语料整理中"过渡态。
⑥ **评测报告**：落地（hit@3→hit@5）。HIT_K=5 对齐生成 top-5；判分 LLM 只报事实、分数规则硬算、编造 ≥1 处封顶 3 分；评测走真实检索原语不降级。前端 EvalPanel 展示离线 benchmark（hit@5/质量分/耗时/成本/语料版本）+ 真实对话质量 + 重新评测；最新报告 2026-08-26-259c06：count=6，hit@5=0.583，quality=3.833，avg_cost≈¥0.0181（评测集仅 ai-tutoring 6 条，含 1 条边界拒答）。

流水线现状（一鱼两吃闭环）：语料 → 对账 → 完善文档 → 切片 → 入 COS → 双池召回（rag-full + rag-slice 双向量 + BM25 四路 RRF）→ 生成带引用 → 成本展示 → 评测出报告。AI答疑 已全链路跑通，rag-system 整理中。

## 追问与防御

- **引导问题=预定答案，那 RAG 检索是假的？** → 不是。引导题是**池内原题直出**（不做 LLM 改编，2026-08-26 实测改编引入池外概念匹配不到切片），但点击后仍走双向量 -q 问题路真实检索（sim~0.99）；自由输入走源文档池纯 RAG 真发挥，可现场随意问没准备的问题。可答性由池保证、检索真实发生，两件事不冲突。
- **两道门分别挡什么？范围门只在白盒生效意味着什么？** → 权限门挡"能不能看"——Java 网关角色门，非 STUDENT 固定 403、0 token 不产 trace（Python 无权限门，仅 verify_internal_token）；范围门挡"有没有覆盖"——检索置信度 0.75/0.5 双路都低才拒答，短路不调 generate 省成本。注意：0.75/0.5 只在白盒 check_boundary 生效，旧 1.6C /query 只有空命中拒答，这是"两道门"在代码里的真实边界。
- **答不上来 / doubao 挂了会硬编或拖垮吗？** → 不会。范围门触发 → boundary 固定话术 0 token；向量路 2s 超时 → 空路降级 + degraded 标记；生成超时/异常 → 写死话术 + 召回清单（不空答）；旧 1.6C 端点是 doubao 挂 → references 当答案。降级响应结构不变，前端照常渲染。
- **token 成本展示是真的吗？怎么保证？** → 白盒链路真采——include_usage=True + 流末 usage chunk 解析，prompt/completion/cache_hit/total 来自方舟真实返回，非估算。诚实边界：旧 1.6C 不采 usage、embedding 未单列、cacheHit 取不到置 0 隐藏（0 不显示防误导），面试表述按"白盒链路真采、1.6C/embedding 未接"为准。
