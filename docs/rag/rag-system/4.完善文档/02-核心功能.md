# 02 核心功能

> 模块=rag-system｜节=02｜问题表=操作｜权威度=高（正文）

## 为什么（语雀/动机）

面试官需要一个**能上手操作的入口**：点进来就能问，答案有依据，指标可展示。功能设计围绕"面试问答现场演示"展开。

## 怎么设计（方案）

**操作流程**（对齐 rag-system.md 问题表"面试官怎么操作"）：
```
点页面 → 概览卡(这页讲什么) → 引导问题(预写变体) / 自由输入
 → 答案 + 召回文档面板 + mermaid 流程图 + token 成本展示
```

**关键功能**：
1. **页面锚定**（D3）：前端传 `page` → 页面模式锁页检索；不传/跨页 → 全局模式跨页。前端主动带 page，提升检索确定性、可解释。
2. **双池**（D2）：
   - **索引层池**：每页 5~8 条 QA（`问题 + 答案要点 + 引用`），doc_type=`qa`。引导问题命中 → 答案可控、上下文小、便宜。
   - **源文档池**：完善文档全文，doc_type=`source`。自由问题命中 → 纯 RAG 真发挥。
3. **两道门**（D4）：权限门（前置校验，能不能看）+ 范围门（后置，检索置信度阈值 → 边界回答不硬编）。
4. **生成带引用**（D6）：强制引用、无引用不输出、跨页按页标注（"知识图谱页§x … AI答疑页§y"）。
5. **追问限制**（D9）：5 轮/会话，防上下文膨胀；到了提示开新会话。

## 落地真相（代码）

- `core/rag/`：classify(意图钩子) → retrieve_vector/retrieve_bm25(双路召回) → orchestrate(RRF×权威×锚定) → generate(doubao+引用)。
- `POST /api/tutoring/rag/query`：1.6C 契约，返回 `{answer, references, intent, version}`。
- 降级语义：向量挂→纯 BM25；doubao 挂→references 当答案；无命中→拒答不编造。

## 追问与防御

- **"自由输入也能答？"** → 源文档池纯 RAG 真发挥（不是只答预写问题）。
- **"引导问题=预定答案？"** → 变体文案强制检索 + 自由问题纯 RAG + 现场随意问一个没准备的。
- **"双池怎么判断走哪个？"** → doc_type 区分（qa/source），页面锚定 + 检索置信度综合决策。
