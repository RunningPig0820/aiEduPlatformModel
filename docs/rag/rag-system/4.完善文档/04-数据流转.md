## 为什么（语雀/动机）

面试官要一条链路讲清"这系统数据怎么走"——数据流是 RAG 的骨架：离线侧证明"散落语料能变成可检索的知识块"，在线侧证明"提问能变成带引用的答案"，跨模块看 RAG 怎么把 AI答疑/知识图谱的故事串成一答。

## 怎么设计（方案）——两条链路

**① 离线语料链路（语料 → 可检索）**

1. **语料 → 完善文档**：五来源（语雀/OpenSpec/代码分析/坑档案/引导）+ 切片清单 → 每模块整理 8 节（定位/功能/为什么/数据流/技术/坑/指标/权限），一节=一个答案单元。
2. **切片**：slice_corpus 按 LAYERS 表 + 标题正则切块（完善文档整篇一块、语雀按 h2、OpenSpec/坑档案按 h3、过滤 Risks/Non-Goals 段）→ 产出双池 jsonl。
3. **双池 jsonl**：切片池（细节块+引导问题，pool=slice）+ 全量池（整篇一块，pool=full）；tags 带 module/category/source/authority/anchor。
4. **摘要 + embedding**：切片一句话 ≤30 字 / 全量 40~80 字 → dashscope text-embedding-v3 768d。
5. **COS 入桶**：build_index put_vectors → 向量桶 rag-1318177119（rag-full/rag-slice）；upload_cos 读文件头 `> COS路径:` → 普通桶 ai-edu-1318177119（rag-source/、rag-slices/ 前缀，供"查看原文"）。

**② 在线问答链路（提问 → 带引用的答案）**

1. **前端发起**：面板（sessionId + history 最近 5 轮）→ POST /ask stream=true。
2. **Java 角色门**：session role==STUDENT 放行、非学生固定 403（0 token）→ permission 事件（含 traceId）前置。
3. **Python 编排**：intent（模块锚点+类别，问候/clarify/switch）→ rewrite 改写 → recall 双池三路（全量向量 + 切片 -c/-q 双向量 + BM25，单路 2s 超时降级）→ rerank 四路 RRF×权威×锚定 Top-3 → boundary 范围门（0.75/0.5 拒答短路）→ doubao 流式生成（强制引用）→ LCS 引用校验 → done。
4. **Java 中继 + 落库**：桥保序透传（滤 Python permission）→ snake→camel 重建 → Redis 会话累计 token/轮数 + trace 快照（TTL 24h）。
5. **前端白盒**：5 阶段行按序点亮 → 引用块先灰后亮（rerank 灰显/done quotedKeys 高亮）→ CostBar 成本 → close 结算 / 断线补查 turns。

跨模块闭环：AI答疑→掌握度→图谱点亮→薄弱点分析；RAG 跨页检索多页引用把闭环串成一答。

## 落地真相（代码）

> ⚠️ **总翻转**：方案"同一 COS 索引 + doc_type=qa/source 区分双池、前端传 page、两道门都在 Python 链"落地为：**rag-full/rag-slice 两个物理 COS 索引 + metadata.module 过滤选池 + 池前缀 key（metadata 10 字段无 doc_type）**；页面锚定演进为 current_project/anchor 模块过滤 + locked_sections 节加权 1.5（白盒链路节加权被旁路）；**权限门在 Java（Python 无权限门）、范围门 0.75/0.5 只在白盒 check_boundary 生效**。

- **离线产物实存**：`scripts/rag/data/rag_slices-{module}.jsonl` + `rag_slices_full-{module}.jsonl`（实测 ai-tutoring 294+23、question-analysis 317+25）；入桶 key=`{rag-full|rag-slice}/{module}/{file}/{anchor}#{idx}`（切片池每块 -c/-q 双向量）；原文走普通桶 `rag-source/` / `rag-slices/` 前缀。
- **在线现状**：token 白盒流式/评测真采、embedding 未单列；会话聚合（累计 token/轮数、close 结算、trace 补查）全归 **Java Redis**（`rag:assistant:*`，TTL 24h），Python 显式无状态；close 不中止在途流。
- ⚠️ **rag-system 悬空**：未入 MODULE_DATA（仅 ai-tutoring+question-analysis），只在锚点闭集 + DEFAULT_MODULE 出现——anchor=rag-system 当前必边界拒答；部分完善文档仍为旧单行头（无 `> COS路径:`）upload_cos 会跳过，语料就绪即自动可答。

## 追问与防御

- **"数据在哪存？"** → 相似度在 COS 向量桶 rag-1318177119（rag-full/rag-slice，768d/cosine）；原文/切片视图在普通桶 ai-edu-1318177119；语料 jsonl 留本地（向量桶不收普通对象）供 BM25/反查；会话状态在 Java Redis；Python 无状态。
- **"离线在线怎么衔接？"** → 衔接点=双池 jsonl + 统一 key 规则（build_index.make_key == query._key_of）：离线切片→embed→入桶，在线向量命中后按 key 反查本地 jsonl 拿全文/摘要喂生成，BM25 直读同批 jsonl。
- **"断线怎么恢复？"** → 每轮 done 的 camel JSON 落 `rag:assistant:trace:{traceId}`（TTL 24h）；SSE 中断前端凭 permission.traceId 调 `GET turns/{traceId}` 补回 answer/quotedKeys/usage；超窗 10002 提示重发；close 结算累计 token/轮数。
