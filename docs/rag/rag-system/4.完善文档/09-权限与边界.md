# 09 权限与边界

> 模块=rag-system｜节=09｜问题表=最危险问题｜权威度=高（正文）

## 为什么（语雀/动机）

面试官会问"这系统有没有边界？会不会答错/乱答/越权？"——两道门 + 边界话术就是回答。

## 怎么设计（方案）——两道门 + 边界

**权限门（前置）**：
- 校验"能不能看"——未授权页面直接拒绝访问。
- 落地：`x-internal-token` 鉴权（`POST /api/tutoring/rag/query` 需内部 token）。

**范围门（后置）**：
- 检索置信度阈值——索引层 0.75 / 源文档池 0.5。
- 低于阈值 → **边界回答**（预写话术），不硬编。
- **为什么**：范围门 = 检索置信度，语料即边界，无需单独分类器。

**边界原则**（最危险问题防御）：
1. 语料没覆盖 → 拒答"该问题语料未覆盖，建议问项目相关话题"，**不编造**。
2. 生成失败 → 降级返回召回块清单（references 当答案），不空答。
3. 全挂 → 边界话术兜底（最坏也能答）。

## 落地真相（代码）

- `api/rag.py`：`verify_internal_token` + 降级语义（向量挂→纯 BM25 / doubao 挂→references / 无命中→拒答）。
- `core/rag/eval_agent.py`：编造封顶 3 分（判分标准里编造权重最高）。
- 追问限制：5 轮/会话防上下文膨胀（设计，AI答疑 侧已落地）。

## 追问与防御

- **"这是预写答案吧？检索是假的？"** → 变体文案强制走检索 + 自由问题纯 RAG + 现场随意问一个没准备的。
- **"超范围会怎样？"** → 边界话术不硬编（范围门 → 预写"语料未覆盖"）。
- **"为什么不接 Neo4j 做 GraphRAG？"** → 语料是文档不是图谱；图谱能力在知识图谱页讲，RAG 边界 = 文档问答。
