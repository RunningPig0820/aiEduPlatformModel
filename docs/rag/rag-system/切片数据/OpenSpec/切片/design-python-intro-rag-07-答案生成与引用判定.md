### D6. 生成:doubao 流式 + 强制引用 + 按页标注

> 检索摘要：生成阶段怎么堵幻觉？复用ark_stream直连方舟流式，prompt强制只基于检索上下文回答、每条引用标注来源页、无引用不输出正文，跨页按页分段引用

- 复用 `ark_stream.py` 直连方舟流式;**强制引用**:prompt 要求只基于检索上下文回答、每条引用标注来源页、无引用不输出正文。
- 跨页答案按页分段引用(`知识图谱页§3 … AI答疑页§5 …`)。
- **为什么**:强制引用同时堵死幻觉和跑题("检索不到就边界拒绝,没引用就不输出正文")。
- **备选**:预写完整答案直发 → RAG 沦为查表,弃。

### Requirement: 生成后展示「召回文档原文」面板

> 检索摘要：生成后要不要展示原文证据？回答生成后展示SHALL附带「召回文档原文」面板，显示本次检索命中的源文档段落，引用可回源

- 系统 SHALL 在生成回答后,展示界面附带「召回文档原文」面板,显示本次检索命中的源文档段落。
- 与 D10 的关系:D10 仅在生成失败时"展示召回原文"作为降级;本块是正常回答后的**常驻证据面板**,两者场景不同。
- 设计意图:强制引用 + 常驻原文面板 = 引用可回源、回答可核验。

#### Scenario: 展示召回原文
- **WHEN** 生成回答后
- **THEN** 展示 SHALL 附带「召回文档原文」面板,显示本次检索命中的源文档段落
