### D9. 会话与追问限制

> 检索摘要：会话追问怎么控制成本与节奏？页面锚定会话追问默认锁定当前页，追问上限5轮/会话，超限提示开启新一轮对话，上下文不无限膨胀

- 页面锚定会话:追问默认锁定当前页;跨页由全局模式处理。
- 追问上限 **5 轮/会话**,超限提示"信息较多,请开启新一轮对话"(文案预写)。
- **为什么**:上下文不无限膨胀 = 成本可控 + 节奏可控。

### D10. 降级矩阵 + 重试策略

> 检索摘要：各环节故障怎么降级？query理解、检索、打分、生成、展示各有重试与降级到关键词/边界话术/召回原文/预写答案卡片，LLM挂了也能答，超时检索<2s生成<15s

| 环节 | 故障 | 重试 | 降级到 | 最差兜底 |
|------|------|------|--------|---------|
| query 理解 | embedding API 挂/超时 | 否 | 关键词/规则(jieba) | 提示换说法 |
| 检索(COS) | 查询失败/超时/索引缺失 | 是, 短超时重试1~2次 | 关键词检索兜底 | 边界话术 |
| 打分/范围门 | 全低于阈值 | — | 边界回答 | 同上 |
| 生成(doubao) | 失败/限流/流断 | 否(流已起) | 展示召回原文 | 预写答案卡片 |
| 展示 | mermaid 渲染失败 | 否 | 文本/预置图片 | 纯文字答案 |
- **为什么**:复用既有失败语义模式(错误冒泡 / 吞异常降级 / 关 SDK 重试 / 20s 超时)。**预写答案 = 天然兜底**:LLM 挂也能答。
- 超时:检索链 < 2s,生成流 < 15s,超时即降级。

### D11. demo 可靠性:COS + 预建索引 + 本地兜底

> 检索摘要：demo现场怎么保证检索可用？用COS向量桶生产链路叙事，但demo前预建索引避开10s异步写后不可即查，保留本地索引兜底路径断网降级

- 用 COS 向量桶(生产链路叙事),但 **demo 前预建索引**(避开 10s 异步写后不可即查)。
- 保留本地索引兜底路径(同接口抽象),断网时降级到本地。

### Requirement: 重试策略明细

> 检索摘要：RAG重试策略怎么定？仅COS查询执行短超时指数退避最多2次，doubao流式生成与embedding不重试避免重复计费，失败直接降级

- 系统 SHALL 仅对 COS 查询执行重试:短超时、**指数退避**、最多 2 次。
- LLM 生成与 **embedding 均不重试**。
- 设计意图(为什么 LLM 不重试):生成/embedding 是计费调用,**自动重试会重复计费**;COS 查询是便宜幂等操作,短超时重试 1~2 次可自愈。

#### Scenario: COS 查询重试
- **WHEN** COS 查询首次失败
- **THEN** 系统 SHALL 按指数退避重试最多 2 次,仍失败则进入降级流程

#### Scenario: LLM 不重试
- **WHEN** doubao 流式生成失败
- **THEN** 系统 SHALL 不自动重试(避免重复计费),直接降级

### Requirement: 降级矩阵 Scenario 明细

> 检索摘要：降级矩阵的独有场景？生成失败时引导问题直接展示索引层预写答案卡片（区别于自由问题展示召回原文）；检索与关键词均失败返回边界话术不抛裸错误

#### Scenario: 生成失败展示预写答案
- **WHEN** doubao 生成失败/超时/流断
- **THEN** 系统 SHALL 展示检索到的召回原文;**若为引导问题则直接展示索引层预写答案卡片**

#### Scenario: 全链路失败边界兜底
- **WHEN** 检索与关键词均失败
- **THEN** 系统 SHALL 返回边界话术,**不抛裸错误给用户**
