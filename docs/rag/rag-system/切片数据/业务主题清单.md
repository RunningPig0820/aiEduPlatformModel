## 合并规则

1. 每份源文档只产它覆盖的主题块（不产空块）；同一主题跨多份源文档 → 各自文档内合并,不跨文档合并（文档独立性保持）。
2. 一块 = 该主题在该文档内的所有相关条目合并（决策+选型+场景+###），**去掉结构编号头**（D#/选型N/场景N/阶段N 作正文内容保留,不作文件名）。
3. 块命名：`{主题编号}-{主题短名}.md`（如 `03-双池检索设计.md`），多份源文档同主题块共存靠 `source_doc` 元标签区分（摄入时推导）。
4. 每块带 检索摘要（业务向,模拟用户提问）+ 头部精简 5 行 + 权威度（语雀 0.8 / OpenSpec 0.7）+ 类别（9 视角）。
5. summary 短标题式 `{主题短名}`；超长拆 -2/-3。
6. 被结构切片（D#/### 一文件）的旧块：重切完成后由主会话清理。
