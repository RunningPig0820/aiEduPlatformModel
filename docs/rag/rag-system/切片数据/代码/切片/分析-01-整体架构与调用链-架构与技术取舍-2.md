## 评测 agent（核心机制 5）

评测是离线闭环，用来"用数据证明检索准、答案好"：
- **走真实检索原语，不降级**：评测跑真实检索链路（intent → 双池召回 → 融合），不经带降级语义的 API——设计意图是"向量挂了就暴露，不让降级掩盖问题"。所以评测时 COS/网络不稳会得到差的指标，这是特性不是 bug。
- **指标**：hit@5（方案里的 hit@3 已演进为 hit@5）+ precision@k + LLM 判分 + 聚合（含 latency/cost/quoted_valid_ratio）。
- **判分机制**：LLM 只输出 `covered_count / fabricated / rationale`，分数由规则硬算（覆盖比例 100%→5 分，逐档降，0%→0 分），**编造 ≥1 处 → 封顶 3 分**——把"不编造"作为硬约束。判分解析失败重试 1 次，仍失败记 0 并标记未判分。
- **边界拒答评测**：专门的边界拒答用例，断言触发范围门，触发 → 5 分，未触发 → 0 分，0 token 不进生成。
- 评测集当前仅 ai-tutoring 6 条（项目介绍/操作/数据关联/难点/最危险 + 1 条边界拒答"帮我写一封辞职信"），强制 module=ai-tutoring，≥5 条才跑。
- 报告版本 = `日期-全块文本 sha1 前缀`，可版本对比；实测最新报告 count=6, hit@5=0.583, quality=3.833。

## 引导问题 = 索引层入口（核心机制 6）

- **入口引导**：进入页面点引导问题，从底座池取 3 条入门级问题，通用模板 + 模块中文名动态替换（"能不能先介绍一下{模块}？"），0 token。
- **结束建议**：会话结束给建议时**直接返回池内原题**（必含 ≥1 条 rag 组），不做 LLM 改编——这是一个被实测反转的设计：LLM 改编会偏离池内范围、产生无对应切片的新问题，匹配不上，所以改回池内原题 0 token 100% 可答。这与方案 D3"引导问题=索引层规范问题的变体写法"相反。
- **底座池现状**：ai-tutoring / question-analysis / knowledge-graph 三模块有池，rag-system 无独立池，兜底到 ai-tutoring。
- 引导问题可答性由切片池引导问题块 + 双向量 -q 问题路保证（对池内原题命中 sim~0.99）。

## rag-system 模块现状（关键事实）

- 意图锚定规则已支持 rag-system（关键词"rag/检索/召回/向量/bm25/rrf"→ rag-system），且意图优先级规则已写好：只有问题无指代且明确问 RAG 系统整体实现（点名"rag 系统/整体架构/召回算法"）才选 rag-system，否则保持 current_project。
- **但当前模块语料数据里没有 rag-system 的 jsonl**（现有全为 ai-tutoring + question-analysis），所以 anchor=rag-system 的问题当前必然落边界拒答"该问题语料未覆盖"，与完善文档 01"rag-system 模块语料整理中"一致。这是过渡状态，规则已为语料就绪铺路。

## 设计要点

- **双池定位演进**：方案"索引层 QA + 源文档池"落地为"切片池（细节+引导，-q 问题路专答引导）+ 全量池（整篇）"，两池各管一个目标：切片池管引导/细节，全量池管整体/自由问。
- **打分公式**：`final = RRF_score × authority × anchor_w`，四路 RRF 各贡献 `1/(RRF_K + rank)`，权威度（1.0 完善文档 / 0.8 代码 / 0.7 语雀）参与连乘，节锚定命中 ×1.5。
- **白盒链路纪律**：boundary 短路不调 generate（防无谓 token），clarify/问候 0 token，生成降级 0 token——token 成本是被显式管控的。
- **Python 无状态**：history/trace_id 只消费不落库，turns/close/累计 token 归 Java Redis，水平扩展叙事有代码支撑。
- **意图 LLM 结构化 + 多层兜底**：LLM 输出结构化意图（anchor/category/categories/switch_detected/ambiguous/candidates）→ schema 校验 → 失败回退模块关键词 + 节关键词 → 指代词兜底。degraded 走 200 不报错。
- **引用确定性**：LCS 最长公共子串硬匹配，连续 ≥8 中文字符（或 12 英文字符折算）命中即 is_quoted，纯函数可入评测。
