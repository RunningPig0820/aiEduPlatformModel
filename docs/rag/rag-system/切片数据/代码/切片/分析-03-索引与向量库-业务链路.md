## 业务描述与业务场景

索引与向量库层是 RAG 语料「切片 → 可检索」的中间件: 把 `scripts/rag/data/*.jsonl` 的语料块做 embedding, 写入腾讯云 COS 向量索引; 查询时按模块过滤召回 Top-K 相似块, 供 RRF 融合 + 权威度加权 → doubao 生成。

场景边界:
- **双池**: 全量池 `rag-full`(整篇文档, 管整体问题) + 切片池 `rag-slice`(细节块, 管追问/细节)。两个池**共用同一向量桶 `rag-1318177119`, 各自独立索引**(settings.py:92 注释、settings.py:99-105 `COS_VECTORS_INDEXES`)。
- **多模块共用索引**: ai-tutoring/question-analysis(已入) 与 knowledge-graph/rag-system(锚点闭集已定但语料未建) 同写 rag-full/rag-slice 索引, **靠 metadata.module 标签 + query 侧 Filter 过滤隔离**(build_index.py:5、query.py:35-40、query.py:458-465)。
- **普通桶放原文**: 源语料 + 切片视图上传 COS 普通桶 `ai-edu-1318177119`(upload_cos.py:36-37、settings.py:114), 前端「查看原文」走 `/api/rag/source/{key}` 读该桶(api/rag.py:57-72)。

## 高层业务调用链

```
切片/整篇 .md
  → slice_corpus.py 生成 jsonl  (scripts/rag/data/rag_slices*.jsonl, 每行 {text, summary, tags})
  → build_index.py 阶段3: 逐块 embed → put_vectors(批20) → rag-1318177119/rag-full|rag-slice
      ├ 切片池每块写 2 key: {key}-c = embed(summary+"\n"+text) / {key}-q = embed(summary)   (build_index.py:166-175)
      └ 全量池写 1 key:  ≤5000 字符 embed(summary+全文), 超限只 embed(summary)               (build_index.py:176-183)
  → upload_cos.py 阶段2: 读 `> COS路径:` 头 → put_object → ai-edu-1318177119/rag-source|rag-slices/<模块>/...
  → 查询时 query.py:
      retrieve_vector(question, vector_type, module) → build_filter({"module": {"$eq": module}}) → query_vector(Filter=...)   (query.py:458-479)
      retrieve_dual = 全量池单向量 + 切片池双向量(-c/-q 按 key 后缀拆两路) + 本地 BM25       (query.py:507-526)
      orchestrate = RRF(四路) × authority × 节锚定加权 → top-K                                   (query.py:620-686)
  → generate(doubao)  +  text 反查: metadata 不含 text, 全文/全量摘要经 key 反查本地 jsonl  (build_index.py:14, query.py:584-606)
```

**文字链路复述**: 切片/整篇 .md 先由 `slice_corpus.py` 生成 jsonl(scripts/rag/data/rag_slices*.jsonl, 每行 {text, summary, tags}); `build_index.py` 阶段3 逐块 embed、put_vectors 批 20 写入向量桶 `rag-1318177119` 的 rag-full(全量池) 或 rag-slice(切片池)——切片池每块写 2 个 key(`-c` 内容路 embed(summary+"\n"+text)、`-q` 问题路 embed(summary)), 全量池写 1 个 key(≤5000 字符 embed(summary+全文), 超限只 embed(summary))。`upload_cos.py` 阶段2 读 md 文件头 `> COS路径:` 把源语料/切片视图 put_object 到普通桶 `ai-edu-1318177119`(`rag-source/<模块>/...` 源语料 + `rag-slices/<模块>/...` 切片视图)。查询时 `query.py` 的 retrieve_vector 经 `build_filter({"module": {"$eq": module}})` 过滤后 query_vector 召回, retrieve_dual 融合全量池单向量 + 切片池双向量(`-c`/`-q` 按 key 后缀拆两路) + 本地 BM25, 最后 orchestrate 用 RRF(四路) × 权威度 × 节锚定加权取 top-K 交给 doubao 生成; 因 metadata 不含 text, 全文/全量摘要经 key 反查本地 jsonl(build_index.py:14, query.py:584-606)。
