## 代码事实 → 降级与容错机制（业务视角）

**四段降级语义按序 + 响应结构不变**：1.6C 检索问答端点的降级顺序是固定的——向量挂→退纯 BM25（references 仍返回）/ doubao 挂→把召回块清单当答案（不空答）/ 无命中→拒答固定话术（不编造）/ 所有路径返回结构一致。前端只按同一份响应契约渲染，这是「降级对前端透明」的关键：无论哪段外部依赖故障，前端拿到的都是同一结构，只是内容从「完整答案」换成「召回清单」或「拒答话术」。

**各端点的兜底行为**：
- 1.6C 检索问答：向量路异常降级纯 BM25；doubao 生成异常把召回块清单当答案（「生成服务不可用，以下为检索到的语料：- [{file}/{anchor}] {summary}」）；空命中拒答「该问题语料未覆盖，建议问项目相关话题」；其余异常统一 500「rag query failed」。鉴权失败 403。
- 白盒链路助手：非流式异常 500；流式（SSE）异常不中断已发出的流，改发 SSE error 事件（code 500）；重新评测走后台线程，已有一轮在跑则幂等返回 already_running，后台异常只记日志不阻塞 HTTP；无评测报告给 404「暂无评估报告」；引导接口是静态池 0 token，未知项目回退默认模块。
- 查看原文：读 COS 失败给 404（而非 500），且只有白名单前缀（rag-source/、rag-slices/）才允许读取，防任意 COS key 被读。
- 评测工具：触发评测在同步线程池跑（run_eval 延迟导入、不阻塞事件循环），异常统一 500「rag eval run failed」；查报告无报告时返回 has_report=False 的空结构，异常 500。

**范围门 0.75/0.5（只在白盒链路生效）**：`check_boundary` 是白盒链路的低置信拒答门，判定规则——rerank 结果为空直接拒答（无语料模块/无命中）；向量置信 < 0.75 且 BM25 置信 < 0.5 双路都低才拒答（单路高即过，双路互补）；通过则继续。实际调用时向量置信取双池任一最大值，触发就发 boundary 事件 + 立即 done、不调生成。**关键边界：1.6C 检索端点没有这道门**，它只有 `if not hits` 空命中拒答，不读置信度，低置信但非空的命中照常进生成。评测的边界拒答类型也复用同一道门，但走独立追踪函数。

**token usage 真算（三侧现状不一致）**：流式白盒链路已修——流式生成显式要求 usage chunk，流末尾的 usage 被捕获并组装成 prompt/completion/cache_hit/total，随 done 事件返回 tokens_usage；评测侧也已抓 usage 并聚合成 avg_tokens / cost_yuan。**仍然丢失的两侧**：1.6C /query 端点生成时未要求返回 usage，且响应模型契约里根本没有 usage 字段；embedding 侧只返回向量，dashscope 的 usage 没被抓。→ 对账结论是「半落地」：流式与评测已真算，1.6C 端点与 embedding 侧仍丢。

**意图/改写/生成的内部降级**：intent 意图钩子走 LLM 结构化，失败/超时/非法 JSON 回退关键词锚定并打 degraded 标记；追问改写失败回退原问题（不降级成空串）；多模块语料加载缺失文件跳过容错（不因一个模块文件缺崩整链路）；该模块无语料返回空池，编排层自然低置信过滤（无语料模块拒答是正确的）。意图/改写调用 20s 超时且关重试，判断要快、不卡 RAG 查询。

## 设计要点

- **短路纪律（防无谓成本）**：白盒边界触发后立即 done、绝不调生成——rerank 空时若放行，doubao 会自生成「未覆盖」话术约 32 token，编排器必须拦下这笔无谓成本。
- **单路超时降级而非整链路失败**：白盒向量召回每路独立 2s 超时，一路挂只影响该路，BM25 本地路永远可用——用「多路召回本身就是降级备份」的思路换可用性。
- **评测不降级**：评测走真实检索原语（向量/BM25/编排），不走带降级语义的 API——向量挂了就暴露真实质量，不让降级掩盖问题。这是「降级与评测质量」的刻意取舍：面向用户的接口降级，面向质量的评测不降级。
- **0 token 兜底矩阵**：边界拒答、生成超时/异常、问候/澄清、会话关闭全用写死话术，不调 LLM，成本为 0——降级文案全部硬编码，保证结构稳定且零成本。
- **异步评测防重复**：重新评测用线程锁包全局 running 标志，已有一轮在跑则幂等返回，后台线程 daemon 化不阻塞 HTTP——现场演示「重新评测」不卡接口。
- **降级语义复用**：CLI 调试脚本与 1.6C API 共用同一套降级（向量挂→BM25 / 无命中→拒答 / 生成挂→清单），本地调试所见即线上行为。
