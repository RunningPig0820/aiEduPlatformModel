## 业务描述与业务场景

**业务描述**：学生端全局右栏常驻的"RAG 项目介绍助手"面板（前端白盒化落地层）。它把后端 Python 的 RAG 全链路中间状态以 SSE 事件透传后**按序点亮阶段行**（权限→意图→改写→召回重排→生成），把召回 Top-K 块做成**先灰显、done 后按 quotedKeys 高亮**的引用卡片，提供引导 chips（开始引导+结束建议）、澄清点选、token 成本面板、断线补查与结束对话结算。核心交互契约（三端定稿 2026-08-25）：`permission → intent → (clarify|switch) → rewrite → rerank → (boundary) → token* → done`。

**业务场景**：
- 学生进入学生端任意页面，右栏助手面板默认展开，第一屏展示开始引导 chips + "向 RAG 项目介绍助手提问"占位
- 学生提问 → 白盒流水线实时点亮（发送中 live 面板）+ 流式正文纯文本逐字展示（不中途解析 Markdown），done 后气泡整块切完整 Markdown
- rerank 事件到达 → 引用面板灰显折叠 Top-K 块卡片；done.quotedKeys 命中块高亮+"已引用"徽标（点击展开摘要/filePath/查看原文）
- 模糊问题 → 澄清卡候选 chips 点选 = 重发原问 + currentProject=点选锚点；切换模块 → "已切换至 X"；低置信 → 边界拒答
- 每轮 done 展示本轮四字段成本并累计进头部"本场成本"；点击"结束对话"弹窗结算会话轮数+累计 token
- SSE 中途断开（无 done）→ 错误消息带"补查本轮"按钮，凭本轮 permission.traceId 调 turns 接口补回完整结果

## 职责

**职责**：作为 RAG 白盒链路的**前端展示与交互层**——消费 Java 网关中继的 SSE 白盒事件、按事件点亮阶段/渲染引用块/驱动澄清与引导交互、展示 token 成本、支持断线补查与会话结算；同时做**前端兜底**（引导接口未建→静态池、后端澄清文案缺失→前端重写、单轮 45s 超时自关闭）。
**不做什么**：不直连 Python（查看原文走 Java 代理）；不生成 traceId（每轮由后端生成，前端不传）；不做 RAG 检索/重排/生成任何模型逻辑；不校验引导 direction（"必含 RAG 方向"由后端 guide 契约保证）；不做跨页历史维护（换页重挂载清空，页面是唯一权威上下文）。
**分工要点**（组件级职责，不含行号）：
- **RagAssistantPanel**（主面板 603 行）：SSE 事件分发与状态机、流水线快照、历史/超时/断线/close 全交互
- **PipelineStages**：白盒阶段行渲染（5 行 + 三分支横幅）
- **ReferencePanel**：引用块卡片 + 查看原文弹窗（灰显/高亮折叠态）
- **GuideChips / ClarifyCard**：开始引导 chips / 澄清候选卡
- **CostBar / EvalPanel**：成本四字段条 / 离线评测 + 真实对话质量面板
- **ragSse**：SSE 流解析与事件分发 + 断线判定
- **ragAssistant API 模块**：ask/guide/close/turns/source/eval 八端点封装
- **pageModuleMap**：页面 pageCode→模块锚点映射 + id→中文 label + clarify 文案本地化/兜底

## 高层业务调用链（学生页→引导chips→ask SSE→阶段面板/召回块→成本→close）

```mermaid
flowchart LR
    A[学生端页面<br/>DashboardLayout 挂载<br/>key=pageCode mode=inline] --> B[GuideChips 空态<br/>GET /guide?currentProject=]
    B -- /guide 404 → FALLBACK_GUIDE --> B1[静态池 3 条<br/>标注"静态建议"]
    A -- 提问/点 chip --> C[handleSend<br/>POST /api/rag/assistant/ask stream=true<br/>sessionId+history+currentProject]
    C --> D[readRagSse 按 event 分发]
    D -- permission --> D1[存 traceId<br/>stages.permission 点亮]
    D -- intent --> D2[意图行: category·anchor<br/>degraded/ambiguous 标注]
    D -- clarify --> D3[ClarifyCard 候选 chips<br/>点选=重发原问+currentProject]
    D -- switch --> D4[已切换至 X 横幅]
    D -- rewrite --> D5[③Query改写: → rewrittenQuery]
    D -- rerank --> D6[④召回·重排 + ReferencePanel<br/>Top-K 块灰显折叠]
    D -- boundary --> D7[⑤边界拒答横幅]
    D -- token* --> D8[流式正文纯文本逐字展示]
    D -- done --> E[快照 pipeline 内联<br/>quotedKeys 高亮引用块 + 本轮成本 + 建议 chips]
    E --> F[CostBar 头部本场累计<br/>done.tokensUsage 累加]
    E --> G[历史 historyRef 最近 5 轮]
    A -- 结束对话 --> H[POST sessions/{sessionId}/close<br/>弹窗 rounds+sessionUsage]
    D -- EOF 无 done → 抛错 --> I[error 分支 recoverTraceId<br/>按钮补查本轮 → GET turns/{traceId}]
    D -- 45s 无 done/error --> J[ROUND_TIMEOUT_MS 自关闭<br/>提示重试]
```

**文字链路复述**：学生端页面右栏常驻面板，空态先拉引导建议（后端未建则静态池兜底并标注"静态建议"）；学生提问或点引导 chip 发起流式 ask（带 sessionId/history/currentProject），SSE 事件按 permission→intent→(clarify|switch)→rewrite→rerank→(boundary)→token→done 顺序分发；permission 先到存 traceId，阶段行随事件逐条点亮；rerank 到达渲染引用块（先灰显），done 后按 quotedKeys 高亮命中块并内联完整流水线快照 + 本轮成本 + 建议 chips；每轮成本累计进头部"本场成本"，历史最近 5 轮随下轮携带；断线（EOF 无 done）凭 traceId 补查本轮，45s 无完成自关闭提示重试；点"结束对话"弹窗结算 rounds + 累计 token。
