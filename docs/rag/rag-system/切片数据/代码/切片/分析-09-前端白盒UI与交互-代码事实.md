## SSE 事件消费（`RagAssistantPanel.handleSend` + `ragSse.readRagSse` + `ragAssistant.askStream`）

- **发起**：`cancelRef.current = ragApi.askStream(params, (type, data) => {...})`（RagAssistantPanel.jsx:141）；params 含 `currentProject`（projectOverride 或页面锚点）、`question`、`sessionId`、`history`（最近 5 轮）、`traceId` 后端生成前端不传（RagAssistantPanel.jsx:132-139）
- **传输层**：`askStream` 用原生 `fetch('/api/rag/assistant/ask', {POST, stream:true, credentials:'include'})`，**不走 axios 拦截器**（ragAssistant.js:26-34）；响应非 ok（含 403）→ 尝试读 JSON message → `onEvent('error', err)`（ragAssistant.js:34-51）
- **SSE 解析**：`readRagSse` 按行解析 `event:`/`data:` 行，camelCase JSON `JSON.parse` 后按 `currentEvent` 分发；`sawDone` 记录是否见过 done（ragSse.js:50-66）
- **事件分发 → 阶段 state**：permission 存 traceId（流开始即存，断线补查用）；intent/clarify/switch/rewrite/rerank/boundary 各自 `setStage`；token 追加 `streamingRef.current += data.text ?? data.content ?? ''` 并 setStreamingContent；done 取 `finalContent = streamingRef.current`、清超时、累加 tokensUsage、组装 aiMessage.pipeline=stagesRef.current（RagAssistantPanel.jsx:142-224）
- **done 的 aiMessage 完整结构**：`{content, traceId, pipeline, tokensUsage, quotedKeys: data.quotedKeys||[], suggestions: data.suggestions||[]}`（RagAssistantPanel.jsx:179-193）
- **clarify 文案优先级**：`displayMessage = localizeModuleIds(data.message, [data.default, ...(data.candidates||[])]) || buildClarifyMessage(data, getModuleLabel(currentProject))`——后端 message 存在则本地化英文 id 展示，缺失才用前端重写（RagAssistantPanel.jsx:147-154）；`localizeModuleIds` 按 id 长到短替换中文 label（pageModuleMap.js:60-71），`buildClarifyMessage` 补"当前在「X」功能页"语境（pageModuleMap.js:76-84）
- **非流式 `ragApi.ask`**（`stream:false`）在 API 模块存在（ragAssistant.js:62）但 **UI 未使用**（grep src 无 `.ask(` 调用点，仅 askStream 在面板使用）
- **`RAG_EVENTS` 常量**（ragSse.js:9-19）导出但 **grep 全 src 无 import**——死枚举，事件名实际以字面量字符串走分发

## 阶段展示映射（`PipelineStages.jsx`）

- **门控**：`if (!started) return null`——未开始不发请求不渲染（PipelineStages.jsx:28）
- **5 阶段行**：①权限控制 `permission.role · 放行/拒绝`（done=!!permission, active=!permission && streaming）；②意图识别 `category · anchorLabel + degraded/ambiguous 标注`；③Query改写 `→ rewrittenQuery`；④召回·重排 `Top-N 块` 或 boundary 时 `命中为空`；⑤生成/待澄清/边界拒答三分支（PipelineStages.jsx:70-107）
- **done 终止一切转圈**：`generateDone = !!done`；③ active 条件 `!rewrite && !clarifying && !!intent && !switchInfo && !generateDone`（PipelineStages.jsx:87），④ active `!rerank && !boundary && !clarifying && !!rewrite && !generateDone`（PipelineStages.jsx:93）——问候轮等不发 rewrite/rerank 的短路径在 done 后不再转圈（TC-4.4 断言"已跳过/完成"）
- **三分支横幅**：switch→`已切换至 {getModuleLabel(toAnchor)}`（bg-primary 横幅，PipelineStages.jsx:56-60）；clarify→`需澄清: {displayMessage}`（bg-warning 横幅 + 候选数，PipelineStages.jsx:61-68）；boundary→`⑤边界拒答 {boundary.message}`（PipelineStages.jsx:98-99）；clarifying 时⑤为"待澄清"行（`默认:{label}`，PipelineStages.jsx:96-97）
- **两处渲染点**：发送中 live 面板 `<PipelineStages {...stages} started streaming />`（RagAssistantPanel.jsx:505）；done 快照 `{message.pipeline && <PipelineStages {...message.pipeline} started />}`（RagAssistantPanel.jsx:412-414）——**快照用 stagesRef 同步维护**（setStage 先写 ref 再 setState，保证 done 能读到完整阶段，RagAssistantPanel.jsx:48-52,117-118）

## 召回块先灰后亮 + 查看原文（`ReferencePanel.jsx` + `ragAssistant.source`）

- **先灰后亮**：rerank 事件到达即渲染引用面板（live：`{stages.rerank?.blocks?.length > 0 && <ReferencePanel blocks={stages.rerank.blocks} />}`，**不传 quotedKeys**→全灰显折叠，RagAssistantPanel.jsx:506；done 快照带 quotedKeys：`<ReferencePanel blocks={message.pipeline.rerank.blocks} quotedKeys={message.quotedKeys} />`，RagAssistantPanel.jsx:415-417）
- **quotedKeys 高亮**：`quotedSet = useMemo(() => new Set(quotedKeys||[]), [quotedKeys])`，`BlockCard quoted={quotedSet.has(b.blockId)}`（ReferencePanel.jsx:78,107）；命中块：`border-success/50 bg-success/5` + `已引用`徽标 + `font-semibold text-success`（ReferencePanel.jsx:22,31,34-39）
- **高亮但默认折叠**：注释明确"命中块高亮+'已引用'徽标;所有块默认折叠,点击展开看摘要/filePath/查看原文"（ReferencePanel.jsx:11-12,18）；`BlockCard` 初始 `useState(false)`，摘要/filePath 在 open 分支内（ReferencePanel.jsx:20,50-71）。TC-10 断言"已引用徽标 + 默认折叠(摘要不可见)，点击展开可见"（rag-assistant-f1.spec.mjs:503-506）
- **块卡片信息**：标题/blockId + Top-N 排名（`score.toFixed(4)` 仅在 title 属性 tooltip，不显示百分比——TC-8 断言 `panel.getByText(/%/)).toHaveCount(0)`，RagAssistantPanel f1:438-439）+ 摘要 + filePath（ReferencePanel.jsx:22-47,50-71）
- **查看原文走 Java 代理**：`viewSource` → `ragApi.source(block.filePath)` → `request.get('/rag/assistant/source', { params: { path: filePath } })`（ReferencePanel.jsx:86; ragAssistant.js:80）——`request` baseURL `/api` 拼成 `GET /api/rag/assistant/source?path=<urlencoded>`，**query 传参不走 path**（语雀 1.4 D-D：file_path 含 http:// 前缀走 path 会被容器拒）；前端不直连 Python
- **原文弹窗**：成功 `typeof data === 'string' ? data : (data?.content ?? JSON.stringify(data))`（兼容字符串/content 两种返回）→ ReactMarkdown 渲染全文；失败弹窗内提示不阻塞主链路（ReferencePanel.jsx:82-91,115-150）
- **无块不渲染**：`if (!blocks.length) return null`（ReferencePanel.jsx:93）——与 boundary 空召回区分

## 引导 chips（`GuideChips.jsx` + `ragAssistant.guide`）

- **触发时机**：面板空态（`messages.length === 0 && !streamingContent`）渲染 `<GuideChips onPick={handleSend} onLoaded={setGuideTitles} currentProject={currentProject} />`（RagAssistantPanel.jsx:388-391）
- **拉取**：`useEffect` 挂载即 `ragApi.guide(currentProject)` → `request.get('/rag/assistant/guide', { params: { currentProject } })`（GuideChips.jsx:34; ragAssistant.js:71），后端契约 `{suggestions:[{title,direction}]}`（GuideChips.jsx:8-11）
- **静态池兜底**：请求失败/空 → `setFallback(true)` + `apply(FALLBACK_GUIDE)`；FALLBACK_GUIDE 3 条均含 RAG 字样（"想了解 RAG 的整体架构吗？/想知道知识库语料是如何流转入库的吗？/想看看评测体系是怎么设计的吗？"），UI 标注"(静态建议)"（GuideChips.jsx:15-19,43-49,62-66）。TC-4.1b 显式 mock 404 验证（rag-assistant-f1.spec.mjs:596-608）
- **前端不校验 direction**：只 `suggestions.map(s => s?.title)` 取标题（丢弃 direction，GuideChips.jsx:35-38）；"必含 ≥1 条 RAG 方向"由后端 guide 契约保证（GuideChips.jsx:9 注释），前端 fallback 池天然全 RAG
- **点击重发**：chip → `onPick?.(t)` → 父面板 `handleSend(t)` 作为新问题重发重走链路（GuideChips.jsx:78; RagAssistantPanel.jsx:391）
- **onLoaded 回传**：`onLoaded?.(list)` 把引导标题喂给父面板 `guideTitles`，进收起气泡建议池（GuideChips.jsx:31; RagAssistantPanel.jsx:39,68-76,77-80）
- **必传 currentProject**：TC-4.1 断言 `/guide?currentProject=question-analysis` 查询参数（rag-assistant-f1.spec.mjs:587-589）

## 澄清交互（`ClarifyCard.jsx` + `handleClarifyPick`）

- **渲染**：clarify 事件到达 → live 卡（RagAssistantPanel.jsx:508）或 done 快照卡（RagAssistantPanel.jsx:419-421）`<ClarifyCard clarify={...} onPick={handleClarifyPick} />`
- **候选 chips**：`candidates` 字符串 id 数组（如 `["ai-tutoring","rag-system",...]`），`getModuleLabel(id)` id→中文 label 渲染，未知 id 显示原文兜底；data-testid `rag-clarify-<id>`（ClarifyCard.jsx:23-38; pageModuleMap.js:53-55）
- **点选语义**：`handleClarifyPick(projectId)` 取 `lastQuestionRef.current` 原问 → `handleSend(originalQuestion, projectId, true)` **force=true 跳过 isLoading 重开一轮**，params.currentProject=点选模块 id（RagAssistantPanel.jsx:229-233,133）；**不是发裸功能名**——TC-4.2 断言第二次请求体 `question='你好'`、`currentProject='ai-tutoring'`（rag-assistant-f1.spec.mjs:667-675）
- **default 提示**：未选择时默认使用「label」功能介绍（ClarifyCard.jsx:40-44）
- 点选模块与会话锚点不同 → 后端 switch 事件照常触发（ClarifyCard.jsx:9-10 注释）
