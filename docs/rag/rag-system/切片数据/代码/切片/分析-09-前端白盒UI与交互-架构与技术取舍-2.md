## sessionId 生成与按页会话

- **sessionId 前端生成、整场复用**：每轮 ask 带同一 sessionId，Java 以 sessionId 为键累计 token/轮数；格式为 `sess_<时间戳>_<随机串>`（**自定义格式，非 UUID**，与设计文档"UUID"描述不符）。
- **按页独立会话**：面板以 `key={pageCode}` 挂在学生端布局右栏，换页即重挂载 → 消息/sessionId/token/流水线/历史全重置，在途 SSE 随卸载取消；无需手动 close 旧会话，规避"LLM 上下文猜错模块 vs 用户所在页"的矛盾。
- pageCode 由路由路径推导（转大写下划线），映射不到模块时兜底为全局模式。

## 断线补查 + 超时自关闭

- **断线判定**：SSE 流 EOF 且未收到 done → 主动抛错（否则会静默挂到超时）。
- **补查**：错误分支凭本轮 permission.traceId 调 turns 接口补回完整结果（answer/tokensUsage/quotedKeys/suggestions），成功渲染"已补查"徽标；trace 过期（业务错误码）提示重新发送。
- **单轮 45s 超时自关闭**：前端先于后端桥 60s 触发，超时取消在途流 + 提示重试；卸载时清理在途流与定时器。
- force 重开：澄清点选/断线重试先取消在途流 + 清超时再重开一轮。

## 成本面板（CostBar）

- 每轮 done 的 tokensUsage 四字段（prompt/completion/cacheHit/total）展示在本轮气泡下，并累加进头部"本场成本"独立行。
- **cacheHit 展示规则**：`cacheHitTokens > 0` 才显示并标注"(估算)"——后端拿不到（doubao 不报 cached_tokens）固定发 0，0 时直接隐藏，避免"缓存命中0"误导；totalTokens 缺失时兜底为 prompt+completion。

## close 结算 + 非学生占位 + 追问展开

- **结束对话**：头部"结束对话"按钮（仅学生可见）调 close 接口，弹窗展示"本次对话总消耗"（rounds + sessionUsage 累计 token）；失败显示 error。
- **角色门**：非学生（非 STUDENT 角色）不发 ask、只渲染"当前非学生无法使用"占位；后端 403 兜底。
- **追问展开（最近 5 轮上下文）**：每轮 done 后把 {question, answer, anchor} 追加进历史并只保留最近 5 轮，下轮 ask 携带；刷新/换页重挂载 → 历史清空 = 新会话。

## 渲染细节与建议 chips

- **流式正文 vs 定稿 Markdown 分离**：token 期间纯文本逐字展示（不解析 Markdown——流式中途语法不完整），done 后气泡整块切 ReactMarkdown。
- done 建议 chips 纵向满宽浅色 pill，点击作为新问题再问；元信息行含已补查/引用命中 N/#traceId。
- 收起气泡建议池：引导标题 + done 建议去重轮换展示；inline 收起为右上角悬浮气泡，fixed 为右侧居中细条。
- EvalPanel（评测面板）：折叠一屏放输入区上方，含离线 benchmark（hit@3/质量分/平均耗时/引用有效/avgTokens/总成本/语料版本）+ 真实对话质量区段 + 重新评测（幂等 + 轮询）。

## 设计要点（机制取舍）

- **白盒化 = 事件即状态**：SSE 事件名 ↔ 阶段 state 键一一对应，阶段行按到达顺序点亮，`done` 是所有分支（正常/clarify/boundary/switch）的终止点，到达即停转圈并定稿。
- **stagesRef 双写**：写 ref 再 setState，解决"done 到达时阶段 state 未 flush"的时序问题，保证快照完整内联。
- **先灰后亮**：rerank 无 quotedKeys 全灰 → done 带 quotedKeys 硬匹配命中块高亮，非 LLM 自述。
- **澄清点选契约冻结**：点选候选 = 重发原问 + currentProject 锚定，后端以 currentProject 权威定位模块。
- **按页会话 = key 重挂载**：规避 LLM 上下文猜错模块 vs 用户所在页矛盾；换页自动清空，无需手动 close。
- **前端兜底分层**：/guide 静态池、clarify 文案重写、45s 超时自关闭、source 弹窗失败提示——每个后端未就绪/异常点前端都有不阻塞主链路的降级。
- **渲染正确性细节**：流式纯文本 vs done Markdown 分离；引用分数只显示排名不显示百分比；cacheHit 0 隐藏；建议 chips 纵向满宽。
