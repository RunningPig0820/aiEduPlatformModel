## SSE 事件消费机制（白盒链路的前端骨架）

- **传输层**：面板用原生 fetch 发 `POST /api/rag/assistant/ask`（stream=true），**故意不走 axios 拦截器**（避免拦截器吞掉 SSE 流式响应）；响应非 ok（含 403）时读 JSON 错误 message 走 error 分支。
- **SSE 解析与分发**：流按行解析 `event:`/`data:`，JSON 解析后按事件类型分发到阶段 state；记录是否见过 done（断线判定依据）。
- **事件→状态映射**：permission 最先到达并存储 traceId（断线补查用，traceId 由后端生成前端不传）；intent/clarify/switch/rewrite/rerank/boundary 各自点亮对应阶段；token 事件把正文逐字追加进流式缓冲并展示；done 事件取流式全文、清超时、累加 tokensUsage、组装完整 aiMessage（content + traceId + pipeline 快照 + quotedKeys + suggestions）。
- **clarify 文案优先级**：后端 message 存在则把英文模块 id 本地化展示，缺失才由前端重写补充"当前在「X」功能页"语境。
- **历史遗留死代码**：非流式 ask 接口在 API 层存在但 UI 未使用；RAG_EVENTS 事件名常量导出但从未被 import（事件实际以字面量字符串分发）。

## 白盒阶段展示（PipelineStages）

- 门控：未开始不发请求不渲染。
- **5 阶段行**：①权限控制（role · 放行/拒绝）②意图识别（category · anchor + degraded/ambiguous 标注）③Query 改写（→ rewrittenQuery）④召回·重排（Top-N 块，boundary 时显示"命中为空"）⑤生成/待澄清/边界拒答三分支。
- **done 是所有分支的终止点**：到达即停止一切转圈并定稿；问候轮等不发 rewrite/rerank 的短路径 done 后不再转圈。
- **三分支横幅**：switch→"已切换至 X"；clarify→"需澄清"横幅 + 候选数；boundary→"边界拒答"横幅；clarifying 时⑤为"待澄清"行。
- **两处渲染点**：发送中 live 面板 + done 后内联快照；快照用 ref 同步维护，保证 done 到达时能读到完整阶段。

## 召回块先灰后亮 + 查看原文（ReferencePanel）

- **先灰后亮数据流**：rerank 事件到达即渲染引用面板（此时无 quotedKeys，Top-K 块全部灰显折叠）；done 携带 quotedKeys（与 rerank 块 blockId 硬匹配，基于 LCS，非 LLM 自述）→ 命中块才高亮 + "已引用"徽标；quotedKeys 为空则全部保持灰显。
- **高亮但默认折叠**：命中块只是视觉高亮，不自动展开，点击才展开摘要/filePath/查看原文。
- **块卡片信息**：标题/blockId + Top-N 排名（分数只做 tooltip，不显示百分比，避免误导）+ 摘要 + filePath。
- **查看原文走 Java 代理**：前端不直连 Python，以 query 传参（file_path 含 http:// 前缀走 path 会被容器拒）；弹窗失败只提示不阻塞主链路。
- 无块不渲染，与 boundary 空召回区分。

## 引导 chips（GuideChips）

- 面板空态渲染，挂载即拉引导建议；后端契约返回 `{suggestions:[{title,direction}]}`。
- **静态池兜底**：请求失败/空 → 落到 FALLBACK_GUIDE 3 条（均含 RAG 字样），UI 标注"(静态建议)"，不弹错。
- **前端不校验 direction**：只取 title 展示，丢弃 direction；"必含 RAG 方向"由后端 guide 契约保证，兜底池天然全 RAG。
- 点击 chip = 作为新问题重发重走链路；引导标题回传父面板进收起气泡建议池。

## 澄清交互（ClarifyCard）

- clarify 事件到达 → 渲染候选卡；候选是模块 id 字符串数组，id→中文 label 渲染，未知 id 显示原文兜底。
- **点选语义冻结**：点选候选 = **重发原问题 + currentProject=点选模块 id**（不是发裸功能名），跳过 loading 重开一轮；后端以 currentProject 权威锚定模块，点选模块与会话锚点不同 → switch 事件照常触发。
- 未选择时默认使用「label」功能介绍。
