# 切片数据 / 坑档案

> 来源：`5.难点/坑档案-开发与验证.md`（难点经验层，权威 0.8）——每条目（验证方法 V# + 踩坑 K#）一个文件，原文照搬 + 双证据。
> 切片方式：**提示词 + 大模型**，**一条目一文件**双切片（开发向 + 面试向），**全部在 `切片/`**——继承 `切片数据/代码` 双切片法，形态对齐 ai-tutoring/question-analysis 坑档案。
> 切片提示词：`处理方案/提示词/坑档案-切片-提示词.md`（2026-08-28 建骨架，切片待生成）。

## 双切片（全部在 `切片/`）

| 切片 | 文件 | 处理 |
|---|---|---|
| **开发向** | `切片/坑档案-V{编号}-*.md` / `切片/坑档案-K{编号}-*.md` | 条目原文照搬（V# 方法/价值/证据；K# 坑/现象/根因/解决/价值/证据），证据全保留（git commit + 文件:行号） |
| **切片（面试向）** | `切片/坑档案-V{编号}-*-复盘.md` / `切片/坑档案-K{编号}-*-复盘.md` | 过滤 commit/行号/路径噪声，突出口述要点与复盘，`target: 面试项目问答` |
