## 坑点复盘
**现象**：想把 jsonl 语料副本传到 COS 普通对象（供运行时拉取），实测上传报 `AccessDenied: bucket is role mode`——向量桶拒绝普通对象写入。

**触发链路**：语料 build 出 jsonl 副本 → 计划入 COS 普通对象 → 供 BM25/反查运行时拉取 → 写入向量桶被拒。

**根因**：向量桶是 role mode 专用桶，只服务向量 API，拒绝普通对象写入。

**解决思路与权衡**：jsonl 副本留本地——它本来就是 build 输入，BM25/反查直接从本地读，不需要远程拉取；方案文档同步调整说明。权衡点：放弃"副本上云"的远程访问便利，换取"不折腾存储架构"的简单可靠。

## 面试口述要点
设计 jsonl 语料副本时想传 COS 普通对象供运行时拉取，结果向量桶是 role mode、只服务向量 API、拒普通对象写入。复盘发现副本本就是 build 输入，BM25/反查从本地读即可，没必要上云——方案按实际存储约束调整，而不是硬造一条上传链路。
