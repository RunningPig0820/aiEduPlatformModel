## 坑点复盘
**现象**：每轮回答结束前端会展示"结束建议"候选题，但学生点其中一题问出去后答非所问或直接被拒答——引导价值断裂，引导题本应把学生带到高频方向。

**触发链路**：回答完成 → 结束建议生成器用 LLM"换种提问方法"把池内原题改编 → 前端候选 chips → 学生点击 → 发起提问检索。改编后的新问题引入了语料池外的概念，切片池没有对应内容 → 低置信 → 拒答。

**根因**：结束建议依赖 LLM 自由改编，把池内问题改得"更具体"时引入了池外概念（例如把"三张表关系"改写成"数据怎么和向量索引关联"，引入"向量索引"这个切片池不存在的概念）→ 新问题没有对应切片 → 检索不到。本质是引导语"自由发挥"破坏了"引导问题=索引层入口"的可答性闭环——只有池内原题才保证 100% 有对应切片。

**排查定位思路**：用户实测点"结束建议"改编题复现答非所问，对照历史 known-issues 里"引导建议太随机、很多不可答"的同类记录，定位到结束建议生成器的 LLM 改编逻辑。

**解决思路与权衡**：反转——结束建议不再做 LLM 改编，直接从语料可答的底座池抽取原题返回，保证 100% 可答且 0 token 成本。技术权衡：牺牲"引导语多样性"换"可答性闭环"，代价是引导题固定、缺乏新鲜感。

## 面试口述要点
引导系统的可答性闭环——引导问题必须从"语料可答的底座池"取原题，LLM 自由改编会引入池外概念破坏检索。技术权衡：用"引导语多样性"换"100% 可答 + 0 token"，代价是引导题固定。
