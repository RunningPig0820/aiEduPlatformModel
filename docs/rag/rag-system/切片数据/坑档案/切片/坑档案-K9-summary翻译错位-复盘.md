## 坑点复盘
**现象**：引导题（如"AI答疑如何使用？"）点击后检索不到自己的答案块——BM25 排第 7、向量路不进 top，引导题作为"索引层入口"失灵。

**触发链路**：引导题点击 → 检索 → 切片池里引导题块的摘要（索引特征之一）是 LLM 翻译版——把问题标题"AI答疑如何使用？"翻成"学生端拍题/打字/粘贴...使用闭环"这类答案式描述 → 检索特征与用户 query（原问题标题）语义错位。

**根因**：引导问题块的摘要用 LLM 翻译，把"用户会问的问题"翻成"答案式描述"，导致向量/BM25 的检索特征（摘要+正文）与用户真实 query 语义错位。本质：引导题这类"问题即内容"的块，摘要应等于用户会问的问题本身，翻成答案式描述反而错位。

**排查定位思路**：实测引导题命中情况——BM25、向量、编排三路检索全偏（排第 7、不进 top）；对照切片数据发现引导题块的摘要（索引特征之一）是 LLM 翻译版，与用户 query 语义错位。

**解决思路与权衡**：引导问题摘要直接用问题标题，不做 LLM 翻译；同时防住 md 头再次被翻译，重新生成切片并重入切片池。实测 BM25 第 7→第 1、向量路从不进 top→第 1、编排结果也命中目标块。权衡：牺牲摘要"读起来像介绍"的观感，换检索语义对齐。

## 面试口述要点
索引块摘要的语义对齐——向量/BM25 检索的特征是"块摘要+正文"，对预写 QA/引导题这类"问题即内容"的块，摘要取问题标题比 LLM 改写可靠。踩坑收获：离线切片的"元数据语义"和"线上 query 语义"必须对齐，翻译/改写会引入不可控错位。
