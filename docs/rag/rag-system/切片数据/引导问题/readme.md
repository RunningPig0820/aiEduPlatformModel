## 二、切片（提示词 + 大模型逐问作答）

> 引导问题这层"问题已有要作答"——和代码/坑档案"切已有内容"不同，问答切片是**逐问作答**（问题列表=问题矿，合成问答/问答切片=答案库）。

- **切片方式**：提示词 + 大模型逐问作答/从合成问答拆条，**一问题一文件**，全落 `切片/`。提示词：`处理方案/提示词/引导问题-切片-提示词.md`。
- **答案第一铁律**：只答语料里有的，禁编造；语料未实现/未做如实写"本期未实现/Non-Goal"；参考语料未覆盖 → 空答案兜底不产出完整切片。
- **结合 文档 + 代码**：答案按 9 视角映射表结合 完善文档 + 分析 + 坑档案 作答；design 方案 ≠ 线上现状（⚠️翻转体现），现状优先代码/坑。
- **结构**：标题=问题 → 5 行头（权威度 1.0，注释"合成问答≠原始证据"）→ 核心结论一句话可照讲 → 分层展开每点带依据 → 证据指针。
