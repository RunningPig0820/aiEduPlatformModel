## 回答

**核心结论**：链路全掌控 + 可解释——白盒要求意图/改写/召回/重排/token 全阶段 SSE 透传，框架黑盒讲不出"双池/两道门/阈值哪来"；小语料显式否决重排模型，自建轻量 RRF 即够。

**分层展开**：
- **白盒是硬要求**：本系统要把 RAG 全链路中间状态（intent→rewrite→recall→rerank→token→done）以 SSE 事件逐阶段透传前端，现成框架（LangChain/LlamaIndex）是黑盒，讲不出"为什么双池、两道门、阈值 0.75/0.5 哪来"（依据：完善文档 01/03）。
- **自建范围**：切片、索引、双池召回、RRF 打分、范围门、评测全自建——每一层为什么这么设计都讲得清，面试官顺着问能对答如流（依据：完善文档 01 追问段）。
- **否决重排模型**：小语料显式否决重排模型（D9/D10/选型4）——自建轻量 RRF 融合（`RRF_K=60`）× 权威度 × 锚定加权即可，不引入重排模型的黑盒复杂度（依据：完善文档 03/05）。
- **面试口径**：用现成框架等于把可解释性外包给黑盒；自己搭图的是"链路掌控 + 深度可讲"，这正是白盒演示能力的来源（依据：完善文档 03）。
