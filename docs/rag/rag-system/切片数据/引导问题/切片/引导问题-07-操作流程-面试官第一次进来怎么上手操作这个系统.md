## 回答

**核心结论**：学生端右栏常驻面板，进页面点引导 chips 或自由输入 → 白盒 SSE 逐事件点亮 → 出带引用的流式答案 + 召回文档面板 + token 成本 → 可追问、可 close 结算。

**分层展开**：
- **入口**：学生端任意页面右栏常驻面板（`DashboardLayout` 挂 `mode="inline"`，`key={pageCode}` 换页重挂载独立会话），面板默认展开；非学生显示占位不发请求（依据：分析-09）。
- **开始引导**：面板空态给引导 chips（`GET /guide?currentProject=` 取 3 条入口题；`/guide` 404 时前端兜底静态池并标注"(静态建议)"）或直接自由输入（依据：分析-09）。
- **问答过程**：`POST /ask`（带 sessionId+history+currentProject）→ Java 角色门产 permission → 白盒 SSE 事件按序点亮 5 阶段行（权限→意图→改写→召回·重排→生成）→ 流式正文逐字展示（依据：完善文档 02 / 分析-09）。
- **结果展示**：done 后带引用的完整答案（气泡整块切 Markdown）+ 召回块"先灰后亮"（`quotedKeys` 命中块高亮 + "已引用"徽标，默认折叠点击展开查看原文）+ 本轮 token 成本四字段（依据：分析-09）。
- **收尾**：可追问（done.suggestions 池内原题 2~3 条 + 引导标题池轮换）、可点"结束对话"close 结算轮数 + 累计 token（依据：分析-09）。
