## 回答

**核心结论**：语料 → `slice_corpus` 按 LAYERS 表+标题正则切块 → 双池 jsonl → LLM 摘要 → dashscope text-embedding-v3 768 维 embed → `build_index` 入 COS 向量桶（rag-full/rag-slice）。

**分层展开**：
- **切块**：`slice_corpus.py` 按 `LAYERS` 表定切法 + `SPLIT_RE`（`#`~`####` 标题）找边界——完善文档整篇一块、语雀按 h2、OpenSpec/坑档案按 h3；OpenSpec 的 `Risks/Migration/OpenQuestions/Non-Goals` 段整段过滤；超长块按段落贪心拆多块**不丢尾部**（依据：分析-02）。
- **双池 jsonl**：`rag_slices-{module}.jsonl`（切片池 pool=slice）+ `rag_slices_full-{module}.jsonl`（全量池 pool=full）；字段 `{text, summary, tags{module/category/source/authority/section/file/anchor/pool}}`（依据：分析-02）。
- **摘要 + embedding**：LLM 批量摘要（切片一句话 ≤30 字 / 全量逐篇 40~80 字）→ dashscope `text-embedding-v3` 显式 **768 维**（模型默认 1024，索引预建 768/float32/cosine，维度建好不可改）（依据：分析-02 / 分析-03）。
- **入桶**：`build_index.py` 读 jsonl → embed → `put_vectors` 入 COS 向量桶 `rag-1318177119`（`rag-full`/`rag-slice` 两个物理索引）；切片池每块双向量 `-c`/`-q`；原文另走 `upload_cos.py` 按 md 文件头 `> COS路径:` 上传普通桶（依据：分析-03）。
