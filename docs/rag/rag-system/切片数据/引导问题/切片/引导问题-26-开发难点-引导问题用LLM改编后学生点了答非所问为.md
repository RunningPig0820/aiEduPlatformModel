## 回答

**核心结论**：K7：LLM 改编"换提问方法"会引入**池外概念**（如"向量索引"）无对应切片 → 匹配不到答案；反转池内原题直出 0 token，牺牲引导多样性换 100% 可答 + 省 token。

**分层展开**：
- **现象**：每轮回答结束前端展示"结束建议"候选题，学生点击后**答非所问/拒答**——引导价值断裂（依据：坑档案 K7）。
- **根因**：`gen_suggestions` 用 LLM"换提问方法"改编池内原题，引入池外概念——如把池内"题目记录/错误事件/掌握度三张表关系"编成"题目数据怎么和向量索引关联"（引入"向量索引"）→ 新问题没对应切片 → 检索不到（依据：坑档案 K7）。
- **反转（修复）**：`ee4f8d6`——结束建议直接返回**池内原题**（0 token，不做 LLM 改编）：`_pool_suggestions` 池内抽样（必含 ≥1 条 rag 组）、`gen_suggestions` 池内原题直出、删 `_SUGGEST_SYSTEM`/`_suggest_scope`（依据：坑档案 K7 / 分析-05）。
- **权衡**：牺牲"引导语多样性"换"100% 可答 + 0 token"，代价是引导题固定；双向量 `-q` 问题路对池内原题命中 sim~0.99（依据：坑档案 K7）。
