## 回答

**核心结论**：一池满足不了"引导可控 + 自由纯 RAG"两个目标：只有预写 QA → 自由问题全拒答、RAG 没证据；只有源文档全文 → 答案不可控、现场易翻车；双池分层各管一目标。

**分层展开**：
- **双池目标**：索引层预写 QA 池（可控、便宜，引导问题=池内原题直出）+ 源文档池全文 chunk（真发挥，自由问题走纯 RAG 证据）（依据：完善文档 03）。
- **只留一个池的致命问题**：只有预写 QA → 自由问题全边界拒绝、RAG 没有证据；只有源文档全文 → 答案不可控、现场易翻车——一池无法同时满足两个目标（依据：完善文档 03 / 引导问题.md 第 30 问）。
- **落地形态**：`rag-full` 全量池（整篇一块，ai-tutoring 实测 23 块，管整体/全局问题）+ `rag-slice` 切片池（294 块细节 + 引导问题块，管追问/细节，每块 `-c`/`-q` 双向量）（依据：分析-01）。
- **演进**：方案"同一 COS 索引 + doc_type=qa/source 区分"落地为**两个物理 COS 索引** `rag-full`/`rag-slice`（metadata 无 doc_type，被 module + pool 取代）（依据：分析-01 / 分析-03）。
