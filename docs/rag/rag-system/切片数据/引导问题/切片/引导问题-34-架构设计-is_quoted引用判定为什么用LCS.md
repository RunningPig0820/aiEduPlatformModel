## 回答

**核心结论**：LLM 自述与真实依据可能不一致、白盒露怯；LCS 最长公共子串（连续 8 中/12 英字符命中）纯函数硬匹配、可单测可入评测，生成完才匹配故 done 后置补发（先灰后亮）。

**分层展开**：
- **为什么不用 LLM 自述**：LLM 自述"引用了哪些块"可能与真实依据不一致，白盒场景一问就露怯（依据：完善文档 03）。
- **LCS 硬匹配**：最长公共子串匹配，连续 ≥8 中文字符（或 12 英文字符折算）命中即 `is_quoted`——纯函数、可单测、可入评测（`lcs_quote_match`，`assistant.py:189-238`）（依据：完善文档 03 / 分析-01）。
- **done 后置补发**：8 字窗口对单 token 不友好 → 生成完才匹配，故 done 后置补发 quotedKeys；前端"先灰后亮"——rerank 到达灰显折叠、done 带 quotedKeys 命中块高亮（依据：完善文档 03 / 分析-09）。
- **评测同源**：评测 D3 引用校验用同一 `lcs_quote_match`，断言 quoted_keys ⊆ 召回块 key（`_quoted_check`，`eval_agent.py:206-219`）（依据：分析-06）。
