## 回答

**核心结论**：范围门 = 召回置信度（向量 `1-平均余弦距离` / BM25 `min(1.0,top_score/10)`），0.75/0.5 双路都低才拒、单路高即过；缓解误拒靠双池 + 引导问题把高频问题收纳进索引层。

**分层展开**：
- **范围门判定**：白盒 `check_boundary`——rerank 空 → 拒答；或 `vec_conf<0.75 且 bm_conf<0.5` 双路都低才拒、单路高即过；触发 → boundary 固定话术 + 短路不调 generate（依据：分析-04 / 完善文档 09）。
- **置信度来源**：向量置信度 = `1 - 平均余弦距离`；BM25 置信度 = `min(1.0, top_score/10)`；`vec_conf = max(全量池置信, 切片池置信)`（任一高即不算低）（依据：分析-04 / 分析-06）。
- **会误拒好问题吗**：缓解靠双池 + 引导问题——高频问题收纳进索引层（池内原题 100% 可答），自由问题靠双池互补召回尽量命中；阈值语义 08-25 校正过（初版误用 RRF 分 0.01~0.05 量级永远够不到阈值，改用召回置信度）（依据：完善文档 09）。
- **⚠️ 边界诚实**：范围门 0.75/0.5 只在白盒链路生效，1.6C 旧端点无阈值门只有空命中拒答——低置信但非空命中仍进生成，可能硬编（依据：完善文档 09 / 分析-04）。
