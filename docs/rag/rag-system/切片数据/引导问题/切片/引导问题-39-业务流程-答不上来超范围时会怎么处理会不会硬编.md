## 回答

**核心结论**：三层兜底不硬编：语料没覆盖 → 边界话术（"未找到关联文档，我尚未掌握"）0 token；生成失败 → 召回块清单当答案不空答；全挂 → 边界话术兜底；评测对编造封顶 3 分用数据压。

**分层展开**：
- **三层兜底**：①语料没覆盖 → 边界话术不编造（BOUNDARY_MSG"未找到关联文档，我尚未掌握。"，0 token 短路不调 generate）；②生成失败 → 召回块清单当答案不空答；③全挂 → 边界话术兜底（依据：完善文档 09 / 分析-07）。
- **1.6C 端点对应**：无命中 → "该问题语料未覆盖，建议问项目相关话题"（0 token）；doubao 挂 → "生成服务不可用，以下为检索到的语料：..."（召回清单当答案）（依据：分析-07）。
- **白盒端点对应**：范围门低置信 → BOUNDARY_MSG；生成超时/异常 → GEN_TIMEOUT_MSG/GEN_FAIL_MSG + 召回清单（reason="timeout"）（依据：分析-07）。
- **防硬编的数据手段**：评测对"编造"封顶 3 分（`fabricated → min(base,3)`）——宁可漏要点也不许编，用数据压低编造答案（依据：分析-06 / 完善文档 09）。
