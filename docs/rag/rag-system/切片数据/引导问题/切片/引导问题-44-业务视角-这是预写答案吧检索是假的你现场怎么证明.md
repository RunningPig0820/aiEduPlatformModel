## 回答

**核心结论**：引导题点击仍走切片池 `-q` 问题路真检索（sim~0.99），池内原题只保可答；自由输入走源文档池纯 RAG 真发挥，可现场随意问一个没准备的——可答性由池保证、检索真实发生。

**分层展开**：
- **引导题不是查表**：点击引导题仍走**正常检索链路**（`POST /ask` → intent→rewrite→recall→rerank→generate），且走切片池 `-q` 问题路对池内原题命中 sim~0.99——池内原题只为 100% 可答，检索真实发生（依据：完善文档 02 / 分析-05）。
- **自由输入真发挥**：自由输入走源文档池纯 RAG 真检索——可现场随意问一个没准备的问题，走真实召回→生成（依据：完善文档 02）。
- **现场证明方法**：让面试官现场输入一个**没准备过的问题**，白盒 SSE 面板会把检索→增强→生成全链路逐步点亮，答案引用块可见可回源——这不是预写答案能装出来的（依据：完善文档 02 / 分析-09）。
- **两件事不冲突**：可答性由池保证（引导题可控）+ 检索真实发生（自由输入纯 RAG），并存不冲突（依据：完善文档 02）。
