## 回答

**核心结论**：双池分层 / 页面锚定 / 两道门 / 白盒 SSE 全阶段透传 / LCS 引用硬匹配 / token 真算，把"检索怎么一步步工作"当场演示出来，面试官看得见、可以现场随意追问。

**分层展开**：
- **六个显式强项**：双池分层（引导可控 + 自由纯 RAG）、页面锚定（模块/节两级）、两道门（权限门 + 范围门）、白盒 SSE 全阶段透传、LCS 引用硬匹配（可解释可评测）、token 真算（成本可控可展示）——普通 RAG 都是黑盒（依据：完善文档 03 / 引导问题.md 第 47 问）。
- **现场演示**：白盒 SSE 链路把"检索怎么一步步工作"当场演示——5 阶段行按序点亮（权限→意图→改写→召回·重排→生成）、召回块先灰后亮、quotedKeys 命中块高亮"已引用"徽标、查看原文回源（依据：完善文档 02 / 分析-09）。
- **可现场追问**：面试官可现场随意问没准备的问题（走源文档池纯 RAG 真发挥），也可追问"这个答案为什么引用这块"（LCS 硬匹配 + 引用回源可解释）（依据：完善文档 02）。
- **数据背书**：评测报告 hit@k + 质量分 + 版本对比，现场可重跑评测（`POST /eval/run` 后台线程真实跑一轮）（依据：完善文档 01 / 分析-09）。
