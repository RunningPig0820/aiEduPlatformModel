## 回答

**核心结论**：向量在 COS 向量桶 `rag-1318177119`（`rag-full`/`rag-slice` 两个物理索引，768d/float32/cosine）；原文/切片视图在普通桶 `ai-edu-1318177119`（`rag-source/`、`rag-slices/` 前缀，供查看原文）。

**分层展开**：
- **向量存储**：COS 向量桶 `rag-1318177119`，**两个物理索引** `rag-full`（全量池，ai-tutoring 实测 23 块）+ `rag-slice`（切片池，294 块细节 + 引导问题），dashscope `text-embedding-v3` 768 维 / float32 / cosine（依据：分析-03 / 完善文档 08）。
- **原文存储**：普通桶 `ai-edu-1318177119`，前缀 `rag-source/<模块>/...`（源语料）+ `rag-slices/<模块>/...`（切片视图），供前端"查看原文"（`GET /api/rag/source/{key}`，前缀白名单放行）（依据：分析-03 / 分析-08）。
- **双池同桶异索引**：两个池共用同一向量桶、各自独立索引；多模块靠 `metadata.module` 标签 + query 侧 COS `Filter($eq)` 过滤隔离（依据：分析-03）。
- **语料 jsonl 留本地**：`scripts/rag/data/`（向量桶 role mode 不收普通对象，见 K3）（依据：分析-03 / 坑档案 K3）。
