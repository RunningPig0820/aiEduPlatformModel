## 回答

**核心结论**：不做图谱检索召回（语料是文档不是图谱）、不接 RAGAS 全量框架（聚焦 hit@k + LLM 判分两个信号）、不做真 mermaid 动态生成、不做生产级部署鉴权。

**分层展开**：
- **图谱检索召回（Non-Goal）**：语料是项目方案文档不是图谱，召回对象是文档向量 + BM25；图谱检索是本模块 Non-Goal，知识图谱能力在知识图谱模块讲（依据：完善文档 01/03 / 分析-01）。
- **RAGAS 全量框架**：不接 RAGAS 全量框架——聚焦 hit@k + LLM 判分两个信号，不自找评测框架复杂度（依据：完善文档 01 / 分析-06）。
- **真 mermaid 动态生成**：不做真 mermaid 动态生成（语料按原文保留已有图，不凭空造流程）（依据：引导问题.md 第 53 问）。
- **生产级部署鉴权**：不做生产级部署鉴权（当前定位是面试/汇报演示场景，鉴权靠 Java 角色门 + 内部 token 即可）（依据：引导问题.md 第 53 问）。
- **追问上限**：追问 5 轮/会话 Python 刻意不做（无状态），归 Java Redis 承接（依据：分析-01 对账要点）。
