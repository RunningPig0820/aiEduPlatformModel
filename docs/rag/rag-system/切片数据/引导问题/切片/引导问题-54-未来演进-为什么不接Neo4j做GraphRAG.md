## 回答

**核心结论**：语料是项目方案文档不是图谱，召回对象是文档向量 + BM25；图谱检索是本模块 Non-Goal，知识图谱能力在知识图谱模块讲（跨模块闭环 RAG 用跨页引用串）。

**分层展开**：
- **语料形态决定召回方式**：本模块语料是项目方案/设计/分析文档，不是图谱结构——召回对象是文档向量 + BM25，不是图遍历/图路径推理（依据：完善文档 03 / 引导问题.md 第 54 问）。
- **图谱检索 = Non-Goal**：不做图谱检索召回是本模块明确 Non-Goal（依据：完善文档 01 / 分析-01 职责段）。
- **图谱能力在哪讲**：知识图谱能力（EduKG 概念/Statement/TextbookKP、Neo4j 图模型、匹配率 97.1% 等）在知识图谱模块讲，不在本模块重复（依据：引导问题.md 第 54 问）。
- **跨模块怎么串**：跨模块闭环（AI答疑→掌握度→图谱→薄弱点）RAG 用跨页引用把图谱故事串成一答，不需要接 GraphRAG（依据：引导问题.md 第 54 问）。
