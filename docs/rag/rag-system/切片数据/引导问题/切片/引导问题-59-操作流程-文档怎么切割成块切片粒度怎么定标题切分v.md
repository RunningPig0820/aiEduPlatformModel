## 回答

**核心结论**：以标题正则 SPLIT_RE（认 #~#### 四级标题）+ LAYERS 表逐来源定切分等级为主——完善文档整篇一块（file）、语雀按 h2、OpenSpec/坑档案按 h3、引导问题整篇一块（guided），超长 split 块按段落贪心拆块不丢尾——粒度原则"一块=一个业务问题的完整答案"，不用固定长度硬切（会切碎语义）。

**分层展开**：
- **切分边界**：`SPLIT_RE = ^(#{1,4})\s+(.*)$` 认 #~#### 标题；`LAYERS` 表逐来源定 split_level——完善文档 `mode=file` 整篇一块（一节=一个问题答案）、语雀 h2、OpenSpec h3 且过滤 Risks/Migration/OpenQuestions/Non-Goals 段、代码分析 h2、坑档案 h3 每坑一块、引导问题 `mode=guided` 整篇一块（依据：分析-02 slice_corpus.py:28-45）。
- **超长处理**：split 块上限 6000 字符，超限按段落贪心拆块**不丢尾**；file/guided 模式上限 12000 截断并标注 `[已截断]`；<60 字符纯标题/空块直接丢弃（依据：分析-02 slice_corpus.py:25-27、78-96、127-143）。
- **粒度原则**：一块=一个业务问题的完整答案，固定长度硬切会切碎语义；OpenSpec 另按业务主题语义合并成块（业务主题清单）（依据：分析-02）。
- **摘要配套**：切片池 LLM 批量一句话 ≤30 字、全量池逐篇文档级 40~80 字；引导问题 summary 直接用问题标题、不做 LLM 翻译（K9 防语义错位：翻译版实测 sim 0.65 召不回，改标题后 BM25 第 7→第 1）（依据：分析-02 / 坑档案 K9）。
