## 回答

**核心结论**：向量（embedding+余弦）擅长语义相似（同义改写/口语化问题），BM25（jieba+Okapi）擅长关键词精确匹配（专有名词/编号/术语）——两路互补且互为降级备份：向量路挂→降级纯 BM25，BM25 纯本地断电可用。

**分层展开**：
- **各擅所长**：向量路 embed（dashscope text-embedding-v3 768d）+ cosine 距离，语义泛化强，能答同义改写；BM25 jieba 分词 + Okapi（k1=1.5、b=0.75）本地全文打分，专有名词/编号/术语精确命中（依据：分析-04 / 分析-03）。
- **双池三路落地**：全量池向量 `rag-full` + 切片池双向量 `rag-slice`（-c 内容路 embed(summary+text) / -q 问题路 embed(summary)）+ 本地 BM25，合成**四路 RRF** 融合输入（依据：分析-04 retrieve_dual）。
- **互为降级备份**：向量路异常/超时 → 降级纯 BM25（1.6C 构造空向量结果 / 白盒单路 2s 超时降空路）；BM25 纯本地 jsonl 打分，断网断电可用（依据：分析-07 降级矩阵 / 语雀总揽 §2）。
- **落地注意**：切片池每块双向量会占向量 top-k，需 `VEC_K+2` 补偿；同块 -c/-q 两路命中各贡献 RRF 互补，代价是检索成本翻倍（依据：分析-04 隐性坑7）。
