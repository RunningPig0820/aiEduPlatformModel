## 回答

**核心结论**：四路分数量纲/分布不可比（向量余弦距离 vs BM25 原始分），加权和需标定权重且易被极端分数带偏；RRF（Σ 1/(60+rank)）只看名次、无需标定、稳健轻量，小语料显式否决重排模型、自建轻量 RRF 即够。

**分层展开**：
- **不可比问题**：向量 confidence=1-平均余弦距离、BM25 confidence=min(1.0, top_score/10)，量纲与分布都不同，直接加权和需要标定权重、且易被一路的极端分数带偏（依据：分析-04 / 完善文档 05）。
- **RRF 公式**：`score = Σ 1/(RRF_K + rank)`，RRF_K=60，rank 为 enumerate 序号从 0 起；只看名次不看原始分，天然归一、无需标定，对分数量纲不敏感（依据：分析-04 query.py:43、650-659）。
- **轻量否决重排**：小语料显式否决重排模型（cross-encoder），自建轻量 RRF 即够用（依据：完善文档 03）。
- **隐性坑**：RRF 分数量级小（约 0.01~0.05），不能当置信度与范围门 0.75/0.5 阈值直接比——范围门必须另用召回 confidence（向量 1-平均距离 / BM25 min(1.0,top_score/10)）（依据：分析-04 隐性坑8 / assistant.py:385-386）。
