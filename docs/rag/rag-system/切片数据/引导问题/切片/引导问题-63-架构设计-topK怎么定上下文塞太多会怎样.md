## 回答

**核心结论**：TOP_K=5（生成块数，HIT_K 由 3 改 5 对齐）、VEC_K=12（向量召回数，双向量需 +2 补偿）、BM25_K=10、RERANK_K=3（白盒回传）；塞太多→上下文膨胀推高 token 成本 + 噪音块稀释答案精度 + 单块超 MAX_GEN_TEXT=1200 截断丢尾。

**分层展开**：
- **常量取值**：TOP_K=5 生成用块数（query.py:44）；VEC_K=12 向量召回数（query.py:46，切片池双向量 -c/-q 各占位故 +2 补偿）；BM25_K=10；RERANK_K=3 白盒 rerank 回传块数；HIT_K=5 评测 hit@k（2026-08-26 由 3 改 5，对齐生成上下文 top-5）（依据：分析-04 常量表）。
- **塞太多的代价**：上下文膨胀直接推高 token 成本（top-K 限制是成本叙事的一环）；噪音块挤占上下文、稀释答案精度；单块生成超 `MAX_GEN_TEXT=1200` 被截断丢尾（依据：分析-04 / 语雀总揽 §7.2）。
- **请求侧约束**：1.6C 端点 `top_k` 默认 5、ge=1 le=20（依据：分析-04 models/rag.py:14）。
