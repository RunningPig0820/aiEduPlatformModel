## 回答

**核心结论**：三层兜底不硬编——语料没覆盖→边界话术"未找到关联文档，我尚未掌握"0 token 拒答；生成失败→召回块清单当答案不空答；全挂→边界话术；白盒范围门 0.75/0.5 双路都低才拒、单路高即过。

**分层展开**：
- **三层兜底**：语料没覆盖 → 边界话术（1.6C "该问题语料未覆盖，建议问项目相关话题" / 白盒 BOUNDARY_MSG "未找到关联文档，我尚未掌握。"）0 token 直返、不调 generate；生成失败 → 召回块清单当答案不空答；全挂 → 边界话术兜底，最坏也能答（依据：完善文档 09 / 分析-07）。
- **范围门判定**：白盒 `check_boundary`——rerank 空即拒；或 `vec_conf<0.75 且 bm_conf<0.5` 双路都低才拒、单路高即过；触发短路不调 generate（防 doubao 自生成"未覆盖"话术烧 32 token）（依据：分析-04 assistant.py:388-408、616-625）。
- **诚实标注**：1.6C 旧端点没有 0.75/0.5 阈值门，只有 `if not hits` 空命中拒答——低置信但非空命中仍会进生成；模块 docstring 自称"置信度过低→拒答"与实际不符（依据：分析-07 对账要点 / 坑档案 A1）。
- **评测压制编造**：边界拒答评测类型走 `_boundary_trace`、0 token，正确拒答 score=5、未触发（意外高置信）score=0（依据：分析-06 _boundary_trace）。
