## 回答

**核心结论**：四层防幻觉——生成强制只基于召回语料+末尾统一贴参考来源；is_quoted 用 LCS 最长公共子串硬匹配（连续≥8 中/12 英字符命中）判定引用真伪而非 LLM 自述；评测判分编造封顶 3 分；边界拒答不编造。

**分层展开**：
- **强制引用**：生成强制只基于召回语料、末尾统一贴参考来源，答案可溯源；白盒链路 rerank 精排 Top-K 块现组织语言（依据：完善文档 03/05）。
- **is_quoted LCS 硬匹配**：`lcs_quote_match` 最长公共子串（连续≥8 中文字符/12 英文字符窗口命中即 is_quoted），纯函数硬匹配、不靠 LLM 自述（LLM 自述与真实依据可能不一致、白盒露怯）；生成完才匹配，故 done 后置补发、前端"先灰后亮"（依据：分析-04 / 完善文档 05、assistant.py:189-238）。
- **编造封顶 3 分**：评测判分 LLM 只报事实（covered_count/fabricated/rationale）、分数由 `_score_from_covered` 确定性硬算（100%→5、≥80%→4…0%→0），`fabricated` 为真时 `min(base, 3)` 封顶——编造权重高于遗漏，宁可漏要点也不许编（依据：分析-06 eval_agent.py:164-183）。
- **边界不编造**：语料没覆盖 → 边界话术拒答（"未找到关联文档，我尚未掌握"），0 token，绝不硬编（依据：完善文档 09）。
