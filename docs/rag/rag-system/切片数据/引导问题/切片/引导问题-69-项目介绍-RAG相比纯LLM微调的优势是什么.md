## 回答

**核心结论**：相比纯 LLM 硬答——答案可控可溯源（双池分层+要点+生成、is_quoted 硬匹配）、可解释可证明（白盒 SSE 全阶段透传+评测数据背书）；相比微调——语料驱动无需训练数据/算力，语料入库即自动可答、无代码改动。

**分层展开**：
- **vs 纯 LLM**：纯 LLM 硬答不可控、易编造；RAG 用双池分层 + "要点+生成" B 路线锁答案范围、is_quoted LCS 硬匹配引用真伪、边界拒答不编造——答案可控可溯源（依据：完善文档 03）。
- **vs 微调**：微调要训练数据+算力+重训周期；RAG 语料驱动，语料切片入 MODULE_DATA 即自动可答、无代码改动（语料白名单本身就是权限层），且报告按语料版本可 --compare 对比定位回归（依据：完善文档 01 / 引导问题 56）。
- **可解释可证明**：白盒 SSE 全阶段透传（意图/改写/召回/重排/token），面试官看得见"检索怎么一步步工作"；评测数据背书（hit@k + 质量分 + 版本对比）（依据：完善文档 03）。
