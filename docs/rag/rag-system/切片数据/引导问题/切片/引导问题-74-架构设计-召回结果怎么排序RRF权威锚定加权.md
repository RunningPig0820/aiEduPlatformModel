## 回答

**核心结论**：四路 RRF 融合 `score = Σ 1/(60+rank) × authority 权威度(1.0/0.8/0.7 乘性权重) × anchor_w 节锚定(命中节 ×1.5)`，按分降序取 top-K=5——权威分层让高权威块即使 RRF 略低也能排前。

**分层展开**：
- **三信号相乘**：`score = rrf * authority * anchor_w`（query.py:667）——RRF 管多路互补、authority 管语料可信度分层、anchor_w 管页面锚定（命中节 ×1.5），与方案 D5 "similarity×问题类型×页面锚定" 对应但实现用 RRF 替代纯相似度（依据：分析-04 / 完善文档 05）。
- **RRF 融合**：RRF_K=60，四路（全量向量/切片-c/切片-q/BM25）做并集，每路贡献 `1/(60+rank)`，rank 从 0 起（依据：分析-04 query.py:650-659）。
- **权威度分层**：语料块 tags.authority 缺省 0.7，实测 {1.0（完善文档/引导问题）、0.8（代码分析/坑档案）、0.7（语雀等原始语料）}；作为 RRF 的乘性权重，高权威块即使 RRF 略低也能排前（依据：分析-04 / 完善文档 08）。
- **落地注意**：白盒链路 recall 写死 `locked_sections=[]`，节级锚定 ×1.5 被旁路（只做模块级锚定），仅 1.6C 端点完整传节级；分类别过滤已在 2026-08-26 禁用（LLM 判类不准误伤），只按 module 过滤（依据：坑档案 A6 / 分析-04）。
