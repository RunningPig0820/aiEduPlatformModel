### 引导问题 = 索引层入口

UI 引导问题为索引层规范问题的**变体写法**（例：UI"你们为什么拆成三段" vs 索引"为什么拆 decide/generate/question-understand"），强制检索真实发生、避免"点按钮=预定答案"。证据：语雀-原文件-问题3.md / 问题5.md；design-python-project-intro-rag.md D3。

### 引导静态池（方案 suggestions_pool.json → 代码 GUIDE_POOL dict）

后端预置静态池（非 LLM 生成），每次问答完成后随机抽 2~3 条引导建议，强制引导学生围绕方向追问（静态化降本）。证据：语雀-原文件-问题8.md。

⚠️【落地】代码实现为 **Python dict `GUIDE_POOL`**（`core/rag/guide_pool.py`，**非 json 文件**）；方向由方案的 4 组扩展为 **5 组**（`intro/operation/data_relation/difficulty` + **rag 桥接子集**，rag 组可与其他组重复、scope 去重）；已入池 ai-tutoring(75 去重)/question-analysis(70)/knowledge-graph(64)，**rag-system 未入池**（兜底 `FALLBACK_MODULE="ai-tutoring"`）。证据：分析-05。

⚠️【落地反转】方案"UI 引导问题 = 索引层规范问题**变体写法**、强制检索真实发生"在代码中被**反转**为**池内原题直出**（`assistant.py:326-331`，注释记录 2026-08-26 用户实测：LLM 改编引入池外概念致新问题匹配不到切片）；引导题纯池不切片，点击后走双向量 `-q` 问题路检索（命中 sim~0.99）。

### 问候识别与欢迎引导（D-E）

⚠️【定稿 D-E】"你好/Hi/在吗"识别为 `category="问候"`、`ambiguous=false`，**不触发 clarify**；走**欢迎话术 + 引导池建议**（0 生成 token，不 recall 不 generate），指向 ①项目介绍②操作③数据关联④难点。代码 `is_greeting` 关键词预检（短句 ≤8 字才命中防误杀，assistant.py:361,366-372）+ `WELCOME_MSG` 直返 done（assistant.py:580-586）。证据：design-java D-E；分析-05。

### 选型12：引导语选型
> 检索摘要：引导语静态化降本——方案"静态池 suggestions_pool.json 随机抽 2~3 条 + 索引层预写引导（规范问题+变体配对强制检索）"；代码落地为 Python dict GUIDE_POOL 5 组，结束建议直接返池内原题（用户实测 LLM 改编引入池外概念致新问题匹配不到切片，反转"变体文案强制检索"）。

- 选型场景：引导面试官问什么的引导语怎么来，控制在可控路径内
- 候选方案A：索引层预写引导（规范问题+变体文案配对）
  - 方案A优劣：引导问题=索引层入口，UI chips 点击命中索引层 QA；每页写两套文案（UI 变体 + 索引规范问题）让检索真实发生，避免"点按钮=预定答案"。⚠️ 代码实测反转：LLM 改编"换提问方法"引入池外概念（如"向量索引"），新问题无对应切片→学生点了匹配不到答案。
- 候选方案B：suggestions_pool.json 静态池随机（08-25 简化）
  - 方案B优劣：每次问答完成后从预设静态池随机抽 2~3 条返回前端，强制引导 4 方向（项目介绍/操作流程/数据关联/技术难点）；非 LLM 生成，0 token 0 耗时。
- 候选方案C：LLM 动态生成引导语
  - 方案C优劣（致命短板）：话术更贴当前问答；但每次问答多一次 LLM 调用，费 token 费时，与"静态化降本"目标相悖。
- 最终拍板：引导语静态化——suggestions_pool.json 静态池随机 2~3 条 ✅；引导问题=索引层预写规范问题，配变体文案走检索
- 拍板理由：引导语静态化降本、0 token（问题8 §6 明确"严禁动态生成引导语以节省 Token 和耗时"）；引导问题作为索引层入口保证可控可预演（问题3 ③）；LLM 动态生成是"省 token 考量"的反面（问题8 spec 结尾自留口子但主拍板静态池）。
- 落地对账：⚠️ 形式变化 + ⚠️ 反转——静态池落地为 **Python dict `GUIDE_POOL`**（`guide_pool.py:27`，**非 json 文件**），方向由方案 4 组扩为 **5 组**（intro/operation/data_relation/difficulty + **rag 桥接子集**，可与其他组重复、scope 去重，`guide_pool.py:11-14,316`）；结束建议 `gen_suggestions` **直接返回池内原题**（`assistant.py:326-331` 注释记录 2026-08-26 用户实测反转），必含 ≥1 条 rag 组，0 token；引导题纯池不切片，点击后走双向量 `-q` 问题路检索（sim~0.99，`assistant.py:330-331`）；⚠️ 已入池 ai-tutoring(75 去重)/question-analysis(70)/knowledge-graph(64)，**rag-system 未入池**（兜底 `FALLBACK_MODULE="ai-tutoring"`，`guide_pool.py:309,313,319-321`）。结论=静态池落地、变体文案反转、池文件形式变化。
