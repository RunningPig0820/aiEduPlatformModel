### 离线语料建设（策展，非全量倾倒）

**来源**：语雀（产品意图）+ 代码注释/实现（落地事实）+ OpenSpec design 决策（为什么）+ git 提交（坑）+ api 契约（接口摘要）。证据：语雀-原文件-问题7.md。

1. 每模块产出一份**完善文档（8 节）**：①产品定位 ②核心功能 ③为什么这么设计 ④数据流转(含预置 mermaid) ⑤技术实现 ⑥关键坑与解法 ⑦数据规模与指标 ⑧权限与边界。证据：语雀-原文件-问题6.md / 问题7.md。
2. **切片 + metadata**：按 markdown 标题切分，保留 页面+章节 层级，metadata 带 `page / doc_type / section / source_doc`。证据：语雀-原文件-问题1.md / 问题8.md。
3. **嵌入**：dashscope 768d / bge 本地备选；维度固定不可改（换模型=全量重建）。证据：语雀-原文件-问题1.md / rag-system.md。
4. **索引**：COS 向量桶 `rag-index`（生产）/ 本地 FAISS（demo）同一接口抽象。证据：语雀-原文件-问题1.md。

**语料策展规则**：每页精选一套权威文档（如每模块 = 1 产品规划 + 1 设计方案）；问题记录/草稿/内部讨论/未发布文档明确不收录；spec/api 原文全文不进；除 RAG智能客服"规划中功能点"外内部规划状态不进。语料白名单本身就是权限层。证据：语雀-原文件-问题1.md / 问题7.md。

### 源文档 chunk metadata

完善文档全文切片，metadata 四元组：

| 字段 | 含义 |
|---|---|
| page | 所属页面/模块（知识图谱/AI答疑/组织中心/学生知识点分析/RAG问答系统） |
| doc_type | qa（索引层）/ source（源文档池） |
| section | 8 节之一（定位/功能/为什么/数据流/技术/坑/指标/权限） |
| source_doc | 来源文档，支撑"点击查看原文"+ 召回文档面板 |

切片时把源文档全文存进 metadata，答案生成后前端渲染**召回文档面板**（面试官能看到系统捞了哪几段原文）——把 RAG 检索从黑盒变成"能指给你看"。证据：语雀-原文件-问题5.md / 问题8.md。

【落地】代码 metadata 实际 10 字段**无 doc_type**：`version/module/category/source/authority/section/file/file_path/anchor/summary`（`build_index.py:145-157`，注释"doc_type 与 module 同值冗余已去掉 2026-08-26"）；切片全文不进 metadata（≤2048B 限制），命中后经 key 反查本地 jsonl。证据：分析-01/03。

### 相关风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 语料版本矛盾 | 语料空模板/多版本方案/未发布草稿，同问题召回互相矛盾版本当场翻车 | 每页策展精选权威文档，完善文档向代码事实对齐、冲突以代码为准 |
| embedding 维度不可改 | 换模型 = 全量重建；需 checksum 校验发现过期 | — |
| 索引依赖 COS 10s 异步 | demo 需预建索引规避写后即查 miss | — |

### 上线灰度策略

1. **demo 兜底**：生产走 COS 向量桶（生产链路叙事），demo 默认本地 FAISS + 索引抽象层同接口；COS 10s 异步写后不可即查→demo 前预建索引。证据：design-python-project-intro-rag.md D11；语雀-原文件-问题1/5.md。
2. **迁移顺序**：先产出「知识图谱」完善文档作标本→确认格式→补其余模块（+ RAG 功能点文档）→离线脚本（完善文档→切片→embedding→COS 建 rag-index，`--clear` 幂等）→在线链路分阶段（召回→打分/范围门→生成/引用→权限门→降级→token 展示）。证据：design-python-project-intro-rag.md Migration。
3. **回滚**：新增 `/api/rag/*` 独立路由，不影响既有 tutoring 路径；ark_stream 改动对既有调用透明（多返回 usage，不改变流式语义）；评测 agent 纯离线（`/api/rag/eval/*` 独立前缀），不触碰 `/api/rag/ask` 主链路。证据：design-python-project-intro-rag.md / design-python-rag-eval-agent.md Migration。
