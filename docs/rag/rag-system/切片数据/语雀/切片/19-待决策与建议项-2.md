### 评测体系补强（问题12）

分层评估框架：L1 知识库层（覆盖率/重复率/过期版本占比）、L2 检索层（Context Recall / Context Precision）、L3 生成层（Faithfulness / Answer Relevancy）、L4 端到端层（Answer Correctness / Latency / Cost）。行动清单：🔴 必须扩充评估集（30~50 条，覆盖项目介绍/操作流程/数据关联/难点技术/边界拒答 5 类）；🔴 必须跑一轮完整 baseline；🟡 补分层指标 + 回归测试；🟢 加分引入 RAGAS（行业标准对比分数）。现状基准（来自评测工具）：`hit@3 = 0.80`、`质量分 = 3.6~4.6/5`、`单条耗时 ≈ 5.6s`、`单条成本 ≈ ¥0.016`、语料 234 块。证据：语雀-原文件-问题12.md。⚠️【落地】指标已演进：`HIT_K=5`、双向量 + 判分硬算后最新报告（`data/eval/reports/2026-08-26-259c06.json`）为 `hit@5=0.583 / quality=3.833 / avg_latency≈17.4s / avg_cost≈¥0.0181`、评测集 6 条（ai-tutoring）；`hit_cases 5/6` 与 `hit_at_k_avg 0.583` 是两套口径。证据：分析-06。
