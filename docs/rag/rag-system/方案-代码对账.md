## 关键边界（三端职责切分）

- **权限门只在 Java、且只查 role 不查 userId**：`Controller.requireStudent`（`Controller:117-123`）走 `TutoringAuth.isStudent`（`TutoringAuth:24-26`）只比对 `role=="STUDENT"`，**不同于**同步业务用的 `TutoringAuth.requireStudent`（`TutoringAuth:29-38`，先校验 userId 登录态）——RAG 网关侧缺 userId 但 role=STUDENT 的会话理论可放行；**Python 侧无权限门**，所有端点仅 `verify_internal_token`。（分析-08）
- **source 白名单在 Python，Java 是纯 HTTP 转发**：Java `Controller.source` 不做前缀校验、不读 COS，`CosFileStorageServiceImpl` 是通用存储（tutoring transcript 等）不在 RAG source 链；`rag-source/`/`rag-slices/` 白名单 + COS 读全在 Python `api/rag.py:50-72`。（分析-08）
- **会话聚合全归 Java Redis**：turns/close/累计 token/trace 快照全部在 Java（`rag:assistant:*` 键，TTL 24h）；Python 显式无状态（`api/rag_assistant.py:9-12`"turns/close/累计 token 归 Java Redis，Python 不建 close/turns 端点"）。（分析-08）
- **close 不中止在途流**：Java `close()` 仅置 closed 标志 + 读回累计（`AppService:138-167`），**无在途流中止逻辑**；生成中中止由 Python `is_disconnected` 独立负责——Java close 与 Python 断连取消是两条独立路径。（分析-08）
- **degraded 降级标记不达前端**：`DEGRADED_VECTOR/DEGRADED_BM25` 定义了（`assistant.py:26-28`）但 `pipeline_events` 未放进 rerank/done 事件（`assistant.py:613,650-652`）；Java `SseRerankDTO` 无 degraded 字段——前端拿不到"本轮降级"显式信号。（分析-07/08）
- **前端"排除 AI答疑页"被推翻（全局挂载）**：design D2 早期 Non-Goal"AI答疑页不挂 RAG 助手"已过时，`DashboardLayout` **全局挂载不排除任何页**（`DashboardLayout.jsx:81`），TC-5/TC-REAL 均进 `/student/ai-qa` 验证 RAG 面板 + 左引导 + 中内容三栏；`PAGE_TO_MODULE.STUDENT_AI_QA→ai-tutoring` 保留。（分析-09）
- **quotedKeys 高亮折叠 ≠ 设计高亮展开**：设计 D5/spec"done.quotedKeys 命中块高亮展开"，代码实现为"命中块**高亮 + 已引用徽标但默认折叠**，点击才展开摘要/原文"，未命中灰显折叠；TC-10 明确定稿该行为。（`ReferencePanel.jsx:11-12,20`；`rag-assistant-f1.spec.mjs:503-506`）
